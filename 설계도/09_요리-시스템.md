# 09. 요리 시스템

> 재료 상세 목록 → **[재료-목록.md](재료-목록.md)** 참조 (2026-06-29 확정).

## 세계관 맥락

- `게임 시스템 설계.md §8-4`: **"요리 = 특수 요리로 전투 전 버프 적용(일정 시간 스탯 강화)"**. 교육 RPG의 테마에서 요리는 "실험과 조합"의 메타포 — 재료(각 대륙에서 얻은 물질·에너지)를 조합해 새로운 효과를 만들어낸다.
- 재료는 6대 과목 대륙 **고유 재료 30종**(대륙당 5종, 3등급)과 **일반 범용 재료 12종**(조미료·공용 식재료)으로 구성. 세계관 동식물 직접 활용 → 상세 목록은 **[재료-목록.md](재료-목록.md)** 참조.
- **레시피 첫 해금은 문제풀이** — "재료를 알아야 요리를 할 수 있다"는 교육 테마. 해금 후엔 재료만 있으면 즉시 제작.

## 1. 목표 / 완료 정의

1. **재료 적립**: 적 처치 시 해당 대륙 재료가 확률 드롭. 메조리아 주방 패널 상점 탭에서 골드로 재료 구매 가능.
2. **레시피 해금**: 잠긴 레시피는 `unlockProblemId` 문제 정답 시 해금. unlockProblemId 비었으면 기본 해금.
3. **요리 제작**: 재료+골드 보유 충분 → 로스터에서 대상 캐릭터 선택 → `Cook()` → 재화 소비 + 캐릭터에 버프 설정.
4. **버프 적용**: 버프 있는 캐릭터가 전투에 진입하면 해당 세션 내내 스탯에 % 보너스 반영. 버프는 절대 만료 시각(UTC unix초)으로 저장 → 로그아웃 후에도 만료 시각 유지.
5. **저장**: 재료·해금 레시피·캐릭터 버프 만료 시각이 재로그인 후에도 유지.
6. **UI**: 메조리아 주방 건물 E → `CookingPanel` 오픈. 레시피 탭 + 재료 상점 탭.

### 3-3. 요리 상태 & 서비스

**`Scripts/Meta/CookingState.cs`** (신규):
```csharp
public class CookingState
{
    public IngredientWallet Ingredients { get; } = new IngredientWallet();
    public List<string> UnlockedRecipeIds { get; } = new List<string>();

    public bool IsUnlocked(RecipeDef r) =>
        string.IsNullOrEmpty(r.unlockProblemId) || UnlockedRecipeIds.Contains(r.id);

    public void Unlock(RecipeDef r)
    {
        if (!UnlockedRecipeIds.Contains(r.id)) UnlockedRecipeIds.Add(r.id);
    }

    public CookingData Export() => new CookingData
    {
        ingredients    = Ingredients.Export(),
        unlockedIds    = UnlockedRecipeIds.ToArray(),
    };

    public void LoadState(CookingData data)
    {
        if (data == null) return;
        Ingredients.LoadState(data.ingredients);
        UnlockedRecipeIds.Clear();
        if (data.unlockedIds != null) UnlockedRecipeIds.AddRange(data.unlockedIds);
    }
}

[Serializable] public class CookingData
{
    public IngredientWalletData ingredients;
    public string[]             unlockedIds;
}
```

**`Scripts/Meta/CookingService.cs`** (신규, static):
```csharp
public static class CookingService
{
    static RecipeDatabase _db;
    static RecipeDatabase Db => _db ??= Resources.Load<RecipeDatabase>("RecipeDatabase");

    // 해금 여부
    public static bool IsUnlocked(RecipeDef r) => MetaState.Cooking.IsUnlocked(r);

    // 레시피 해금 (문제 정답 후 호출)
    public static void UnlockRecipe(RecipeDef r)
    {
        MetaState.Cooking.Unlock(r);
        MetaSaveService.Save();
    }

    // 제작 가능 여부
    public static bool CanCook(RecipeDef r, out string reason)
    {
        if (!IsUnlocked(r))                   { reason = "레시피 잠김"; return false; }
        foreach (var ic in r.ingredients)
            if (!MetaState.Cooking.Ingredients.CanSpend(ic.kind, ic.amount))
            { reason = $"{CookingCatalog.DisplayName(ic.kind)} 부족"; return false; }
        if (!MetaState.Wallet.CanAfford(CurrencyKind.Gold, r.goldCost))
        { reason = $"골드 부족 (필요 {r.goldCost})"; return false; }
        reason = null; return true;
    }

    // 제작 실행 — target 캐릭터에게 버프 적용
    public static bool Cook(RecipeDef r, OwnedCharacter target)
    {
        if (!CanCook(r, out _)) return false;
        // 골드 먼저 차감 (실패 시 재료 건드리지 않음)
        if (!MetaState.Wallet.TrySpend(CurrencyKind.Gold, r.goldCost)) return false;
        foreach (var ic in r.ingredients) MetaState.Cooking.Ingredients.TrySpend(ic.kind, ic.amount);
        // 버프 설정 (기존 교체)
        target.foodBuff = new OwnedCharacter.ActiveFoodBuff
        {
            recipeId      = r.id,
            expiryUnixSec = DateTimeOffset.UtcNow.ToUnixTimeSeconds() + r.buff.durationMinutes * 60L,
        };
        MetaState.Roster.NotifyChanged();
        MetaSaveService.Save();
        return true;
    }

    // 전투 진입 시 버프 해석 (만료 시 null)
    public static FoodBuff? ResolveBuff(OwnedCharacter owned, long nowUnixSec)
    {
        var fb = owned?.foodBuff;
        if (fb == null || fb.expiryUnixSec <= nowUnixSec) return null;
        var r = Db?.ById(fb.recipeId);
        return r?.buff;   // RecipeDef 없으면 null (안전 방어)
    }

    // 상점 재료 구매
    public static bool BuyIngredient(IngredientKind kind, int price)
    {
        if (!MetaState.Wallet.TrySpend(CurrencyKind.Gold, price)) return false;
        MetaState.Cooking.Ingredients.Add(kind, 1);
        MetaSaveService.Save();
        return true;
    }
}
```

```csharp
            ? CookingCatalog.RarityOf(k) == IngredientRarity.Normal
            : CookingCatalog.RarityOf(k) == IngredientRarity.Rare);
    if (pool.Length == 0) pool = droppable; // 폴백
    var picked = pool[UnityEngine.Random.Range(0, pool.Length)];
    MetaState.Cooking.Ingredients.Add(picked, 1);
}
```

- 기본 드롭 시도 확률 35%(인게임 체감 밸런스에 따라 조정).
- 특산 재료(`RarityOf == Special`)는 `DroppableOf`에서 반환하지 않음(보스/퀘스트 한정).
- Mesoria 적은 드롭 없음(`DroppableOf(Mesoria)` → 빈 배열).

## 6. 엣지 케이스 / 주의점

| 상황 | 처리 방식 |
|------|----------|
| 구 세이브(cooking 키 없음) | `TryGetValue` 실패 → LoadState 스킵 → 빈 상태(재료 0, 해금 없음, 기본 해금 레시피만 사용 가능) |
| `foodBuff` 필드 없는 구 세이브 | `JsonUtility` 역직렬화 시 null → 버프 없음으로 처리 |
| 버프 중복 요리 | `Cook`이 `target.foodBuff` 덮어씀(연장 아님). UI에 "기존 버프가 교체됩니다" 안내 권장 |
| 전투 중 만료 | 진입 시 1회만 `ApplyFoodBuff` → 그 전투 내내 유지. 전투 중 타이머 없음 |
| 재화 원자성 | `CanCook`으로 전량 확인 → 골드 `TrySpend` 먼저(실패 가능) → 재료 차감(확인 후라 실패 없음) |
| `long` 직렬화 | Unity 6 / JsonUtility long 지원 O. 구버전이면 string으로 우회 (이 프로젝트 Unity 6 확정) |
| RecipeDatabase 없음 | `CookingService.Db` null-safe → `ResolveBuff` null, `CanCook` false(전 레시피 해금 불가). Seed 미실행 방어 |
| 주방 건물 없음 | `OpenKitchen` null 체크. MetaUISetup 와이어링 누락이면 E키 반응 없음 |
| unlockProblemId가 DB에 없음 | 폴백: 난이도 Mid 랜덤 문제(또는 기본 해금 처리). 설계도엔 strict(DB에 없으면 잠김 유지)로 명시 |
| 버프 잔여시간 표시 | 캐릭터 선택 드롭다운에서 `(expiryUnixSec - now) / 60` 분 단위로 표시. 만료 시 "없음" |
| 전 스탯 버프 레시피(전지전능 향연) | 재료 8종 각 1개 + 희귀 향신료×2 — 스탯 계산은 4개 Pct 모두 0.15f |
