## 세계관 맥락

- NPC와 수집 캐릭터 모두 "관계를 쌓을 수 있는 존재"로 취급한다. 캐릭터는 수학·과학 개념의 의인화이므로 그 개념을 깊이 이해할수록(문제풀이·전투동행) 캐릭터와 가까워진다는 교육 테마.
- 선물은 09 요리의 **재료 인벤토리**를 소비 — "탐험에서 얻은 재료로 마음을 전달한다"는 수집 루프와의 자연스러운 연결.
- 호감도는 단순 수치가 아니라 **단계(tier)** 구조 — 등급이 높은 캐릭터일수록 더 깊은 관계(더 높은 단계)를 가질 수 있어 희귀 캐릭터의 육성 가치를 강화.

## 1. 목표 / 완료 정의

1. **획득 경로 4종** 동작: a 대화 선택지·b 선물·c 전투 동행·d 문제풀이/일일 모두 호감도 수치를 증가시킨다.
2. **등급별 단계** 동작: 캐릭터는 rarity에 따라 최대 3~7단계, NPC는 고정 5단계. 단계 도달 시 보상 자동 지급.
3. **전투 스탯 반영**: 캐릭터 호감도 단계에 따라 ATK/DEF/HP에 % 보너스 적용.
4. **도감 UI**: 도감 상세에 호감도 섹션(게이지·단계·선물 버튼) 표시.
5. **04 대화 연결**: `AffinityChangeAction`이 실제 서비스를 호출하고, `AffinityMin/Max` 조건이 단계를 참조해 이벤트 대화가 자동 해금된다.
6. **저장**: 호감도 수치·일일 획득량·리셋 날짜가 재로그인 후에도 유지.
7. **일일 상한**: b/c/d 경로는 대상당 하루 최대 100 포인트 제한. a 대화는 상한 없음.

### 3-2. AffinityState — 저장소

**`Scripts/Meta/AffinityState.cs`** (신규):
```csharp
public class AffinityState
{
    // affinityId → 누적 포인트
    Dictionary<string, int> _points   = new Dictionary<string, int>();
    // affinityId → 오늘 획득한 포인트 (a 대화 제외)
    Dictionary<string, int> _daily    = new Dictionary<string, int>();
    string _lastResetDate = "";        // "2026-06-29" UTC 날짜

    const int DAILY_CAP = 100;

    // 일일 리셋 (UTC 날짜 변경 시 자동)
    void CheckDailyReset()
    {
        string today = DateTime.UtcNow.ToString("yyyy-MM-dd");
        if (_lastResetDate != today) { _daily.Clear(); _lastResetDate = today; }
    }

    public int  GetPoints(string id) => _points.TryGetValue(id, out var v) ? v : 0;
    public int  DailyRemaining(string id)
    {
        CheckDailyReset();
        int used = _daily.TryGetValue(id, out var v) ? v : 0;
        return Mathf.Max(0, DAILY_CAP - used);
    }

    // delta > 0만 허용. isDialogue=true면 일일 상한 무시.
    public int Add(string id, int delta, bool isDialogue = false)
    {
        if (delta <= 0) return 0;
        CheckDailyReset();
        int actual = delta;
        if (!isDialogue)
        {
            int rem = DailyRemaining(id);
            if (rem <= 0) return 0;
            actual = Mathf.Min(delta, rem);
            _daily[id] = (_daily.TryGetValue(id, out var d) ? d : 0) + actual;
        }
        _points[id] = GetPoints(id) + actual;
        return actual;   // 실제 반영된 포인트 반환
    }

    public AffinityData Export() { ... }
    public void LoadState(AffinityData data) { ... }
}

[Serializable]
public class AffinityData
{
    public string[] ids;
    public int[]    points;
    public string[] dailyIds;
    public int[]    dailyAmounts;
    public string   lastResetDate;
}
```

### 3-3. AffinityTuning — 등급별 테이블

**`Scripts/Meta/AffinityTuning.cs`** (신규, 정적):

| 등급 | 최대단계 | 단계별 누적 필요치(누진) | 만렙 스탯보너스(ATK/DEF/HP) | 단계업 결정 base |
|------|---------|----------------------|---------------------------|----------------|
| N | 3 | 100 / 250 / 450 | +3% | 5 |
| R | 4 | 100 / 250 / 450 / 700 | +4% | 8 |
| SR | 5 | 100 / 250 / 450 / 700 / 1000 | +6% | 15 |
| SSR | 6 | 100 / 250 / 450 / 700 / 1000 / 1400 | +8% | 30 |
| UR | 7 | 100 / 250 / 450 / 700 / 1000 / 1400 / 1900 | +10% | 60 |
| NPC (고정) | 5 | 100 / 250 / 450 / 700 / 1000 | (스탯 무관) | — |

- **스탯 배율 계산**: 현재 단계 / 최대단계 × 만렙보너스. 예) SSR 3단계 → 3/6 × 8% = +4%.
- **단계업 결정 비용**: 누적 포인트가 `thresholds[newTier-1]`를 넘을 때 자동 지급(1회성). 결정 개수 = `base × newTier`.
- **골드 지급**: 단계업 시 항상 `base × newTier × 50` 골드 (튜닝 가능).

```csharp
public static class AffinityTuning
{
    public static int MaxTier(Rarity r) => r switch { N=>3, R=>4, SR=>5, SSR=>6, UR=>7, _=>3 };
    public static int MaxTierNpc() => 5;
    public static int[] Thresholds(Rarity r) => r switch { ... };
    public static int[] ThresholdsNpc() => new[]{100,250,450,700,1000};
    public static float MaxStatPct(Rarity r) => r switch { N=>0.03f, R=>0.04f, SR=>0.06f, SSR=>0.08f, UR=>0.10f, _=>0.03f };
    public static int CrystalBase(Rarity r) => r switch { N=>5, R=>8, SR=>15, SSR=>30, UR=>60, _=>5 };
    public static int GoldPerTier(Rarity r) => CrystalBase(r) * 50;

    // 누적 포인트 → 현재 단계 (캐릭터)
    public static int TierOf(int points, Rarity r)
    {
        var t = Thresholds(r);
        int tier = 0;
        foreach (var th in t) { if (points >= th) tier++; else break; }
        return tier;
    }
    // NPC 전용
    public static int TierOfNpc(int points)
    {
        var t = ThresholdsNpc();
        int tier = 0;
        foreach (var th in t) { if (points >= th) tier++; else break; }
        return tier;
    }
}
```

### 3-4. AffinityService — 통합 서비스

**`Scripts/Meta/AffinityService.cs`** (신규, static):

```csharp
public enum AffinitySource { Dialogue, Gift, Combat, Study }

public static class AffinityService
{
    static CharacterDatabase _charDb;
    static CharacterDatabase CharDb =>
        _charDb ??= Resources.Load<CharacterDatabase>("CharacterDatabase");

    // id가 수집 캐릭터인지 판정
    public static bool IsCharacter(string id) => CharDb?.ById(id) != null;

    public static int  PointsOf(string id)    => MetaState.Affinity.GetPoints(id);
    public static int  MaxTierOf(string id)
    {
        if (IsCharacter(id)) return AffinityTuning.MaxTier(CharDb.ById(id).rarity);
        return AffinityTuning.MaxTierNpc();
    }
    public static int  TierOf(string id)
    {
        int pts = PointsOf(id);
        if (IsCharacter(id)) return AffinityTuning.TierOf(pts, CharDb.ById(id).rarity);
        return AffinityTuning.TierOfNpc(pts);
    }

    // ATK/DEF/HP 공통 배율 (1f = 변화 없음)
    public static float StatMult(CharacterDef def)
    {
        if (def == null) return 1f;
        int tier = TierOf(def.id);
        int maxT = AffinityTuning.MaxTier(def.rarity);
        float pct = (float)tier / maxT * AffinityTuning.MaxStatPct(def.rarity);
        return 1f + pct;
    }

    // 핵심 수치 변경 진입점
    public static int Change(string id, int delta, AffinitySource source)
    {
        bool isDlg = source == AffinitySource.Dialogue;
        int prevTier = TierOf(id);
        int actual = MetaState.Affinity.Add(id, delta, isDlg);
        if (actual <= 0) return 0;

        int newTier = TierOf(id);
        if (newTier > prevTier)
            GrantTierReward(id, newTier);

        MetaSaveService.Save();
        return actual;
    }

    // 선물 — 재료 1개 소비 → 호감도 증가
    // 선호 판정: ① giftLikes 포함 → +50 / ② 대륙 일치 → +30 / ③ 기타 → +10
    public static bool GiftIngredient(string id, IngredientKind kind)
    {
        if (!MetaState.Cooking.Ingredients.TrySpend(kind, 1)) return false;

        var def = IsCharacter(id) ? CharDb.ById(id) : null;
        int delta = 10; // 기본 비선호

        if (def != null)
        {
            bool isLiked = def.giftLikes != null &&
                System.Array.IndexOf(def.giftLikes, kind) >= 0;
            bool isSameContinent = CookingCatalog.ContinentOf(kind).HasValue &&
                CookingCatalog.ContinentOf(kind).Value == def.continent;

            if      (isLiked)        delta = 50;
            else if (isSameContinent) delta = 30;
        }
        // NPC는 선물 판정 없음 → 일률 +20
        else delta = 20;

        Change(id, delta, AffinitySource.Gift);
        return true;
    }

    static void GrantTierReward(string id, int newTier)
    {
        if (IsCharacter(id))
        {
            var def = CharDb.ById(id);
            // 결정 종류: GachaService의 country→CrystalKind 매핑 재사용
            var crystal = GachaService.CrystalForCharacter(def);
            int amount  = AffinityTuning.CrystalBase(def.rarity) * newTier;
            MetaState.Crystals.Add(crystal, amount);
            int gold = AffinityTuning.GoldPerTier(def.rarity) * newTier;
            MetaState.Wallet.Add(CurrencyKind.Gold, gold);
        }
        else // NPC
        {
            MetaState.Wallet.Add(CurrencyKind.Gold, newTier * 500);
        }

        OnTierUp?.Invoke(id, newTier);
    }

    // 단계업 시 발생 이벤트 (UI 알림 구독용)
    public static event System.Action<string, int> OnTierUp;
}
```

> `GachaService.CrystalForCharacter(def)` — 기존 가챠 중복 지급 시 country→CrystalKind 매핑 메서드. 없으면 별도 static 테이블로 추출.

### 3-5. 획득 경로 구현

#### a. 대화 선택지 — `AffinityChangeAction.cs` 수정

04 대화 §4의 스텁:

#### c. 전투 동행 — 스테이지/전투 클리어 훅

#### d. 문제풀이 / 일일 대화

(Study source는 일일 상한 적용 — 대화도 하루 1회 자연 제한)

### 3-7. 전투 반영 — CombatCharacter.cs 수정

  - 누적 포인트·다음 단계까지 필요치 (예: "250 / 450 pts")
  - 현재 스탯 보너스 (예: "ATK/DEF/HP +2.7%")
  - 일일 잔여 포인트 (예: "오늘 남은 포인트: 47")
  - **[선물] 버튼** — 클릭 시 재료 선택 드롭다운(보유 수량 표시) → `AffinityService.GiftIngredient`
  - 만렙 달성 시 "★ 만렙 달성 — 스킨 해금" 텍스트 (스킨 실제 적용은 11 셀셰이딩 후속)

**NPC 호감도 (04 DialogueUI 수정)**:
- 대화 UI 상단에 소형 게이지 바 추가 (텍스트로 대체 가능: "친밀도: ★★☆☆☆").
- 별도 관계 패널은 YAGNI.

### 3-10. 부가 보상

**d 스킨 (CharacterDef 수정)**:
```csharp
[Header("호감도 만렙 스킨 (셀셰이딩 후속 구현)")]
```

**e 편의 (NPC 만렙)**:
- 플래그 `AffinityService.TierOf(npcId) == AffinityService.MaxTierOf(npcId)` 로 판단.
- 상점 할인·레시피 추가 제공은 해당 시스템(상점/요리) 구현 시 연동. 이 설계도에서는 진입점만 명시.

## 6. 엣지 케이스 / 주의점

| 상황 | 처리 방식 |
|------|----------|
| 구 세이브(affinity 키 없음) | TryGetValue 실패 → LoadState 스킵 → 빈 상태(모두 0단계) |
| 일일 상한 도달 후 Change() | `Add()` 반환 0, 포인트·세이브 변경 없음. UI에 "오늘 상한 도달" 표시 권장 |
| 대화(a) 음수 delta | `Add()`에서 delta≤0 무시. 호감도 감소 시스템 미지원(YAGNI) |
| CharacterDatabase 미로드 | `IsCharacter()` false → NPC 고정 단계로 폴백. 서버 로딩 지연 방어 |
| giftLikes 비어있는 캐릭터 선물 | 대륙 매칭만 판정(+30) or 비선호(+10). null 안전 처리 필수 |
| 04 대화 미구현 상태 | AffinityChangeAction·DialogueCondition 스텁은 04 구현 후에만 활성화. 독립 구현 단계 명시 |
| `CookingCatalog.ContinentOf` null 반환 | 범용 재료(null) → 대륙 일치 불가 → 비선호(+10). `HasValue` 체크 필수 |
| 동일 id로 NPC·캐릭터 키 충돌 | `CharacterDef.id`는 `"char_xxx"`, `npcId`는 `"npc_xxx"` 네이밍 규칙으로 방지 (시드 작성 시 확인) |
| 단계업 보상 중복 지급 | `TierOf(before) < TierOf(after)`일 때만 한 번 지급. 포인트 역주행 없으므로 중복 불가 |
| 스탯 배율 곱연산 초과 | 만렙 기준 UR: 승급(+10%) × 요리(+20%) × 호감도(+10%) ≈ +44% 복합. 소폭 유지 위해 각 시스템 수치 재조정 가능 |
| JsonUtility Dictionary 직렬화 | 불가 — `AffinityData`의 병렬 배열 DTO로 변환 필수. Export/LoadState에서 처리 |
