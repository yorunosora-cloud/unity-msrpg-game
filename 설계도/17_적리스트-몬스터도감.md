# 17. 적 리스트 — 몬스터 도감

---

## 세계관 맥락

- **이 문서는 필드/던전에 등장하는 일반 몬스터의 분류·데이터 틀을 다룬다.**
- 역사적 과학자 보스(유클리드 등)의 전투·패턴·아레나는 [07_보스전.md](07_보스전.md)의 `BossDef` 소관이다.
  이 문서에서 `tier=Boss`인 행은 **도감 인덱스로만 존재**하며, 전투 스탯/패턴을 재정의하지 않고
  `bossDefId`로 07의 `BossDef`를 링크한다.
- 몬스터 테마·이름은 [세계관 아이디어-2.txt](../../세계관%20아이디어-2.txt)의 대륙별 국가·랜드마크·
  고유 동식물에서 가져온다 (예: 수학 대륙의 "미지수 덩굴", "칸토르의 용").
- **1차 구현 범위**: 7개 대륙 전체의 분류 스캐폴드(빈 틀) + 수학(아틀란티스) 대륙에 레퍼런스 몬스터
  3종(잡몹/중간보스/보스 각 1종). 나머지 6개 대륙 콘텐츠는 사용자가 CSV에 행을 추가하며 채운다.

---

## 1. 목표 / 완료 정의

1. `Resources/Data/enemy_catalog.csv` 파일 하나가 존재하고, **사용자는 이 CSV만 편집**해서 몬스터를
   추가·수정한다 (코드를 건드리지 않음).
2. CSV는 7개 대륙 섹션(주석 구분)으로 스캐폴드되어 있고, 수학 대륙에는 잡몹/중간보스/보스 레퍼런스
   행 3개가 채워져 있어 "이렇게 입력하면 된다"는 예시가 된다. 나머지 대륙은 헤더만 있는 빈 섹션.
3. `EnemyCsvImporter`가 이 CSV를 파싱해 `EnemyDef[]`로 변환하고, `EnemyCatalog`가 이를 로드·캐시해
   대륙·국가·출현지역·급·레벨대로 조회할 수 있다.
4. `EnemyCatalog.LevelBandId(EnemyDef)`가 `"lv:min-max"` 형태의 문자열을 반환하고, 이는
   [15_일일주간-임무.md](15_일일주간-임무.md)의 `EnemyKill` 목표 `contextId`로 쓸 수 있는 형태다
   (실제 연동은 미래 필드 콘텐츠 세션의 선택적 확장점 — §6 참고).
5. `tier=Boss`인 몬스터는 `bossDefId`로 07의 `BossDef`와 연결되어 있어, 도감에서 보스를 보면
   실제 전투 정의를 찾아갈 수 있다.
6. **이번 범위에 포함되지 않는 것**: 기존 `Enemy` MonoBehaviour의 스폰 경로 변경, 실제 필드/던전에
   catalog 기반 몬스터 배치. 이 문서는 데이터 틀만 세운다.

## 3. 아키텍처

### 3-1. 저장 방식: CSV 원본 + 임포터

사용자가 직접 만지는 **유일한 파일은 CSV**다. 게임(및 도감 UI)이 쓰는 데이터는 이 CSV를 읽어서
만들어진다.

```
Resources/Data/enemy_catalog.csv   ← 사용자가 편집하는 원본 (엑셀/메모장 등)
        │  EnemyCsvImporter.Parse(TextAsset)
        ▼
EnemyDef[]                          ← 파싱된 순수 데이터
        │  EnemyCatalog가 최초 접근 시 로드·캐시
        ▼
EnemyCatalog.All / ByContinent(...) / Get(id) / InLevelBand(...) / LevelBandId(...)
```

WebGL 빌드 대상이므로 파일시스템 직접 읽기 대신 `Resources.Load<TextAsset>("Data/enemy_catalog")`
로 로드한다 (씬/빌드 관계없이 항상 접근 가능).

### 3-2. 분류 축 (엄격한 트리)

각 몬스터는 아래 4단계 경로에 **정확히 하나만** 소속된다 (여러 지역 중복 출현은 지원하지 않음 —
필요하면 행을 복제, §6 참고).

```
대륙 (Continent)
 └─ 국가 (nation, 문자열)
     └─ 출현지역 (region, 문자열) — regionKind: Landmark(랜드마크) / MidZone(중간구역)
         └─ 급 (tier) — Boss / MiniBoss / Normal
```

추가로 트리와 독립적인 분류 속성(태그성) 3개를 더 둔다:

- `family` — 계열/타입 (예: 정령·기계종·야수·식물형·용족). 자유 문자열.
- `grouping` — `Swarm`(군집) / `Solo`(단일).
- `habitat` — 서식/환경 (예: 지상·수중·공중·밀림). 자유 문자열.

```csharp
public enum EnemyTier   { Normal, MiniBoss, Boss }
public enum RegionKind  { Landmark, MidZone }
public enum Grouping    { Swarm, Solo }
```

### 3-3. `EnemyDef` (순수 C#, Serializable — MonoBehaviour 아님)

CSV의 각 열이 필드 하나에 정확히 대응한다 (매핑 규칙은 §3-6).

```csharp
[System.Serializable]
public class EnemyDef
{
    // 식별 · 분류
    public string     id;            // 전역 유일 키
    public string     nameKo;
    public Continent  continent;
    public string     nation;
    public string     region;
    public RegionKind regionKind;
    public EnemyTier  tier;
    public string     family;
    public Grouping   grouping;
    public string     habitat;

    // 레벨 · 전투
    public int        levelMin;
    public int        levelMax;
    public Continent  weakness;
    public int        maxHp;
    public int        def;
    public int        expReward;
    public EnemySkillRef[] skills;   // 이름:타입 쌍의 배열

    // 드롭 · 보상
    public int        dropGold;
    public int        dropMaterialAmt;   // weakness 과목 연구자원 지급량 (0이면 기본값 expReward/10 사용)
    public string[]   dropItems;         // "아이템id:수량" 문자열 배열, 선택

    // 표시
    public string      iconPath;    // 선택, 빈 값 허용
    public string      modelPath;   // 선택, 빈 값 허용
    public string      descKo;      // 도감 설명문, 선택

    // 보스 링크 (tier == Boss 일 때만 사용)
    public string      bossDefId;   // 07_보스전.md BossDef 참조 키
}

[System.Serializable]
public struct EnemySkillRef { public string name; public string type; }
```

### 3-4. `EnemyCatalog` (static)

```csharp
public static class EnemyCatalog
{
    public static IReadOnlyList<EnemyDef> All { get; }        // 최초 접근 시 CSV 로드·캐시

    public static EnemyDef            Get(string id);
    public static IEnumerable<EnemyDef> ByContinent(Continent c);
    public static IEnumerable<EnemyDef> ByNation(Continent c, string nation);
    public static IEnumerable<EnemyDef> ByRegion(string region);
    public static IEnumerable<EnemyDef> ByTier(EnemyTier tier);
    public static IEnumerable<EnemyDef> InLevelBand(int min, int max);

    /// <summary>15 임무 contextId로 쓸 수 있는 레벨대 밴드 키. 예: "lv:5-8"</summary>
    public static string LevelBandId(EnemyDef def) => $"lv:{def.levelMin}-{def.levelMax}";
}
```

### 3-5. 대륙 → 국가 → 대표 랜드마크 매핑 (CSV 스캐폴드 근거)

세계관 파일에서 가져온 매핑. CSV 섹션 주석과 도감 표 스캐폴드가 이 표를 그대로 따른다.

| 대륙 | 국가(들) | 대표 랜드마크 예시 |
|---|---|---|
| Physics (물리) | 뉴턴 제국 / 맥스웰 공국 / 볼츠만 열공화국 / 아인슈타인 연방 / 양자혁명군 | 만유인력의 왕궁, 빛의 속도 철로, 엔트로피의 대로, 시공간 왜곡 관측소, 슈뢰딩거의 상자 연구소 |
| Chemistry (화학) | 교황청 인오르가니아 / 황제령 오르가니아 / 피지컬리아 공국 / 아날리티카 연맹 / 오비탈 혁명파 | 원소 주기율표 대성당, 벤젠의 육각 신전, 촉매의 영원한 화로, 분광 분석의 등대, 전자구름의 혼돈 지대 |
| Biology (생명과학) | 헬릭스 제국 / 제네시스 왕국 / 에코스 연맹 | 이중나선 황궁, CRISPR 편집 연구소, 멘델의 유전 도서관, 해부학의 지하 성역, 진화의 세계수, 생태계 순환 대원 |
| EarthSci (지구과학) | 천문 부족 / 해양 부족 / 대기 부족 / 지질 부족 | 거대 천문대 피라미드, 세계 해류 신전, 토네이도 정령의 영혼 평원, 판구조 산맥 신전, 판게아 유적 |
| **Math (수학)** | 유클리드 평원 / 산술의 탑 / 해석의 바다 / 대수의 숲 / 논리·집합의 고원 / 아크시움 | 유클리드 대성당, 힐베르트의 무한 호텔, 뉴턴-라이프니츠 폭포, 페르마의 마지막 서재, 러셀의 역설 탑, 세계수 아크시움 |
| Info (정보) | 튜링 중앙집권국 / 오픈소스 연합 / 암호화 제국 / 데이터 마이닝 공화국 / 해커 길드 | 튜링 테스트 탑, 알고리즘 코어, 포크의 자유 광장, 불가능한 퍼즐 요새, 언더넷 심연 |
| Mesoria (메조리아) | (국가 대신 구역/길드) | 그랜드 하버, 지식의 거래 시장, 통합 학술원, 실크로드 광장, 중립 조약의 탑 — **안전 허브 성격이 강해 몬스터가 적거나 없을 수 있음**(이벤트성 등장 정도) |

### 3-6. CSV 스키마 (열 = `EnemyDef` 필드 1:1 매핑)

| CSV 열 | `EnemyDef` 필드 | 값 형식 | 비고 |

| `nameKo` | `nameKo` | 문자열 | |

| `nation` | `nation` | 문자열 | §3-5 매핑표의 국가명 |
| `region` | `region` | 문자열 | 랜드마크/중간구역 이름 |
| `regionKind` | `regionKind` | `Landmark`\|`MidZone` | |
| `tier` | `tier` | `Normal`\|`MiniBoss`\|`Boss` | |
| `family` | `family` | 문자열 | 자유 (예: 식물형, 용족, 정령) |
| `grouping` | `grouping` | `Swarm`\|`Solo` | |
| `habitat` | `habitat` | 문자열 | 자유 (예: 지상/밀림, 공중) |
| `levelMin`,`levelMax` | `levelMin`,`levelMax` | 정수 | 권장 레벨대, `levelMin<=levelMax` |
| `weakness` | `weakness` | `Continent` 이름 | 보통 자기 대륙과 동일(그 과목 스킬로 약점 공략) |
| `maxHp`,`def`,`expReward` | 동일 | 정수 | `tier=Boss`는 빈 값 허용(07 BossDef가 실제 전투 스탯 소유) |
| `skills` | `skills` | `이름:타입` 쌍을 `;`로 구분 | 예: `채찍질:근접`. 빈 값 허용(잡몹은 스킬 없어도 됨) |
| `dropGold` | `dropGold` | 정수 | |
| `dropMaterialAmt` | `dropMaterialAmt` | 정수 | 0이면 기존 `Enemy.Die()` 방식(`expReward/10`)과 동일 취급 |
| `dropItems` | `dropItems` | `아이템id:수량`을 `;`로 구분 | 선택, 빈 값 허용 |
| `iconPath`,`modelPath` | 동일 | 문자열 | 선택, 빈 값 허용 |
| `desc` | `descKo` | 문자열 | 선택, 도감 설명문 |
| `bossDefId` | `bossDefId` | 문자열 | `tier=Boss`일 때만. 07의 BossDef 키 |

### 3-7. 급(tier) 처리 규칙

- `Normal`/`MiniBoss`: 이 문서의 `maxHp`/`def`/`expReward`/`skills`가 스탯의 원천.
- `Boss`: 이 문서는 **도감 인덱스**(어느 대륙·국가·지역에 있는지, 이름·설명)만 제공.
  실제 HP/패턴/아레나는 `bossDefId`로 연결된 07의 `BossDef`가 소유한다. 혼선 방지를 위해
  Boss 행의 `maxHp`/`def`/`expReward`/`skills`는 **빈 값으로 둔다**(도감 표시용 수치가 필요하면
  BossDef 값을 조회해 쓰도록 나중에 확장).

## 6. 엣지 케이스 / 주의점

- **id 유일성**: 전역에서 중복되면 안 됨 — 임포터가 로드 시 중복 발견하면 경고 로그 + 뒤에 나온 행 무시
  (또는 테스트로 강제). 명명 규칙: `대륙_지역slug_급_이름slug` 고정.
- **엄격한 트리의 한계**: 같은 몬스터가 여러 지역에 출현해야 하면 **행을 복제**해서 별도 `id`로 등록한다
  (예: `..._region-a_...`, `..._region-b_...`). 하나의 `EnemyDef`가 여러 지역에 속하는 것은 지원하지 않음.
- **CSV 파싱 강건성**: 값에 쉼표가 포함될 경우 따옴표 이스케이프 필요, 빈 셀은 해당 필드 기본값(0 또는
  빈 문자열)으로, 열 순서가 바뀌어도 헤더 이름으로 매핑하므로 안전.
- **빈 대륙 섹션**: 헤더만 있고 행이 0개인 대륙이 있어도 `EnemyCatalog.All`은 정상 로드되어야 하며
  `ByContinent`가 빈 시퀀스를 반환해야 함(예외 발생 금지).
- **Boss 소유권 혼선 방지**: 17번 문서는 "누가·어디에 있는가"의 인덱스일 뿐, "어떻게 싸우는가"는
  07번 문서다. 두 문서를 함께 수정할 필요가 있는 경우는 새 보스 추가 시뿐.
- **`weakness`가 자기 대륙과 다를 수 있음**: 기본은 동일(그 과목 스킬로 공략)이지만, 혼종/이종
  몬스터(예: 메조리아의 하이브리드 종)는 다른 대륙 약점을 가질 수 있음 — 강제하지 않음.
- **세계관 표기 일치**: 국가·랜드마크 이름은 `세계관 아이디어-2.txt`의 표기를 그대로 따른다
  (신규 지명 창작 금지, 메모리 `feedback_map_worldview_reference` 관례 준수).
- **15 임무 연동은 여전히 선택적**: 이 문서가 완성돼도 `EnemyKill` 목표의 `contextId`는 실제 필드
  스폰이 `enemyDefId`를 갖기 전까지 자동으로 채워지지 않는다. 그 전까지 15 임무는 계속
  `contextId=""`(전체 처치)로 정상 동작한다 — 이는 **버그가 아니라 의도된 단계적 연동**이다.

## 7. 검증 방법

- **EditMode 테스트**:
  - CSV 파싱 결과 개수가 CSV의 실제 유효 행 수와 일치하는지.
  - 모든 `id`가 유일한지.
  - `ByContinent(Continent.Math)`가 레퍼런스 3행을 반환하는지.
  - `InLevelBand(min,max)`가 겹치는 레벨대만 반환하는지.
  - `LevelBandId(def)`가 `"lv:{min}-{max}"` 포맷을 반환하는지.
  - `ByTier(EnemyTier.Boss)`로 조회한 행의 `bossDefId`가 비어있지 않은지.
- **문서 자체 검증**: 아래 §7-참고의 마크다운 표(수학 예시)와 CSV 예시 3행의 필드 값이 1:1로
  일치하는지 대조.
- **미래 연동 스모크 (문서 기술, 실행은 콘텐츠 세션 몫)**: `EnemyCatalog.Get("math_forest-algebra_normal_unknown-vine")`
  값을 가져와 `EnemySpawner`/`Enemy`에 이름·약점·스킬을 반영해 스폰하면 필드에 해당 이름을 가진
  적이 등장하는지 확인.
