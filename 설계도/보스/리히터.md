## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"크기는 측정할 수 있다 — 객관적인 숫자로."**

20세기 중반 미국의 지진학자 찰스 리히터(Charles Richter)를 형상화한 존재. 지진이 방출하는
에너지를 로그 척도의 객관적 수치(규모)로 측정하는 리히터 규모를 고안했다. 판구조 산맥
신전 3보스 중 "객관적 측정" 단계 — 허턴의 기초 이론을 실제 현상의 정량화로 이어가는 중간
난이도 관문.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 제임스 허턴
  (동일과정설, '지질학의 아버지') · 찰스 리히터(지진 규모) · 주세페 메르칼리(지진 진도,
  한국이 채택한 수정 메르칼리 진도)"
- [테라노바_판구조산맥신전.md](../../디자인/던전/테라노바_판구조산맥신전.md) §2, §6: 리히터
  갱도의 중간보스 "진동화석룡"을 처치하면 얻는 열쇠로 진입하는 지진계 측정실 아레나의 주인.

### 포지션
판구조 산맥 신전 3보스방 중 **중간 난이도**. 미니보스 "진동화석룡"의 "약·중·강 3단계 순차
발동" 개념을 4페이즈로 확장 — 페이즈가 진행될수록 동시에 활성화되는 진동 등급이 누적되어,
마지막 페이즈에는 4개 등급(약·중·강·초강)이 한꺼번에 발동하는 "규모 누적형" 보스.

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — RichterSetup.cs로 구현 가능)

```
리히터 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 회색 현대 정장
├── SeismoCloak (Pivot) empty   pos(0, 1.5, 0)          — 지진계 그래프 무늬가 그려진 코트 자락
│   └── CloakPanel×3   납작 Cube  각 scale(0.4, 1.3, 0.05)
├── SeismoChart       Cube(소형, 두루마리형) scale(0.3, 0.4, 0.05)  pos(0.5, 1.3, 0.2)  — 손에 든 진동 기록지(지진도)
├── WeakPoint         (BossWeakPoint) pos(0, 1.7, 0.4)  — 가슴에 걸친 지진계 계기판
│   └── GaugeGlow     Cylinder(납작, 계기판형)  scale 0.32  Color: 짙은 회색  Emission OFF→ON 노출 시
├── TremorAnchor×4    empty     각기 다른 반경(약·중·강·초강)  — 단계별 진동파 장판 소환 자리
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 4단계(약·중·강·초강)의 진동파 장판이 각기 다른 반경·색 농도로 표시되며,
페이즈가 진행될수록 동시에 표시되는 장판 수가 늘어난다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 현대적 과학자 정장 + 가슴에 부착된 지진계 계기판(약점 오브젝트) 혼합 스타일 —
  "수치화된 이론가" 이미지.
- **소품**: 손에 든 진동 기록지(지진도) — 실제 지진파 그래프가 그려진 두루마리.
- **발광**: 계기판 — 평상시 짙은 회색, 노출 시 밝은 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 짙은 회색 정장(#3A3D42) + 그래프 무늬 주황(#E8823C) + 밝은 Emission(#F2A65A, 약점).
- **실루엣**: 키 약 3.0 Unity units. 3보스 중 가장 정밀하고 기계적인 실루엣.

|----------|---------|-------------------|---------------------|

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 거의 정지, 제자리에서 측정
- 패턴 캐스팅과 무관하게 거의 이동하지 않고 제자리에서 진동 기록지를 확인하는 자세를 유지 —
  "측정"이라는 정적인 행위를 모션으로도 일관되게 반영.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너와 동기화. 새로운 등급의 진동 장판이 처음 나타나는
  "등급 추가" 연출(화면에 등급 아이콘 잠시 표시).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 코트 자락 흔들림 | 항상(약하게) | `Update()`: `CloakPanel[i].localRotation`을 `Mathf.Sin(Time.time*speed+i)`로 흔듦 |
| 진동파 장판 발동 | TieredTremor 캐스팅 중 | 각 `TremorAnchor`에서 등급별 반경의 장판 순차/동시 생성 |
| 계기판 Emission | 최고 등급 장판 발동 직후 | `GaugeGlow` 머티리얼 Emission 짧게 On |

## 5. 약점 메커니즘

### 가슴의 지진계 계기판 (BossWeakPoint)
- **위치**: 가슴 전면(localPos 0, 1.7, 0.4).
- **노출 타이밍**: 매 페이즈의 **가장 강한 등급**(최고 공장)이 발동한 직후 자동
  `SetExposed(duration)` 호출 — duration은 페이즈별로 0.8s→1.0s→1.2s→1.4s로 늘어남(§4).
  등급이 늘어날수록 노출 기회 자체도 많아짐(P4에서는 4개 등급이 거의 동시에 발동하므로
  체감 기회가 가장 많음).
- **시각 피드백**: 평상시 짙은 회색 → 노출 시 밝은 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 계기판 약점(×3)과는 독립.

## 11. 향후 확장

- **리깅 모션**: 코트 그래프 무늬 셰이더 애니메이션, 기록지 확인 제스처.
