## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"유전자는 염색체 위에 한 줄로 늘어서 있고, 가까운 유전자는 함께 유전된다."**

20세기 초 미국의 생물학자 토머스 헌트 모건(Thomas Hunt Morgan)을 형상화한 존재. 컬럼비아 대학의 "파리방"에서 초파리를 대규모로 키우며 **흰 눈 돌연변이**를
발견했고, 이를 성(性)과 연관된 유전으로 설명해 **염색체설**(유전자는 염색체 위에 있다)을 입증했다. 연관과 교차, 유전자 지도를 체계화해 노벨상을 받았다.
멘델의 유전 도서관 3보스 중 **중간 난이도**(고전유전학 계보의 2단계).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 멘델 · 모건 · 매클린톡(유전법칙 → 염색체설 → 전이인자로 이어지는 고전유전학 계보)".
- [바이오스_멘델유전도서관.md](../../디자인/던전/바이오스_멘델유전도서관.md) §1, §6: 둥근·초록 방군 중간보스 "흰눈초파리" 처치 열쇠로 진입하는 초파리방의 주인.
  진행 순서 ②번(멘델 처치 후 개방).

### 포지션
멘델의 유전 도서관 **중간 난이도**(둥근·초록 방군, 4페이즈). 난이도 계단: 멘델 3P → **모건 4P** → 매클린톡 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 초 미국 실험 생물학자 + 초파리 실험 장비. 1910년대 미국 대학 실험실 시절의 생물학자 복장(흰 실험 가운·둥근 안경)에 유리병·확대경·
초파리 배양 장비를 갖춘 모습. 린네~멘델·오덤과 시대(20세기 초)·직업(실험 생물학자)·장비(실험실 유리기구)로 구분.

### 2-A 지금 (프리미티브 조립 — MorganSetup.cs로 구현 가능)

```
모건 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 흰 실험 가운
├── Glasses           Torus×2 or Cylinder×2(납작)  pos(0, 2.5, 0.4)  — 둥근 안경(장식)
├── Magnifier         Cylinder(납작)+가는 손잡이  pos(0.5, 1.4, 0.3)  — 손에 든 확대경(장식)
├── WeakPoint         (BossWeakPoint) pos(0, 2.2, 0.4)  — 목에 건 초파리 배양병
│   └── FlyBottle     Cylinder(투명 우유병)  scale(0.25, 0.35, 0.25)  Emission OFF→ON 노출 시
│       └── Flies     Sphere(아주 작음)×N  눈 색이 페이즈마다 변함(붉음→흰색)
├── ChromosomeEmitter empty     pos(0, 0, 0)  — 염색체 장판 생성·교차·연쇄 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 바닥 장판은 **X자형 염색체** 모양이고, 염색체 위에 **작은 점(유전자 좌위)** 이 표시된다. 연관된 장판 쌍은 점선(연관선)으로 이어진다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 초 미국 실험 생물학자 — 흰 실험 가운·둥근 안경·넥타이, 목에 초파리 배양병, 손에 확대경.
- **소품**: 목에 건 초파리 배양병(약점, 병 속 초파리 눈 색이 변함), 확대경, 유리 시험관(장식).
- **발광**: 배양병 — 평상시 투명, 노출 시 병 속 초파리가 밝게 Emission(눈 색이 선명히 드러남).
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 흰 가운(#EDEDE8) + 실험실 청록(#4E8F8A) + 초파리 눈 붉음(#C0392B)/흰색(#F4F4F0) + 밝은 Emission(#FFF1E0, 약점).
- **실루엣**: 키 약 3.0 Unity units. 둥근 안경과 목의 병으로 3보스 중 가장 실험실스러운 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 염색체 장판 4단계 — 염색체설 → 연관 → 교차 → 유전자 지도를 페이즈별 장판 규칙으로 옮긴다. 멘델(법칙 추가)과 같은 **누적형**이지만 장판이
**쌍·교차·일렬 연쇄**로 "연결된 움직임"을 읽는 것이 핵심이다.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **염색체설** — 유전자는 염색체 위에 있다 | **X자형 염색체 장판**(두 막대가 교차하는 십자형)이 지정 위치에 예고 후 발동 |
| P2 | **연관** — 가까운 유전자는 함께 유전된다 | 장판이 **쌍**으로 소환되어 **연관선(점선)** 으로 이어지고, 두 장판이 **항상 함께 움직이고 함께 터진다**(연결선 위도 장판) |
| P3 | **교차** — 염색체 사이에서 일부가 교환된다 | 두 염색체 장판이 발동 직전 **교차하며 일부 구간의 위치가 서로 바뀐다** — 안전 위치가 예고와 달라짐 |
| P4 | **유전자 지도** — 유전자의 거리와 순서를 지도화 | 막대 장판 위 **유전자 좌위 4~5개가 일렬**로 늘어서 있고, **가까운 점은 동시에, 먼 점은 시간차로 연쇄 폭발** |

| 패턴 에셋 | 유전학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `ChromosomePattern.asset` (신규) | **염색체설·연관·교차·유전자 지도** | 염색체 모양 장판이 쌍·교차·일렬 연쇄로 발동 | 현미경을 보며 염색체 도형을 그림 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 모건이 확대경으로 허공을 가리키면 **염색체 장판 텔레그래프**가 나타난다(페이즈별 규칙).
2. 플레이어는 장판의 **쌍·교차·연쇄 순서**를 읽어 안전 위치로 이동한다.
3. 장판이 모두 발동되고 나면 모건이 **목에 건 배양병을 들여다보며** 초파리 형질을 관찰한다 — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 규칙 | 시전 순환 |
|--------|----------|----------|
| P1 | 염색체 | 염색체 |
| P2 | 염색체 + 연관 | 염색체 → 연관 → 염색체 → 연관 … |
| P3 | + 교차 | 염색체 → 연관 → 교차 → 염색체 … |
| P4 | + 유전자 지도 | 염색체 → 연관 → 교차 → 유전자 지도 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 중앙 부근 정지, 관찰 중심
- 실험대 앞에 선 듯 중앙 부근에서 거의 이동하지 않고 확대경으로 허공을 가리킨다.
- 장판 발동 후 **목에 건 배양병을 두 손으로 들어 올려 들여다보는** 모션을 취한다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 배양병 속 초파리의 눈 색이 한 단계 변하는 연출(붉음 → 주황 → 연분홍 → **흰색** — 흰 눈 돌연변이).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 염색체 장판 | 시전 시작 | X자형 `Quad` 2장을 십자로 겹쳐 생성, 염색체 위에 점 `Sphere` 표시 |
| 연관선/연관 이동 | P2~ | 두 장판을 `LineRenderer`로 연결, 같은 `Lerp`로 함께 이동 |
| 교차 | P3~ | 두 염색체의 일부 구간 위치를 발동 직전 스왑(`Transform` 위치 교환) |
| 유전자 지도 연쇄 | P4 | 점 좌위들이 거리에 비례한 지연 시간으로 순차 폭발 |
| 배양병 확인 | 장판 발동 직후 | 보스가 병을 들어 올리는 모션 + `FlyBottle` Emission On |

## 5. 약점 메커니즘

### 목에 건 초파리 배양병 (BossWeakPoint)
- **위치(확정)**: 목(가슴 위, localPos 0, 2.2, 0.4). 이미 쓴 부위(손·허리·어깨 위·등·가슴·머리 위·팔뚝·팔 안쪽)와 구분되는 **목**.
- **노출 타이밍(확정)**: 염색체 장판이 모두 발동한 **직후**, 모건이 **배양병을 들여다보는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s).
  시간 기반이라 중간 난이도에 적합하고, 노출 중에는 장판이 남아 있지 않다.
- **병 속 변화**: 병 속 초파리 눈 색이 페이즈마다 바뀌어(붉음→흰색) 현재 페이즈를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 투명 병 → 노출 시 병 속 초파리와 눈 색이 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 배양병 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 흰눈초파리 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: X자 염색체 장판 예고→발동, 종료 직후 배양병 1.8s 노출(병 속 초파리 눈 붉음).
- [ ] **P2 전환**: HP 75% → 배너 + 연관 쌍 장판(연결선, 동시 이동·폭발), 노출 1.6s.
- [ ] **P3 전환**: HP 50% → 배너 + 교차(발동 직전 위치 교환), 노출 1.4s.
- [ ] **P4 전환**: HP 25% → 배너 + 유전자 지도(일렬 좌위 연쇄 폭발), 노출 1.2s(초파리 눈 흰색).
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 매클린톡 게이트 개방 조건 충족.
