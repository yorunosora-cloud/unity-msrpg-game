# 왓슨 보스 구현 설계도

> **위치**: `설계도/보스/왓슨.md`
> **역할**: [07_보스전.md](../07_보스전.md) 공통 템플릿을 왓슨에 실제로 어떻게 구체화할지 명세.
> [슈반.md](슈반.md)·[모건.md](모건.md)·[헤켈.md](헤켈.md)와 동일한 구조를 따른다.
> **범위**: 왓슨 보스 본체 + 염기 모형 조립실 아레나만. 던전 전체 구조는
> [바이오스_이중나선황궁.md](../../디자인/던전/바이오스_이중나선황궁.md) 소관.
> **비주얼 명세 원칙**: 모든 비주얼·아레나 섹션은 **① 지금(프리미티브)** / **② 미래(최종 아트)** 2단 레이어로 기술.
> **확정/초안 구분**: 비주얼 컨셉·4페이즈·약점(팔꿈치에 낀 염기 판지 카드 묶음)·패턴 방향(염기 상보 안전지대 4단계, **짝이 맞지 않는 부분은 결합이 형성되지 않아 안전지대**)·
> 노출 타이밍(수소결합 장판 발동 직후 카드를 짝 맞추는 동안)은 사용자 확정. 장판 세부·수치·대사는 **초안**.
> **레벨 스케일링**: maxHp/def 및 패턴 수치는 스케일링 **기준값**([[dungeon_level_scaling_rule]]).
> **크릭과의 난이도 정합**: 왓슨 탑·크릭 탑은 **순서가 자유**이므로 [크릭.md](크릭.md)와 **페이즈 수(4)·maxHp·def·약점 노출 시간 구조를 동일하게** 맞춘다.
> **⚠ 게임적 설정 표시**: 염기 상보 규칙(A↔T 2중, G↔C 3중 수소 결합)은 실제 지식이나, "염기 장판이 쌍으로 나타나 결합이 형성되면 위험하고 형성되지 않으면 안전하다",
> "이중 가닥으로 감기며 회전한다", "카드를 짝 맞추는 동안 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"맞는 짝끼리만 결합한다 — 염기쌍이 이중나선의 비밀이다."**

20세기 중반 미국 출신 분자생물학자 제임스 왓슨(James Watson)을 형상화한 존재. 크릭과 함께 1953년 DNA의 **이중나선 구조** 모형을 제안했고, 판지로 오려 낸
염기 모형을 짝지어 보다가 **A–T, G–C가 같은 모양으로 맞물린다**는 것을 발견했다. 이중나선 황궁 3보스 중 **왓슨 탑의 보스**(크릭 탑과 동급, 두 탑 중 하나).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 왓슨 · 크릭 · 프랭클린(DNA 이중나선 구조 발견)".
- [바이오스_이중나선황궁.md](../../디자인/던전/바이오스_이중나선황궁.md) §1, §6: 왓슨 탑 중간보스 "나선독수리병기" 처치 열쇠로 진입하는 염기 모형 조립실의 주인. 크릭 탑과 **순서 자유**.

### 포지션
이중나선 황궁 **중간 난이도**(왓슨 탑, 4페이즈). 두 탑 보스는 동급(왓슨 4P = 크릭 4P)이고 최종은 프랭클린 5P.
> **⚠ 게임적 설정**: 왓슨 탑 = DNA 한 가닥에 대응하는 게임용 해석.

## 2. 비주얼 명세

**컨셉(확정)**: 1950년대 케임브리지 신진 유전학자 + 염기 모형 장비. 1950년대 영국 케임브리지 캐번디시 연구소 시절의 신진 유전학자 복장(트위드 재킷·넥타이·말쑥한 신사)에
염기 모형 장비(판지 염기 카드·금속판 모형)를 갖춘 모습. 린네~피르호와 시대(1950년대)·직업(분자 유전학자)·장비(염기 모형)로 구분(오덤=20세기 중반 미국 생태학자·매클린톡=여성 유전학자와도 구별).

### 2-A 지금 (프리미티브 조립 — WatsonSetup.cs로 구현 가능)

```
왓슨 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 회색 트위드 재킷
├── Hair              Sphere(납작)  scale(0.55, 0.3, 0.55)  pos(0, 2.7, 0)  — 흩어진 머리
├── Tie               Cube(가늘고 긴)  scale(0.12, 0.5, 0.04)  pos(0, 1.7, 0.45)  — 넥타이(장식)
├── MetalPlate        Cube(소형 금속판)  pos(0.5, 1.3, 0.3)  — 손에 든 염기 금속판 모형(장식)
├── WeakPoint         (BossWeakPoint) pos(-0.55, 1.3, 0.1)  — 팔꿈치에 낀 염기 판지 카드 묶음
│   └── CardBundle    Cube(얇은 카드 4장)  scale 0.2  A·T·G·C 4색(초록·빨강·노랑·파랑)  Emission OFF→ON 노출 시
├── BaseEmitter       empty     pos(0, 0, 0)  — 염기 장판·수소결합선 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 염기 4색 — **A=초록, T=빨강, G=노랑, C=파랑** 원형 장판. 장판 쌍 사이에 **수소결합선**(점선)이 나타나면 결합 장판(위험), 선이 없으면 안전지대로 표시된다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 1950년대 케임브리지 신진 유전학자 — 트위드 재킷·넥타이·헝클어진 머리, 한 손에 염기 금속판 모형, 팔꿈치에 염기 판지 카드 묶음.
- **소품**: 팔꿈치의 염기 판지 카드 묶음(약점, 오려 낸 A·T·G·C 모양 카드), 염기 금속판 모형, 연구 노트(장식).
- **발광**: 카드 묶음 — 평상시 종이 질감, 노출 시 카드가 짝에 맞게 정렬되며 밝은 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 회색 재킷(#6A6A66) + 염기 A 초록(#5FA05A)/T 빨강(#C0392B)/G 노랑(#E8C84A)/C 파랑(#3E6CB0) + 밝은 Emission(#FFF8D8, 약점).
- **실루엣**: 키 약 3.0 Unity units. 팔꿈치의 카드 묶음과 금속판 모형이 상반신 실루엣을 특징짓는다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 염기 상보 안전지대 4단계 — 염기 상보 규칙(A↔T, G↔C)과 수소결합을 장판 규칙으로 옮긴다.
**핵심 규칙(사용자 확정)**: 쌍으로 나타나는 염기 중 **짝이 맞지 않는(비상보) 쌍은 수소결합이 형성되지 않으므로 그 사이가 안전지대**다. 짝이 맞는(상보) 쌍은 결합이 형성되어 결합 장판이 위험하다.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **염기**(A·T·G·C) | 4색 원형 장판 4개가 소환되어 **각각 위험** |
| P2 | **상보 결합** | 장판이 **쌍**으로 배치된다. **상보 쌍(A–T, G–C)** 은 **수소결합선**이 이어져 **선 위가 위험**, **비상보 쌍**(예: A–G, T–C)은 **결합선이 없어 쌍 사이가 안전지대** |
| P3 | **수소결합 수** | **A–T는 결합 2개**(얇은 선·피해 보통), **G–C는 결합 3개**(굵은 선·피해 큼). 비상보 쌍 사이 안전지대는 동일하게 안전 |
| P4 | **이중 가닥(이중나선)** | 쌍 장판들이 **두 가닥으로 감기며 회전**하고 **안전지대(비상보 쌍 사이)도 함께 회전** |

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `BasePairingPattern.asset` (신규) | **염기 상보 규칙·수소결합** | 염기 장판 쌍과 결합선, 결합 미형성 쌍 사이가 안전 | 판지 카드를 짝지어 허공에 늘어놓음 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 왓슨이 팔꿈치의 판지 카드를 꺼내 짝지으면 **염기 장판 쌍의 텔레그래프**가 나타난다(염기 색 장판 + 쌍 사이의 결합선 예고).
2. 플레이어는 쌍마다 **결합선이 있는지 없는지**를 읽어, **결합선이 없는(비상보) 쌍 사이 안전지대**로 이동한다.
3. 결합 장판이 발동되면 왓슨이 **카드 묶음을 짝 맞추며 확인**하는 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 규칙 | 시전 순환 |
|--------|----------|----------|
| P1 | 염기 | 염기 |
| P2 | + 상보 결합 | 염기 → 상보 → 염기 → 상보 … |
| P3 | + 수소결합 수 | 염기 → 상보 → 수소결합 → 염기 … |
| P4 | + 이중 가닥 | 염기 → 상보 → 수소결합 → 이중 가닥 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 작업대 앞에서 카드 정렬
- 모형 조립실 작업대 앞에서 거의 이동하지 않고 판지 카드를 짝지어 놓는 자세를 유지한다.
- 결합 장판 발동 후 **팔꿈치의 카드 묶음을 펼쳐 짝을 맞춰 보는** 모션 — 이때 팔꿈치가 플레이어 쪽으로 향한다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 카드 묶음에 새 규칙(상보 → 수소결합 → 이중 가닥) 아이콘이 표시되는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 염기 장판 | 시전 시작 | 4색 원형 `Quad` 장판 소환 |
| 상보 결합선 | P2~ | 상보 쌍 사이에 `LineRenderer` 결합선 + 선 폭의 장판. 비상보 쌍은 선 없음 |
| 수소결합 수 | P3~ | A–T 선 2줄(얇게), G–C 선 3줄(굵게) |
| 이중 가닥 회전 | P4 | 쌍 장판 전체를 두 가닥 나선으로 배치해 `Rotate`, 안전지대도 같은 회전 |
| 카드 정렬 | 장판 발동 직후 | 보스 모션 + `CardBundle` Emission On |

## 5. 약점 메커니즘

### 팔꿈치에 낀 염기 판지 카드 묶음 (BossWeakPoint)
- **위치(확정)**: 왼쪽 팔꿈치(localPos -0.55, 1.3, 0.1). 이미 쓴 부위(손·허리·어깨 위·등·가슴/품·머리 위·팔뚝·팔 안쪽·목·허벅지·종아리·이마)와 구분되는 **팔꿈치**.
- **노출 타이밍(확정)**: 수소결합 장판이 **발동한 직후**, 왓슨이 **카드 묶음을 짝 맞춰 보는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.2s). **크릭과 동일한 시간 기반 방식**으로 두 보스 난이도를 맞춘다. 노출 중에는 장판이 남아 있지 않다.
- **카드 단서**: 카드 묶음의 카드 구성이 페이즈마다 바뀌어(염기 → 상보 짝 → 결합선 → 이중 가닥) 현재 페이즈를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 종이 질감 → 노출 시 카드가 짝에 맞게 정렬되며 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 카드 묶음 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 나선독수리병기 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.

- [ ] **P4 전환**: HP 25% → 배너 + 두 가닥 회전(안전지대도 회전), 노출 1.2s.
