## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"자연은 아름다운 형태를 만든다 — 생물과 환경의 관계를 이름 붙이고 그려 낸다."**

19세기 독일의 생물학자 에른스트 헤켈(Ernst Haeckel)을 형상화한 존재. 1866년 "생태학(Ökologie)"이라는 용어를 만들어
생물과 환경의 관계를 다루는 학문의 이름을 붙였고, 방산충·해파리 등의 대칭미를 정밀한 도판으로 그린 『자연의 예술 형태』로 유명하다.
생태계 순환 대원 3보스 중 **"소비자" 링의 중간 난이도 보스**.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 훔볼트 · 헤켈 · 오덤(생물지리 개척 → '생태학' 용어 창시 →
  생태계를 하나의 시스템으로 체계화한 개념사 계보)".
- [바이오스_생태계순환대원.md](../../디자인/던전/바이오스_생태계순환대원.md) §1, §6: 소비자 링 중간보스 "군집사냥이리" 처치 열쇠로
  진입하는 생태학 도판 수족관의 주인. 진행 순서 ②번(훔볼트 처치 후 개방).

### 포지션
생태계 순환 대원 **중간 난이도**(소비자 링, 4페이즈). 난이도 계단: 훔볼트 3P → **헤켈 4P** → 오덤 5P.
> **⚠ 게임적 설정**: 헤켈=소비자 링은 개념사 계보를 영양 단계 순서에 맞춘 게임용 대응이다.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 후반 독일 교수 + 도판 화가 장비. 수염이 크고 단정한 독일 대학 교수 복장(정장 조끼)에 스케치북·연필·
현미경을 갖춘 모습. 린네(18세기 라플란드)·월리스(빅토리아시대 열대)·다윈(비글호 학자)·훔볼트(낭만주의 탐험가)와 시대·직업(교수·화가)·
장비(도판 화구)로 구분.

### 2-A 지금 (프리미티브 조립 — HaeckelSetup.cs로 구현 가능)

```
헤켈 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 남색 정장 조끼
├── Beard             Sphere(납작)  scale(0.55, 0.45, 0.4)  pos(0, 2.45, 0.35)  — 큰 수염
├── Sketchbook        Cube(소형)  scale(0.4, 0.5, 0.06)  pos(-0.5, 1.3, 0.25)  — 손에 든 스케치북(장식)
├── Pencil            Cylinder(가는)  scale(0.05, 0.3, 0.05)  pos(0.45, 1.4, 0.3)  — 연필(장식)
├── WeakPoint         (BossWeakPoint) pos(0, 4.0, 0)  — 머리 위에 떠 있는 살아있는 방산충 도판(액자)
│   └── RadiolarianPlate  Quad(액자형)+Sphere(방산충)  scale 0.6  Emission OFF→ON 노출 시
├── SymmetryEmitter   empty     pos(0, 0, 0)  — 방사대칭 장판 생성·회전 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 바닥에 방사형(별 모양) 장판 텔레그래프가 그려지고, 장판 개수가 페이즈마다 늘어난다. 약점 도판은 평상시
머리 위 높은 곳에 떠 있다가 노출 시 헤켈의 손 높이로 내려온다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 후반 독일 교수 — 정장 조끼·큰 수염·단정한 머리, 스케치북·연필·현미경.
- **소품**: 머리 위 떠 있는 방산충 도판 액자(약점, 정교한 방사형 골격 무늬), 스케치북, 연필, 현미경(장식).
- **발광**: 방산충 도판 — 평상시 은은한 푸른 빛, 노출 시 도판 전체와 방사 골격이 밝게 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 남색 조끼(#2E3A5C) + 도판 청록(#3E9C9A) + 양피지색(#E8DDB8) + 밝은 Emission(#BFF2EE, 약점).
- **실루엣**: 키 약 3.1 Unity units + 머리 위 떠 있는 도판으로 4~5 units 높이 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 방사대칭 도판 장판 — 『자연의 예술 형태』의 방사대칭 도판을 공격 장판 모양으로 직역. **대칭 수가 페이즈마다 증가**한다.
누적 디버프형(리히터·메르칼리)·교체형(다윈·훔볼트)과 달리 **"대칭 패턴 읽기"** 가 핵심이다.

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `RadialSymmetryPattern.asset` (신규) | **방사대칭**(방산충·해파리 도판의 대칭미) | 보스를 중심으로 방사형 장판(별·꽃 모양)이 그려지고 같은 각도 간격으로 발동 | 스케치북에 대칭 도형을 그리는 손짓 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 헤켈이 스케치북에 대칭 도형을 그리는 모션 → 바닥에 **방사형 장판 텔레그래프**(N개의 방사 빔)가 나타난다.
2. 일정 시간 후 모든 방사 빔이 **동시에 발동** — 플레이어는 빔 사이의 **안전 부채꼴**에 서 있어야 한다.
3. 장판 발동이 끝나면 **머리 위 도판이 내려온다**(헤켈이 도판을 손으로 받아 확인) — 이 동안 **약점 노출**(§5).
4. 도판이 올라가면 다음 시전.

### 페이즈별 규칙 (초안)
| 페이즈 | 방사 대칭 수 | 추가 요소 |
|--------|------------|----------|
| P1 | **4방향** | 빔 4개 — 안전 부채꼴 넓음 |
| P2 | **6방향** | 빔 6개 |
| P3 | **8방향** | 빔 8개 + 중심 원형 장판(헤켈 가까이 접근 불가) |
| P4 | **12방향** | 빔 12개 + 시전마다 **회전 각도 오프셋**(안전 부채꼴 위치가 매번 달라짐) + 외곽 동심원 링 장판 |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 중앙 고정, 도판 확인 시 도판이 하강
- 헤켈은 아레나 중앙 부근에서 거의 이동하지 않고 스케치북에 대칭 도형을 그리는 자세를 유지한다(방사 장판의 기준점이므로 중앙 고정).
- 장판 발동 후 머리 위 도판이 **천천히 내려와** 헤켈의 어깨 높이에서 잠시 멈춘다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 도판 속 방산충 무늬가 더 복잡한 새 대칭형으로 바뀌는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 방사 장판 | 시전 시작 | `SymmetryEmitter` 기준으로 N개의 빔(`Quad`)을 같은 각도 간격으로 배치·텔레그래프 후 발동 |
| 회전 오프셋 | P4 시전마다 | 빔 전체를 임의 각도로 회전(`transform.rotation`) |
| 도판 하강 | 장판 발동 종료 후 | `WeakPoint`를 Y 4.0 → 2.2로 `Lerp`, 노출 시간 동안 유지 후 복귀 |
| 도판 Emission | 하강 중 | `RadiolarianPlate` 머티리얼 Emission On |

## 5. 약점 메커니즘

### 머리 위에 떠 있는 살아있는 방산충 도판 (BossWeakPoint)
- **위치(확정)**: 평상시 헤켈의 머리 위(localPos 0, 4.0, 0) — 근접 공격으로는 닿기 어려운 높이.
- **노출 타이밍(확정)**: 방사대칭 장판이 한 번 발동하고 끝난 직후, 헤켈이 도판을 확인하려 **도판이 내려와** 어깨 높이(localPos 0, 2.2, 0)에서
  멈추는 동안 `SetExposed(duration)` 호출. duration은 §4 표(1.6s→1.0s). 내려오기 전에는 약점 판정이 없다.
- **공략 흐름**: 장판 발동 중에는 안전 부채꼴에서 버틴다 → 도판이 내려오는 순간 헤켈 가까이 접근해 공격. 중심 원 장판(P3~)이 있어도
  장판 발동이 끝난 뒤에는 소멸하므로 접근 가능하다.
- **시각 피드백**: 평상시 은은한 푸른빛 → 노출 시 도판과 방사 골격이 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 도판 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 군집사냥이리 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 4방향 방사 장판 텔레그래프→동시 발동, 안전 부채꼴 존재, 장판 종료 후 도판 하강 1.6s 노출(하강 전에는 판정 없음).
- [ ] **P2 전환**: HP 75% → 배너 + 6방향 장판, 노출 1.4s.
- [ ] **P3 전환**: HP 50% → 배너 + 8방향 + 중심 원 장판, 노출 1.2s.
- [ ] **P4 전환**: HP 25% → 배너 + 12방향 + 회전 오프셋 + 외곽 링, 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 분해자 링 게이트 개방 조건 충족.

## 11. 향후 확장

- **리깅 모션**: 스케치북에 그리는 손짓, 도판 받아 확인하는 모션, 수염 흔들림.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **도판 다양화**: 페이즈마다 도판 속 생물(방산충→해파리→…)이 바뀌고 장판 모양도 해당 생물의 대칭형을 따르는 확장안.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
