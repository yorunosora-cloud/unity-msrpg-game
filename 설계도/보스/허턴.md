## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"과정은 멈추지 않는다 — 느리게, 그러나 반드시."**

18세기 스코틀랜드의 지질학자 제임스 허턴(James Hutton)을 형상화한 존재. "지질학의 아버지"로
불리며, 현재 관찰되는 지질 작용(침식·퇴적)이 아주 오랜 시간에 걸쳐 지형을 만들었다는
동일과정설을 제창했다. 판구조 산맥 신전 3보스 중 "기초 이론" 단계 — 지질학이라는 학문
자체의 출발점을 상징하는, 가장 낮은 난이도의 관문.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 제임스 허턴
  (동일과정설, '지질학의 아버지') · 찰스 리히터(지진 규모) · 주세페 메르칼리(지진 진도,
  한국이 채택한 수정 메르칼리 진도)"
- [테라노바_판구조산맥신전.md](../../디자인/던전/테라노바_판구조산맥신전.md) §2, §6: 허턴
  갱도의 중간보스 "화석양서류"를 처치하면 얻는 열쇠로 진입하는 시커 포인트 부정합 관찰지
  아레나의 주인.

### 포지션
판구조 산맥 신전 3보스방 중 **가장 쉬움**. 미니보스 "화석양서류"의 패턴을 그대로 보스
규모로 확장한 것 외에 신규 패턴을 추가하지 않았다 — 난센·코페르니쿠스와 같은 "패턴 수
극단적 단순함" 철학을 이 던전에서도 반복해, 지구과학 대륙 마지막 랜드마크의 진입 관문
역할을 한다.

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — HuttonSetup.cs로 구현 가능)

```
허턴 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 갈색 프록코트
├── FieldCoat (Pivot) empty     pos(0, 1.5, 0)          — 야외 답사용 가죽 가방이 달린 코트 자락
│   └── CoatPanel×3    납작 Cube  각 scale(0.45, 1.3, 0.05)
├── RockHammer        Cylinder(망치 자루) + Cube(망치 머리) scale(0.15, 0.6, 0.15)  pos(0.5, 1.3, 0.2)  — 손에 든 암석망치
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.3, 0.3)  — 손에 든 암석망치(지질 답사 도구)
│   └── HammerGlow    Cube(소형)  scale 0.25  Color: 짙은 회색  Emission OFF→ON 노출 시
├── ErosionAnchor     empty     pos(0, 1.0, 0)          — 침식 장판 소환 자리
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 암석망치돌진은 원형 근접 텔레그래프, 침식장판은 지속형 원형 장판으로
표시 — 미니보스와 동일한 형태를 그대로 확대해 사용.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 18세기 신사 프록코트 + 가죽 야외 가방(답사 장비) 혼합 스타일 — 해들리와 유사한
  신사 계보이나 더 실용적이고 흙 묻은 질감.
- **소품**: 손에 든 암석망치(지질 답사 도구) — 약점 오브젝트.
- **발광**: 망치 머리 — 평상시 짙은 회색, 노출 시 밝은 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 짙은 갈색 코트(#4A3524) + 가죽 가방(#6B4A32) + 밝은 Emission(#B8A888, 약점) + 침식장판 흙갈색(#8A6F4A).
- **실루엣**: 키 약 3.0 Unity units. 3보스 중 가장 정직하고 소박한 실루엣.

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 느린 답사 이동
- 패턴 캐스팅 사이(idle 구간) 플레이어를 향해 저속으로 걸어 이동(~1.3 m/s) — 야외 답사를
  다니듯 침착하고 일정한 걸음걸이.

### 페이즈 전환
- P2·P3 진입 시 짧은 무적(~1초) + 배너와 동기화. 암석망치를 들어 지면을 가리키는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 코트 자락 흔들림 | 항상 | `Update()`: `CoatPanel[i].localRotation`을 `Mathf.Sin(Time.time*speed+i)`로 흔듦 |
| 암석망치돌진 경로 표시 | RockHammerCharge 캐스팅 중 | `ErosionAnchor`에 직선 텔레그래프 라인 렌더 |
| 망치 Emission | 돌진 종료 직후 | `HammerGlow` 머티리얼 Emission 짧게 On |

## 5. 약점 메커니즘

### 손에 든 암석망치 (BossWeakPoint)
- **위치**: 오른손(localPos 0.5, 1.3, 0.3).
- **노출 타이밍**: `RockHammerChargeHutton`이 끝나고 멈추는 순간 직후 자동
  `SetExposed(1.0f)` 호출 — 페이즈 무관 고정 1.0초, 매 돌진마다 반복.
- **시각 피드백**: 평상시 짙은 회색 → 노출 시 밝은 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 망치 약점(×3)과는 독립.
