## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"자연은 고도에 따라 층을 이룬다 — 모든 생명은 하나의 그물로 이어진다."**

18~19세기 독일의 박물학자 알렉산더 폰 훔볼트(Alexander von Humboldt)를 형상화한 존재. 남미 탐험(안데스 침보라소 산 등정)에서
고도에 따라 식생이 달라지는 것을 관찰·측정해 「자연도(Naturgemälde)」로 그렸고, 기후·식생·지형의 관계를 총체적으로 보는
생물지리학·생태학의 선구자다. 생태계 순환 대원 3보스 중 **"생산자" 링의 입문 관문**.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 훔볼트 · 헤켈 · 오덤(생물지리 개척 → 생태학 용어 창시 →
  생태계를 하나의 시스템으로 체계화한 개념사 계보)".
- [바이오스_생태계순환대원.md](../../디자인/던전/바이오스_생태계순환대원.md) §1, §6: 생산자 링 중간보스 "포식덩굴" 처치 열쇠로
  진입하는 자연도 고도대 전시실의 주인. 진행 순서 ①번.

### 포지션
생태계 순환 대원 **입문 관문**(생산자 링, 3페이즈). 난이도 계단: 훔볼트 3P → 헤켈 4P → 오덤 5P.
> **⚠ 게임적 설정**: 훔볼트=생산자 링은 개념사 계보를 영양 단계 순서에 맞춘 게임용 대응이다.

## 2. 비주얼 명세

**컨셉(확정)**: 낭만주의 탐험가 + 안데스 측정 장비. 19세기 초 낭만주의 시대 독일 귀족 탐험가의 긴 코트와 부츠에
기압계·온도계 등 측정 장비를 멘 모습. 이미 쓴 린네(라플란드)·월리스(빅토리아시대 열대)·다윈(비글호 학자)과 시대·국가·장비로 구분.

### 2-A 지금 (프리미티브 조립 — HumboldtSetup.cs로 구현 가능)

```
훔볼트 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 녹색 긴 코트
├── Hat               Cylinder(납작)+Cone  pos(0, 3.0, 0)  — 챙 넓은 탐험가 모자
├── Thermometer       Cube(소형)  scale 0.15  pos(0.5, 1.3, 0.25)  — 손에 든 온도계(장식)
├── Compass           Cylinder(납작)  scale 0.2  pos(-0.4, 1.9, 0.35)  — 목에 건 나침반(장식)
├── WeakPoint         (BossWeakPoint) pos(0, 1.7, -0.5)  — 등에 멘 휴대용 기압계
│   └── BarometerTube Cylinder(세로 가늘고 긴)  scale(0.12, 0.55, 0.12)  Color: 유리색  Emission OFF→ON 노출 시
│       └── MercuryColumn  Cylinder(안쪽 은색)  scale 가변 — 높이가 페이즈마다 낮아짐
├── AltitudeEmitter   empty     pos(0, 0, 0)  — 고도대 하자드 생성·환경 교체 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 아레나 바닥 색이 고도대별로 바뀐다(P1 짙은 초록 → P2 푸른 회색 안개 → P3 흰 설경). 하자드 텔레그래프는 해당
고도대 색으로 표시.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 낭만주의 시대 독일 귀족 탐험가 — 긴 코트·부츠·챙 넓은 모자, 등에 휴대용 수은 기압계, 목에 나침반, 허리에 온도계.
- **소품**: 휴대용 수은 기압계(약점, 길고 가는 유리관), 나침반, 온도계, 『자연도』 두루마리(장식).
- **발광**: 기압계 유리관 — 평상시 투명, 노출 시 수은 기둥과 유리가 밝게 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 짙은 녹색 코트(#2F4A3A) + 황동 장비(#B8924A) + 수은 은색(#C9CED6) + 밝은 Emission(#F2F0C8, 약점).
- **실루엣**: 키 약 3.1 Unity units. 등의 세로로 긴 기압계 튜브가 뒤에서 보면 가장 눈에 띄는 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 고도대 환경 교체 — 「자연도」의 고도별 식생대를 전장 환경으로 직역. 다윈의 부리 교체형과 같은 **교체형**이지만
공격 종류가 아니라 **아레나 환경 하자드**가 바뀐다.

| 페이즈 | 고도대 (게임적 설정) | 환경 하자드 | 기압계 수은 기둥 |
|--------|------------------|----------|----------------|
| P1 | **저지(열대 습지)** | 바닥에서 덩굴이 솟는 원형 장판(맞으면 이동속도 감소) | 꽉 참 |
| P2 | **산지(안개 숲)** | 안개 오버레이(시야 감소) + 낙엽이 떨어지는 원형 낙하 장판 | 중간 |
| P3 | **고산(한랭 동결)** | 바닥 일부가 얼어붙는 빙결 장판(위에서 이동 시 미끄러짐) + 정지 시 서리 피해 | 낮음 |

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `AltitudeBandPattern.asset` (신규) | **고도에 따른 식생대 분포(자연도)** | 아레나 환경이 고도대로 교체, 해당 고도대 하자드 발동 | 자연도 두루마리를 펼쳐 고도를 지시 |

### 동작 순서 (한 번의 시전)
1. 현재 고도대의 **환경 하자드**를 예고(텔레그래프)한 뒤 발동 — 플레이어는 안전 지대로 이동.
2. 하자드 사이클이 끝나면 훔볼트가 **그 자리에 정지**해 기압계를 확인하는 **측정 모션**에 들어간다. 이 동안 **약점 노출**(§5).
3. 측정 후 다음 사이클 시작. 각 페이즈는 같은 고도대의 하자드를 반복한다.

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 거의 정지, 측정 시 완전 정지
- 평상시 천천히 걸으며 측정 장비를 확인하는 자세. **측정 모션 중에는 완전히 고정**되어 등이 플레이어 쪽으로 향하지 않을
  수 있으므로, 측정 시작 시 몸을 약간 돌려 **등을 반쯤 노출**하는 모션을 둔다(접근 시간 확보).

### 페이즈 전환
- P2~P3 진입 시 짧은 무적(~1초) + 배너. 아레나 환경이 새 고도대로 서서히 교체되고 기압계 수은 기둥이 한 단계 내려간다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 환경 교체 | 페이즈 전환 | 아레나 바닥 `Quad` 머티리얼 색을 고도대 색으로 보간(초록→푸른 회색→흰색) |
| 하자드 발동 | 사이클 시작 | `AltitudeEmitter`가 고도대별 장판(덩굴/낙엽/빙결)을 지정 위치에 소환 |
| 수은 기둥 | 페이즈 전환 | `MercuryColumn` 스케일 Y를 페이즈별 값으로 감소 |
| 측정 모션 | 하자드 종료 후 | 보스 정지 + 몸 약간 돌리기 + `BarometerTube` Emission On(약점 노출) |

## 5. 약점 메커니즘

### 등에 멘 휴대용 기압계 (BossWeakPoint)
- **위치(확정)**: 등(localPos 0, 1.7, -0.5). **메르칼리(등 눈금판)와 부위가 겹치지만** 오브젝트(세로 유리관+수은 기둥)와 노출 방식(하자드
  종료 후 측정 모션)이 달라 구분된다.
- **노출 타이밍(확정)**: 고도대 하자드 사이클이 끝난 뒤 훔볼트가 **정지해 기압을 측정하는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.2s). 측정 중에는 보스가 고정되므로 플레이어가 등 쪽으로 돌아갈 시간이 확보된다.
- **고도 단서**: 수은 기둥 높이가 페이즈마다 낮아져 현재 고도대를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 투명 유리관 → 노출 시 수은 기둥과 유리가 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 기압계 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 포식덩굴 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 저지 환경(초록), 덩굴 장판 예고→발동, 사이클 종료 후 측정 모션 중 기압계 1.8s 노출(수은 기둥 꽉 참).
- [ ] **P2 전환**: HP 66% → 배너 + 환경 푸른 회색 + 안개/낙엽 하자드, 수은 기둥 하강, 노출 1.5s.
- [ ] **P3 전환**: HP 33% → 배너 + 환경 설경 + 빙결 장판(미끄러짐), 수은 기둥 최저, 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 하자드·환경 효과 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 소비자 링 게이트 개방 조건 충족.

## 11. 향후 확장

- **리깅 모션**: 코트 자락 흔들림, 측정 모션(기압계 확인), 나침반·온도계 사용 제스처.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **고도대 연출 강화**: 환경 교체 시 식생·하늘색·파티클(안개/눈)이 함께 전환되는 확장안.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
