> **수치 기준**: 모든 수치는 **Lv1 기준 값**이며 실제 값은 [21_던전-레벨-스케일링.md](../21_던전-레벨-스케일링.md)가 정한다(maxHp·def는 §4-4-bis 공통표).

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"무기물에서 유기물이 태어난다 — 같은 원자도 배열이 바뀌면 다른 물질이 된다."**

19세기 독일의 화학자 프리드리히 뵐러(Friedrich Wöhler)를 형상화한 존재. 1828년 무기 화합물인 **시안산암모늄**을 가열해 생물이 만드는 물질로 여겨지던 **요소**를 얻었다.
두 물질은 원자의 종류와 수가 같고 배열만 다른 **이성질체**다. 유기화학의 출발점으로 꼽히며, 벤젠의 육각 신전 3보스 중 **합성 구역의 입문 관문**이다.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "벤젠의 육각 신전 보스: 케쿨레 · 뵐러 · 폴링".
- [알케미아_벤젠육각신전.md](../../디자인/던전/알케미아_벤젠육각신전.md) §1, §2: 합성 구역 중간보스 "흑연 골렘" 처치 후 진입하는 합성 실험실의 주인. 진행 순서 ①번(역사순).

### 포지션
벤젠의 육각 신전 **입문 관문**(합성 구역, 3페이즈). 난이도 계단: **뵐러 3P** → 케쿨레 4P → 폴링 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 독일 화학자 + 증발 접시·결정 장비. 19세기 초 독일 학자 복장(높은 깃 코트)에 요소 결정이 자라는 증발 접시와 알코올 램프를 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — WohlerSetup.cs로 구현 가능)

```
뵐러 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 녹색 코트
├── Hair              Sphere(납작)  scale(0.55, 0.32, 0.55)  pos(0, 2.7, 0)
├── Collar            Cube×2(소)  pos(±0.25, 2.25, 0.4)  — 높은 깃
├── SpiritLamp        Cylinder+작은 불꽃 Sphere  pos(-0.55, 1.35, 0.35)  — 알코올 램프(장식)
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.45, 0.4)  — 손에 든 증발 접시
│   └── Dish          Cylinder(납작)  scale(0.4, 0.05, 0.4)  Emission OFF→ON 노출 시
│       └── Crystals  Cube(작음, 기울임)×N  — 페이즈마다 늘어나는 요소 결정
├── SynthesisEmitter  empty     pos(0, 0, 0)  — 이온·열·원자 장판 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 암모늄 이온=파란 장판(+), 시안산 이온=붉은 장판(−), 가열=주황 파동선, 원자=색 구슬 장판(N 파랑·C 검정·O 빨강·H 흰색).

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 독일 화학자 — 녹색 높은 깃 코트, 한 손에 증발 접시, 다른 손에 알코올 램프.
- **소품**: 증발 접시(약점, 바늘 모양 요소 결정), 알코올 램프.
- **발광**: 결정 — 평상시 흰색, 노출 시 밝은 청백색 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 코트 녹색(#2F4A38) + 접시 도자기(#EDE8DC) + 결정 청백(#E8F6FF) + 불꽃 주황(#E8823C) + 바로크 금(#C9A646).
- **실루엣**: 키 약 3.0 Unity units. 앞으로 받쳐 든 접시와 램프 불빛이 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 요소 합성 과정 — 이온 결합 → 가열 → 원자 재배열, 누적.

| 페이즈 | 추가되는 단계 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **이온 결합** | 암모늄(+, 파랑) 장판과 시안산(−, 빨강) 장판이 **서로 끌려와** 만나는 자리에서 발동 |
| P2 | **가열** | **열 파동선**이 아레나를 훑고 지나가며, 먼저 터진 장판 자리가 **다시 끓어올라** 한 번 더 발동 |
| P3 | **원자 재배열** | **원자 구슬 8개**(N 2 · C 1 · O 1 · H 4)가 시안산암모늄 배열에서 **요소 배열**로 미끄러져 옮겨간 뒤 발동 — 원자 수는 그대로 |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `UreaSynthesisPattern.asset` (신규) | **요소 합성**(이온 화합물·가열·이성질화) | 이온·열·원자 장판 | 접시를 램프 불에 가져감 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 뵐러가 램프로 접시를 달구면 **텔레그래프**가 나타난다(다가오는 두 이온 / 열 파동 경로 / 원자 구슬의 도착 위치).
2. 플레이어는 단계별 규칙에 따라 피한다.
   - 이온: 두 장판이 **만나는 지점**을 벗어난다.
   - 가열: 파동선을 피한 뒤 **방금 터진 자리**로 돌아가지 않는다.
   - 재배열: 지금 위치가 아니라 **요소 모양으로 옮겨갈 위치**(가운데 C, 위 O, 양옆 NH₂)를 보고 피한다.
3. 장판 발동 직후 **접시에 요소 결정이 맺히는 동안 약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 단계 | 시전 순환 |
|--------|----------|----------|
| P1 | 이온 결합 | 이온 |
| P2 | + 가열 | 이온 → 가열 … |
| P3 | + 원자 재배열 | 이온 → 가열 → 재배열 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 실험대 앞에서 접시를 달굼
- 합성 실험실의 실험대 앞에서 거의 이동하지 않고 램프로 접시를 달구는 자세를 유지한다.
- 장판 발동 후 **접시를 눈높이로 들어 결정을 확인하는** 모션 — 이때 접시가 플레이어가 접근 가능한 높이로 올라온다.

### 페이즈 전환
- P2~P3 진입 시 짧은 무적(~1초) + 배너. 접시의 결정이 한 단계 자란다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 이온 접근 | P1~ | 파랑·빨강 `Quad`가 `Lerp`로 접근해 합쳐지며 폭발 |
| 열 파동 | P2~ | 주황 선 `Quad` 이동, 지나간 장판 위치에 1.0s 뒤 재폭발 |
| 원자 재배열 | P3 | 원자 구슬 8개 `Lerp` 이동(0.9s) 후 도착 위치 폭발 |
| 결정 확인 | 장판 발동 직후 | 보스 모션 + `Crystals` Emission On |

## 5. 약점 메커니즘

### 요소 결정이 담긴 증발 접시 (BossWeakPoint)
- **위치(확정)**: 왼손에 받쳐 든 증발 접시(localPos 0.5, 1.45, 0.4).
- **노출 타이밍(확정)**: 장판이 **발동한 직후**, 접시에 **결정이 맺히는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s). 시간 기반이라 입문 관문에 단순하며 노출 중에는 장판이 남아 있지 않다.
- **결정 단서**: 결정의 크기가 페이즈를 알려 준다.
- **시각 피드백**: 평상시 흰 결정 → 노출 시 청백색 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 접시 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 흑연 골렘 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 두 이온 장판이 다가와 합쳐지며 발동, 종료 직후 접시 1.8s 노출.
- [ ] **P2 전환**: HP 66% → 배너 + 열 파동과 재폭발, 노출 1.5s.
- [ ] **P3 전환**: HP 33% → 배너 + 원자 구슬 8개 재배열 후 발동, 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 구조 구역 게이트 개방 조건 충족.
