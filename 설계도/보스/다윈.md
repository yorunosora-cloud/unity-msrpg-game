> **위치**: `설계도/보스/다윈.md`
> **역할**: [07_보스전.md](../07_보스전.md) 공통 템플릿을 다윈에 실제로 어떻게 구체화할지 명세.
> [린네.md](린네.md)·[월리스.md](월리스.md)·[메르칼리.md](메르칼리.md)와 동일한 구조를 따른다.
> **범위**: 다윈 보스 본체 + 갈라파고스 섬 아레나만. 던전 전체 구조는
> [바이오스_진화의도원.md](../../디자인/던전/바이오스_진화의도원.md) 소관.

> **확정/초안 구분**: 비주얼 컨셉·5페이즈·약점(어깨 위 핀치, 부리가 페이즈마다 변함)·패턴 방향(부리 형태별
> 패턴 교체+마지막 통합)·노출 타이밍(핀치가 어깨로 복귀할 때)은 사용자 확정. 패턴 세부·수치·대사는 **초안**.
> **레벨 스케일링**: maxHp/def 및 패턴 수치는 스케일링 **기준값**([[dungeon_level_scaling_rule]]).
> **⚠ 게임적 설정 표시**: 갈라파고스 핀치의 부리가 먹이에 따라 분화한 것은 실제 진화생물학 사례이나, "부리
> 형태마다 보스의 공격 방식이 달라진다", "핀치가 날아올라 공격한다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"환경에 맞게 변한 자가 살아남는다 — 자연선택에 의한 진화."**

19세기 영국의 박물학자 찰스 다윈(Charles Darwin)을 형상화한 존재. 비글호 항해에서 갈라파고스 섬의
핀치·거북 등을 관찰했고, 1858년 월리스와 자연선택설을 공동 발표한 뒤 1859년 『종의 기원』을
출간했다. 진화의 도원 3보스 중 **"진화"** 단계 — 린네의 분류, 월리스의 분포 위에 "왜 그렇게 되었는가"를
더하는 **최종 보스**. 겨울에서 시간을 거슬러 올라 도달한 **봄 = 기원(起源)** 의 주인.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "다윈 · 월리스 · 린네(1858년 공동 발표한 자연선택설 + …)".
- [바이오스_진화의도원.md](../../디자인/던전/바이오스_진화의도원.md) §1, §6: 봄 구역 중간보스 "개화포자모체"
  처치 열쇠로 진입하는 갈라파고스 섬의 주인. 진행 순서 ③번(월리스 처치 후 개방).

### 포지션
진화의 도원 **최고 난이도**(봄, 5페이즈). 난이도 계단: 린네 3P → 월리스 4P → **다윈 5P**.

## 2. 비주얼 명세

**컨셉(확정)**: 비글호 시절의 학자 + 핀치 무리. 1830년대 영국 해군 탐사선 비글호에 승선한 젊은 신사 학자의
복장(더블 코트·수첩)에, 부리 모양이 제각각인 핀치들이 주변을 도는 모습. 린네(18세기 라플란드 복장),
월리스(빅토리아시대 열대 탐험가)와 시대·분위기로 구분.

### 2-A 지금 (프리미티브 조립 — DarwinSetup.cs로 구현 가능)

```
다윈 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 남색 더블 코트
├── Hat               Cylinder(납작)  pos(0, 3.0, 0)  — 비글호 시절 모자
├── Notebook          Cube(소형)  scale(0.3, 0.4, 0.06)  pos(-0.5, 1.3, 0.2)  — 손에 든 수첩(장식)
├── FinchPerch        empty     pos(0.55, 2.4, 0.1)  — 어깨 위 핀치 안착 자리
│   └── WeakPoint     (BossWeakPoint) — 약점 핀치 본체
│       └── FinchBody Sphere(소형)+Cone(부리)  scale 0.3  Color: 올리브 갈색  Emission OFF→ON 노출 시
├── FinchFlock×4      Sphere(소형)+Cone  보스 주변을 도는 장식용 핀치(전투 판정 없음)
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**부리 식별 시각**: 어깨 핀치의 부리(`Cone`)가 페이즈마다 모양·색이 바뀐다 — 두껍고 짧음 → 뾰족함 →
가늘고 긺 → 집게형 → (P5) 부리가 4개 형태를 번갈아 변함.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 1830년대 영국 신사 학자 — 남색 더블 코트·모자·수첩, 어깨에 핀치, 주변에 부리 모양이 서로 다른
  핀치 무리.
- **소품**: 손에 든 수첩(생명의 나무 스케치 장식), 어깨의 핀치(약점).
- **발광**: 핀치 — 평상시 올리브 갈색, 노출 시 몸 전체가 밝은 Emission + 부리 끝 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 남색 코트(#2F3A55) + 도화 분홍(#F4B6C2) + 핀치 올리브(#7A7A4A) + 밝은 Emission(#F9D98A, 약점).
- **실루엣**: 키 약 3.2 Unity units. 어깨의 새와 주변 핀치 무리로 3보스 중 가장 화려한 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 부리 형태별 패턴 교체 + 마지막 통합 — 자연선택으로 형질이 환경에 맞게 분화하는 과정을
"페이즈마다 보스의 공격 방식이 바뀌는 것"으로 직역. 누적형(리히터·메르칼리)과 달리 **교체형**.

| 페이즈 | 부리 형태 (게임적 설정) | 패턴 에셋 | 공격 방식 |
|--------|--------------------|----------|----------|
| P1 | 두껍고 짧은 부리 (씨앗 깨기형) | `BeakCrushPattern` | 지정 지점 충격 원형 장판 |
| P2 | 뾰족한 부리 (찌르기형) | `BeakPierceDash` | 직선 돌진 장판 + 돌진 후 짧은 경직 |
| P3 | 가늘고 긴 부리 (원거리형) | `BeakLongShot` | 직선 관통 탄(부채꼴 3발) |
| P4 | 집게형 부리 (도구 사용형) | `BeakPullGrab` | 플레이어를 보스 쪽으로 끌어당기는 인력 장판 + 근접 충격 |
| P5 | 통합 (4형태 순환) | 위 4종 전부 | 4패턴을 순서 없이 빠르게 교체, 핀치 부리가 매번 변함 |

> 패턴 구현은 부리별 개별 클래스 4종 또는 `BeakFormPattern` 한 클래스에 부리 종류 파라미터를 두는 방식
> 모두 가능(구현 단계에서 결정). 각 패턴은 07 §3-7 텔레그래프 동작을 따른다.

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 걸으며 관찰, 핀치가 공격을 대신
- 다윈 본체는 거의 이동하지 않고 수첩에 기록하는 자세를 유지. **공격의 시각적 주체는 어깨의 핀치**
  (핀치가 날아올라 부리 형태에 맞는 공격을 하고 돌아옴).

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 핀치의 부리가 새 형태로 변하는 연출(작은 광채 + 부리 모양 아이콘).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 핀치 비행 | 패턴 시전 중 | `FinchPerch`에서 `WeakPoint`가 이동·공격 후 복귀(`Lerp` 경로) |
| 부리 변화 | 페이즈 전환 | `Cone` 메시/스케일/색을 페이즈별로 교체 |
| 핀치 무리 | 항상 | 장식 핀치 4마리가 `Mathf.Sin`으로 보스 주변을 선회 |
| 핀치 Emission | 복귀 후 노출 중 | `FinchBody` 머티리얼 Emission On |

## 5. 약점 메커니즘

### 어깨 위의 핀치 (BossWeakPoint — 살아 움직이는 약점)
- **위치(확정)**: 평상시 다윈의 어깨(FinchPerch, localPos 0.55, 2.4, 0.1). 패턴 시전 중에는 핀치가
  날아올라 이동하므로 이 동안 **약점 판정 없음**.
- **노출 타이밍(확정)**: 핀치가 부리 형태에 맞는 공격을 수행한 뒤 **다윈의 어깨로 복귀하는 순간**
  `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.0s). 핀치가 날아다니는 동안은 노출되지 않는다.
- **부리 변화**: 핀치의 부리 형태가 페이즈마다 바뀌어 현재 패턴을 알려주는 **공략 단서**가 된다.
- **P5**: 4형태를 번갈아 쓰므로 복귀 직전 부리 형태를 보고 다음 패턴을 예측해야 한다.
- **시각 피드백**: 평상시 올리브 갈색 → 노출 시 핀치 전신 밝은 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 핀치 약점(×3)과는 독립.

- **갈라파고스 섬**: 검은 화산암 해안 위에 도화가 만개한 봄의 섬, 거북과 핀치가 곳곳에, 먼 바다에 비글호의 실루엣.
- **전환 연출**: 페이즈 전환마다 해당 부리 모형이 빛나며 핀치의 부리가 그 형태로 변한다.

## 9. 보상 · 클리어 연동

처치 흐름: `Boss.OnDefeated` → `BossMission.OnBossDefeated` → 던전 클리어 처리(07 §3-10 공통).
다윈은 진화의 도원의 **마지막 보스**(가을→여름→봄 고정 순서의 종착) — 처치 시 던전 완전 클리어.
드랍·보상 세부는 02_던전-스테이지-템플릿.md 소관. 초안 제안:
- **전리품 후보**: 핀치 부리 표본(연구자원), 『종의 기원』 초판 파편(장비 재료?).
- 바이오스 대륙의 **첫 던전 클리어**이므로 레벨 스케일링 하한 카운트([[dungeon_level_scaling_rule]])에 반영.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 개화포자모체 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 두꺼운 부리 + 충격 장판, 핀치 복귀 시 1.8s 노출 확인(비행 중 약점 판정 없음).
- [ ] **P2 전환**: HP 80% → 배너 + 뾰족한 부리·돌진, 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + 가는 부리·관통 탄, 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + 집게형 부리·인력 장판, 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 4패턴 순환, 부리 변화, 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.

## 11. 향후 확장

- **리깅 모션**: 핀치 비행 궤적·날갯짓, 수첩 기록 제스처, 코트 흔들림.

- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
