## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"모든 세포는 세포로부터 나온다 — 생명도 병도 세포의 분열에서 시작된다."**

19세기 후반 독일의 병리학자 루돌프 피르호(Rudolf Virchow)를 형상화한 존재. 1855년 **"모든 세포는 세포로부터"**(Omnis cellula e cellula)를 선언해 세포설을 완성하고,
병이 장기가 아니라 **세포의 이상**에서 비롯된다는 세포병리학을 세웠다. 해부학의 지하 성역 3보스 중 **최종 보스**(세포설 계보의 마지막, 세포 수준).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 슐라이덴 · 슈반 · 피르호(세포설 3단계: 식물세포설 → 동물세포설 → '세포는 세포로부터')".
- [바이오스_해부학지하성역.md](../../디자인/던전/바이오스_해부학지하성역.md) §1, §6: 세포 수준 중간보스 "분열세포모형" 처치 열쇠로 진입하는 병리 해부 강당의 주인. 진행 순서 ③번(슈반 처치 후 개방).

### 포지션
해부학의 지하 성역 **최고 난이도**(세포 수준·세포 분열 구역, 5페이즈). 난이도 계단: 슐라이덴 3P → 슈반 4P → **피르호 5P**.
> **⚠ 게임적 설정**: 피르호=세포 수준(세포 분열)은 세포설 계보 순서와 확대 깊이를 맞춘 게임용 대응이다.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 후반 독일 병리학자 + 병리 해부 장비. 1860~70년대 베를린 병리학자 복장(검은 재킷·실험 앞치마)에 병리 해부 장비(메스·현미경·장기 표본 용기)를 갖춘 모습.
린네~슈반과 시대(19세기 후반)·직업(병리학자)·장비(병리 해부 도구)로 구분(헤켈=19세기 후반 독일 교수·도판 화가와도 직업·장비로 구별).

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 후반 독일 병리학자 — 검은 재킷·흰 앞치마·단정한 머리, 이마에 원형 반사경(진단용), 한 손에 메스·다른 손에 장기 표본 용기.
- **소품**: 이마의 원형 반사경(약점), 메스, 장기 표본 용기, 현미경(장식).
- **발광**: 반사경 — 평상시 은은한 금속빛, 노출 시 반사경이 세포를 비추며 밝은 빛과 함께 반사경 속에 세포 분열상이 비침.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 검은 재킷(#2B2B30) + 흰 앞치마(#EDEDE8) + 세포 분홍(#E8A0B8) + 염색체 보라(#7A4A9C) + 밝은 Emission(#FFF1E0, 약점).
- **실루엣**: 키 약 3.2 Unity units. 이마의 반사경과 흰 앞치마로 3보스 중 가장 의사·병리학자다운 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 세포 분열 5단계 장판 — 세포 분열의 5단계(간기→전기→중기→후기→말기)를 5페이즈에 정확히 대응시킨다. **누적형**이며 "세포는 세포로부터"를 업적 그대로 전투로 바꾼다.

| 페이즈 | 추가되는 분열 단계 | 장판 규칙 (게임적 설정) |
|--------|----------------|----------------------|
| P1 | **간기**(DNA 복제) | 원형 장판이 발동한 뒤 **같은 위치에서 한 번 더 발동**(복제) |
| P2 | **전기**(염색체 응축) | **X자 막대 장판**이 가늘고 진하게 **응축**된 뒤 발동 |
| P3 | **중기**(적도판 정렬) | 아레나 **중앙 적도 띠**에 염색체가 **일렬 정렬**, 띠 위가 위험(좌우 가장자리 안전) |
| P4 | **후기**(염색분체 분리) | 중앙 장판이 **둘로 갈라져 양쪽 극으로 이동**, 경로 위가 위험 |
| P5 | **말기·세포질 분열** | 아레나 중앙에서 바깥으로 **분열선이 번지며 두 구획**으로 나뉨(분열선 위 위험, 두 구획 안은 안전) |

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `CellDivisionPattern.asset` (신규) | **세포 분열(세포는 세포로부터)** | 분열 단계별 장판이 순서대로 발동 | 반사경을 비추며 세포 분열 도형을 그림 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 피르호가 메스로 허공에 분열 도형을 그리면 **분열 단계별 장판 텔레그래프**가 나타난다.
2. 플레이어는 장판의 **복제·응축·정렬·분리·분열선**을 읽어 안전한 위치로 이동한다.
   - 간기: 첫 발동 후 **한 번 더 발동**하므로 첫 발동 직후에도 자리를 벗어나 있어야 한다.
   - 전기: 응축되어 **가늘어진 막대 사이**가 안전하다.
   - 중기: 중앙 띠 **좌우 가장자리**에 선다.
   - 후기: 갈라져 이동하는 장판의 **경로 바깥**으로 피한다.
   - 말기: 분열선이 번지기 전 **한쪽 구획 안**으로 이동한다.
3. 분열 장판이 모두 발동되면 피르호가 **이마의 반사경으로 세포를 비춰** 진단한다 — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 단계 | 시전 순환 |
|--------|----------|----------|
| P1 | 간기 | 간기 |
| P2 | + 전기 | 간기 → 전기 → 간기 → 전기 … |
| P3 | + 중기 | 간기 → 전기 → 중기 → 간기 … |
| P4 | + 후기 | 간기 → 전기 → 중기 → 후기 → 간기 … |
| P5 | + 말기 | 간기 → 전기 → 중기 → 후기 → 말기 (분열 1주기 완성) |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 강당 중앙에서 진단
- 병리 해부 강당 중앙에서 거의 이동하지 않고 메스로 허공에 도형을 그리는 자세를 유지한다.
- 분열 장판 발동 후 **이마의 반사경을 내려 빛을 비추며 세포를 들여다보는** 모션을 취한다 — 이때 반사경이 정면의 접근 가능한 높이로 내려온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 반사경에 비치는 세포 상이 다음 분열 단계로 바뀌는 연출(간기 핵 → 응축 염색체 → 적도판 정렬 → 양극 이동 → 두 세포).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 간기 복제 | P1~ | 원형 장판 발동 후 같은 위치에 0.8s 뒤 재발동 |
| 전기 응축 | P2~ | X자 막대 `Quad`의 폭을 2.0 → 1.0으로 줄이며 발동 |
| 중기 적도 띠 | P3~ | 아레나 중앙을 가로지르는 띠 장판 + 점(염색체) 일렬 배치 |
| 후기 분리 | P4~ | 중앙 장판이 두 개로 나뉘어 양쪽으로 `Lerp` 이동(경로 위 피해) |
| 말기 분열선 | P5 | 중앙에서 바깥으로 선형 장판이 번지며 두 구획 생성 |
| 반사경 진단 | 장판 발동 직후 | 보스 모션 + `HeadMirror` Emission On |

## 5. 약점 메커니즘

### 이마에 단 반사경 (BossWeakPoint)
- **위치(확정)**: 이마(localPos 0, 2.85, 0.35). 이미 쓴 부위(손·허리·어깨 위·등·가슴/품·머리 위·팔뚝·팔 안쪽·목·허벅지·종아리)와 구분되는 **이마**.
- **노출 타이밍(확정)**: 분열 장판이 모두 발동한 **직후**, 피르호가 **이마의 반사경으로 세포를 비춰 진단하는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.0s). 노출 중에는 장판이 남아 있지 않다. 시간 기반이라 다른 최종 보스보다 노출 규칙은 단순하고, **5페이즈·장판 복잡도**가 난이도를 책임진다.
- **세포 상 단서**: 반사경에 비치는 세포 상이 페이즈마다 바뀌어(간기 핵 → 응축 염색체 → 적도판 정렬 → 양극 이동 → 두 세포) 현재 페이즈를 알려 준다.
- **시각 피드백**: 평상시 은은한 금속빛 → 노출 시 반사경이 밝게 빛나며 반사경 속에 세포 분열상이 비친다.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 반사경 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 분열세포모형 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 간기 장판 발동 후 같은 위치 재발동(복제), 종료 직후 반사경 1.8s 노출.
- [ ] **P2 전환**: HP 80% → 배너 + X자 막대 응축 발동, 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + 중앙 적도 띠(좌우 가장자리 안전), 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + 장판이 둘로 갈라져 양극 이동, 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 분열선이 번지며 두 구획(구획 안 안전), 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
