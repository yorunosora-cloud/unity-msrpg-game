## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"이름을 붙이고, 질서 있게 나눈다 — 분류가 곧 이해다."**

18세기 스웨덴의 박물학자 칼 폰 린네(Carl von Linné)를 형상화한 존재. 속명+종명의 이명법으로
생물에 학명을 붙이고 계-강-목-속-종의 위계로 분류하는 체계를 확립해 "분류학의 아버지"로
불린다. 진화의 도원 3보스 중 "분류" 단계 — 다윈의 자연선택 이전에 생물을 질서 있게 나누는
기초를 놓은 **입문 관문**.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: 진화의 도원 보스 "다윈 · 월리스 ·
  린네 (1858년 공동 발표한 자연선택설 + 근대 분류학의 아버지)".
- [바이오스_진화의도원.md](../../디자인/던전/바이오스_진화의도원.md) §1, §6: 가을 구역의 중간보스
  "저장열매갑충"을 처치해 얻은 열쇠로 진입하는 표본실의 주인. 진행 순서 ①번.

### 포지션
진화의 도원 **입문 관문**(가을, 3페이즈). 난이도 계단: 린네 3P → 월리스 4P → 다윈 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 라플란드 탐험 복장 + 식물 채집 장비. 린네가 실제로 남긴 유명한 초상화의
라플란드 탐험 복장(털 달린 외투, 사미족 스타일 모자)에 확대경과 식물 채집통을 든 모습.

### 2-A 지금 (프리미티브 조립 — LinnaeusSetup.cs로 구현 가능)

```
린네 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 청회색 털 외투
├── Hat               Cylinder(납작)+Cone  pos(0, 3.0, 0)  — 라플란드 스타일 모자
├── FurCollar         Sphere(납작)  scale(1.2, 0.3, 1.2)  pos(0, 2.3, 0)  — 털 칼라
├── VasculumBag       Cylinder(누운)  scale 0.25  pos(-0.5, 1.2, 0)  — 허리의 식물 채집통(장식)
├── WeakPoint         (BossWeakPoint) pos(0.55, 1.6, 0.35)  — 손에 든 확대경(루페)
│   └── LoupeGlass    Cylinder(납작, 렌즈형)  scale 0.35  Color: 연한 유리색  Emission OFF→ON 노출 시
├── SpecimenAnchor×N  empty     필드 곳곳  — 표본 소환 자리
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 표본마다 색(주황/초록/보라 등)이 다르고, 같은 색끼리 보스가 선(분류 라인)으로
묶는다. 선이 완성되면 해당 그룹이 폭발.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 18세기 스웨덴 학자 + 라플란드 탐험 복장 혼합 — "숲을 걸으며 이름을 붙이는 박물학자".
- **소품**: 손에 든 황동 확대경, 허리의 식물 채집통, 『자연의 체계』 두루마리(장식).
- **발광**: 확대경 렌즈 — 평상시 투명, 노출 시 밝은 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 청회색 외투(#4A5568) + 황금 가을색(#D8A23A) + 밝은 Emission(#F5E6B0, 약점).
- **실루엣**: 키 약 3.0 Unity units. 허리 채집통과 모자로 3보스 중 가장 소박한 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 표본 분류 패턴 — 분류학의 핵심 행위("나누고 묶는다")를 전투 규칙으로 직역.

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `SpecimenSortingPattern.asset` (신규) | **분류(위계 체계)** — 비슷한 것끼리 묶어 계층으로 정리 | 색이 다른 표본 소환 → 같은 색끼리 선으로 묶임 → 완료 시 그룹 폭발 | 확대경으로 표본을 하나씩 살피며 손짓으로 분류 |

### 동작 순서 (한 번의 시전)
1. 필드에 색이 다른 표본(식물)이 소환된다(표본 수·색 종류는 페이즈별 증가, §4).
2. 보스가 같은 색끼리 **분류 라인**으로 묶는다(분류 진행 게이지 표시, 제한 시간 T초).
3. T초 안에 **플레이어가 표본을 공격해 정리(파괴)** 하면 그 표본은 분류에서 빠지고 폭발 불발.
4. 분류가 완료되면 남은 그룹이 폭발 — **그룹 내 남은 표본 수가 많을수록 폭발 반경·피해가 큼.**
5. **이번 시전의 표본을 전부 정리(파괴)하면** 린네가 "분류가 틀렸다"며 확대경으로 다시 살피는
   상태가 되어 **약점이 노출**된다(§5).

> 신규 패턴 클래스 필요. 미니보스 `저장열매갑충`과는 별개 패턴(입문 관문이라도 린네의 정체성인
> '분류'를 직접 구현하기 위해 신규로 설계).

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 제자리에서 관찰·분류
- 패턴 시전 중 거의 이동하지 않고 확대경으로 표본을 하나씩 살피는 자세를 유지.
- 분류 라인이 연결될 때 손짓으로 선을 긋는 모션.

### 페이즈 전환
- P2~P3 진입 시 짧은 무적(~1초) + 배너. 새 색의 표본이 처음 등장하는 연출("새로운 종 발견" 아이콘).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 분류 라인 | 분류 진행 중 | `LineRenderer`로 같은 색 표본 사이를 연결 |
| 폭발 | 분류 완료 시 | 그룹 중심에 원형 장판 생성(반경 = 기본 + 남은 표본 수 × 계수) |
| 확대경 Emission | 약점 노출 중 | `LoupeGlass` 머티리얼 Emission On |

## 5. 약점 메커니즘

### 손에 든 확대경(루페) (BossWeakPoint)
- **위치(확정)**: 오른손 앞(localPos 0.55, 1.6, 0.35).
- **노출 타이밍(확정)**: 플레이어가 **이번 시전의 표본을 전부 정리**하면 린네가 분류 오류를 확인하려
  확대경을 들어 올려 `SetExposed(duration)` 호출 — duration은 §4 표(1.6s→1.2s).
- **능동 조건**: 허턴(돌진 종료 직후)·리히터(최고 등급 발동 직후)처럼 시간에 맞춰 기다리는
  방식이 아니라 **플레이어의 정리 행동이 조건**. 표본을 못 정리하면 노출 기회 없음.
- **시각 피드백**: 평상시 투명 렌즈 → 노출 시 밝은 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 확대경 약점(×3)과는 독립.

- [ ] **불완전 정리**: 일부만 정리 시 남은 표본 수에 따라 폭발 반경·피해 증가, 노출 없음 확인.
- [ ] **P2 전환**: HP 66% → 배너 + 표본 6개(3색), 노출 1.4s.
- [ ] **P3 전환**: HP 33% → 배너 + 표본 8개(4색), 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 표본 전부 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 여름 가지 게이트 개방 조건 충족.

## 11. 향후 확장

- **리깅 모션**: 확대경 들어올리기, 분류 라인 긋는 손짓, 털 칼라 흔들림.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **위계 시각화 강화**: 폭발 그룹을 계·강·목·속·종 단계로 색·크기 차등화하는 확장안.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
