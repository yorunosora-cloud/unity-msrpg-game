# 분젠 보스 구현 설계도

> **위치**: `설계도/보스/분젠.md`
> **역할**: [07_보스전.md](../07_보스전.md) 공통 템플릿을 분젠에 실제로 어떻게 구체화할지 명세.
> [아레니우스.md](아레니우스.md)·[랭뮤어.md](랭뮤어.md)와 동일한 구조를 따른다.
> **범위**: 분젠 보스 본체 + 불꽃 실험실 아레나만. 던전 전체 구조는
> [알케미아_분광분석등대.md](../../디자인/던전/알케미아_분광분석등대.md) 소관.
> **비주얼 명세 원칙**: 모든 비주얼·아레나 섹션은 **① 지금(프리미티브)** / **② 미래(최종 아트)** 2단 레이어로 기술.
> **확정/초안 구분**: 비주얼 컨셉·4페이즈·약점(손에 든 분젠 버너)·패턴 방향(버너 공기 조절→불꽃색 판별→코발트 유리→새 원소 발견, 누적)·노출 조건(**플레이어가 목표 불꽃색 자리를 모두
> 찾았을 때** — 능동)·보스방(불꽃 실험실)은 사용자 확정. **자리 찾기 세부 규칙**·장판·수치·대사는 **초안**.
> **키르히호프와의 난이도 정합**: 불꽃 구역·선 구역은 **순서가 자유**이므로 [키르히호프.md](키르히호프.md)와 **페이즈 수(4)·maxHp·def**를 동일하게 둔다.
> **수치 기준**: 모든 수치는 **Lv1 기준 값**이며 실제 값은 [21_던전-레벨-스케일링.md](../21_던전-레벨-스케일링.md)가 정한다(maxHp·def는 §4-4-bis 공통표).
> **⚠ 게임적 설정 표시**: 버너의 공기 조절에 따른 불꽃 변화, 불꽃반응색, 코발트 유리로 나트륨의 노란빛을 걸러 칼륨의 보라색을 보는 방법, 분광법에 의한 세슘·루비듐 발견은 실제
> 화학 지식·역사다. "색이 장판 모양이 된다", "자리를 찾으면 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"불꽃의 색이 원소를 말해 준다."**

19세기 독일의 화학자 로베르트 분젠(Robert Bunsen)을 형상화한 존재. 색이 거의 없는 뜨거운 불꽃을 내는 **분젠 버너**를 개량해 불꽃반응을 또렷하게 관찰할 수 있게 했고,
키르히호프와 함께 **분광 분석법**을 확립해 **세슘(1860)·루비듐(1861)** 을 발견했다. 분광 분석의 등대 3보스 중 **불꽃 구역의 보스**(키르히호프와 순서 자유).

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "분광 분석의 등대 보스: 분젠 · 키르히호프 · 모즐리(불꽃반응+선 스펙트럼으로 원소 분석법을 공동 확립)".
- [알케미아_분광분석등대.md](../../디자인/던전/알케미아_분광분석등대.md) §1, §2: 불꽃 구역 중간보스 "세슘 환영수" 처치 후 진입하는 불꽃 실험실의 주인.

### 포지션
분광 분석의 등대 **자유 구역 보스**(4페이즈, 키르히호프와 동급). 난이도 계단: **분젠 4P = 키르히호프 4P** → 모즐리 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 독일 화학자 + 버너·백금선 장비. 19세기 독일 학자 복장에 분젠 버너와 시료를 묻힌 백금선 고리를 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — BunsenSetup.cs로 구현 가능)

```

├── Hair              Sphere(납작)  scale(0.6, 0.35, 0.6)  pos(0, 2.8, -0.05)
```

**패턴 식별 시각**: 색=장판 모양(리튬 빨강 직선 · 나트륨 노랑 넓은 원 · 칼륨 보라 고리 · 구리 청록 십자 · 세슘 파랑 평행선 · 루비듐 짙은 빨강 점선). 장판과 자리에는 색과 함께 **모양**이 있어 색만으로 구분하지 않는다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 독일 화학자 — 검은 코트·가죽 앞치마, 한 손에 분젠 버너, 다른 손에 백금선.
- **소품**: 분젠 버너(공기 구멍이 약점), 백금선 고리, 코발트 유리 조각.
- **발광**: 버너 불꽃 — 원소색, 공기 구멍 — 노출 시 밝은 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 코트 검정(#1E1E24) + 황동(#B08D57) + 불꽃색(#E0443C·#F0C030·#9A5AD0·#30B8A8·#4A90E8·#A8243C) + 코발트(#2848A8) + 밝은 Emission(#F4FBFF, 약점).
- **실루엣**: 키 약 3.1 Unity units. 손에서 솟는 색 불꽃이 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 버너 공기 조절 → 불꽃색 판별 → 코발트 유리 → 새 원소 발견, 4페이즈 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **공기 조절** | **노란 불꽃**(공기 부족: 넓게 퍼지는 약한 장판)과 **푸른 불꽃**(공기 충분: 좁고 강한 부채꼴)이 번갈아 |
| P2 | **불꽃색 판별** | 원소색마다 **장판 모양이 다름**(리튬 직선 · 나트륨 원 · 칼륨 고리 · 구리 십자) |
| P3 | **코발트 유리** | **노란 섬광 지대**가 칼륨(보라) 예고를 가림 — **코발트 유리 지대(푸른 바닥)** 안에서 보면 숨은 보라 장판이 드러남 |
| P4 | **새 원소 발견** | 처음 보는 **세슘(파란 평행선)·루비듐(짙은 빨강 점선)** 장판이 추가 |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `FlameTestPattern.asset` (신규) | **불꽃반응·분광 분석** | 불꽃색 장판·불꽃 자리 | 백금선을 불꽃에 넣어 색을 냄 |

### 플레이어의 불꽃 자리 찾기 (약점 조건, 초안·게임적 설정)
1. 사이클마다 분젠 머리 위에 **목표 원소**가 표시되고, 바닥에는 서로 다른 색의 **불꽃 자리** 여러 개가 놓인다.
2. 플레이어가 목표 원소의 불꽃색 자리에 **0.3초 머물면 찾은 것**이 된다. 틀린 자리는 반응하지 않는다(벌칙 없음).
3. **P1은 원소 이름과 색을 함께 표시**(힌트), **P2부터는 이름만** 표시해 색을 알아야 찾을 수 있다.
4. P3에서는 칼륨 자리가 노란 섬광에 가려지며 코발트 유리 지대에서 보인다. P4 목표에는 세슘·루비듐이 포함된다.
5. 목표를 **모두 찾으면 분젠이 불꽃을 다시 맞추며 약점 노출**(§5). 노출이 끝나면 자리와 목표가 새로 정해진다.

| 페이즈 | 목표 수 | 놓이는 자리 수 | 등장 원소 |
|---|---|---|---|
| P1 | 2 | 4 | 리튬 · 나트륨 · 칼륨 · 구리 |
| P2 | 3 | 4 | 같음 |
| P3 | 3 | 5 | 같음 + 가려진 칼륨 |
| P4 | 4 | 6 | + 세슘 · 루비듐 |

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 공기 조절 | 노랑 → 파랑 … |
| P2 | + 불꽃색 | 공기 → 색 … |
| P3 | + 코발트 유리 | 공기 → 색(섬광) … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 실험대 앞에서 버너를 듦
- 불꽃 실험실 중앙에서 거의 이동하지 않고 백금선을 불꽃에 넣는 동작을 반복한다.
- 목표가 모두 찾아지면 **버너를 앞으로 내밀어 공기 구멍을 돌리는** 모션 — 이때 공기 구멍이 플레이어가 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 찾던 자리는 초기화된다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 노랑/파랑 불꽃 | P1~ | `Flame` 색·크기 전환 + 원/부채꼴 `Quad` |
| 색별 장판 | P2~ | 원소별 모양 `Quad` 조합 |
| 섬광·코발트 | P3~ | 반투명 노랑 `Quad` + 파랑 지대 진입 시 보라 장판 표시 |
| 새 원소 | P4 | 평행선·점선 `Quad` |
| 불꽃 조절(노출) | 목표 모두 찾음 | 보스 모션 + `AirCollar` Emission On |

## 5. 약점 메커니즘

### 분젠 버너의 공기 구멍 (BossWeakPoint)
- **위치(확정: 손에 든 분젠 버너)**: 버너 아래쪽의 공기 구멍(localPos 0.55, 1.3, 0.5).
- **노출 조건(확정)**: **플레이어가 목표 불꽃색 자리를 모두 찾았을 때** `SetExposed(duration)` 호출(능동). duration은 §4 표(2.6s→2.2s).
- **목표 단서**: 남은 목표 원소를 머리 위에 표시한다.
- **시각 피드백**: 평상시 황동 → 노출 시 밝은 점등 + 불꽃이 푸르게 안정.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 버너 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 세슘 환영수 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 노랑/파랑 불꽃 장판 교대, 목표 2곳(이름+색) 찾으면 공기 구멍 2.6s 노출.
- [ ] **P2 전환**: HP 75% → 배너 + 색별 모양 장판, 목표는 이름만, 노출 2.4s.
- [ ] **P3 전환**: HP 50% → 배너 + 섬광, 코발트 지대에서 보라 장판·자리 확인.
- [ ] **P4 전환**: HP 25% → 배너 + 세슘·루비듐 장판과 목표 4곳, 노출 2.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판·자리 소멸 + BossHealthBar 숨김 + SealDoor 비활성화.
- [ ] **키르히호프와의 정합**: 페이즈 수·maxHp·def가 동일한지 확인(순서 자유 난이도 정합).
