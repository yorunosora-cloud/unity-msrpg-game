## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"가이드 RNA 한 줄로 어디든 자를 수 있다 — 유전자가위를 프로그래밍하다."**

미국의 구조생화학자 제니퍼 다우드나(Jennifer Doudna)를 형상화한 존재. 샤르팡티에와 함께 2012년 **Cas9이 가이드 RNA에 의해 원하는 DNA 서열을 자르도록 프로그래밍할 수 있다**는 것을
보였고, 이는 CRISPR-Cas9 유전자가위의 토대가 되었다(2020 노벨 화학상, 샤르팡티에와 공동). CRISPR 편집 연구소 3보스 중 **삽입 구역의 중간 난이도 보스**.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 다우드나 · 샤르팡티에 · 장펑(CRISPR-Cas9 유전자가위 개발 3인, 다우드나·샤르팡티에는 2020 노벨화학상)".
- [바이오스_CRISPR편집연구소.md](../../디자인/던전/바이오스_CRISPR편집연구소.md) §1, §6: 삽입 구역 중간보스 "오삽입합성체" 처치 열쇠로 진입하는 단백질 구조 실험실의 주인. 진행 순서 ②번(샤르팡티에 처치 후 개방).

### 포지션
CRISPR 편집 연구소 **중간 난이도**(삽입 구역, 4페이즈). 난이도 계단: 샤르팡티에 3P → **다우드나 4P** → 장펑 5P. 이 구역은 편집 기능 중 **절단 + 삽입**이 해금되어 있다.
> **⚠ 게임적 설정**: 다우드나=삽입 구역은 CRISPR 개발 시간순과 편집 기능 해금을 맞춘 게임용 대응이다.

## 2. 비주얼 명세

**컨셉(확정)**: 21세기 현대 여성 구조생화학자 + 단백질 모형 장비. 21세기 초 미국 대학 연구실의 현대 여성 구조생화학자 복장(흰 실험 가운·편한 스웨터)에 Cas9 단백질 3D 모형과 시험관을 갖춘 모습.
샤르팡티에(유럽 미생물학자·배양 장비)와 **국가(미국)·직업(구조생화학자)·장비(단백질 모형)** 로 구분.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 21세기 현대 여성 구조생화학자 — 흰 실험 가운·청록 스웨터·어깨까지 오는 머리, 한 손 위에 Cas9 단백질 홀로그램, 다른 손에 시험관.
- **소품**: 손 위에 떠 있는 Cas9 단백질 홀로그램(약점, 가이드 RNA가 감긴 두 로브 구조), 시험관, 단백질 구조 도해(장식).
- **발광**: Cas9 모형 — 평상시 은은한 청록 홀로그램, 노출 시 구조가 밝게 점등하며 가이드 RNA가 표적에 결합하는 연출.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 흰 가운(#EDEDE8) + 청록 스웨터(#3E9C9A) + 가이드 RNA 주황(#E8823C) + 헬릭스 황금(#D8A23A) + 밝은 Emission(#E8FFFF, 약점).
- **실루엣**: 키 약 3.0 Unity units. 손 위에 떠 있는 Cas9 홀로그램이 상반신 실루엣을 특징짓는다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: Cas9 작동 4단계 — Cas9이 가이드 RNA와 결합해 표적을 찾고 자르는 과정(+삽입 수리)을 4페이즈 누적 규칙으로 옮긴다. 샤르팡티에(기억→인식→절단)와 이어지되 다른 단계(결합·탐색·삽입)로 구분.

| 페이즈 | 추가되는 단계 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **가이드 결합**(Cas9 + 가이드 RNA) | 청록 장판과 주황 장판이 **서로를 향해 이동해 합쳐지는 지점**에서 큰 장판이 발동 |
| P2 | **PAM 탐색**(표적 찾기) | **스캔 라인**(가는 흰 선)이 아레나를 가로·세로로 훑고, 스캔이 **멈춘 자리**가 장판으로 확정되어 발동(라인에 닿으면 약한 피해) |
| P3 | **절단**(이중 가닥 절단) | 확정된 자리에 **직교하는 절단선 2줄**(Cas9의 두 절단 도메인)이 겹쳐 발동 |
| P4 | **삽입·수리**(삽입 구역 기능) | 절단선이 지나간 자리에서 **새 조각(분홍)이 바닥에서 솟아올라 일정 시간 뒤 폭발**(원형 3개 연쇄) |

| 패턴 에셋 | 분자생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `Cas9ActionPattern.asset` (신규) | **Cas9 작동**(가이드 결합→표적 탐색→절단→수리·삽입) | 결합·스캔·절단·삽입 장판 | Cas9 홀로그램을 돌려 가이드 RNA를 지정 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 다우드나가 Cas9 홀로그램을 돌리면 **단계별 텔레그래프**가 나타난다(합쳐지는 두 장판 / 스캔 라인 / 확정 자리 표시 / 절단선 예고 / 솟는 조각 예고).
2. 플레이어는 단계별 규칙에 따라 피한다.
   - 결합: 두 장판이 **합쳐지는 지점**을 피한다.
   - 탐색: 스캔 라인이 **멈추기 전에 확정될 자리**를 예측해 벗어난다.
   - 절단: 직교하는 두 줄 사이 **네 쐐기 영역**이 안전하다.
   - 삽입: 절단선이 지난 자리에서 **솟는 조각이 폭발하기 전** 벗어난다.
3. 장판이 모두 발동되면 다우드나가 **손 위의 Cas9 홀로그램을 돌려 살펴본다** — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 단계 | 시전 순환 |
|--------|----------|----------|
| P1 | 가이드 결합 | 결합 |
| P2 | + PAM 탐색 | 결합 → 탐색 → 결합 → 탐색 … |
| P3 | + 절단 | 결합 → 탐색 → 절단 → 결합 … |
| P4 | + 삽입 수리 | 결합 → 탐색 → 절단 → 삽입 수리 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 손 위의 모형을 돌리며 거의 정지
- 실험대 앞에서 거의 이동하지 않고 손 위의 Cas9 홀로그램을 돌려 가이드 RNA를 조정하는 자세를 유지한다.
- 장판 발동 후 **모형을 눈높이로 들어 올려 돌려 살피는** 모션 — 이때 모형이 플레이어가 접근 가능한 높이로 내려온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. Cas9 모형의 구조(닫힘 → 열림 → 표적 결합 → 수리)가 한 단계씩 바뀌는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 가이드 결합 | P1~ | 두 장판 `Quad`가 `Lerp`로 접근해 합쳐지며 큰 장판 폭발 |
| PAM 스캔 | P2~ | 가는 선 `Quad`가 가로·세로로 이동하다 멈춘 자리에 장판 확정 |
| 절단선 | P3~ | 직교 `Quad` 2줄 동시 발동(쐐기 4개 안전) |
| 삽입 조각 | P4 | 절단선 경로에 분홍 조각 `Cylinder`가 솟아오르다 0.8s 뒤 폭발 |
| 모형 살핌 | 장판 발동 직후 | 보스 모션 + `Cas9Model` 높이 보간 + Emission On |

## 5. 약점 메커니즘

### 손 위에 떠 있는 Cas9 단백질 홀로그램 모형 (BossWeakPoint)
- **위치(확정)**: 오른손 위(localPos 0.5, 1.9, 0.35, 평상시 손 위쪽에 떠 있음). 사용자 지침(개연성 우선)에 따라 다우드나의 대표 업적(Cas9 구조·프로그래밍)을 직접 상징하는 위치.
- **노출 타이밍(확정)**: 장판이 모두 발동한 **직후**, 다우드나가 **모형을 돌려 살피는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.2s). 모형이 접근 가능한 높이로 내려오며 노출 중에는 장판이 남아 있지 않다. 시간 기반이라 중간 난이도에 적합하다.
- **모형 단서**: Cas9 모형의 구조(닫힘 → 열림 → 표적 결합 → 수리)가 페이즈마다 바뀌어 현재 단계를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 은은한 청록 홀로그램 → 노출 시 구조가 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. Cas9 모형 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 오삽입합성체 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 두 장판이 서로 다가와 합쳐지며 발동, 종료 직후 Cas9 모형 1.8s 노출.
- [ ] **P2 전환**: HP 75% → 배너 + 스캔 라인이 멈춘 자리에 장판 확정, 노출 1.6s.
- [ ] **P3 전환**: HP 50% → 배너 + 직교 절단선 2줄(네 쐐기 안전), 노출 1.4s.
- [ ] **P4 전환**: HP 25% → 배너 + 절단선 지난 자리에서 조각 솟아 폭발(연쇄 3개), 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 다중 편집 구역 게이트 개방 조건 충족.
