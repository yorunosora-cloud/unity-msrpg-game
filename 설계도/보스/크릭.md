## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"유전 정보는 DNA에서 RNA를 거쳐 단백질로 흐른다 — 정보에는 방향이 있다."**

20세기 중반 영국의 분자생물학자 프랜시스 크릭(Francis Crick)을 형상화한 존재. 왓슨과 함께 DNA 이중나선 모형을 제안했고, 이후 유전 정보가 DNA → RNA → 단백질로 전달된다는
**중심원리(Central Dogma)** 를 정립한 이론가다. 이중나선 황궁 3보스 중 **크릭 탑의 보스**(왓슨 탑과 동급, 두 탑 중 하나).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 왓슨 · 크릭 · 프랭클린(DNA 이중나선 구조 발견)".
- [바이오스_이중나선황궁.md](../../디자인/던전/바이오스_이중나선황궁.md) §1, §6: 크릭 탑 중간보스 "전사번역병기" 처치 열쇠로 진입하는 중심원리 칠판 서재의 주인. 왓슨 탑과 **순서 자유**.

### 포지션
이중나선 황궁 **중간 난이도**(크릭 탑, 4페이즈). 두 탑 보스는 동급(왓슨 4P = 크릭 4P)이고 최종은 프랭클린 5P.
> **⚠ 게임적 설정**: 크릭 탑 = DNA 다른 한 가닥에 대응하는 게임용 해석.

## 2. 비주얼 명세

**컨셉(확정)**: 1950년대 영국 이론 분자생물학자 + 칠판·수식 장비. 1950년대 영국 케임브리지의 키가 크고 활달한 이론 분자생물학자 복장(정장 조끼·넘치는 장난기 있는 인상)에
칠판·분필·수식이 적힌 노트를 갖춘 모습. 왓슨(실험 모형 장비)과 **직업(이론가)·장비(칠판·수식)** 로 구분.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 1950년대 영국 이론 분자생물학자 — 정장 조끼·넥타이·키 큰 체격·활달한 표정, 한 손에 수식 노트, 귀에 분필.
- **소품**: 귀에 꽂은 분필(약점), 수식과 화살표로 가득한 노트, 칠판(아레나 장식).
- **발광**: 분필 — 평상시 흰 분필, 노출 시 분필 끝이 밝게 빛나며 허공에 수식이 떠오름.

- **팔레트**: 남색 조끼(#2E3A5C) + DNA 청록(#3E9C9A) + RNA 주황(#E8823C) + 단백질 보라(#7A4A9C) + 밝은 Emission(#FFFFFF, 약점).

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 중심원리 정보 흐름 4단계 — DNA → RNA → 단백질의 정보 흐름을 장판이 **방향을 가지고 이동**하는 규칙으로 옮긴다(복제 → 전사 → 번역 → 역전사).
왓슨의 "짝 읽기·안전지대 찾기"와 달리 **"정보가 흐르는 방향(화살표)을 읽고 도착 지점을 예측"** 하는 것이 핵심이다.

| 페이즈 | 추가되는 단계 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **복제**(DNA→DNA) | DNA 장판(이중 평행선)이 발동한 뒤 **같은 위치에서 한 번 더 발동**(복제) |
| P2 | **전사**(DNA→RNA) | DNA 장판에서 **RNA 복사본 탄**이 화살표 방향으로 발사되어 **목표 지점에서 폭발** |
| P3 | **번역**(RNA→단백질) | RNA가 도착한 지점에서 **아미노산 구슬**이 일렬로 쌓이다가 **한꺼번에 폭발해 단백질 장판**이 됨 |
| P4 | **역전사**(RNA→DNA, 예외) | 단백질 장판이 발동한 뒤 **거꾸로 되감겨 출발 DNA 장판으로 돌아와 재발동**(정보가 거꾸로 흐름) |

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `CentralDogmaPattern.asset` (신규) | **중심원리**(DNA→RNA→단백질, 복제·전사·번역·역전사) | 정보 흐름 방향 화살표와 단계별 장판 | 분필로 칠판에 화살표와 수식을 씀 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 크릭이 칠판에 화살표를 그으면 **정보 흐름 장판의 텔레그래프**가 나타난다(DNA 장판 → 화살표 → 도착 지점).
2. 플레이어는 **화살표 방향을 읽어 도착 지점을 예측**해 피한다.
   - 복제: 첫 발동 뒤 **같은 자리에서 한 번 더**.
   - 전사: **화살표 끝**에서 폭발.
   - 번역: 구슬이 쌓이는 동안 **폭발 반경 밖**으로 이동.
   - 역전사: 단백질 장판이 **출발 지점으로 되감기며 재발동**하므로 처음 위치도 위험.
3. 정보 흐름 장판이 모두 발동되면 크릭이 **귀에서 분필을 뽑아 칠판에 수식을 쓴다** — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 규칙 | 시전 순환 |
|--------|----------|----------|
| P1 | 복제 | 복제 |
| P2 | + 전사 | 복제 → 전사 → 복제 → 전사 … |
| P3 | + 번역 | 복제 → 전사 → 번역 → 복제 … |
| P4 | + 역전사 | 복제 → 전사 → 번역 → 역전사 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 칠판 앞에서 거의 정지
- 서재의 칠판 앞에 서서 거의 이동하지 않고 화살표와 수식을 쓰는 자세를 유지한다.
- 장판 발동 후 **귀에서 분필을 뽑아 칠판에 수식을 쓰는** 모션 — 이때 분필이 귀에서 손 높이로 내려온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 칠판에 새 단계(전사 → 번역 → 역전사) 화살표가 추가로 그려지는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| DNA 장판/복제 | P1~ | 평행선 `Quad` 장판 발동 후 0.8s 뒤 재발동 |
| RNA 전사탄 | P2~ | DNA 장판에서 구슬 `Sphere`를 화살표 방향으로 `Lerp` 발사, 도착 시 폭발 |
| 번역 구슬 사슬 | P3~ | 도착 지점에서 구슬이 0.3s 간격으로 쌓이다 마지막에 단백질 장판 폭발 |
| 역전사 되감기 | P4 | 단백질 장판 발동 후 역방향 `Lerp`로 출발 DNA 장판에 복귀·재발동 |
| 분필 수식 | 장판 발동 직후 | 보스 모션 + `Chalk` 귀→손 위치 보간 + Emission On |

## 5. 약점 메커니즘

### 귀에 꽂은 분필 (BossWeakPoint)
- **위치(확정)**: 평상시 오른쪽 귀(localPos 0.28, 2.65, 0). 이미 쓴 부위(손·허리·어깨 위·등·가슴/품·머리 위·팔뚝·팔 안쪽·목·허벅지·종아리·이마·팔꿈치)와 구분되는 **귀**.
- **노출 타이밍(확정)**: 정보 흐름 장판이 **발동한 직후**, 크릭이 **분필을 귀에서 뽑아 칠판에 수식을 쓰는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.2s). 분필이 귀에서 **손 높이로 내려와** 접근 가능한 위치가 된다. **왓슨과 동일한 시간 기반 방식**으로 두 보스 난이도를 맞춘다. 노출 중에는 장판이 남아 있지 않다.
- **분필 단서**: 분필 색이 페이즈마다 바뀌어(흰 → 청록 → 주황 → 보라) 현재 단계를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 흰 분필 → 노출 시 분필 끝이 밝게 빛남.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 분필 약점(×3)과는 독립.
