## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"표면의 자리 하나에 분자 하나 — 흡착이 촉매 반응의 무대다."**

미국의 화학자 어빙 랭뮤어(Irving Langmuir)를 형상화한 존재. 기체가 고체 표면의 정해진 자리에 **한 층으로 흡착**한다는 모형(1916~1918)을 세워 표면 촉매 반응을 설명했고,
물 위 **단분자막**을 연구했다. 표면화학으로 노벨 화학상(1932)을 받았으며 기체를 채운 백열전구 연구로도 알려졌다. 촉매의 영원한 화로 3보스 중 **최종 보스**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "촉매의 영원한 화로 보스: 아레니우스 · 반트호프 · 랭뮤어(랭뮤어는 촉매 표면화학·흡착이론)".
- [알케미아_촉매영원한화로.md](../../디자인/던전/알케미아_촉매영원한화로.md) §1, §2: 표면 구역 중간보스 "표면적 인형" 처치 후 진입하는 단분자막 수조실의 주인. 진행 순서 ③번(역사순).

### 포지션
촉매의 영원한 화로 **최고 난이도**(표면 구역, 5페이즈). 난이도 계단: 반트호프 3P → 아레니우스 4P → **랭뮤어 5P**.

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 초 미국 화학자 + 수조·전구 장비. 20세기 초 미국 연구소 과학자 복장(안경·작업 조끼)에 분자막을 다루는 얕은 수조와 기체를 채운 전구를 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — LangmuirSetup.cs로 구현 가능)

```
랭뮤어 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.55, 1.0)  pos(0, 1.55, 0)   Color: 흰 셔츠 + 갈색 조끼
├── Hair              Sphere(납작)  scale(0.55, 0.3, 0.55)  pos(0, 2.8, 0)
├── Glasses           Torus×2 or Cylinder×2(납작)  pos(0, 2.55, 0.45)
├── Bulb              Sphere+Cylinder  scale 0.25  pos(-0.55, 1.5, 0.35)  — 기체 전구(장식, 점광원)
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.4, 0.5)  — 손에 든 얕은 분자막 수조
│   └── Trough        Cube(납작)  scale(0.6, 0.08, 0.35) + 작은 Sphere 한 층  Emission OFF→ON 노출 시
├── SurfaceEmitter    empty     pos(0, 0, 0)  — 흡착 자리 격자 생성 기준
└── CapsuleCollider   center(0, 1.55, 0)  radius 0.5  height 3.1
```

**패턴 식별 시각**: 바닥 흡착 자리 격자 — **빈 목표 자리=녹색 고리**, 플레이어가 채운 자리=황금, 분자가 붙은 자리=청색 구슬, 떨어지기 직전=깜빡임, 반응 쌍=붉은 연결선.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 초 미국 과학자 — 안경·셔츠·작업 조끼, 한 손에 얕은 수조, 다른 손에 전구.
- **소품**: 분자막 수조(약점, 분자 한 층이 떠 있음), 기체 전구.
- **발광**: 수조 — 평상시 잔잔한 물빛, 노출 시 분자막이 무지갯빛으로 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 조끼 갈색(#5A4636) + 물빛(#7EC8E3) + 분자 청색(#3E6CB0) + 목표 녹색(#5FA05A) + 채움 황금(#C9A646) + 밝은 Emission(#E8FBFF, 약점).
- **실루엣**: 키 약 3.1 Unity units. 앞으로 받친 넓은 수조와 한 손의 전구가 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 흡착 → 단층 포화 → 흡착 평형 → 표면 반응 → 탈착, 5페이즈 누적. 아레나 바닥은 **흡착 자리 격자**(초안 6×4).

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **흡착** | 분자가 **빈 자리**에 내려앉으며 그 칸이 폭발(예고 후) |
| P2 | **단층 포화** | 내려앉은 분자가 자리를 **차지한 채 남음**(닿으면 피해). 한 자리에 하나뿐이라 겹쳐 쌓이지 않음 — 빈 길이 줄어듦(최대 절반까지) |
| P3 | **흡착 평형** | 일정 주기마다 **떨어지는 자리 수 = 새로 붙는 자리 수**로 위치가 한꺼번에 바뀜(깜빡임 예고) |
| P4 | **표면 반응** | **이웃한 두 흡착 분자**가 반응해 십자형 폭발 |
| P5 | **탈착** | 생성물이 떨어져 나가며 비워지는 자리에서 **고리 충격파**, 자리는 다시 빈 자리로(촉매 순환) |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `AdsorptionPattern.asset` (신규) | **랭뮤어 흡착·표면 촉매 반응** | 흡착 자리 격자 장판 | 수조의 막을 막대로 밀어 모음 |

### 플레이어의 흡착 자리 채우기 (약점 조건, 게임적 설정)
1. 사이클마다 **빈 목표 자리(녹색 고리)** 가 정해진 수만큼 표시된다(§4 표: 3→5곳).
2. 플레이어가 목표 자리에 **0.3초 머물면 채워진다**(황금).
3. **채운 자리에는 분자가 붙지 못한다**(자리 하나에 하나) — 따라서 **채운 자리는 흡착 폭발에서 안전한 발판**이 된다(초안). 표면 반응·탈착 충격파는 피해야 한다.
4. 채운 자리는 약점이 노출될 때까지 유지된다(피격으로 풀리지 않음, 초안).
5. **모든 목표 자리를 채우면** 랭뮤어가 막을 다시 정리하느라 **약점 노출**(§5). 노출이 끝나면 자리가 초기화되고 새 목표가 정해진다.

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 흡착 | 흡착 |
| P2 | + 포화 | 흡착(잔류) … |
| P3 | + 평형 | 흡착 → 평형 이동 … |
| P4 | + 표면 반응 | 흡착 → 평형 → 반응 … |
| P5 | + 탈착 | 흡착 → 평형 → 반응 → 탈착(순환 완성) |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 수조대 앞에서 막대로 막을 다룸
- 수조실 중앙의 수조대 앞에서 거의 이동하지 않는다.
- 목표 자리가 모두 채워지면 **손의 수조를 앞으로 내밀어 흐트러진 막을 정리하는** 모션 — 이때 수조가 플레이어가 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 채우던 자리는 초기화되고 새 규칙이 시작된다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 흡착 | P1~ | 구슬 `Sphere` 낙하 → 칸 `Quad` 폭발 |
| 잔류 | P2~ | 구슬 유지 + 접촉 피해 트리거 |
| 평형 이동 | P3~ | 깜빡임 1.0s 후 구슬 위치 교체 |
| 반응 | P4~ | 인접 쌍 붉은 선 → 십자 `Quad` |
| 탈착 | P5 | 구슬 상승 + 고리 `Cylinder` 확장 |
| 막 정리(노출) | 목표 모두 채움 | 보스 모션 + `Trough` Emission On |

## 5. 약점 메커니즘

### 손에 든 얕은 분자막 수조 (BossWeakPoint)
- **위치(확정)**: 앞으로 받쳐 든 수조(localPos 0.5, 1.4, 0.5).
- **노출 조건(확정)**: **플레이어가 빈 흡착 자리를 모두 채웠을 때** `SetExposed(duration)` 호출(능동). duration은 §4 표(2.6s→2.2s).
- **자리 단서**: 남은 목표 자리 수를 보스 머리 위 구슬로 표시한다(초안).
- **시각 피드백**: 평상시 잔잔한 물빛 → 노출 시 분자막 점등.
- **데미지 배율**: ×3, 속성 무관.
- **막힘 방지(초안)**: 목표 자리는 분자가 붙지 않은 칸에서만 고르고, 정해진 뒤에는 분자가 붙지 않게 예약한다. 그래서 언제든 채울 수 있다.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 수조 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 표면적 인형 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 목표 자리 3곳 채우면 수조 2.6s 노출, 이후 초기화. 채운 자리에는 분자가 붙지 않음.
- [ ] **P2 전환**: HP 80% → 배너 + 분자 잔류·점유율 50% 이하 유지.
- [ ] **P3 전환**: HP 60% → 배너 + 평형 이동(깜빡임 예고), 목표 4곳.
- [ ] **P4 전환**: HP 40% → 배너 + 이웃 반응 십자 폭발.
- [ ] **P5 전환**: HP 20% → 배너 + 탈착 고리, 목표 5곳, 항상 채울 수 있음.
- [ ] **처치**: HP 0 → defeatLine + 장판·분자 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
