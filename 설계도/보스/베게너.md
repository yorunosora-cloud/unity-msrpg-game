## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"증거는 이미 있었다 — 대륙의 윤곽이 그것을 말해준다."**

독일의 기상학자이자 극지 탐험가 알프레드 베게너(Alfred Wegener)를 형상화한 존재. 대륙의
해안선이 서로 맞물리는 모습에서 대륙이동설을 최초로 제창한 인물이자, 실제 그린란드 탐험 중
사망한 비극적 최후로도 알려져 있다. 판게아 유적 3보스 중 "관찰" 단계 — 판구조론 정립의
첫 단계를 상징하는, 가장 낮은 난이도의 관문.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 알프레드 베게너
  (대륙이동설)·아서 홈스(맨틀대류설)·해리 헤스(해저확장설) — 한국 지구과학Ⅰ 교육과정의
  '판구조론 정립 과정' 표준 3단계"
- [테라노바_판게아유적.md](../../디자인/던전/테라노바_판게아유적.md) §2, §6: 동아프리카
  열곡대 구역의 중간보스 "균열암석거인"을 처치하면 얻는 증거 아이템으로 진입하는 그린란드
  탐험 캠프 아레나의 주인.

### 포지션
판게아 유적 3보스방 중 **가장 쉬움** — 해들리와 마찬가지로 "정직한 개념 관문". 텔레그래프가
크고 느리지만 강력한 대륙형 장판 위주라 예측은 쉬운 편. 홈스·헤스의 복합 패턴을 만나기 전
플레이어가 판게아 특유의 "판 이동 게이트"에 익숙해지는 자리.

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — WegenerSetup.cs로 구현 가능)

```
베게너 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 네이비 정장
├── PolarCoat (Pivot) empty     pos(0, 1.5, 0)          — 정장 위에 걸친 극지용 외투 자락
│   └── CoatPanel×3    납작 Cube  각 scale(0.45, 1.3, 0.05)  — Update에서 개별 파형 흔들림
├── FurHood           Sphere    scale(0.5, 0.35, 0.5)  pos(0, 2.6, -0.1)  Color: 연갈색 모피(외투 후드, 목 뒤로 넘김)
├── MapScrollCase     Cylinder(둘말이) scale(0.22, 0.8, 0.22)  pos(0.5, 1.3, 0.2)  — 평상시 손에 쥔 상태
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.3, 0.3)  — 손에 쥔 대륙 지도장(펼쳤을 때만 노출)
│   └── MapUnfurled   납작 Cube(펼쳐진 지도)  scale(0.8, 1.1, 0.02)  Emission OFF→ON 노출 시,
│                     평상시 비활성 → 지도투사 시전 시 활성화
├── ContinentAura (Pivot) empty pos(0, 1.0, 0)          — 대륙장판 소환 시 지면에 투사되는 윤곽 자리
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 대륙 형태를 닮은 불규칙한 다각형 텔레그래프가 주 예고 신호 — 실제 해안선
윤곽(남아메리카·아프리카 등)을 단순화한 형태를 재사용해 "대륙이 이동해온다"는 느낌을 강조.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 독일 신사 정장 위에 두꺼운 극지 탐험용 모피 외투를 걸친 혼합 스타일 — 평소에는
  학자풍이지만 외투가 극한 환경 탐험가였음을 드러냄.
- **소품**: 손에 항상 들려 있는 두루마리 대륙 지도장 — 평상시 말려 있다가 지도투사 시전 시
  펼쳐짐(약점 노출과 직결).
- **발광**: 지도장 표면 — 평상시 비활성, 펼쳐질 때 대륙 윤곽선이 하늘색 Emission으로 그려짐.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 짙은 네이비 정장(#1E2A3A) + 연갈색 모피(#B89268) + 하늘색 Emission(#7EC8E3, 약점) + 대륙장판 짙은 갈색(#5C4630).
- **실루엣**: 키 약 3.0 Unity units. 두꺼운 외투로 인해 해들리·페렐보다 다부지고 둥근 실루엣.

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 느린 도보 이동 (해들리의 부유와 달리 지면 위를 실제로 걸음)
- 패턴 캐스팅 사이(idle 구간) 플레이어를 향해 저속 도보 이동. 속도 ~1.3 m/s — 3보스 중
  가장 느림("관찰" 단계의 신중함을 반영).
- 발이 지면에 닿아 있으며, 걸음마다 극지용 부츠 발소리 SFX.

### 페이즈 전환
- P2·P3 진입 시 아레나 중앙으로 즉각 이동 + 짧은 무적(~1초), 배너와 동기화.
- 전환 VFX: ① 지금 = 없음. ② 미래 = 지도장이 크게 펼쳐지며 대륙 윤곽이 잠시 허공에 투영.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 외투 자락 파형 흔들림 | 항상 | `Update()`: `CoatPanel[i].localRotation`을 `Mathf.Sin(Time.time*speed+i)`로 흔듦 |
| 지도장 펼침/말림 | 지도투사 시전 시 활성 | `MapUnfurled` 스케일을 0→1 애니메이션, 종료 후 원위치 |
| 지도장 Emission | 노출 시에만 | `MapUnfurled` 머티리얼 Emission 토글(펼침과 동기화) |

## 5. 약점 메커니즘

### 손에 든 대륙 지도장 (BossWeakPoint)
- **위치**: 오른손(localPos 0.5, 1.3, 0.3).
- **노출 타이밍**: `MapProjectionWegener` 시전 직후(두루마리를 펼치는 순간) 자동
  `SetExposed(duration)` 호출 — duration은 페이즈별로 1.0s→0.8s→0.6s로 단축(§4).
- **시각 피드백**: 평상시 말려 있어 비활성 → 노출 시 펼쳐지며 하늘색 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 지도장 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 균열암석거인 처치 → 증거 아이템 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1 패턴**: ContinentZone(대형 장판 접근) / MapProjection(직선 투사) 정상 발동, 지도투사 직후 약점 1.0s 노출 확인.
- [ ] **P2 전환**: HP 66% → 배너 + ContinentCollision(양쪽 충돌+경계선 충격파) 발동, 노출 창 0.8s로 단축 확인.
- [ ] **P3 전환**: HP 33% → 배너 + PangaeaReform(아레나 수축+다중 충격파) 발동, 노출 창 0.6s.
- [ ] **처치**: HP 0 → defeatLine + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 클리어.

## 11. 향후 확장

- **리깅 모션**: 외투 자락 물리 시뮬레이션, 지도장 펼침 애니메이션.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).

- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
