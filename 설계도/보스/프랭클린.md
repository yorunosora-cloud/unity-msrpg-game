## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"구조는 데이터 속에 이미 있다 — 정확한 측정이 진실을 드러낸다."**

20세기 중반 영국의 X선 결정학자 로절린드 프랭클린(Rosalind Franklin)을 형상화한 존재. 킹스 칼리지에서 DNA 섬유의 **X선 회절 사진**을 정교하게 찍어 **사진 51번**(X자 모양 회절 무늬)을 얻었고,
이는 DNA가 나선 구조임을 보여 준 결정적 단서였다. 그러나 이 데이터는 본인 몰래 왓슨과 크릭의 모델 제작에 활용되었고, 그녀는 노벨상 수상 이전에 세상을 떠났다. 이중나선 황궁 3보스 중
**최종 보스**(숨은 기여자의 반전).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 왓슨 · 크릭 · 프랭클린(DNA 이중나선 구조 발견)".
- [바이오스_이중나선황궁.md](../../디자인/던전/바이오스_이중나선황궁.md) §1, §6: 정상 합류부 중간보스 "쌍나선수호병기" 처치 열쇠와 합류부 게이트(DNA 구조·복제 던전 문제)를 통과하면 진입하는
  X선 회절 암실의 주인. **왓슨·크릭을 모두 처치한 뒤** 열린다.

### 포지션
이중나선 황궁 **최고 난이도**(정상 합류부, 5페이즈). 난이도 계단: 왓슨 4P = 크릭 4P(동급) → **프랭클린 5P**.
> **⚠ 게임적 설정**: 프랭클린=정상 합류부 최종 보스는 "숨은 기여자 반전"을 노린 게임용 배치다.

## 2. 비주얼 명세

**컨셉(확정)**: 1950년대 영국 여성 X선 결정학자 + 회절 장비. 1950년대 영국 킹스 칼리지 연구실의 여성 X선 결정학자(흰 실험 가운·단정한 정장 차림)에 X선 회절 장비와
회절 사진 필름 카드를 갖춘 모습. 린네~크릭과 시대(1950년대)·성별(여성)·직업(X선 결정학자)·장비(회절 장비·필름)로 구분(매클린톡=미국 여성 유전학자와는 국가·직업·장비로 구별).

### 2-B 미래 (최종 아트 가이드)

- **모델**: 1950년대 영국 여성 X선 결정학자 — 흰 실험 가운·단정한 올림머리·진지한 표정, 손목에 필름 배지, 손에 회절 카메라와 사진 카드.

- **팔레트**: 흰 가운(#EDEDE8) + X선 빔 흰빛(#F4F8FF) + 회절 무늬 청백(#BFD8F0) + 헬릭스 황금(#D8A23A) + 밝은 Emission(#FFFFFF, 약점).
- **실루엣**: 키 약 3.0 Unity units. 손목의 필름 배지와 회절 카드가 가늘고 정갈한 실루엣을 특징짓는다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: X선 회절 5단계 — 사진 51번의 제작·해석 과정(시료 → 빔 → 회절 → X자 무늬 → 나선 해석)을 5페이즈에 대응시킨다. **누적형**이며
"데이터에서 구조를 읽어 낸다"는 업적을 그대로 전투로 바꾼다.

| 페이즈 | 추가되는 단계 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **시료 + X선 빔** | 아레나 중앙에 **DNA 섬유 시료 기둥**이 서고, **직선 X선 빔**(1~2줄)이 기둥을 향해 발사된다(빔 위가 위험) |
| P2 | **회절**(산란) | 빔이 기둥에 닿으면 **부채꼴(약 60°)로 산란**되어 퍼진다(부채꼴 안이 위험) |
| P3 | **X자 무늬**(사진 51번) | 두 빔이 중앙에서 **X자로 교차**해 X자 장판 — **안전지대는 X의 네 사이 영역(4개 쐐기)** |
| P4 | **긴 노출**(약 62시간) | X자 장판이 **같은 위치에서 3회 중첩 발동**하며 **매 회 반경·피해가 +25% 누적**(노출이 길수록 선명) |
| P5 | **나선 해석** | 회절 무늬를 해석해 **이중나선 소용돌이 장판**으로 합체 — 두 가닥이 회전하며 중앙으로 수렴, **가닥 사이가 안전지대(함께 회전)** |

| 패턴 에셋 | 결정학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `XRayDiffractionPattern.asset` (신규) | **X선 회절**(사진 51번) | 시료·빔·산란·X자·나선의 단계별 장판 | 회절 카메라로 시료를 겨누고 셔터를 누름 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 프랭클린이 회절 카메라로 시료를 겨누면 **빔·산란·무늬 장판의 텔레그래프**가 나타난다.
2. 플레이어는 **빔의 직선·산란 부채꼴·X자 사이 영역·나선 가닥 사이**를 읽어 안전한 위치로 이동한다.
3. 회절 장판이 모두 발동되면 프랭클린이 **손목의 필름 배지를 확인**한다 — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 단계 | 시전 순환 |
|--------|----------|----------|
| P1 | 시료+빔 | 빔 |
| P2 | + 회절 | 빔 → 회절 → 빔 → 회절 … |
| P3 | + X자 무늬 | 빔 → 회절 → X자 → 빔 … |
| P4 | + 긴 노출 | 빔 → 회절 → X자(긴 노출) → … |
| P5 | + 나선 해석 | 빔 → 회절 → X자 → 긴 노출 → 나선 (사진 51번 제작·해석 1주기 완성) |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 암실 한가운데에서 시료를 겨눔
- X선 회절 암실 중앙 부근에서 거의 이동하지 않고 회절 카메라로 시료 기둥을 겨누는 자세를 유지한다.
- 회절 장판 발동 후 **손목의 필름 배지를 들어 올려 확인**하는 모션 — 이때 손목이 플레이어가 접근 가능한 높이로 올라온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 필름 배지에 비치는 회절 무늬가 한 단계 더 선명해지는 연출(점 → 부채꼴 → X자 → 겹침 → 나선).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 시료 기둥 | P1~ | 아레나 중앙에 기둥 `Cylinder` 소환(시전 중 유지, 종료 시 소멸) |
| X선 빔 | P1~ | 직선 `LineRenderer`/`Quad` 장판이 기둥을 향해 발사 |
| 산란 | P2~ | 기둥 위치에서 60° 부채꼴 장판 확산 |
| X자 무늬 | P3~ | 두 빔을 교차시켜 X자 장판 생성, 4개 쐐기 안전지대 표시 |
| 긴 노출 | P4 | X자 장판을 3회 중첩 발동, 매 회 스케일·피해 ×1.25 |
| 나선 해석 | P5 | 두 가닥 소용돌이 장판이 중앙으로 수렴·회전, 가닥 사이 안전지대도 회전 |
| 배지 확인 | 장판 발동 직후 | 보스 모션 + `FilmBadge` Emission On |

## 5. 약점 메커니즘

### 손목에 찬 X선 필름 배지 (BossWeakPoint)
- **위치(확정)**: 왼쪽 손목(localPos -0.55, 1.1, 0.35). 이미 쓴 부위(손·허리·어깨 위·등·가슴/품·머리 위·팔뚝·팔 안쪽·목·허벅지·종아리·이마·팔꿈치·귀)와 구분되는 **손목**
  (오덤의 팔뚝 계량기와는 부위·오브젝트·노출 방식이 다르다).
- **노출 타이밍(확정)**: 회절 장판이 **모두 발동한 직후**, 프랭클린이 **손목의 필름 배지를 확인하는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.0s). 시간 기반이며 노출 중에는 장판이 남아 있지 않다. 5페이즈와 장판 복잡도(X자·누적·나선)가 난이도를 책임진다.
- **필름 단서**: 배지의 노출 정도(필름 어두워짐)와 비치는 무늬가 페이즈마다 바뀌어 현재 단계(점→부채꼴→X자→누적→나선)를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 흰 필름 → 노출 시 X자 회절 무늬가 선명히 떠오르며 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **합류 조건**: 왓슨·크릭 모두 처치 → 정상 합류 → 합류부 게이트(DNA 구조·복제 던전 문제) 개방 → 쌍나선수호병기 처치 열쇠로 진입 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 시료 기둥 소환, X선 직선 빔 예고→발동, 종료 직후 필름 배지 1.8s 노출.
- [ ] **P2 전환**: HP 80% → 배너 + 회절(60° 부채꼴 산란), 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + X자 교차 장판(4쐐기 안전지대), 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + X자 장판 3회 중첩·누적 증가, 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 이중나선 소용돌이(가닥 사이 안전지대 회전), 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + 장판·시료 기둥 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
