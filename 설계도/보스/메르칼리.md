## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"흔들림은 사람이 느낀 만큼이다 — 체감한 피해로 등급을 매긴다."**

19~20세기 초 이탈리아의 화산·지진학자 주세페 메르칼리(Giuseppe Mercalli)를 형상화한 존재.
지진이 사람과 건물에 끼친 **체감 피해**를 I~XII 등급으로 구분하는 진도 척도를 고안했다(한국이
채택한 것은 수정 메르칼리 진도). 판구조 산맥 신전 3보스 중 "주관적 체감" 단계 — 리히터의
객관적 수치(규모)와 대비되는 **"느끼는 지진"**이며, 지구과학 대륙 5개 랜드마크의 마지막 보스.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 제임스 허턴 · 찰스
  리히터 · 주세페 메르칼리(지진 진도, 한국이 채택한 수정 메르칼리 진도)"
- [테라노바_판구조산맥신전.md](../../디자인/던전/테라노바_판구조산맥신전.md) §2, §6: 메르칼리
  갱도의 중간보스 "체감화석초"를 처치하면 얻는 열쇠로 진입하는 피해 체감 전시실의 주인.

### 포지션
판구조 산맥 신전 3보스방 중 **최고 난이도**이자 지구과학 대륙 최종 보스. 미니보스 "체감화석초"의
체감 디버프(화면 흔들림+조작 반전)를 보스 규모로 확장 — 진도 등급이 오를수록 **체감 디버프
종류가 페이즈마다 하나씩 누적**되는 구조. 난이도 계단: 허턴 3P → 리히터 4P → **메르칼리 5P**.

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 초 학자 + 피해 조사관 장비. 허턴(18세기 신사+야외답사 장비)·리히터(현대
과학자 정장+지진계)와 시대·분위기로 구분 — 1900년대 초 이탈리아 학자 복장에 피해 조사용
기록·사진 장비를 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — MercalliSetup.cs로 구현 가능)

```
메르칼리 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 암갈색 20세기 초 코트
├── Hat               Cylinder(납작)  scale(0.6, 0.08, 0.6)  pos(0, 3.05, 0)  — 챙 있는 학자 모자
├── SurveyBook        Cube(소형)  scale(0.3, 0.4, 0.06)  pos(0.5, 1.3, 0.2)  — 손에 든 피해 조사 기록부(장식)
├── Camera            Cube+Cylinder 조합  scale 0.3  pos(-0.5, 1.4, 0.2)    — 목에 건 건판 사진기(장식)
├── WeakPoint         (BossWeakPoint) pos(0, 1.7, -0.5)  — 등에 맨 진도 눈금판 (보스 뒤쪽!)
│   └── ScaleBoard    Cylinder(납작, 원판형)  scale 0.5  Color: 짙은 갈색  Emission OFF→ON 노출 시
├── CoatTail (Pivot)  empty     pos(0, 1.5, 0)  — 코트 자락(흔들림 연출용)
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 활성 체감 디버프마다 화면 가장자리에 아이콘이 표시되고, 보스 발밑에 진도
등급 로마 숫자(I~V)가 페이즈마다 올라간다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 1900년대 초 이탈리아 학자 복장(긴 코트·중절모) + 피해 조사 장비(기록부·건판 사진기)
  혼합 — "현장을 돌며 사람들이 느낀 피해를 적는 조사관" 이미지.
- **소품**: 손에 든 피해 조사 기록부, 목에 건 대형 건판 사진기(플래시는 연출용).
- **발광**: 등의 진도 눈금판 — 평상시 짙은 갈색, 노출 시 밝은 Emission. 페이즈마다 눈금 한 칸씩 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 암갈색 코트(#4A3B32) + 황동 장비(#B8924A) + 밝은 Emission(#F2C46A, 약점).
- **실루엣**: 키 약 3.2 Unity units. 3보스 중 가장 크고 장비가 많은 실루엣.

## 3. 패턴 ↔ 순환 원리 매핑

**방향(확정)**: 체감 디버프가 페이즈마다 누적. 리히터가 "공격 범위·피해"를 늘렸다면 메르칼리는
**플레이어의 조작·시야**를 건드린다.

| 패턴 에셋 | 지질 원리 | 체감 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `FeltIntensityPattern.asset` (신규, 미니보스 `체감디버프` 계승·확장) | **메르칼리 진도** — 사람이 느낀 체감 피해로 등급 구분 | 활성 디버프 목록을 일정 시간 플레이어에게 적용 | 기록부에 등급을 적으며 피해 선언 |

> 단일 패턴 클래스가 **활성 디버프 목록(누적)**을 시전 시마다 플레이어에게 부여한다. 리히터의
> `TieredTremorPattern`(활성 등급 누적)과 구조가 비슷하지만, 데미지 장판이 아니라 **조작·시야
> 디버프**를 거는 점이 다르다.

### 디버프 누적표 (초안)

| 페이즈 | 진도 등급 | 활성 체감 디버프(누적) | 신규 추가분 |
|--------|----------|----------------------|------------|
| P1 | 진도 II~III | 화면 흔들림 | 화면 흔들림(약하게 카메라 진동) |
| P2 | 진도 IV~V | 화면 흔들림 + 조작 반전 | 좌우 이동 반전 |
| P3 | 진도 VI~VII | + 시야 가림 | 화면 가장자리 먼지 오버레이 |
| P4 | 진도 VIII~IX | + 이동 둔화 | 이동속도 감소 |
| P5 | 진도 X 이상 | 전부 + 상하 반전 | 상하 이동까지 반전(전 디버프 최대 강도) |

> 미니보스 체감화석초는 "화면 흔들림+조작 반전" 2종이므로, P1~P2가 그 확장이다. P3 이후는
> 보스 전용 신규 디버프. 디버프 판정은 데미지가 아니라 **조작 방해**이므로 직접 피해는 낮게(§6).

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 현장 조사하듯 천천히 이동
- 플레이어를 정면에 둔 채 느리게 이동하며 기록부를 쓰는 동작을 유지. **등이 약점이므로 평상시에는
  항상 플레이어를 향해 있어** 등을 보이지 않는다.
- 디버프 해제 직후(§5)에는 보스가 **정지 + 몸을 반쯤 돌려 등이 노출**되는 모션으로 약점 접근
  가능함을 시각적으로 알림.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너와 동기화. 새 디버프 아이콘이 화면에 처음 뜨는
  "진도 상승" 연출(플래시 + 진도 숫자가 한 단계 올라감).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 코트 자락 흔들림 | 항상(약하게) | `Update()`: `CoatTail` 자식 회전을 `Mathf.Sin(Time.time*speed)`로 흔듦 |
| 디버프 발동 | FeltIntensity 캐스팅 중 | 활성 디버프를 플레이어에 부여(카메라 진동·입력 반전 플래그 등) |
| 몸 돌리기 | 디버프 해제 직후 | `BossRoot` Y 회전 약 120° 보간 후 `WeakPoint.SetExposed` |
| 눈금판 Emission | 약점 노출 중 | `ScaleBoard` 머티리얼 Emission On |

## 5. 약점 메커니즘

### 등에 맨 진도 눈금판 (BossWeakPoint)
- **위치(확정)**: 등(localPos 0, 1.7, -0.5). 평상시 보스가 플레이어를 정면으로 두고 있으므로
  **약점은 보스 뒤쪽에 가려져 있다**.
- **노출 타이밍(확정)**: 체감 디버프가 **해제된 직후**, 보스가 잠시 휴지 상태가 되며 몸을 돌려
  등을 노출 — 이때 `SetExposed(duration)` 호출. duration은 §4 표(1.6s→0.8s).
- **공략 흐름**: ① 디버프를 버틴다 → ② 해제 직후 보스 뒤로 이동 → ③ 눈금판 공격. 플레이어는
  디버프 중에 미리 보스 뒤쪽 위치를 잡는 판단이 필요(단, 조작 반전·이동 둔화 상태에서 위치 잡기가
  어려운 것이 이 보스의 핵심 난이도).
- **시각 피드백**: 평상시 짙은 갈색 → 노출 시 밝은 Emission + 눈금 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 눈금판 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 체감화석초 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 화면 흔들림만 적용, 해제 직후 보스가 몸을 돌려 눈금판 1.6s 노출 확인.
- [ ] **P2 전환**: HP 80% → 배너 + 조작 반전 추가(화면 흔들림 유지) 확인, 노출 1.4s.
- [ ] **P3 전환**: HP 60% → 배너 + 시야 가림 추가 확인, 노출 1.2s.
- [ ] **P4 전환**: HP 40% → 배너 + 이동 둔화 추가 확인, 노출 1.0s.
- [ ] **P5 전환**: HP 20% → 배너 + 상하 반전 포함 전 디버프 활성 확인, 노출 0.8s.
- [ ] **디버프 종료**: 각 페이즈에서 디버프가 해제될 때 입력/카메라가 정상 복구되는지 확인.
- [ ] **처치**: HP 0 → defeatLine + 디버프 전부 해제 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 클리어.
