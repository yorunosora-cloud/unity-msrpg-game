# 반트호프 보스 구현 설계도

> **위치**: `설계도/보스/반트호프.md`
> **역할**: [07_보스전.md](../07_보스전.md) 공통 템플릿을 반트호프에 실제로 어떻게 구체화할지 명세.
> [뵐러.md](뵐러.md)·[라부아지에.md](라부아지에.md)와 동일한 구조를 따른다.

> [알케미아_촉매영원한화로.md](../../디자인/던전/알케미아_촉매영원한화로.md) 소관.
> **비주얼 명세 원칙**: 모든 비주얼·아레나 섹션은 **① 지금(프리미티브)** / **② 미래(최종 아트)** 2단 레이어로 기술.
> **확정/초안 구분**: 비주얼 컨셉·3페이즈·약점(손에 든 회중시계)·패턴 방향(반응 속도→온도 규칙→화학 평형, 누적)·노출 타이밍(장판 발동 직후 시계로 시간을 잴 때)·보스방(시계의 방)은
> 사용자 확정. 장판 세부·수치·대사는 **초안**.
> **수치 기준**: 모든 수치는 **Lv1 기준 값**이며 실제 값은 [21_던전-레벨-스케일링.md](../21_던전-레벨-스케일링.md)가 정한다(maxHp·def는 §4-4-bis 공통표).
> **⚠ 게임적 설정 표시**: 반응 속도·평형 연구(1884)는 실제 업적이다. **"온도가 10℃ 오르면 속도가 2~3배"는 대략적인 경험칙**(반응마다 다름)이며 게임은 2배로 고정한다.
> 평형은 정반응과 역반응의 속도가 **같아진 상태**(반응이 멈춘 것이 아님)이고, "평형에서 양쪽이 터진다", "시간을 재는 동안 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"반응에는 속도가 있고, 온도는 그 속도를 바꾸며, 마침내 평형에 이른다."**

네덜란드의 화학자 야코뷔스 반트호프(Jacobus H. van 't Hoff)를 형상화한 존재. 1884년 『화학 동역학 연구』에서 **반응 속도**와 **화학 평형**, 온도의 영향을 정리했고,
화학 동역학과 삼투압 연구로 **첫 노벨 화학상**(1901)을 받았다. 촉매의 영원한 화로 3보스 중 **속도 구역의 입문 관문**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "촉매의 영원한 화로 보스: 아레니우스 · 반트호프 · 랭뮤어".
- [알케미아_촉매영원한화로.md](../../디자인/던전/알케미아_촉매영원한화로.md) §1, §2: 속도 구역 중간보스 "농도 인형" 처치 후 진입하는 시계의 방의 주인. 진행 순서 ①번(역사순).

### 포지션
촉매의 영원한 화로 **입문 관문**(속도 구역, 3페이즈). 난이도 계단: **반트호프 3P** → 아레니우스 4P → 랭뮤어 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 네덜란드 화학자 + 회중시계·시험관 장비. 19세기 후반 네덜란드 학자 복장에 커다란 회중시계와 온도가 다른 시험관을 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — VantHoffSetup.cs로 구현 가능)

```
반트호프 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 청색 코트
├── Hair              Sphere(납작)  scale(0.55, 0.32, 0.55)  pos(0, 2.7, 0)
├── Mustache          Cube(소)  scale(0.25, 0.06, 0.05)  pos(0, 2.35, 0.48)
├── TubeBelt          Cylinder×3(가는, 파랑/주황/빨강)  pos(-0.45, 1.2, 0.35)  — 온도가 다른 시험관(장식)
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.55, 0.45)  — 손에 든 회중시계
│   └── PocketWatch   Cylinder(납작)  scale(0.35, 0.05, 0.35) + Cube(바늘)×2  Emission OFF→ON 노출 시
├── RateEmitter       empty     pos(0, 0, 0)  — 시간·온도·평형 장판 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 속도=장판 위 초침 표시, 온도=머리 위 온도 숫자(20/30/40℃)와 장판 색(파랑→주황→빨강), 평형=좌우 두 색 장판과 양방향 화살표.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 네덜란드 학자 — 청색 코트·콧수염, 한 손에 회중시계, 허리에 시험관.
- **소품**: 회중시계(약점), 온도별 색 시험관.
- **발광**: 시계 — 평상시 황동, 노출 시 문자판이 밝게 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 코트 청색(#2E3A5C) + 황동(#B08D57) + 온도 색(#3E6CB0·#F08030·#C0392B) + 밝은 Emission(#FFF3C4, 약점).
- **실루엣**: 키 약 3.0 Unity units. 앞으로 든 큰 회중시계가 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 반응 속도 → 온도 규칙 → 화학 평형, 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **반응 속도** | 시계 방향으로 놓인 장판 6개가 **초침에 맞춰 일정한 간격(0.8초)** 으로 하나씩 발동 |
| P2 | **온도 규칙** | 온도 표시가 **10℃ 오를 때마다 발동 간격이 절반**(20℃ 0.8s → 30℃ 0.4s → 40℃ 0.2s) |
| P3 | **화학 평형** | 좌우 두 진영 장판 사이를 **정반응(→)과 역반응(←)** 장판이 오감. 정반응은 점점 느려지고 역반응은 빨라지며, **속도가 같아지는 순간 양쪽 진영이 동시에 발동**(가운데 띠 안전) |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `ReactionRatePattern.asset` (신규) | **반응 속도론·화학 평형** | 시간·온도·평형 장판 | 회중시계를 누르고 시험관을 들어 올림 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 반트호프가 시계를 누르면 **텔레그래프**가 나타난다(장판 순서 / 온도 숫자 / 좌우 진영과 화살표).
2. 플레이어는 규칙에 따라 피한다.
   - 속도: 초침의 박자에 맞춰 **이미 발동한 칸**으로 이동.
   - 온도: 숫자를 보고 **빨라진 박자**에 대비.
   - 평형: 화살표 속도가 같아지기 전에 **가운데 띠**로.
3. 장판 발동 직후 **시계로 시간을 재는 동안 약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 속도 | 속도(20℃) |
| P2 | + 온도 | 속도 20℃ → 30℃ → 40℃ … |
| P3 | + 평형 | 속도(온도 변화) → 평형 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 방 중앙에서 시계를 보며 정지
- 시계의 방 중앙에서 거의 이동하지 않고 시계와 시험관을 번갈아 보는 자세를 유지한다.
- 장판 발동 후 **시계를 앞으로 내밀어 시간을 재는** 모션 — 이때 시계가 플레이어가 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P3 진입 시 짧은 무적(~1초) + 배너. P2부터 방의 큰 시계 바늘이 빨라진다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 초침 발동 | P1~ | 원형 배치 `Quad` 6개 순차 발동, 초침 `Cube` 회전 |
| 온도 변화 | P2~ | `TextMesh` 온도 + 발동 간격 계수 |
| 평형 | P3 | 좌우 `Quad`와 화살표 이동, 간격 수렴 후 동시 발동 |
| 시간 재기 | 장판 발동 직후 | 보스 모션 + `PocketWatch` Emission On |

## 5. 약점 메커니즘

### 손에 든 회중시계 (BossWeakPoint)
- **위치(확정)**: 오른손의 회중시계(localPos 0.5, 1.55, 0.45).
- **노출 타이밍(확정)**: 장판이 **발동한 직후**, 시계로 **반응 시간을 재는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s). 시간 기반이라 입문 관문에 단순하며 노출 중에는 장판이 남아 있지 않다.
- **시계 단서**: 바늘 속도가 현재 온도(속도)를 알려 준다.
- **시각 피드백**: 평상시 황동 → 노출 시 문자판 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 시계 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 농도 인형 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 장판이 초침 박자로 순차 발동, 종료 직후 시계 1.8s 노출.
- [ ] **P2 전환**: HP 66% → 배너 + 온도 상승에 따라 간격 절반, 노출 1.5s.
- [ ] **P3 전환**: HP 33% → 배너 + 평형 수렴 후 양 진영 동시 발동(가운데 안전), 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 활성화 구역 게이트 개방 조건 충족.
