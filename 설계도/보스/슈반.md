## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"동물도 세포로 이루어져 있다 — 서로 다른 조직도 같은 세포의 원리를 따른다."**

19세기 중반 독일의 생리학자 테오도어 슈반(Theodor Schwann)을 형상화한 존재. 1839년 슐라이덴의 식물세포설에 이어 동물 조직에서도 같은 결론을 내려
**동물세포설**을 제안해 "모든 생물은 세포로 이루어졌다"는 세포설의 토대를 세웠다. 신경 섬유를 감싸는 **슈반세포**와 소화 효소 펩신의 발견으로도 알려져 있다.
해부학의 지하 성역 3보스 중 **중간 난이도**(세포설 계보의 2단계).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 슐라이덴 · 슈반 · 피르호(세포설 3단계: 식물세포설 → 동물세포설 → '세포는 세포로부터')".
- [바이오스_해부학지하성역.md](../../디자인/던전/바이오스_해부학지하성역.md) §1, §6: 조직 수준 중간보스 "동물해부모형" 처치 열쇠로 진입하는 동물 조직 표본실의 주인. 진행 순서 ②번(슐라이덴 처치 후 개방).

### 포지션
해부학의 지하 성역 **중간 난이도**(조직 수준·동물 해부 모형 구역, 4페이즈). 난이도 계단: 슐라이덴 3P → **슈반 4P** → 피르호 5P.
> **⚠ 게임적 설정**: 슈반=조직 수준(동물)은 세포설 계보 순서와 확대 깊이를 맞춘 게임용 대응이다.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 중반 독일 생리학자 + 동물 조직 표본 장비. 1840년대 독일 대학 생리학자 복장(흰 실험 가운·조끼)에 해부 장비(메스·핀셋)와 현미경, 동물 조직 표본을 갖춘 모습.
린네~슐라이덴과 시대(19세기 중반)·국가(독일)·직업(생리학자)·장비(해부 장비·동물 조직 표본)로 구분(슐라이덴=독일 식물학자·현미경과 구별).

### 2-A 지금 (프리미티브 조립 — SchwannSetup.cs로 구현 가능)

```

├── Hair              Sphere(납작)  scale(0.55, 0.3, 0.55)  pos(0, 2.7, 0)  — 단정한 머리

├── WeakPoint         (BossWeakPoint) pos(0.2, 0.5, 0.2)  — 종아리에 감은 신경 다발
```

**패턴 식별 시각**: 조직별 장판 색·형태로 구분 — 상피=연분홍 넓은 평면(구멍 있음), 결합=갈색 줄로 연결된 원, 근육=붉은 박동하는 원, 신경=노란 번개 구슬이 마디를 도약.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 중반 독일 생리학자 — 흰 실험 가운·조끼·단정한 머리, 한 손에 메스·다른 손에 휴대용 현미경, 종아리에 감은 신경 다발.
- **소품**: 종아리의 신경 다발(약점, 수초 마디가 감긴 흰 섬유), 메스·핀셋, 현미경, 동물 조직 슬라이드(장식).
- **발광**: 신경 다발 — 평상시 은은한 노랑, 노출 시 수초 마디가 차례로 밝게 점멸하며 신호가 흐르는 듯한 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 흰 가운(#EDEDE8) + 상피 연분홍(#E8B8C0) + 결합 갈색(#8A6A3A) + 근육 붉음(#B83A3A) + 신경 노랑(#E8C84A) + 밝은 Emission(#FFF1A8, 약점).
- **실루엣**: 키 약 3.0 Unity units. 종아리의 휘감긴 신경 다발이 다리 쪽 실루엣을 특징짓는다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 4대 동물 조직 장판 4단계 — 동물 조직 4종(상피·결합·근육·신경)을 페이즈별 장판 형태로 옮긴다. **누적형**이며 슐라이덴의 단일 육각 타일과 달리
**조직마다 장판의 모양과 움직임이 다르다**는 것이 핵심이다.

| 페이즈 | 추가되는 조직 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **상피조직** — 몸의 표면을 덮는다 | 바닥의 **넓은 면**을 덮는 장판(아레나의 약 70%), **안전 구멍(원형 3개)** 이 뚫려 있음 |
| P2 | **결합조직** — 조직들을 연결한다 | 원형 장판 3~4개가 **줄(결합선)로 연결**되고 **줄 위도 위험** |
| P3 | **근육조직** — 수축과 이완 | 붉은 장판의 **반경이 커졌다 작아졌다(박동)** 3회 반복한 뒤 **최소 반경 상태에서 발동** |
| P4 | **신경조직** — 신호를 전달한다 | **번개 구슬**이 연결선의 **마디(수초 사이)를 도약**하며 각 마디에서 폭발(마디 3~5개) |

| 패턴 에셋 | 생물학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `AnimalTissuePattern.asset` (신규) | **동물세포설·4대 조직** | 조직별 형태의 장판이 발동 | 메스로 허공에 조직 단면을 그림 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 슈반이 메스로 허공을 그으면 조직별 **장판 텔레그래프**가 나타난다.
2. 플레이어는 장판의 **형태**를 읽어 안전한 위치로 이동한다.
   - 상피: 뚫린 **안전 구멍** 안에 선다.
   - 결합: 연결 **줄 사이·원 바깥**으로 피한다(줄 위도 위험).
   - 근육: 박동하는 장판의 **최소 반경 밖**에 선다(발동 순간의 반경이 최소).
   - 신경: 번개 구슬이 도약할 **마디 위치를 예측**해 피한다.
3. 장판이 모두 발동되면 슈반가 **무릎을 굽혀 종아리의 신경 다발을 살핀다** — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 규칙 | 시전 순환 |
|--------|----------|----------|
| P1 | 상피 | 상피 |
| P2 | 상피 + 결합 | 상피 → 결합 → 상피 → 결합 … |
| P3 | + 근육 | 상피 → 결합 → 근육 → 상피 … |
| P4 | + 신경 | 상피 → 결합 → 근육 → 신경 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 거의 정지, 무릎 굽혀 관찰
- 아레나 중앙 부근에서 거의 이동하지 않고 메스로 허공에 조직 단면을 그리는 자세를 유지한다.
- 장판 발동 후 **무릎을 굽혀 종아리의 신경 다발을 살피는** 모션 — 이때 종아리가 플레이어가 접근 가능한 낮은 높이로 노출된다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 종아리 신경 다발의 수초 마디 수가 늘어나는 연출(한 마디씩 추가 점멸).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 상피 장판 | P1~ | 큰 `Quad`(아레나 70%)에 원형 구멍 3개(마스크/구멍 배치) |
| 결합 장판 | P2~ | 원형 장판 3~4개 + 연결 줄 `Quad` |
| 근육 박동 | P3~ | 원형 장판 스케일을 `Mathf.Sin`으로 3회 진동 후 최소 스케일에서 발동 |
| 신경 도약 | P4 | 구슬 `Sphere`가 마디 좌표를 순차 이동하며 각 마디에서 폭발 |
| 신경 살핌 | 장판 발동 직후 | 보스가 무릎을 굽히는 모션 + `NerveBundle` Emission On |

## 5. 약점 메커니즘

### 종아리에 감은 신경 다발 (BossWeakPoint)
- **위치(확정)**: 종아리(localPos 0.2, 0.5, 0.2). 이미 쓴 부위(손·허리·어깨 위·등·가슴/품·머리 위·팔뚝·팔 안쪽·목·허벅지)와 구분되는 **종아리**.
- **노출 타이밍(확정)**: 조직 장판이 모두 발동한 **직후**, 슈반이 **무릎을 굽혀 신경 다발을 살피는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.2s). 무릎을 굽히는 모션으로 종아리가 접근 가능한 높이로 내려온다. 시간 기반이라 중간 난이도에 적합하고, 노출 중에는 장판이 남아 있지 않다.
- **신경 단서**: 신경 다발의 수초 마디 수가 페이즈마다 늘어나 현재 페이즈를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 은은한 노랑 → 노출 시 수초 마디가 차례로 밝게 점멸.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 신경 다발 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 동물해부모형 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 상피 장판(안전 구멍 3개) 예고→발동, 종료 직후 무릎을 굽혀 신경 다발 1.8s 노출.
- [ ] **P2 전환**: HP 75% → 배너 + 결합 장판(연결 줄 위험), 노출 1.6s.
- [ ] **P3 전환**: HP 50% → 배너 + 근육 박동 후 최소 반경 발동, 노출 1.4s.
- [ ] **P4 전환**: HP 25% → 배너 + 신경 마디 도약 연쇄, 노출 1.2s(수초 마디 점멸).
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 세포 수준 확대 게이트 개방 조건 충족.
