## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"바람에는 순환이 있다 — 오르는 곳과 내려앉는 곳은 정해져 있다."**

18세기 영국의 변호사이자 아마추어 기상학자 조지 해들리(George Hadley)를 형상화한 존재.
적도에서 상승한 공기가 위도 30°에서 하강하는 대기 대순환의 첫 번째 셀 — 해들리 순환의
발견자이자 지배자. 대기 부족의 랜드마크 "토네이도 정령의 영혼 평원"의 세 제단 중 첫 번째,
가장 정직하고 읽기 쉬운 관문.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 해들리(해들리 순환)·페렐(페렐 순환)·로스비(로스비파) — 지구과학Ⅰ '대기 대순환' 단원의 이름 붙은 순환·파동 3종"
- [테라노바_토네이도평원.md](../../디자인/던전/테라노바_토네이도평원.md) §2, §6: 중간보스 "해들리의 파수꾼"이 지키는 제단을 클리어하면 열쇠로 진입하는 정글↔사막 교대 아레나의 주인.

### 포지션
토네이도 평원 던전의 3개 보스방 중 **가장 쉬움** — 07의 유클리드처럼 "벽 보스"가 아니라
"정직한 개념 관문". 텔레그래프가 명확하고 예측 가능해, 이후 페렐·로스비의 불규칙성을 만나기
전 플레이어가 회피 기본기를 익히는 자리.

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — HadleySetup.cs로 구현 가능)

```
해들리 (BossRoot)
├── BossBody          Capsule   scale(1.1, 1.6, 1.1)  pos(0, 1.6, 0)   Color: 옅은 회백색(가발+옷)
├── CoatFlare (Pivot) empty     pos(0, 1.6, 0)          — 프록코트 자락, 바람에 휘날리는 시늉
│   └── CoatPanel×4    납작 Cube  각 scale(0.5, 1.2, 0.05)  — Update에서 개별 파형 흔들림
├── WigGeo            Sphere    scale(0.5, 0.4, 0.5)   pos(0, 2.7, 0)  Color: 흰색(가발)
├── WindTrail (Pivot) empty     pos(0, 1.6, 0)          — 몸 주변을 도는 나선형 바람 파티클 자리
│   └── TrailRing×3    납작 Torus 대용 Cylinder  반투명 하늘색, 각기 다른 반지름으로 회전
├── WeakPoint         (BossWeakPoint) pos(0, 1.7, 0.55) — 가슴 전면
│   └── CompassCore   Cylinder(납작)  scale 0.35  Color: 황동색  Emission OFF→ON 노출 시
│       └── CompassNeedle  가늘고 긴 Cube  회전축 자유 회전(항상 회전, 노출 시 가속)
└── CapsuleCollider   center(0, 1.6, 0)  radius 0.55  height 3.2
```

**패턴 식별 시각**: 바닥 텔레그래프(Telegraph)가 주 예고 신호. 상승/하강 장판은 색으로 구분
(상승=옅은 하늘색 상향 그라디언트, 하강=짙은 남색 하향 그라디언트).

### 2-B 미래 (최종 아트 가이드)

- **모델**: 18세기 영국 신사 — 흰 가발, 프록코트, 삼각모(선택). 옷자락이 상시 바람에 나부낌.
- **소품**: 손에 놋쇠 육분의(sextant) 또는 기압계를 든 자세(관측 도구를 여전히 손에서 놓지 않음).
- **발광**: 가슴 나침반 코어 — 평상시 황동색, 노출 시 하늘색 Emission + 바늘 회전 가속.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 흰 가발(#F5F0E8) + 옅은 하늘색(#AEE1F5, 상승) + 짙은 남색(#2A3B6B, 하강) — 대기 부족 팔레트 확장.
- **실루엣**: 키 약 3.2 Unity units. 코트 자락이 넓게 퍼져 실루엣의 절반을 차지.

## 3. 패턴 ↔ 순환 원리 매핑

| 패턴 에셋 | 순환 원리 | 바닥 텔레그래프 비주얼 | 시전 제스처 (미래 레이어) |
|----------|---------|-------------------|---------------------|
| `UpdraftZoneHadley.asset` | 적도 부근 **상승기류** | 옅은 하늘색 상향 원형 장판, 안쪽부터 밝아짐 | 육분의를 하늘로 들어올림 |
| `DowndraftZoneHadley.asset` | 위도 30° **하강기류** | 짙은 남색 하향 원형 장판, 가장자리부터 어두워짐 | 손을 아래로 내리누름 |
| `WindLineHadley.asset` (LineBeamPattern 재사용) | 순환 세포 사이 **지상풍** | 옅은 하늘색 직선 돌풍 장판 | 지팡이처럼 육분의로 직선을 그음 |
| `GaleBarrageHadley.asset` (PolygonBarragePattern 재사용) | 순환 셀 경계의 **난류** | 8방향 방사 돌풍구슬 | 코트 자락을 크게 펼쳐 사방으로 바람을 흩뿌림 |
| `TerrainSwapPattern.asset` (신규) | 상승↔하강의 **이원성** | 아레나 전체 플래시 후 지형 전환(비공격) | 육분의를 뒤집어 반대편을 가리킴 |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 느린 부유 이동 (유클리드와 동일한 저속 추적 패턴 차용)
- 패턴 캐스팅 사이(idle 구간) 플레이어를 향해 저속 부유 이동. 속도 ~1.5 m/s.
- 발이 지면에 닿지 않고 항상 10cm 정도 떠 있음(순환 이미지와 일치).
- 패턴 Execute 시작 시 이동 정지, 완료 후 재개.

### 페이즈 순간이동
- P2·P3 진입 시 아레나 중앙으로 즉각 이동 + 짧은 무적(~1초), 배너와 동기화.
- 텔레포트 VFX: ① 지금 = 없음. ② 미래 = 바람 소용돌이로 흩어졌다 재조립.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 코트 자락 파형 흔들림 | 항상 | `Update()`: `CoatPanel[i].localRotation`을 `Mathf.Sin(Time.time*speed+i)`로 흔듦 |
| 바람 파티클 링 회전 | 항상 | `WindTrail.Rotate(0, ringSpeed*Time.deltaTime, 0)`, 페이즈별 가속 |
| 나침반 바늘 회전 | 항상(느림) → 노출 시(빠름) | `CompassNeedle.Rotate` 속도 전환 |

## 5. 약점 메커니즘

### 가슴의 회전 나침반 (BossWeakPoint)
- **위치**: 가슴 전면(localPos 0, 1.7, 0.55).
- **노출 타이밍**: P2 진입 즉시(`exposeWeakPointOnEnter=true`, 5s) / P3에서는 GaleBarrage
  Execute 종료 직후 수동 `SetExposed(5f)` 호출(07 §4 패턴 훅 참조).
- **시각 피드백**: 평상시 황동색 저속 회전 → 노출 시 하늘색 Emission + 바늘 고속 회전.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 나침반 약점(×3)과는 독립.

## 8. 보스 아레나 — 정글↔사막 교대

### 8-A 지금 (HadleyBossRoomBuilder.cs 산출물)

| GameObject | Primitive | 설명 |
|-----------|-----------|------|
| BossFloor | Cylinder | 원형 중립 바닥(전환 시 밑에 항상 존재) |
| JungleSet (부모 오브젝트) | Plane(녹색) + Cube×N(나무 대용) | 정글 상태일 때만 Active |
| DesertSet (부모 오브젝트) | Plane(황토색) + Cube×N(바위 대용) | 사막 상태일 때만 Active |
| BossRoomTrigger | BoxCollider(trigger) | 진입 → BossBrain.StartBattle() |
| SealDoor | Cube | 전투 시작 시 활성화(이탈 방지) |

`TerrainSwapPattern.Execute()`가 `JungleSet.SetActive`/`DesertSet.SetActive`를 토글하고
동시에 파티클(먼지↔안개) 프리셋을 교체. 두 세트는 항상 상호 배타적으로 하나만 Active.

### 8-B 미래 (최종 아트 가이드)
- **정글 상태**: 짙은 녹음, 습한 안개 파티클, 열대 조류 울음 SFX.
- **사막 상태**: 건조한 모래바람 파티클, 아지랑이 셰이더, 뜨거운 바람 SFX.
- **전환 연출**: 두 지형이 겹쳐 보이는 짧은 디졸브(0.5초) 후 완전 전환 — "같은 바람이 만든
  두 얼굴"이라는 테마를 시각화.
