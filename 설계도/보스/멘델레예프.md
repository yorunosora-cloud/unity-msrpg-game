## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"규칙을 믿으면, 보지 못한 원소의 성질까지 예언할 수 있다."**

19세기 러시아의 화학자 드미트리 멘델레예프(Dmitri Mendeleev)를 형상화한 존재. 1869년 원소를 원자량과 성질에 따라 배열한 **주기율표**를 발표했다. 성질이 맞도록 필요하면 원자량 순서를
바꾸었고(텔루륨·아이오딘), 아직 발견되지 않은 원소의 **빈칸**을 남겨 성질을 예언했다 — 에카알루미늄(갈륨, 1875)·에카붕소(스칸듐, 1879)·에카규소(저마늄, 1886).
원소 카드를 늘어놓으며 표를 맞췄다는 일화가 전한다. 원소 주기율표 대성당 3보스 중 **최종 보스**.

### 세계관 근거

- [알케미아_원소주기율표대성당.md](../../디자인/던전/알케미아_원소주기율표대성당.md) §1, §2: 주기율표 구역 중간보스 "갈륨 성상" 처치 후 진입하는 원소 카드 서재의 주인. 진행 순서 ③번.

### 포지션
원소 주기율표 대성당 **최고 난이도**(주기율표 구역, 5페이즈). 난이도 계단: 라부아지에 3P → 뉴랜즈 4P → **멘델레예프 5P**.

## 2. 비주얼 명세

**패턴 식별 시각**: 바닥 격자 칸마다 원소 기호·원자량 표시, 족(세로줄)마다 고유 색, 빈칸 칸은 점선 테두리.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 러시아 화학자 — 긴 머리·풍성한 수염·두꺼운 외투, 주위를 도는 원소 카드.
- **소품**: 원소 카드 더미, 빈칸 카드(약점), 깃펜(빈칸에 성질을 적어 넣음).
- **발광**: 빈칸 카드 — 평상시 흐릿한 점선, 노출 시 예언된 원소의 기호·성질이 황금빛으로 나타남.

- **실루엣**: 키 약 3.1 Unity units. 긴 머리·수염과 주위를 도는 카드가 실루엣을 만든다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 족 → 주기 → 원자량 역전 → 빈칸 예언 → 주기율표 완성, 5페이즈 누적. 아레나 바닥은 **원소 격자**(초안: 7열=족 × 4행=주기).

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **족**(세로줄) | 같은 **세로줄**의 칸들이 **동시에** 발동(1~2줄) |
| P2 | **주기**(가로줄) | **가로줄**의 칸들이 **원자량 순**(왼→오)으로 차례차례 발동 |
| P3 | **원자량 역전** | 일부 두 칸(텔루륨 127.6 / 아이오딘 126.9)이 **원자량보다 성질(족)** 을 따라 자리를 바꿔, 발동 순서·색이 족 기준으로 정해짐 |
| P4 | **빈칸 예언** | **빈칸 칸**이 나타나고 **위·아래 이웃(같은 족)의 효과**를 이어받아 발동 — 이웃을 보고 효과를 예측해 피함 |
| P5 | **주기율표 완성** | **격자 전체**가 발동하고, 카드에 **지정된 족 세로줄 하나만 안전** |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `PeriodicTablePattern.asset` (신규) | **주기율표**(족·주기·성질에 따른 배열·원소 예언) | 원소 격자 장판 | 카드를 펼쳐 격자에 내려놓음 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 멘델레예프가 카드를 펼치면 **격자 텔레그래프**(세로줄 / 가로줄 순서 / 자리 바꿈 표시 / 빈칸 / 안전 족)가 나타난다.
2. 플레이어는 규칙에 따라 피한다.
   - 족: 발동하는 **세로줄 밖**으로 이동.
   - 주기: **원자량 순서**를 읽고 이미 발동한 칸으로 이동.
   - 역전: 원자량 숫자만 믿지 말고 **족 색**을 따른다.
   - 빈칸: **위·아래 칸의 효과**(즉시/지연/확산)를 보고 대비한다.
   - 완성: 카드에 지정된 **안전 족**으로 이동한다.
3. 장판 발동 직후 멘델레예프가 **빈칸 카드에 원소를 채워 넣는 동안 약점 노출**(§5).

### 족별 효과 (초안)
| 족(열) | 예시 | 효과 |
|---|---|---|
| 알칼리 금속 | Li·Na·K | 즉시 폭발 |
| 할로젠 | F·Cl·Br | 퍼지는 기체 |
| 그 외 열 | — | 즉시 발동 또는 0.6s 지연 발동(열마다 고정) |

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 족 | 족 |
| P2 | + 주기 | 족 → 주기 … |
| P3 | + 원자량 역전 | 족 → 주기 → 역전 … |
| P4 | + 빈칸 예언 | 족 → 주기 → 역전 → 빈칸 … |
| P5 | + 완성 | 족 → 주기 → 역전 → 빈칸 → 완성 |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 서재 책상 앞에서 카드를 배열
- 서재 책상 앞에서 거의 이동하지 않고 카드를 늘어놓는 자세를 유지한다.
- 장판 발동 후 **빈칸 카드를 앞으로 끌어와 깃펜으로 적는** 모션 — 이때 빈칸 카드가 플레이어가 접근 가능한 높이로 내려온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 벽의 빈칸 카드가 하나씩 채워지는 연출(예언 적중).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 족 발동 | P1~ | 격자 `Quad` 세로줄 동시 발동 |
| 주기 발동 | P2~ | 가로줄 칸을 0.35s 간격 순차 발동 |
| 자리 바꿈 | P3~ | 두 칸 `Lerp` 교환 연출 후 족 기준 판정 |
| 빈칸 | P4~ | 점선 `Quad`, 위·아래 칸 효과 복제 |
| 완성 | P5 | 전체 칸 발동, 안전 열 하나 제외 + 보스 앞 카드에 안전 족 색 표시 |
| 카드 채우기 | 장판 발동 직후 | 보스 모션 + `BlankCard` Emission On |

## 5. 약점 메커니즘

### 빈칸 원소 카드 (BossWeakPoint)
- **위치(확정)**: 보스 앞에 떠 있는 빈칸 카드(localPos 0, 1.6, 0.8).
- **노출 타이밍(확정)**: 장판이 **발동한 직후**, 멘델레예프가 **빈칸에 원소를 채워 넣는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.0s). 시간 기반이며 노출 중 새 장판은 없다(퍼지는 기체는 남을 수 있음).
- **카드 단서**: P5에서는 카드에 **안전 족**이 표시된다.
- **시각 피드백**: 평상시 점선 카드 → 노출 시 예언 원소 기호·성질 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 카드 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 갈륨 성상 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 세로줄 동시 발동, 종료 직후 빈칸 카드 1.8s 노출.
- [ ] **P2 전환**: HP 80% → 배너 + 가로줄 원자량 순 발동, 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + 두 칸 자리 바꿈 후 족 기준 판정, 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + 빈칸이 위·아래 효과 상속, 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 전체 발동, 지정 족만 안전, 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
