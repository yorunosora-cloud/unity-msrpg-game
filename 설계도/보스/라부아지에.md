## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"반응 전후에 질량은 보존된다 — 측정이 화학을 과학으로 만든다."**

18세기 프랑스의 화학자 앙투안 라부아지에(Antoine Lavoisier)를 형상화한 존재. 정밀한 측정으로 **질량 보존 법칙**을 세우고, 원소를 "더 이상 분해되지 않는 물질"로 정의했으며
『화학 원론』(1789)에 원소표를 실었다. 산소·수소의 이름을 붙였고 플로지스톤설을 뒤집어 "근대 화학의 아버지"로 불린다. 원소 주기율표 대성당 3보스 중 **원소 구역의 입문 관문**.
(원소표에는 빛·열소처럼 오늘날 원소가 아닌 항목도 있었다.)

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "원소 주기율표 대성당 보스: 뉴랜즈 · 멘델레예프 · 라부아지에(원소 개념 확립 → 규칙성 발견 시도 → 현대 주기율표 완성)".
- [알케미아_원소주기율표대성당.md](../../디자인/던전/알케미아_원소주기율표대성당.md) §1, §2: 원소 구역 중간보스 "산소 성상" 처치 후 진입하는 천칭 실험실의 주인. 진행 순서 ①번.

### 포지션
원소 주기율표 대성당 **입문 관문**(원소 구역, 3페이즈). 난이도 계단: **라부아지에 3P** → 뉴랜즈 4P → 멘델레예프 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 18세기 프랑스 학자 + 정밀 저울 장비. 흰 가발·긴 코트의 18세기 프랑스 학자 복장에 커다란 정밀 천칭과 유리 종(밀폐 실험 기구)을 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — LavoisierSetup.cs로 구현 가능)

```

├── Wig               Sphere(납작)  scale(0.6, 0.4, 0.6)  pos(0, 2.75, 0)  — 흰 가발
├── Collar            Cube(소)  scale(0.5, 0.15, 0.1)  pos(0, 2.2, 0.45)  — 흰 레이스 깃
├── Balance           empty     pos(0, 1.7, 0.7)  — 두 손으로 받친 커다란 천칭
│   ├── Beam          Cylinder(가로)  scale(0.06, 0.9, 0.06)  — 기울기 연출
│   ├── PanLeft       Cylinder(납작)  scale(0.5, 0.03, 0.5)  pos(-0.9, -0.5, 0)

│   └── Pivot         Sphere(소)  scale 0.22  Emission OFF→ON 노출 시
```

**패턴 식별 시각**: 분해=큰 원이 작은 원 4개로 갈라짐, 결합=작은 원들이 모여 큰 원, 평형=아레나 좌우의 접시 색 원(왼쪽 청록·오른쪽 황금).

### 2-B 미래 (최종 아트 가이드)

- **모델**: 18세기 프랑스 학자 — 흰 가발·짙은 남색 긴 코트·레이스 깃, 두 손으로 받친 대형 정밀 천칭.
- **소품**: 대형 천칭(중심축이 약점), 허리의 유리 플라스크, 뒤편의 유리 종(장식).
- **발광**: 중심축 — 평상시 은색 금속, 노출 시 황금빛 Emission(천칭이 수평을 맞추며 떨리다 점등).
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 남색 코트(#2E3A5C) + 흰 가발(#EDEDE8) + 금속 은(#B8BEC6) + 교황청 금(#C9A646) + 밝은 Emission(#FFF3C4, 약점).
- **실루엣**: 키 약 3.0 Unity units. 가슴 앞에 넓게 펼쳐진 천칭이 실루엣을 결정한다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 질량 보존 3단계 누적 — **모든 장판의 총 넓이가 보존**된다. 나뉘고(분해), 모이고(결합), 한쪽이 커지면 다른 쪽이 작아진다(평형).

| 페이즈 | 추가되는 규칙 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **분해** | 큰 원형 장판(반경 6)이 예고된 뒤 **작은 원 4개(반경 3)** 로 갈라져 흩어진 자리에서 발동 (총 넓이 동일) |
| P2 | **결합** | 흩어진 작은 원 4개(반경 3)가 **한 점으로 모여 큰 원(반경 6)** 이 되어 발동 |
| P3 | **평형** | 아레나 좌우에 **접시 원 2개**가 생기고 천칭이 기운 만큼 한쪽은 커지고 다른 쪽은 작아짐(두 원의 넓이 합 일정) |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `MassConservationPattern.asset` (신규) | **질량 보존 법칙**(분해·결합·반응 전후 질량 동일) | 분해·결합·평형 장판 | 천칭을 들어 기울임 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 라부아지에가 천칭을 기울이면 **텔레그래프**가 나타난다(갈라지는 원 / 모이는 원 / 좌우 접시 원의 최종 크기).
2. 플레이어는 규칙에 따라 피한다.
   - 분해: 큰 원 바깥이 아니라 **작은 원이 흩어질 자리**를 보고 그 틈으로 이동.
   - 결합: 작은 원 사이에 있으면 **모이는 중심**에 휘말리므로 바깥으로 벗어난다.
   - 평형: 천칭이 **올라간 쪽(가벼운 쪽) 원이 작다** — 작은 원 쪽 공간으로 이동.
3. 장판이 발동한 뒤 천칭이 **흔들리다 수평을 맞추는 동안 중심축 약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 규칙 | 시전 순환 |
|--------|----------|----------|
| P1 | 분해 | 분해 |
| P2 | + 결합 | 분해 → 결합 → 분해 → 결합 … |
| P3 | + 평형 | 분해 → 결합 → 평형 → 분해 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 실험대 앞에서 천칭을 받쳐 듦
- 천칭 실험실 중앙의 실험대 앞에서 거의 이동하지 않고 천칭을 받쳐 든 자세를 유지한다.
- 장판 발동 후 천칭을 **앞으로 내밀어 수평을 맞추는** 모션 — 이때 중심축이 플레이어가 접근 가능한 높이로 내려온다.

### 페이즈 전환
- P2~P3 진입 시 짧은 무적(~1초) + 배너. P3 진입 시 아레나 바닥에 좌우 접시 문양이 떠오른다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 분해 | P1~ | 큰 원 `Quad` → 1.0s 뒤 작은 원 4개가 `Lerp`로 흩어짐 → 발동 |
| 결합 | P2~ | 작은 원 4개가 중심으로 `Lerp` → 큰 원으로 교체 → 발동 |
| 평형 | P3 | `Beam` 회전(기울기)에 맞춰 좌우 원 `scale` 변경 → 발동 |
| 평형 맞추기 | 장판 발동 직후 | `Beam` 진동 감쇠 + `Pivot` Emission On |

## 5. 약점 메커니즘

### 정밀 천칭의 중심축 (BossWeakPoint)
- **위치(확정)**: 가슴 앞에 받쳐 든 천칭의 중심축(localPos 0, 1.7, 0.7).
- **노출 타이밍(확정)**: 장판이 **발동한 직후**, 천칭이 **흔들리다 수평을 맞추는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s). 시간 기반이라 입문 관문에 단순하며, 노출 중에는 장판이 남아 있지 않다.
- **저울 단서**: 천칭의 기울기가 P3에서 좌우 원 크기를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 은색 → 노출 시 황금빛 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 중심축 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 산소 성상 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 큰 원이 작은 원 4개로 갈라져 발동, 종료 직후 중심축 1.8s 노출.
- [ ] **P2 전환**: HP 66% → 배너 + 작은 원 4개가 모여 큰 원, 노출 1.5s.
- [ ] **P3 전환**: HP 33% → 배너 + 좌우 접시 원(천칭 기울기 연동), 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 옥타브 구역 게이트 개방 조건 충족.

## 11. 향후 확장

- **리깅 모션**: 코트 자락, 천칭 기울이기·수평 맞추기, 유리 플라스크 흔들기.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **평형 연출 강화**: 접시 위에 반응 전후 물질이 보이는 연출 확장안.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
