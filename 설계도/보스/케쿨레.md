> **위치**: `설계도/보스/케쿨레.md`

> **범위**: 케쿨레 보스 본체 + 뱀의 꿈 연회장 아레나만. 던전 전체 구조는
> [알케미아_벤젠육각신전.md](../../디자인/던전/알케미아_벤젠육각신전.md) 소관.
> **비주얼 명세 원칙**: 모든 비주얼·아레나 섹션은 **① 지금(프리미티브)** / **② 미래(최종 아트)** 2단 레이어로 기술.
> **확정/초안 구분**: 비주얼 컨셉·4페이즈·약점(손에 든 벤젠 고리 모형)·패턴 방향(탄소 4가→사슬→고리→결합 교대, 누적)·노출 타이밍(장판 발동 직후 고리가 닫힐 때)·
> 보스방(뱀의 꿈 연회장)은 사용자 확정. 장판 세부·수치·대사는 **초안**.
> **수치 기준**: 모든 수치는 **Lv1 기준 값**이며 실제 값은 [21_던전-레벨-스케일링.md](../21_던전-레벨-스케일링.md)가 정한다(maxHp·def는 §4-4-bis 공통표).
> **⚠ 게임적 설정 표시**: 탄소 4가·탄소 사슬(1857~58), 벤젠 고리 구조(1865), 결합이 번갈아 바뀐다는 가설(1872)은 실제 업적이나 **실제 벤젠의 여섯 결합은 모두 같다(공명)**.
> 뱀 꿈은 케쿨레가 훗날(1890) 회고한 것으로 전해지는 일화다. "결합이 장판이 된다", "고리가 닫히는 동안 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"탄소는 네 번 결합하고, 이어지고, 마침내 고리를 이룬다."**

19세기 독일의 화학자 아우구스트 케쿨레(August Kekulé)를 형상화한 존재. 탄소가 **네 개의 결합**을 이루며 서로 이어져 **사슬**을 만든다고 제안했고(1857~58), 1865년 **벤젠의 고리 구조**를
내놓았다. 단일·이중 결합이 빠르게 번갈아 바뀐다는 가설(1872)도 세웠다. 벤젠의 육각 신전 3보스 중 **구조 구역의 중간 난이도 보스**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "벤젠의 육각 신전 보스: 케쿨레 · 뵐러 · 폴링".
- [알케미아_벤젠육각신전.md](../../디자인/던전/알케미아_벤젠육각신전.md) §1, §2: 구조 구역 중간보스 "풀러렌 골렘" 처치 후 진입하는 뱀의 꿈 연회장의 주인. 진행 순서 ②번(역사순).

### 포지션
벤젠의 육각 신전 **중간 난이도**(구조 구역, 4페이즈). 난이도 계단: 뵐러 3P → **케쿨레 4P** → 폴링 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 독일 화학자 + 분자 구조 모형 장비. 19세기 중반 독일 교수 복장(풍성한 수염·조끼)에 원자를 막대로 이은 분자 구조 모형과 고리 그림 스케치북을 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — KekuleSetup.cs로 구현 가능)

```
케쿨레 (BossRoot)
├── BossBody          Capsule   scale(1.05, 1.5, 1.05)  pos(0, 1.5, 0)   Color: 검은 교수 코트
├── Beard             Capsule(납작)  scale(0.42, 0.4, 0.22)  pos(0, 2.25, 0.4)
├── Vest              Cube(납작)  scale(0.5, 0.6, 0.1)  pos(0, 1.5, 0.5)  — 조끼
├── Sketchbook        Cube(납작)  scale(0.35, 0.45, 0.04)  pos(-0.55, 1.35, 0.3)  — 스케치북(장식)
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.55, 0.4)  — 손에 든 벤젠 고리 모형
│   └── RingModel     Sphere×6 + Cylinder×6(단일·이중 결합)  scale 0.45  Emission OFF→ON 노출 시
├── BondEmitter       empty     pos(0, 0, 0)  — 결합·사슬·고리 장판 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.52  height 3.0
```

**패턴 식별 시각**: 결합선=밝은 직선, 사슬=탄소 구슬과 선, 고리=육각형 테두리, 결합 교대=한 줄(단일)·두 줄(이중) 선.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 독일 교수 — 검은 코트·조끼·풍성한 수염, 한 손에 벤젠 고리 모형, 다른 손에 스케치북.
- **소품**: 벤젠 고리 모형(약점), 스케치북, 어깨 위로 어른거리는 꼬리를 문 뱀의 환영(장식).
- **발광**: 고리 모형 — 평상시 흑연색, 노출 시 하늘빛 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 코트 검정(#1E1E24) + 흑연 구슬(#4A4A4A) + 하늘빛 Emission(#BFE8FF) + 자주(#8E3E7A) + 바로크 금(#C9A646).
- **실루엣**: 키 약 3.0 Unity units. 손의 육각 고리와 수염이 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 탄소 4가 → 사슬 → 고리 → 결합 교대, 4페이즈 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **탄소 4가** | 탄소 점에서 **네 방향 결합선**이 뻗어 발동(대각 네 영역이 안전) |
| P2 | **탄소 사슬** | 탄소 점들이 이어진 **사슬**이 한쪽 끝부터 차례로 발동 |
| P3 | **벤젠 고리** | 사슬의 양 끝이 닫혀 **육각 고리**가 됨 — 고리 선이 발동한 뒤 **안쪽 또는 바깥쪽** 중 표시된 쪽이 발동 |
| P4 | **결합 교대** | 고리의 **단일·이중 결합 6변이 번갈아 자리를 바꾸며** 발동(이중 결합 변은 폭이 두 배) |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `BenzeneStructurePattern.asset` (신규) | **유기화학 구조론**(탄소 4가·사슬·벤젠 고리·1872 진동 가설) | 결합선·사슬·고리 장판 | 고리 모형을 돌려 결합을 연결 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 케쿨레가 모형을 돌리면 **텔레그래프**가 나타난다(네 방향선 / 사슬 순서 / 고리의 안·밖 표시 / 단일·이중 변 배치).
2. 플레이어는 단계별 규칙에 따라 피한다.
   - 4가: 네 결합선 사이 **대각 영역**으로.
   - 사슬: **이미 발동한 마디**로 이동.
   - 고리: 표시된 쪽의 **반대편**(안/밖)으로.
   - 교대: 곧 **단일 결합이 될 변** 쪽 틈으로(바뀌는 순서를 읽음).
3. 장판 발동 직후 **모형의 고리가 닫히는 동안 약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 4가 | 4가 |
| P2 | + 사슬 | 4가 → 사슬 … |
| P3 | + 고리 | 4가 → 사슬 → 고리 … |
| P4 | + 교대 | 4가 → 사슬 → 고리 → 교대 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 연회장 중앙에서 모형을 돌림
- 연회장 중앙에서 거의 이동하지 않고 손의 고리 모형을 돌리는 자세를 유지한다.
- 장판 발동 후 **모형을 앞으로 내밀어 고리를 닫는** 모션 — 이때 모형이 플레이어가 접근 가능한 높이로 내려온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. P3 진입 시 연회장의 뱀 장식이 꼬리를 물어 고리를 이룬다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 네 방향선 | P1~ | 직선 `Quad` 4개 |
| 사슬 | P2~ | 탄소 점 `Sphere`와 선, 0.3s 간격 순차 발동 |
| 고리 | P3~ | 육각 테두리 `Quad` 6개 → 안/밖 `Quad` |
| 결합 교대 | P4 | 6변 단일·이중 폭을 0.8s마다 교체 후 발동 |
| 고리 닫기 | 장판 발동 직후 | 보스 모션 + `RingModel` Emission On |

## 5. 약점 메커니즘

### 손에 든 벤젠 고리 모형 (BossWeakPoint)
- **위치(확정)**: 오른손의 벤젠 고리 모형(localPos 0.5, 1.55, 0.4).
- **노출 타이밍(확정)**: 장판이 **발동한 직후**, 모형의 **고리가 닫히는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s). 시간 기반이며 노출 중에는 장판이 남아 있지 않다.
- **모형 단서**: 모형의 상태(점 → 사슬 → 고리 → 교대)가 현재 페이즈를 알려 준다.
- **시각 피드백**: 평상시 흑연색 → 노출 시 하늘빛 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 모형 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 풀러렌 골렘 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 네 방향 결합선 발동, 종료 직후 고리 모형 1.8s 노출.
- [ ] **P2 전환**: HP 75% → 배너 + 사슬 순차 발동, 노출 1.6s.
- [ ] **P3 전환**: HP 50% → 배너 + 고리와 안·밖 발동, 노출 1.4s.
- [ ] **P4 전환**: HP 25% → 배너 + 단일·이중 결합 교대 후 발동, 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 결합 구역 게이트 개방 조건 충족.
