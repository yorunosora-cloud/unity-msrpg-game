> **⚠ 게임적 설정 표시**: 활성화 에너지와 아레니우스 식(1889)은 실제 업적이고, 분자 에너지 분포·충돌 방향·촉매는 반응 속도론의 실제 개념이다. "언덕 높이가 발동 지연이 된다",
> "방향이 맞는 쌍만 폭발한다", "온도가 떨어지는 동안 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"반응하려면 언덕을 넘어야 한다 — 온도와 활성화 에너지가 속도를 정한다."**

스웨덴의 화학자 스반테 아레니우스(Svante Arrhenius)를 형상화한 존재. 1889년 반응이 일어나려면 넘어야 하는 **활성화 에너지** 개념과 속도 상수의 온도 의존을 나타내는
**아레니우스 식** `k = A·e^(−Ea/RT)`를 제시했다. 이온화 이론으로 노벨 화학상(1903)을 받았다. 촉매의 영원한 화로 3보스 중 **활성화 구역의 중간 난이도 보스**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "촉매의 영원한 화로 보스: 아레니우스 · 반트호프 · 랭뮤어(아레니우스 방정식은 반트호프의 연구에 근거해 제안됨)".
- [알케미아_촉매영원한화로.md](../../디자인/던전/알케미아_촉매영원한화로.md) §1, §2: 활성화 구역 중간보스 "온도 인형" 처치 후 진입하는 용광로 온도실의 주인. 진행 순서 ②번(역사순).

### 포지션
촉매의 영원한 화로 **중간 난이도**(활성화 구역, 4페이즈). 난이도 계단: 반트호프 3P → **아레니우스 4P** → 랭뮤어 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 말 스웨덴 화학자 + 온도계·에너지 곡선 장비. 19세기 말 스웨덴 학자 복장(콧수염·정장)에 커다란 온도계 지팡이와 에너지 곡선이 그려진 판을 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — ArrheniusSetup.cs로 구현 가능)


**패턴 식별 시각**: 언덕=솟은 고리와 높이 표시(낮음/중간/높음), 분자=작은 원(빠른 분자는 빨강), 충돌=화살표가 붙은 쌍, 촉매=녹색 발광 지점.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 말 스웨덴 학자 — 회색 정장·풍성한 콧수염, 한 손에 온도계 지팡이, 다른 손에 곡선판.
- **소품**: 온도계 지팡이(수은구가 약점), 에너지 곡선판.
- **발광**: 수은구 — 평상시 붉은 액체, 노출 시 은백색으로 밝게 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 정장 회색(#3C3C46) + 황동(#B08D57) + 액체 빨강(#C0392B) + 촉매 녹색(#5FA05A) + 밝은 Emission(#F4F8FF, 약점).
- **실루엣**: 키 약 3.0 Unity units. 키만 한 온도계 지팡이가 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 활성화 에너지 → 분자 에너지 분포 → 충돌 방향 → 촉매, 4페이즈 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **활성화 에너지** | 솟아오른 **언덕 고리장판** 3개 — 언덕이 **높을수록 늦게** 터짐(낮음 1.0s · 중간 1.6s · 높음 2.2s) |
| P2 | **분자 에너지 분포** | 작은 **분자 장판**이 흩어짐 — 온도가 오르면 **언덕을 넘는 빠른 분자(빨강, 큰 피해)** 의 수가 늘어남 |
| P3 | **충돌 방향** | 화살표가 붙은 분자 쌍 — **방향이 맞게 마주 보는 쌍만 폭발**하고, 어긋난 쌍은 지나침 |
| P4 | **촉매** | **촉매 지점(녹색)** 이 생겨 **주변 언덕이 낮아짐** → 그쪽 장판이 먼저 터지는 새 순서가 됨 |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `ActivationEnergyPattern.asset` (신규) | **반응 속도론**(활성화 에너지·에너지 분포·충돌 이론·촉매) | 언덕·분자·충돌·촉매 장판 | 온도계 지팡이를 용광로 쪽으로 들어 올림 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 아레니우스가 지팡이를 들면 **텔레그래프**가 나타난다(언덕 높이 / 분자 위치와 색 / 화살표 / 촉매 지점).
2. 플레이어는 규칙에 따라 피한다.
   - 언덕: **높이를 읽어** 터지는 순서를 예측.
   - 분포: **빨간 분자**를 우선 피함.
   - 충돌: **마주 보는 화살표 쌍**만 피하면 됨.
   - 촉매: **촉매 주변이 먼저** 터지므로 그쪽에서 먼저 벗어남.
3. 장판 발동 직후 **온도가 떨어지는 동안(지팡이를 살필 때) 약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 활성화 에너지 | 언덕 |
| P2 | + 에너지 분포 | 언덕 → 분포 … |
| P3 | + 충돌 방향 | 언덕 → 분포 → 충돌 … |
| P4 | + 촉매 | 언덕+촉매 → 분포 → 충돌 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 용광로 앞에서 지팡이를 짚음
- 용광로 앞에서 거의 이동하지 않고 온도계 지팡이를 짚은 자세를 유지한다.
- 장판 발동 후 **지팡이를 눈앞으로 기울여 눈금을 살피는** 모션 — 이때 수은구가 플레이어가 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 지팡이의 액체 눈금과 방의 거대 온도계가 한 단계 오른다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 언덕 고리 | P1~ | `Cylinder` 고리가 높이에 따라 솟고 지연 후 발동 |
| 분자 장판 | P2~ | 작은 `Quad` 다수, 빨강 비율 = 온도 |
| 충돌 쌍 | P3~ | 화살표 `Quad` 쌍이 접근, 방향 판정 후 발동 |
| 촉매 지점 | P4 | 녹색 `Quad` 반경 안 언덕의 지연 단축 |
| 눈금 살피기 | 장판 발동 직후 | 보스 모션 + `Bulb` Emission On |

## 5. 약점 메커니즘

### 큰 온도계 지팡이의 수은구 (BossWeakPoint)
- **위치(확정)**: 온도계 지팡이의 둥근 액체 주머니(localPos 0.6, 1.15, 0.35).
- **노출 타이밍(확정)**: 장판이 **발동한 직후**, **온도가 떨어지며 눈금을 살피는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s). 시간 기반이며 노출 중에는 장판이 남아 있지 않다.
- **눈금 단서**: 액체 높이가 현재 페이즈(온도)를 알려 준다.
- **시각 피드백**: 평상시 붉은 액체 → 노출 시 은백색 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 수은구 약점(×3)과는 독립.

### 8-B 미래 (최종 아트 가이드)
- **용광로 온도실**: 성채 심부의 거대 용광로와 온도계가 있는 방. 벽에 솟았다 내려가는 에너지 곡선이 새겨져 있다.
- **전환 연출**: 페이즈 전환마다 거대 온도계가 오르고, P4에서 벽의 곡선에 낮은 두 번째 곡선이 나타난다(촉매 경로).

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 온도 인형 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 언덕 3개가 높이 순으로 지연 발동, 종료 직후 수은구 1.8s 노출.
- [ ] **P2 전환**: HP 75% → 배너 + 분자 장판, 고온에서 빨강 비율 증가, 노출 1.6s.
- [ ] **P3 전환**: HP 50% → 배너 + 방향이 맞는 쌍만 폭발, 노출 1.4s.
- [ ] **P4 전환**: HP 25% → 배너 + 촉매 주변 언덕이 먼저 발동, 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 표면 구역 게이트 개방 조건 충족.
