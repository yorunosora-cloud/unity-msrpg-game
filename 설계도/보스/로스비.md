## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"파동은 홀로 움직이지 않는다 — 지나간 자리마다 새로운 파문이 인다."**

20세기 스웨덴계 미국 기상학자 칼-구스타프 로스비(Carl-Gustaf Rossby)를 형상화한 존재.
편서풍대를 남북으로 굽이치는 대규모 파동 — 로스비파(Rossby wave)의 구현자이자 지배자.
대기 부족 랜드마크 "토네이도 정령의 영혼 평원"의 세 제단 중 마지막이자 가장 강력한 관문.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 해들리(해들리 순환)·페렐(페렐 순환)·로스비(로스비파) — 지구과학Ⅰ '대기 대순환' 단원의 이름 붙은 순환·파동 3종"
- [테라노바_토네이도평원.md](../../디자인/던전/테라노바_토네이도평원.md) §2, §6: 중간보스 "로스비의 이무기"가 지키는 제단을 클리어하면 열쇠로 진입하는 지하 타원형 공동 아레나의 주인.

### 포지션
토네이도 평원 던전의 3개 보스방 중 **최고 난이도** — 해들리의 정직함, 페렐의 불규칙성을
모두 통과한 플레이어를 시험하는 최종 관문. 로스비 본인의 S자 돌진 위협과 함께, 페이즈가
진행될수록 불어나는 바람무녀기 무리를 함께 상대해야 하는 **군중전** 성격이 다른 두 보스와의
결정적 차이.

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — RossbySetup.cs로 구현 가능)

```
로스비 (BossRoot)
├── BossBody          Capsule   scale(1.1, 1.5, 1.1)  pos(0, 1.5, 0)   Color: 짙은 남색 정장(트렌치코트)
├── TrenchCoat (Pivot) empty    pos(0, 1.5, 0)          — 트렌치코트 자락, S자 돌진 시 크게 펄럭임
│   └── CoatPanel×4    납작 Cube  각 scale(0.5, 1.3, 0.05)  — Update에서 개별 파형 흔들림
├── ChartCase         Cylinder(둘말이) scale(0.25, 0.9, 0.25)  pos(0, 1.6, -0.5)  Color: 갈색 가죽 케이스, 등에 멘 위치
├── HandChart         납작 Cube(지도 겸 차트보드)  pos(0.5, 1.2, 0.2)  — 손에 든 파동선 기상도
├── WeakPoint         (BossWeakPoint) pos(0, 1.6, -0.5)  — 등 뒤 지도 케이스
│   └── ScrollCore    Cylinder(가는 원통)  scale 0.28  Color: 어두운 가죽색  Emission OFF→ON 노출 시
├── WaveTrail (Pivot) empty     pos(0, 1.0, 0)          — S자 돌진 경로를 따라 남는 파동선 잔상 자리
│   └── TrailSegment×N 납작 Cube(생성/소멸)  S자 경로를 따라 순차 배치
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.55  height 3.0
```

**패턴 식별 시각**: S자 돌진 경로는 바닥에 파동선 텔레그래프(옅은 남색 곡선)로 미리 표시.
소환 지점은 경로 위 일정 간격마다 소환 마커(작은 회오리 아이콘)로 표시된 후 실제 소환.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 초 현대 기상학자 — 정장 위에 트렌치코트, 손에는 파동선이 그려진
  기상도(차트보드)를 항상 들고 있음.
- **소품**: 등에 멘 둘말이 지도 케이스(파동선 기상도 두루마리) — 약점 오브젝트 겸 장비.
- **발광**: 등 지도 케이스 코어 — 평상시 어두운 가죽색, 노출 시 남색 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 짙은 남색 코트(#28304A) + 갈색 가죽 케이스(#6B4A32) + 남색 Emission(#4C6FE0, 약점) + 옅은 남색 파동선(#8FA8E8).
- **실루엣**: 키 약 3.1 Unity units. 해들리·페렐보다 다부진 실루엣 — 등 뒤 지도 케이스가 실루엣에 도드라짐.

## 3. 패턴 ↔ 순환 원리 매핑

| 패턴 에셋 | 순환 원리 | 바닥 텔레그래프 비주얼 | 시전 제스처 (미래 레이어) |
|----------|---------|-------------------|---------------------|
| `SCurveDashRossby.asset` (신규, 중간보스 계승·확장) | 편서풍대를 굽이치는 **로스비파의 파동 이동** | 옅은 남색 S자 곡선 경로 전체 표시 → 순차 진행 | 코트를 펄럭이며 몸 전체로 S자를 그리며 돌진 |
| `SummonTrailRossby.asset` (신규, 중간보스 계승·확장, **페이즈별 강화**) | 파동이 지나간 자리에 이는 **2차 파문**(로스비파의 하위 소용돌이) | S자 경로 위 소환 마커(회오리 아이콘) → 바람무녀기 등장 | 지나가며 손끝으로 경로에 점을 찍듯 소환 신호 |

> 07 §3-7 텔레그래프 동작(80% 경고→플래시→20%→Physics Overlap→Damage) 준용. 두 패턴 모두
> 중간보스 "로스비의 이무기"의 축소판 패턴과 **동일 클래스를 파라미터만 다르게 재사용**
> (보스는 돌진 판정 반경·소환 개수·소환 개체 강화 배율만 상향). 신규 패턴을 늘리지 않고
> 기존 2종을 **페이즈마다 파라미터로 강화**하는 방식(§4)으로 "최종 보스다운 물량"을 표현.

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: S자 돌진 중심 (평상시 정지, 패턴 시에만 이동)
- 패턴 캐스팅 사이(idle 구간)에는 제자리에서 손에 든 차트를 확인하는 자세로 정지 —
  해들리(느린 부유)·페렐(순간이동)과 다른 세 번째 이동 정체성.
- `SCurveDashRossby` 실행 시에만 실제로 이동 — S자 경로를 따라 빠르게(속도 ~7 m/s) 전진.
- 돌진 경로 종료 지점에서 잠시(0.6s) 멈춰 등 뒤 지도를 펼쳐보는 동작 — 이 순간 약점 노출(§5).

### 페이즈 전환
- P2·P3·P4 진입 시 아레나 중앙으로 즉각 이동 + 짧은 무적(~1초), 배너와 동기화.
- 텔레포트 대신 **단거리 S자 돌진**으로 중앙 복귀(별도 VFX 불필요, 기존 돌진 모션 재사용).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 코트 자락 파형 흔들림 | 돌진 중 강하게, 평상시 약하게 | `Update()`: 돌진 상태 플래그에 따라 `Mathf.Sin` 진폭 전환 |
| 파동선 잔상 생성 | 돌진 중 | `WaveTrail`에 `TrailSegment`를 일정 간격으로 Instantiate 후 페이드아웃 |
| 지도 케이스 발광 | 돌진 종료 직후(약점 노출 구간) | `ScrollCore` 머티리얼 Emission 토글 |

## 5. 약점 메커니즘

### 등에 멘 파동선 기상도 지도 케이스 (BossWeakPoint)
- **위치**: 등 뒤(localPos 0, 1.6, -0.5) — 정면에서는 보이지 않고, 로스비가 돌진 종료 후
  멈춰 지도를 펼쳐볼 때만 등이 플레이어 쪽으로 노출될 여지가 생긴다는 설정.
- **노출 타이밍**: `SCurveDashRossby` 종료 직후(멈춤 모션과 동기화) 자동 `SetExposed(duration)`
  호출 — duration은 페이즈별로 1.0s→0.9s→0.8s→0.6s로 단축(§4).
- **시각 피드백**: 평상시 어두운 가죽색 → 노출 시 남색 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 지도 케이스 약점(×3)과는 독립.

### 8-B 미래 (최종 아트 가이드)

- **조명**: 어둡고 좁은 지하 공간 — GlowVein과 보스·소환 개체의 발광만이 주 광원.

- **전환 연출**: P4 진입 시 벽면 GlowVein 전체가 한 번에 밝아지며 "총동원 소환" 예고.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 제단 클리어 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1 패턴**: SCurveDash(경로 표시+돌진+접촉 피해) 정상 발동, 종료 후 지도 케이스 1.0s 노출 확인. SummonTrail 1마리 소환 확인.
- [ ] **P2 전환**: HP 75% → 배너 + SummonTrail 2마리 소환 확인, 노출 창 0.9s로 단축 확인.
- [ ] **P3 전환**: HP 50% → 배너 + SummonTrail 3마리(스탯 1.3배) 소환 확인, 노출 창 0.8s.
- [ ] **P4 전환**: HP 25% → 배너 + "총동원 소환"(5마리 동시) 1회 발동 확인 → 이후 3마리 반복 확인, 노출 창 0.6s.
- [ ] **군중전 밸런스**: P3~P4에서 소환된 바람무녀기 무리와 로스비 본체 위협이 동시에 감당 가능한 난이도인지 확인(과도할 시 소환 상한 또는 쿨다운 조정).
- [ ] **처치**: HP 0 → defeatLine + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 클리어.

## 11. 향후 확장

- **리깅 모션**: 코트 자락 물리 시뮬레이션, S자 돌진 잔상 셰이더.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **소환 상한 시스템**: 현재 화면에 살아있는 소환 개체 수 상한을 두어 과도한 군중전을 방지하는 안전장치 — 밸런스 테스트 후 필요 시 `SummonTrailPattern`에 `maxAliveSummons` 파라미터 추가.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
