# 키르히호프 보스 구현 설계도

> **위치**: `설계도/보스/키르히호프.md`
> **역할**: [07_보스전.md](../07_보스전.md) 공통 템플릿을 키르히호프에 실제로 어떻게 구체화할지 명세.
> [분젠.md](분젠.md)·[랭뮤어.md](랭뮤어.md)와 동일한 구조를 따른다.
> **범위**: 키르히호프 보스 본체 + 프리즘 관측실 아레나만. 던전 전체 구조는
> [알케미아_분광분석등대.md](../../디자인/던전/알케미아_분광분석등대.md) 소관.
> **비주얼 명세 원칙**: 모든 비주얼·아레나 섹션은 **① 지금(프리미티브)** / **② 미래(최종 아트)** 2단 레이어로 기술.
> **확정/초안 구분**: 비주얼 컨셉·4페이즈·약점(햇빛을 모으는 오목거울)·패턴 방향(연속 스펙트럼→방출선→흡수선→태양의 원소 판별, 누적)·노출 조건(**플레이어가 목표 원소의 선 위치를 모두 밟았을
> 때** — 능동)·보스방(프리즘 관측실)은 사용자 확정. **선 위치 찾기 세부 규칙**·장판·수치·대사는 **초안**.
> **분젠과의 난이도 정합**: 불꽃 구역·선 구역은 **순서가 자유**이므로 [분젠.md](분젠.md)와 **페이즈 수(4)·maxHp·def·목표 수·노출 시간**을 동일하게 둔다.
> **수치 기준**: 모든 수치는 **Lv1 기준 값**이며 실제 값은 [21_던전-레벨-스케일링.md](../21_던전-레벨-스케일링.md)가 정한다(maxHp·def는 §4-4-bis 공통표).
> **⚠ 게임적 설정 표시**: 연속·방출·흡수 스펙트럼에 관한 키르히호프의 법칙과 태양의 어두운 선(프라운호퍼선) 해석은 실제 과학이나, "스펙트럼 띠가 아레나 바닥이 된다",
> "선 위치가 장판이 된다", "선을 모두 밟으면 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"빛의 선을 읽으면, 닿을 수 없는 곳의 원소도 알 수 있다."**

19세기 독일의 물리학자 구스타프 키르히호프(Gustav Kirchhoff)를 형상화한 존재. 뜨거운 고체는 **연속 스펙트럼**, 뜨거운 희박한 기체는 **방출선**, 차가운 기체를 지난 빛은 같은 위치의
**흡수선**을 만든다는 분광 법칙을 정리했고, 태양 빛의 어두운 선으로 **태양 대기의 원소**를 밝혔다. 분젠과 함께 분광 분석법을 확립했다.
분광 분석의 등대 3보스 중 **선 구역의 보스**(분젠과 순서 자유).

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "분광 분석의 등대 보스: 분젠 · 키르히호프 · 모즐리".
- [알케미아_분광분석등대.md](../../디자인/던전/알케미아_분광분석등대.md) §1, §2: 선 구역 중간보스 "루비듐 환영수" 처치 후 진입하는 프리즘 관측실의 주인.

### 포지션
분광 분석의 등대 **자유 구역 보스**(4페이즈, 분젠과 동급). 난이도 계단: **분젠 4P = 키르히호프 4P** → 모즐리 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 독일 물리학자 + 태양광 관측 장비. 19세기 독일 학자 복장에 햇빛을 모으는 오목거울과 태양 스펙트럼 도표를 갖춘 모습. 분젠(버너·백금선)과 장비로 구분.

### 2-A 지금 (프리미티브 조립 — KirchhoffSetup.cs로 구현 가능)

```
키르히호프 (BossRoot)
├── BossBody          Capsule   scale(0.95, 1.5, 0.95)  pos(0, 1.5, 0)   Color: 짙은 갈색 코트
├── Hair              Sphere(납작)  scale(0.55, 0.32, 0.55)  pos(0, 2.7, 0)
├── Beard             Capsule(작은)  scale(0.3, 0.25, 0.15)  pos(0, 2.25, 0.42)
├── SpectrumChart     Quad  scale(0.6, 0.25, 1)  pos(-0.65, 1.55, 0.3)  — 태양 스펙트럼 도표(어두운 선)
├── WeakPoint         (BossWeakPoint) pos(0.55, 1.55, 0.45)  — 손에 든 오목거울
│   └── ConcaveMirror Sphere(납작 반구)  scale(0.45, 0.45, 0.12)  Emission OFF→ON 노출 시
├── SunBeam           가는 Cylinder(반투명)  위에서 거울로 내려오는 햇빛(장식)
├── LineEmitter       empty     pos(0, 0, 0)  — 스펙트럼 띠·선 장판 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 바닥의 **파장 띠**(400~700nm 눈금), 방출선=밝은 가는 띠, 흡수선=어두운 띠, 원소 도표=벽과 머리 위의 선 무늬.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 독일 학자 — 갈색 코트·짧은 수염, 한 손에 오목거울, 다른 손에 스펙트럼 도표.
- **소품**: 오목거울(약점), 태양 스펙트럼 도표, 작은 프리즘.
- **발광**: 거울 — 평상시 은색, 노출 시 햇빛이 모여 강하게 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 코트 갈색(#4A3A30) + 거울 은(#D0D8E0) + 햇빛 노랑(#FFE9A0) + 스펙트럼 색 + 흡수선 검정(#101018) + 밝은 Emission(#FFFBE8, 약점).
- **실루엣**: 키 약 3.0 Unity units. 손의 둥근 거울과 위에서 내려오는 빛줄기가 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 연속 스펙트럼 → 방출선 → 흡수선 → 태양의 원소 판별, 4페이즈 누적. 아레나 바닥은 **파장 띠**(왼쪽 보라 400nm → 오른쪽 빨강 700nm, 초안).

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **연속 스펙트럼** | 빈틈없는 **빛 띠**가 한쪽에서 반대쪽으로 훑고 지나감(미리 보이는 진행 방향 반대로 피하거나 통과 후 지역으로) |
| P2 | **방출선** | 한 원소의 **선 위치만** 밝게 발동(예: 수소 410·434·486·656nm) |
| P3 | **흡수선** | 띠 **전체가 발동하고 어두운 선 위치만 안전** |
| P4 | **태양의 원소 판별** | 여러 원소의 어두운 선이 섞인 **태양 스펙트럼**을 보여 주고 원소 하나를 지목 — **그 원소의 선 위치가 폭발**하므로 도표와 대조해 피함 |

**원소 선 위치(nm, 초안 데이터)**: 수소 410·434·486·656 / 나트륨 589 / 칼슘 393·397 / 마그네슘 518 / 철 527 / 리튬 610·671.
(400nm보다 짧은 칼슘 선은 띠의 왼쪽 끝에 표시.)

| 패턴 에셋 | 화학·물리 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|-------------|---------|---------------------|
| `SpectrumLinePattern.asset` (신규) | **키르히호프 분광 법칙** | 파장 띠 장판 | 거울로 햇빛을 모아 바닥에 비춤 |

### 플레이어의 선 위치 밟기 (약점 조건, 초안·게임적 설정)
1. 사이클마다 머리 위에 **목표 원소**가 표시되고, 그 원소의 선 위치 중 **지정된 수**만큼 찾아야 한다.
2. 파장 띠의 해당 위치에 **0.3초 머물면 그 선이 밝혀진다**. 틀린 위치는 반응하지 않는다(벌칙 없음). 밝힌 선은 노출 때까지 유지.
3. **P1은 원소 이름과 선 위치 표시를 함께**(힌트), **P2부터는 원소 이름만** 보여 주며 벽의 원소 도표를 보고 위치를 찾는다.
4. 목표 선을 **모두 밝히면** 키르히호프가 거울의 초점을 다시 맞추며 **약점 노출**(§5). 노출이 끝나면 목표가 새로 정해진다.

| 페이즈 | 찾을 선 수 | 등장 원소 |
|---|---|---|
| P1 | 2 | 수소 · 나트륨 |
| P2 | 3 | 수소 · 나트륨 · 리튬 |
| P3 | 3 | + 마그네슘 · 칼슘 |
| P4 | 4 | + 철 |

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 연속 | 연속 |
| P2 | + 방출선 | 연속 → 방출 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 창가에서 거울을 비춤
- 관측실의 햇빛 창 아래에서 거의 이동하지 않고 거울의 각도를 조절한다.
- 목표 선이 모두 밝혀지면 **거울을 앞으로 내밀어 초점을 맞추는** 모션 — 이때 거울이 플레이어가 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. 바닥의 밝힌 선은 초기화된다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 연속 띠 | P1~ | 폭 있는 `Quad`가 띠를 따라 이동 |
| 방출선 | P2~ | 지정 위치에 가는 `Quad` 발동 |
| 흡수선 | P3~ | 전체 `Quad` 발동, 어두운 선 위치만 판정 제외 |
| 태양 판별 | P4 | 벽 도표 + 머리 위 원소 이름, 해당 위치 발동 |
| 초점 맞추기(노출) | 선 모두 밝힘 | 보스 모션 + `ConcaveMirror` Emission On |

## 5. 약점 메커니즘

### 햇빛을 모으는 오목거울 (BossWeakPoint)
- **위치(확정)**: 손에 든 오목거울(localPos 0.55, 1.55, 0.45).
- **노출 조건(확정)**: **플레이어가 목표 원소의 선 위치를 모두 밟았을 때** `SetExposed(duration)` 호출(능동). duration은 §4 표(2.6s→2.2s, 분젠과 동일).
- **목표 단서**: 머리 위 원소 이름과 남은 선 수, 벽의 원소 도표.
- **시각 피드백**: 평상시 은색 → 노출 시 햇빛이 모여 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 거울 약점(×3)과는 독립.
