## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"궤도에는 법칙이 있다 — 타원의 모양도, 도는 속도도, 우연이 아니다."**

독일의 천문학자 요하네스 케플러(Johannes Kepler)를 형상화한 존재. 행성이 원이 아니라
타원 궤도를 그리며, 태양에 가까울수록 빠르고 멀수록 느리게 움직인다는 행성운동법칙을
수학적으로 증명했다. 거대 천문대 피라미드 3보스 중 마지막이자 가장 강력한 관문 — 코페르니쿠스의
개념, 갈릴레이의 관측을 모두 수학 법칙으로 완성시킨 존재.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 니콜라우스
  코페르니쿠스(지동설)·갈릴레오 갈릴레이(관측천문학)·요하네스 케플러(행성운동법칙) —
  지구과학Ⅰ '행성의 운동' 단원 표준 서사"
- [테라노바_거대천문대피라미드.md](../../디자인/던전/테라노바_거대천문대피라미드.md) §2, §6:
  케플러 계단의 중간보스 "타원궤도혜성"을 처치하면 얻는 열쇠로 진입하는 타원궤도 모형실
  아레나의 주인.

### 포지션
거대 천문대 피라미드 3보스방 중 **최고 난이도** — 판게아 유적의 헤스와 마찬가지로 던전
최종보스답게 **5페이즈**로 설계했다. 미니보스 "타원궤도혜성"의 근일점 가속·원일점 감속
컨셉을 보스 규모로 확장해, 페이즈가 진행될수록 동시에 존재하는 타원 궤도의 수가 늘어난다
(헤스의 "대칭광선 쌍 증가"와 같은 물량 증가형 난이도 곡선).

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — KeplerSetup.cs로 구현 가능)

```
케플러 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 청록색 학자 가운
├── ScholarRobe (Pivot) empty   pos(0, 1.5, 0)          — 가운 자락
│   └── RobePanel×3    납작 Cube  각 scale(0.4, 1.3, 0.05)
├── OrbitCompass      Cylinder(원반형, 타원 눈금) scale(0.35, 0.05, 0.35)  pos(0.5, 1.3, 0.2)  — 손에 든 타원 궤도 계산 도구
├── WeakPoint         (BossWeakPoint) pos(0, 1.7, 0.4)  — 가슴의 타원궤도 도표판
│   └── DiagramGlow   납작 Cube(도표판형)  scale(0.4, 0.5, 0.05)  Color: 짙은 청록  Emission OFF→ON 노출 시(각 궤도 근일점 통과 직후)
├── OrbitAnchor×5      각기 다른 타원 궤도 자리(페이즈별 활성화 개수 증가)
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 각 타원 궤도는 바닥에 새겨진 타원형 텔레그래프 경로로 표시 — 경로를
따라 도는 발광체가 원일점(먼 지점)에서는 느리게, 근일점(가까운 지점)에서는 급가속하며
플레이어 방향으로 파고든다. 페이즈가 진행될수록 동시에 존재하는 타원 경로의 수가 늘어난다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 학자풍 가운 + 손에 든 타원 궤도 계산 도구(눈금이 그려진 원반, 실제 케플러의
  기하학적 작도 방식을 형상화).
- **소품**: 가슴에 걸친 타원궤도 도표판(약점 오브젝트) — 여러 개의 타원이 겹쳐 그려진 도표.
- **발광**: 도표판 — 평상시 어두운 청록, 각 궤도의 근일점 통과 직후 짧게 강한 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 짙은 청록 가운(#1F4A45) + 금색 궤도선(#D4AF37) + 밝은 Emission(#4EE0C4, 약점).
- **실루엣**: 키 약 3.1 Unity units. 3보스 중 가장 기하학적이고 정교한 실루엣 — 몸 주위로
  여러 타원 궤도선이 항상 은은하게 떠 있음.

## 3. 패턴 ↔ 순환 원리 매핑

| 패턴 에셋 | 천문 원리 | 바닥 텔레그래프 비주얼 | 시전 제스처 (미래 레이어) |
|----------|---------|-------------------|---------------------|
| `EllipticalOrbitPattern.asset` (신규, 미니보스 계승·확장) | **케플러 제1법칙**(타원 궤도) + **제2법칙**(면적속도 일정 — 근일점 가속·원일점 감속) | 타원형 경로 텔레그래프, 경로를 따라 도는 발광체가 근일점에서 급가속 | 궤도 계산 도구를 들어 타원을 그리듯 손을 움직임 |

> 07 §3-7 텔레그래프 동작(80% 경고→플래시→20%→Physics Overlap→Damage) 준용. 케플러는
> 헤스와 동일한 방식으로 **패턴 종류를 늘리지 않고 동시 존재 궤도 수를 페이즈마다 늘림**
> (1→2→3→4→5개). 미니보스 "타원궤도혜성"의 `EllipticalRushPattern`과 **동일 클래스를
> 파라미터만 다르게 재사용**(보스는 동시 궤도 수·반경·데미지만 상향).

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 거의 정지, 제자리에서 계산
- 패턴 캐스팅과 무관하게 거의 이동하지 않고 제자리에서 궤도 계산 도구를 조작하는 자세를
  유지 — 실제 공격은 본체가 아니라 궤도를 도는 발광체들이 수행.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너와 동기화. 도구를 높이 들어올리며 새 타원 궤도를
  하나 더 그려내는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 가운 자락 흔들림 | 항상 | `Update()`: `RobePanel[i].localRotation`을 `Mathf.Sin(Time.time*speed+i)`로 흔듦 |
| 타원 발광체 이동 | 항상(패턴 활성 궤도 수만큼) | 타원 경로를 매개변수화한 궤도 방정식을 따라 위치 갱신, 근일점 근처에서 속도 급증 |
| 도표판 Emission | 각 궤도의 근일점 통과 직후 | `DiagramGlow` 머티리얼 Emission 짧게 On(궤도별로 독립 트리거) |

## 5. 약점 메커니즘

### 가슴의 타원궤도 도표판 (BossWeakPoint)
- **위치**: 가슴 전면(localPos 0, 1.7, 0.4).
- **노출 타이밍**: 활성화된 각 타원 궤도가 근일점을 통과한 직후 자동 `SetExposed(duration)`
  호출 — duration은 페이즈별로 0.8s→1.0s→1.2s→1.4s→1.6s로 **늘어남**(§4). 궤도 수가 많을수록
  근일점 이벤트 자체도 자주 발생해 기회가 배가됨.
- **시각 피드백**: 평상시 어두운 청록 → 노출 시 밝은 Emission.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 도표판 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 타원궤도혜성 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1 패턴**: EllipticalOrbit(궤도 1개, 4.0s 회전) 정상 발동, 근일점 통과 직후 약점 0.8s 노출 확인.
- [ ] **P2~P5 전환**: HP 80/60/40/20% 도달마다 배너 + 궤도 수 순차 증가(2→3→4→5) + 회전 주기 단축 + 노출 시간 증가(1.0→1.2→1.4→1.6s) 확인.
- [ ] **최종 페이즈 밸런스**: P5(5개 궤도 동시 존재)에서 회피 공간이 과도하게 좁아지지 않는지 확인.
- [ ] **처치**: HP 0 → defeatLine + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 클리어.

## 11. 향후 확장

- **리깅 모션**: 가운 물리 시뮬레이션, 궤도 계산 도구 조작 애니메이션.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **궤도 색상 구분**: 동시에 존재하는 여러 타원을 색상으로 구분해 가독성을 높이는 확장안.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
