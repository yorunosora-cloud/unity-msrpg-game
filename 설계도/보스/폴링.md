## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"원자가 어떻게 손을 잡는지가 분자의 모양과 성질을 정한다."**

20세기 미국의 화학자 라이너스 폴링(Linus Pauling)을 형상화한 존재. **전기음성도** 척도를 만들고 **혼성 오비탈**과 **공명** 개념으로 화학 결합을 설명했으며(『화학 결합의 본질』, 1939),
**수소 결합**이 지탱하는 단백질의 **알파 나선**을 제안했다(1951). 1954년 노벨 화학상, 1962년 노벨 평화상을 받았다. 벤젠의 육각 신전 3보스 중 **최종 보스**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "벤젠의 육각 신전 보스: 케쿨레 · 뵐러 · 폴링".
- [알케미아_벤젠육각신전.md](../../디자인/던전/알케미아_벤젠육각신전.md) §1, §2: 결합 구역 중간보스 "다이아몬드 골렘" 처치 후 진입하는 분자 모형 궁정의 주인. 진행 순서 ③번(역사순).

### 포지션
벤젠의 육각 신전 **최고 난이도**(결합 구역, 5페이즈). 난이도 계단: 뵐러 3P → 케쿨레 4P → **폴링 5P**.

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 미국 화학자 + 공-막대 분자 모형 장비. 20세기 중반 미국 연구자 복장(정장·베레모)에 큰 공-막대 분자 모형과 칠판을 갖춘 모습.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 미국 화학자 — 갈색 정장·베레모, 한 손에 공-막대 분자 모형, 다른 손에 분필.
- **소품**: 분자 모형(약점), 칠판(결합식), 종이로 접은 알파 나선(장식).
- **발광**: 모형 — 평상시 색 구슬, 노출 시 결합 막대가 밝게 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 정장 갈색(#5A4636) + 칠판 녹색(#2E4A3C) + 원자 색(N #3E6CB0·O #C0392B·C #1E1E24·H #EDEDE8) + 전자 노랑(#E8C84A) + 하늘빛 Emission(#BFE8FF).
- **실루엣**: 키 약 3.1 Unity units. 베레모와 손의 분자 모형이 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 전기음성도 → 결합 극성 → 혼성 → 수소 결합 → 공명, 5페이즈 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **전기음성도** | 두 원자 장판(값 표시) 사이의 **전자 장판이 전기음성도가 큰 원자 쪽으로 끌려가** 그 자리에서 발동 |
| P2 | **결합 극성** | 값 차이에 따라 — **비극성**: 가운데 발동 / **극성**: 양쪽 발동(큰 쪽이 더 넓음) / **이온성**: 두 이온으로 완전히 갈라져 각각 크게 발동 |
| P3 | **혼성** | 중심 원자에서 **sp(2선, 180°)·sp²(3선, 120°)·sp³(3선 + 중심 원, 위를 향한 네 번째 결합)** 결합선 발동 |
| P4 | **수소 결합** | **알파 나선** 점선이 바깥으로 감기며 순서대로 발동, **i번째와 i+4번째 점이 짝으로 이어져** 연결선도 발동 |
| P5 | **공명** | 벤젠 고리 **여섯 결합이 모두 같은 폭·세기로 동시에** 발동(중심과 바깥이 안전) — 케쿨레의 교대가 하나로 합쳐짐 |

전기음성도 값(폴링 척도): H 2.20 · C 2.55 · N 3.04 · O 3.44 · F 3.98 · Na 0.93 · Cl 3.16.

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `ChemicalBondPattern.asset` (신규) | **화학 결합론**(전기음성도·극성·혼성·수소 결합·공명) | 원자·전자·결합·나선·고리 장판 | 칠판에 결합식을 적음 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 폴링이 **칠판 쪽으로 돌아 결합식을 적는다** — 이 동안 바닥에 텔레그래프가 나타나고 **뒤로 뻗은 손의 분자 모형이 노출**된다(§5). 칠판의 식이 다음 공격의 힌트다.
2. 다 적으면 폴링이 돌아서며 장판이 발동한다. 플레이어는 규칙에 따라 피한다.
   - 전기음성도: **값이 큰 원자** 쪽에서 벗어난다.
   - 극성: 값 차이를 읽어 가운데/양쪽/갈라짐을 판단.
   - 혼성: 칠판의 sp·sp²·sp³ 표기로 **선 사이 각도**의 틈을 찾는다.
   - 수소 결합: 나선 순서와 **i+4 연결선**을 피한다.
   - 공명: **고리 중심 또는 바깥**으로.
3. 플레이어는 **약점을 칠 것인가, 텔레그래프를 읽고 자리를 잡을 것인가**를 판단해야 한다.

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | 전기음성도 | 전기음성도 |
| P2 | + 극성 | 전기음성도 → 극성 … |
| P3 | + 혼성 | 전기음성도 → 극성 → 혼성 … |
| P4 | + 수소 결합 | 전기음성도 → 극성 → 혼성 → 수소 결합 … |
| P5 | + 공명 | 전기음성도 → 극성 → 혼성 → 수소 결합 → 공명 |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 칠판 앞에서 돌아서고 다시 마주 봄
- 칠판 앞에서 거의 이동하지 않고, 시전마다 **칠판 쪽으로 몸을 돌려** 적은 뒤 **돌아서며** 발동한다.
- 적는 동안 분자 모형을 든 손이 몸 뒤(플레이어 쪽)로 향해 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 궁정의 거대 분자 모형이 새 결합을 얻는다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 칠판 적기(노출) | 시전 시작 | 보스 회전 + `TextMesh` 한 글자씩 표시 + `BallStickModel` Emission On |
| 전자 이동 | P1~ | 노란 `Quad` `Lerp` → 발동 |
| 극성 분기 | P2~ | 값 차이로 장판 배치 선택 |
| 혼성 선 | P3~ | 중심에서 직선 `Quad` 2~3개 + 원 |
| 나선 | P4~ | 나선 경로 점 12개 0.2s 순차 + i/i+4 선 |
| 공명 고리 | P5 | 육각 `Quad` 6개 동시 |

## 5. 약점 메커니즘

### 공-막대 분자 모형 (BossWeakPoint)
- **위치(확정)**: 손에 든 분자 모형(localPos 0.5, 1.5, 0.4 — 칠판을 향해 돌면 플레이어 쪽에 위치).
- **노출 타이밍(확정)**: 폴링이 **칠판에 결합식을 적는 동안**(공격 발동 **전**) `SetExposed(duration)` 호출. duration = 적는 시간(§4 표, 1.8s→1.0s)이며 바닥 텔레그래프와 겹친다.
  다른 보스와 달리 **공격 직전의 기회**라, 계속 때릴지 자리를 잡을지 판단해야 한다.
- **칠판 단서**: 칠판의 식(전기음성도 값·sp 표기·고리)이 다음 장판을 알려 준다.
- **시각 피드백**: 평상시 색 구슬 → 노출 시 결합 막대 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 모형 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 다이아몬드 골렘 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 칠판에 적는 동안 모형 1.8s 노출, 이후 전자 장판이 큰 값 원자 쪽에서 발동.
- [ ] **P2 전환**: HP 80% → 배너 + 비극성/극성/이온 분기, 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + sp/sp²/sp³ 각도선, 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + 나선 순차 발동과 i+4 연결선, 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 공명 고리 동시 발동(중심·바깥 안전), 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
