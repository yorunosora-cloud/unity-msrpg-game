## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"유전자는 제자리에 고정되어 있지 않다 — 염색체 위를 옮겨 다니며 형질을 바꾼다."**

20세기 중반 미국의 유전학자 바버라 매클린톡(Barbara McClintock)을 형상화한 존재. 옥수수 낟알 색이 얼룩덜룩한 무늬를 만드는 현상을 관찰해
**전이인자(점핑 유전자)**, 즉 염색체 위의 위치를 옮겨 다니며 다른 유전자의 발현을 조절하는 요소를 발견했다. 당시에는 받아들여지지 않았으나 훗날 노벨 생리의학상을
받았다. 멘델의 유전 도서관 3보스 중 **최종 보스**(고전유전학 계보의 마지막).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 멘델 · 모건 · 매클린톡(유전법칙 → 염색체설 → 전이인자로 이어지는 고전유전학 계보)".
- [바이오스_멘델유전도서관.md](../../디자인/던전/바이오스_멘델유전도서관.md) §1, §6: 주름·초록 방군(이중 열성 단 1칸) 중간보스 "쭈글초록변이체" 처치 열쇠로 진입하는
  옥수수밭의 주인. 진행 순서 ③번(모건 처치 후 개방, 가장 희귀한 칸).

### 포지션
멘델의 유전 도서관 **최고 난이도**(주름·초록 1칸, 5페이즈). 난이도 계단: 멘델 3P → 모건 4P → **매클린톡 5P**.

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 중반 여성 유전학자 + 옥수수 현장 장비. 1940~50년대 미국 여성 유전학자의 작업복·실험용 장갑 차림에 현미경과 옥수수 이삭을 갖춘 모습.
린네~멘델·모건·오덤과 시대(20세기 중반)·성별·직업(유전학자)·장비(옥수수 이삭·현미경)로 구분.

### 2-A 지금 (프리미티브 조립 — McClintockSetup.cs로 구현 가능)

```
매클린톡 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 올리브색 작업복
├── Hair              Sphere(납작)  scale(0.55, 0.3, 0.55)  pos(0, 2.7, 0)  — 짧게 묶은 머리
├── Microscope        Cylinder(소)+Cube  pos(0.5, 1.2, 0.3)  — 허리춤의 휴대용 현미경(장식)
├── WeakPoint         (BossWeakPoint) pos(0, 1.6, 0.45)  — 품에 안은 알록달록 옥수수 이삭
│   └── MosaicCorn    Cylinder(긴 타원)  scale(0.3, 0.55, 0.3)  Emission OFF→ON 노출 시
│       └── Kernels   Sphere(아주 작음)×N  낟알 색이 페이즈마다 점프(노랑→빨강→보라→흰→알록달록)
├── JumpEmitter       empty     pos(0, 0, 0)  — 점핑 장판 생성·이동 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 바닥에 **장판**이 예고된 뒤 **빛나는 점**처럼 다른 위치로 **점프**하고, 점프 경로와 도착 지점에 텔레그래프가 표시된다. 장판 색이 낟알 색과 같다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 중반 미국 여성 유전학자 — 작업복·실험용 장갑·짧은 머리, 허리의 휴대용 현미경, 품에 알록달록 옥수수 이삭.
- **소품**: 알록달록 옥수수 이삭(약점, 노랑·빨강·보라·흰 낟알이 얼룩덜룩), 휴대용 현미경, 현장 노트(장식).
- **발광**: 이삭 — 평상시 은은한 빛, 노출 시 낟알들이 색이 바뀌며 밝게 Emission.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 올리브 작업복(#5B5E3A) + 낟알 노랑(#E8C84A)/빨강(#C0392B)/보라(#7A4A9C)/흰색(#F4F4F0) + 밝은 Emission(#FFF1A8, 약점).
- **실루엣**: 키 약 3.0 Unity units. 품의 옥수수 이삭이 가슴 앞에서 화려하게 빛나는 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 점핑 장판 — 전이인자(점핑 유전자)의 핵심인 **위치 이동**을 장판의 **점프**로 직역. 페이즈가 오를수록 **점프 횟수·연쇄가 증가**한다.
앞선 법칙 추가(멘델)·4단계 누적(모건)과 달리 **"움직이는 장판을 추적해 착지 위치를 읽는 것"** 이 핵심이다.

| 페이즈 | 점핑 규칙 (게임적 설정) |
|--------|----------------------|
| P1 | 장판 1개가 **1회 점프**한 뒤 착지 지점에서 발동 |
| P2 | 장판 1개가 **연속 2회 점프**(점프마다 짧은 텔레그래프)한 뒤 최종 착지 지점에서 발동 |
| P3 | 장판 **2개**가 각자 점프하며, **떠난 자리에 변이 흔적(잔류 장판)** 이 일정 시간 남음 |
| P4 | 점프한 장판이 착지하면 **인접한 다른 장판을 활성화**(활성자→분리자 연쇄 폭발 — Ac/Ds 개념, 게임적 설정) |
| P5 | 장판 **3개가 동시에 점프**하며 **점프 경로에도 얇은 장판**이 남음 |

| 패턴 에셋 | 유전학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `JumpingElementPattern.asset` (신규) | **전이인자(점핑 유전자)** — 위치를 옮기며 형질을 바꿈 | 장판이 점프하며 위치가 바뀌고 낟알 색이 변함 | 옥수수 이삭을 가리키며 장판을 "튕겨" 보냄 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 매클린톡가 이삭을 가리키면 **장판이 지정 위치에 텔레그래프**로 나타난다.
2. 장판이 **빛나는 점으로 변해 다른 위치로 점프**한다(점프 횟수·개수는 페이즈별). 점프 경로와 착지 지점이 표시되므로 플레이어는 **최종 착지 위치를 읽어** 피한다.
3. 모든 장판이 **착지해 발동**을 마치면, 매클린톡가 이삭을 내려다보며 **낟알 색이 바뀌는 동안** **약점 노출**(§5).

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 밭 한가운데에서 이삭을 살피며 서성임
- 옥수수밭 중앙 부근에서 느리게 서성이며 이삭을 살핀다. 장판 점프 중에는 이삭을 가리키는 제스처를 취한다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 이삭 낟알 색이 한 단계 점프하는 연출(노랑 → 빨강 → 보라 → 흰색 → 알록달록).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 점핑 장판 | 시전 시작 | 장판 `Quad`가 점(`Sphere`)으로 변해 다음 좌표로 포물선 `Lerp`, 착지 시 장판 복원 |
| 변이 흔적 | P3~ | 떠난 자리에 잔류 장판 `Quad`를 일정 시간 남김 |
| 연쇄 활성화 | P4~ | 착지 지점 인접 장판을 즉시 발동 |
| 경로 장판 | P5 | 점프 궤적에 얇은 장판 생성 |
| 낟알 색 변화 | 모든 장판 착지 후 | `Kernels` 머티리얼 색을 다음 색으로 변경 + `MosaicCorn` Emission On(약점 노출) |

## 5. 약점 메커니즘

### 품에 안은 알록달록 옥수수 이삭 (BossWeakPoint)
- **위치(확정)**: 품(가슴 앞, localPos 0, 1.6, 0.45). 리히터의 가슴 계기판과 부위는 비슷하나 오브젝트(알록달록 이삭)와 노출 방식(낟알 색 변화 중)이 다르다.
- **노출 타이밍(확정)**: 점프하던 **장판이 모두 착지해 발동을 마친 직후**, 매클린톡가 이삭을 살피며 **낟알 색이 바뀌는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.0s). 시간 기반이며 점프 중에는 약점이 노출되지 않는다 — **착지 타이밍을 읽는 것**이 공략 포인트다.
- **낟알 색 단서**: 낟알 색이 페이즈마다 점프(노랑→빨강→보라→흰→알록달록)해 현재 페이즈를 알려 주는 시각 단서가 된다.
- **시각 피드백**: 평상시 은은한 빛 → 노출 시 낟알이 색을 바꾸며 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 이삭 약점(×3)과는 독립.

## 9. 보상 · 클리어 연동

처치 흐름: `Boss.OnDefeated` → `BossMission.OnBossDefeated` → 던전 클리어 처리(07 §3-10 공통). 매클린톡은 멘델의 유전 도서관의 **마지막 보스**(멘델→모건→매클린톡 고정 순서의 종착)로
처치 시 던전 완전 클리어. 드랍·보상 세부는 02_던전-스테이지-템플릿.md 소관. 초안 제안:
- **전리품 후보**: 옥수수 낟알 무늬 표본(연구자원), 매클린톡의 현미경 파편(장비 재료?).
- 바이오스 **세 번째 던전 클리어**이므로 레벨 스케일링 하한 카운트([[dungeon_level_scaling_rule]])에 반영.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 쭈글초록변이체 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 장판 1개 1회 점프 후 발동, 착지 후 이삭 낟알 색 변화 1.8s 노출(점프 중에는 노출 없음).
- [ ] **P2 전환**: HP 80% → 배너 + 연속 2회 점프, 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + 장판 2개·변이 흔적 잔류, 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + 착지 시 인접 장판 연쇄 활성화, 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 3개 동시 점프·경로 장판, 노출 1.0s(낟알 알록달록).
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.

## 11. 향후 확장

- **리깅 모션**: 이삭 안은 자세 흔들림, 현미경 들여다보기, 장판 튕기는 손짓.

- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
