## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"형질은 입자처럼 분리되어 전해지고, 그 비율에는 법칙이 있다."**

19세기 중반 오스트리아의 수도사 그레고어 멘델(Gregor Mendel)을 형상화한 존재. 수도원 정원에서 완두를 수만 그루 재배·교배해 **분리의 법칙·우열의
법칙·독립의 법칙**과 3:1, 9:3:3:1 같은 비율을 발견했다. 당대에는 인정받지 못했으나 후대에 "유전학의 아버지"로 평가받는다. 멘델의 유전 도서관 3보스 중
**첫 번째 입문 관문**(고전유전학 계보의 시작).

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 멘델 · 모건 · 매클린톡(유전법칙 → 염색체설 → 전이인자로 이어지는 고전유전학 계보)".
- [바이오스_멘델유전도서관.md](../../디자인/던전/바이오스_멘델유전도서관.md) §1, §6: 노랑·주름 방군 중간보스 "주름완두거수" 처치 열쇠로 진입하는
  수도원 완두 정원의 주인. 진행 순서 ①번.

### 포지션
멘델의 유전 도서관 **입문 관문**(노랑·주름 방군, 3페이즈). 난이도 계단: 멘델 3P → 모건 4P → 매클린톡 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 수도사 + 정원 실험 장비. 19세기 중반 오스트리아 수도원 수도사의 흑갈색 수도복에 정원 일용 도구(물조리개·수분용 붓)와
완두 바구니를 갖춘 모습. 린네(18세기 라플란드)·월리스(빅토리아시대 열대)·다윈(비글호 학자)·훔볼트(낭만주의 탐험가)·헤켈(독일 교수)·오덤(미국 생태학자)과
**직업(수도사)·국가(오스트리아)·장비(정원 도구)** 로 구분.

### 2-A 지금 (프리미티브 조립 — MendelSetup.cs로 구현 가능)

```
멘델 (BossRoot)

├── Hood              Sphere(납작)  scale(0.8, 0.5, 0.8)  pos(0, 2.7, -0.1)  — 수도복 두건
├── Rope              Cylinder(가는)  scale(0.5, 0.05, 0.5)  pos(0, 1.1, 0)  — 허리 매듭 끈(장식)
├── Brush             Cylinder(가는)  scale(0.04, 0.35, 0.04)  pos(0.5, 1.4, 0.3)  — 인공 수분용 붓(장식)
├── WeakPoint         (BossWeakPoint) pos(-0.5, 1.4, 0.35)  — 팔에 낀 완두 바구니
│   └── PeaBasket     Cylinder(오목 바구니)  scale(0.35, 0.25, 0.35)  Emission OFF→ON 노출 시
│       └── Peas      Sphere(소)×N  노랑 3 : 초록 1 비율로 배치(페이즈마다 구성 변화)
```

**패턴 식별 시각**: 바닥 장판은 **색(노랑/초록)과 모양(둥근/주름)** 으로 구분된다. 노랑=우성(큰 피해), 초록=열성(작은 피해), 주름=모서리진 십자형, 둥근=원형.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 오스트리아 수도사 — 흑갈색 수도복·두건·허리 끈, 한 팔에 완두 바구니, 손에 인공 수분용 붓.
- **소품**: 완두 바구니(약점, 노랑·초록 완두 3:1), 수분용 붓, 실험 노트(장식).
- **발광**: 바구니 — 평상시 은은한 노란빛, 노출 시 완두가 밝게 Emission(노랑·초록 비율이 또렷이 드러남).
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 흑갈색 수도복(#3A2F28) + 완두 노랑(#E8C84A) + 완두 초록(#6FA85A) + 한지 흰색(#EDE7D8) + 밝은 Emission(#FFF1A8, 약점).
- **실루엣**: 키 약 3.0 Unity units. 팔에 낀 바구니와 두건으로 3보스 중 가장 소박하고 정적인 실루엣.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 3법칙 직역 — 멘델의 세 법칙을 페이즈별 장판 규칙으로 옮기고, **페이즈마다 법칙이 추가(누적)** 된다.

| 페이즈 | 추가되는 법칙 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **분리의 법칙** — 대립 유전자가 분리되어 전달 | 원형 장판 1개가 예고된 뒤 **두 개로 갈라져 양쪽으로 벌어지며** 발동 |
| P2 | **우열의 법칙** — 우성이 겉으로 드러난다 | 노랑(우성) 장판이 초록(열성)보다 **3:1 비율**로 소환, 노랑=큰 반경·높은 피해 / 초록=작은 반경·낮은 피해 |
| P3 | **독립의 법칙** — 색과 모양이 독립적으로 유전 | 아레나가 **4×4 격자**로 나뉘어 16칸에 4종 장판이 **9:3:3:1**로 배치 — 안전 칸은 **초록·주름 단 1칸** |

| 패턴 에셋 | 유전학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `MendelLawPattern.asset` (신규) | **멘델의 세 법칙**(분리·우열·독립) | 페이즈별 법칙에 맞는 색·모양 장판 | 수분 붓으로 허공에 교배 표를 그림 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 멘델가 붓으로 허공에 도형을 그리면 **법칙에 맞는 장판 텔레그래프**가 바닥에 나타난다(P1 분리 / P2 우열 / P3 독립 중 활성 법칙).
2. 플레이어는 장판의 **색·모양을 읽어** 안전한 위치로 이동한다.
   - P1: 한 장판이 둘로 갈라지는 방향을 예측해 피한다.
   - P2: 초록(열성) 장판의 작은 범위 쪽이 안전하다.
   - P3: 16칸 중 **초록·주름 칸 1개**가 유일한 안전 지대다(9:3:3:1의 "1").
3. 장판이 발동되면 멘델가 **바구니를 내려다보며 교배 결과를 세는** 모션에 들어간다 — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 법칙 | 시전 순환 |
|--------|----------|----------|
| P1 | 분리 | 분리 |
| P2 | 분리 + 우열 | 분리 → 우열 → 분리 → 우열 … |
| P3 | 분리 + 우열 + 독립 | 분리 → 우열 → 독립 → 분리 … |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 거의 정지, 바구니를 내려다봄
- 아레나 중앙 부근에서 천천히 서성이며 바구니 속 완두를 세는 자세를 유지한다(수도원 정원을 산책하는 연출).

### 페이즈 전환
- P2~P3 진입 시 짧은 무적(~1초) + 배너. 바구니 속 완두 구성이 새 법칙에 맞게 바뀌는 연출(P2 노랑 3:초록 1, P3 4종 완두 9:3:3:1).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 장판 텔레그래프 | 시전 시작 | 법칙별 장판(원형/십자형 `Quad`, 노랑/초록 머티리얼) 생성 후 발동 |
| 분리 장판 | P1~ | 원형 장판이 발동 직전 둘로 나뉘어 반대 방향으로 `Lerp` 이동 |
| 4×4 격자 | P3 | 아레나를 16칸으로 나눠 칸별 장판 머티리얼 배정(9/3/3/1) |
| 바구니 확인 | 장판 발동 직후 | 보스가 고개를 숙이는 모션 + `PeaBasket` Emission On |

## 5. 약점 메커니즘

### 팔에 낀 완두 바구니 (BossWeakPoint)
- **위치(확정)**: 왼팔 안쪽(localPos -0.5, 1.4, 0.35). 이미 쓴 부위(손·허리·어깨 위·등·가슴·머리 위·팔뚝)와 구분되는 **팔 안쪽 바구니**.
- **노출 타이밍(확정)**: 법칙 장판이 발동한 **직후** 멘델가 바구니를 내려다보며 **교배 결과(완두 비율)를 확인하는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.2s). 시간 기반이라 입문 관문에 단순하며, 노출 중에는 장판이 남아 있지 않다.
- **시각 피드백**: 평상시 은은한 노란빛 → 노출 시 바구니 속 완두가 밝게 점등, 현재 페이즈의 비율(3:1 / 9:3:3:1)이 시각적으로 드러난다.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 바구니 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 주름완두거수 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
