## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"여러 곳을 동시에, 인간 세포에서 — CRISPR를 실용으로 끌어올리다."**

중국계 미국인 신경과학·유전체 공학자 장펑(Feng Zhang)을 형상화한 존재. 2013년 CRISPR-Cas9을 **인간 세포**에서 작동시키고, 여러 가이드 RNA로 **여러 유전자를 동시에 편집(다중 편집)** 할 수
있음을 보였다. 이론(샤르팡티에·다우드나)을 인간 세포 적용이라는 실용 단계로 넘긴 인물이며, **실용·팽창주의** 헬릭스 제국의 정체성과 맞닿는다. CRISPR 편집 연구소 3보스 중 **최종 보스**.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 다우드나 · 샤르팡티에 · 장펑(CRISPR-Cas9 유전자가위 개발 3인)".
- [바이오스_CRISPR편집연구소.md](../../디자인/던전/바이오스_CRISPR편집연구소.md) §1, §6: 다중 편집 구역 중간보스 "다중편집변이체" 처치 열쇠로 진입하는 인간 세포 편집실의 주인. 진행 순서 ③번(다우드나 처치 후 개방).

### 포지션
CRISPR 편집 연구소 **최고 난이도**(다중 편집 구역, 5페이즈). 난이도 계단: 샤르팡티에 3P → 다우드나 4P → **장펑 5P**. 이 구역은 편집 기능 **절단 + 삽입 + 다중 편집**이 모두 해금되어 있다.
> **⚠ 게임적 설정**: 장펑=다중 편집 구역은 CRISPR 개발 시간순과 편집 기능 해금을 맞춘 게임용 대응이다.

샤르팡티에(유럽 미생물학자)·다우드나(미국 구조생화학자)와 **국적(중국계 미국)·직업(유전체 공학자)·장비(편집 태블릿)** 로 구분.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 다중 편집 5단계 — 장펑의 다중 편집(multiplex) 업적을 **편집 지점 수가 늘어나는 구조**로 직역한다(단일 → 동시 2곳 → 동시 3곳 → 연쇄 → 전체). **누적형**이며
샤르팡티에(절단)·다우드나(작동 단계)와 달리 **여러 지점의 동시 장판을 색으로 읽는 것**이 핵심이다.

| 페이즈 | 추가되는 단계 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **단일 편집**(가이드 1개) | **청록** 장판 1개(한 지점)가 예고 후 발동 |
| P2 | **동시 2곳** | **청록 + 주황** 2가이드가 **동시에 2지점**을 편집 — 두 장판이 같은 타이밍에 발동 |
| P3 | **동시 3곳** | **청록 + 주황 + 분홍** 3가이드가 **동시에 3지점**을 편집(색마다 다른 장판 크기) |
| P4 | **연쇄 편집** | 한 지점의 발동이 **다른 지점의 장판을 연쇄 발동**시킴(빛줄기로 연결, 0.4s 간격 순차 발동) |
| P5 | **전체 편집** | 아레나가 가이드별 **4색 구역**(청록·주황·분홍·황금)으로 나뉘고 **모든 구역이 편집(발동)되며, 장펑 태블릿에 표시된 색 구역 하나만 안전**(편집 제외) |

| 패턴 에셋 | 생명공학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `MultiplexEditingPattern.asset` (신규) | **다중 편집**(multiplex genome editing) | 가이드 색별 편집 지점 장판이 동시·연쇄·전체로 발동 | 태블릿에서 가이드를 선택해 편집 지점을 지정 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 장펑이 태블릿을 조작하면 **가이드 색별 편집 지점의 텔레그래프**가 나타난다(P5는 4색 구역과 태블릿에 표시된 **안전 색**).
2. 플레이어는 색·타이밍을 읽어 피한다.
   - 단일/동시: 같은 타이밍에 발동하는 **여러 지점 모두 피한다**.
   - 연쇄: 빛줄기 순서대로 **0.4s 간격 연쇄** — 아직 발동 안 한 지점으로 가지 않는다.
   - 전체: 태블릿 화면에 표시된 **안전 색 구역**으로 이동한다.
3. 편집 장판이 모두 발동되면 장펑가 **태블릿으로 편집 결과를 확인**한다 — 이 동안 **약점 노출**(§5).

### 시전 순환 (초안)
| 페이즈 | 활성 단계 | 시전 순환 |
|--------|----------|----------|
| P1 | 단일 | 단일 |
| P2 | + 동시 2곳 | 단일 → 2곳 → 단일 → 2곳 … |
| P3 | + 동시 3곳 | 단일 → 2곳 → 3곳 → 단일 … |
| P4 | + 연쇄 | 단일 → 2곳 → 3곳 → 연쇄 … |
| P5 | + 전체 편집 | 단일 → 2곳 → 3곳 → 연쇄 → 전체(다중 편집 1주기 완성) |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 편집대 앞에서 태블릿 조작
- 인간 세포 편집대 앞에서 거의 이동하지 않고 손의 태블릿을 조작하는 자세를 유지한다.
- 편집 장판 발동 후 **태블릿을 눈높이로 들어 결과를 확인하는** 모션 — 이때 태블릿이 플레이어가 접근 가능한 높이로 올라온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 태블릿 화면의 편집 지점 수가 한 단계 늘어나는 연출(1 → 2 → 3 → 연결선 → 전체 구역).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 단일/동시 편집 | P1~ | 가이드 색 `Quad` 장판을 같은 타이밍에 N개 발동 |
| 연쇄 편집 | P4~ | 지점들을 `LineRenderer`로 연결, 0.4s 간격 순차 발동 |
| 전체 편집 | P5 | 아레나를 4색 구역 `Quad`로 분할, 안전 색 하나만 발동 제외 + 태블릿 화면에 안전 색 표시 |
| 태블릿 확인 | 장판 발동 직후 | 보스 모션 + `GenomeTablet` Emission On |

## 5. 약점 메커니즘

### 손에 든 유전체 편집 태블릿 (BossWeakPoint)
- **위치(확정)**: 오른손(localPos 0.5, 1.4, 0.35). 부위는 린네·허턴·샤르팡티에(손)와 같지만 **사용자 지침에 따라 개연성 우선**(인간 세포 다중 편집을 설계하는 현대 연구자의 도구)이며
  오브젝트·노출 방식·단서가 다르다.
- **노출 타이밍(확정)**: 편집 장판이 모두 발동한 **직후**, 장펑이 **태블릿으로 편집 결과를 확인하는 동안** `SetExposed(duration)` 호출.
  duration은 §4 표(1.8s→1.0s). 시간 기반이며 노출 중에는 장판이 남아 있지 않다. 5페이즈·다중 장판 복잡도(색·연쇄·구역)가 난이도를 책임진다.
- **화면 단서**: 태블릿 화면의 편집 지점 수·색이 페이즈마다 바뀌어(1 → 2 → 3 → 연결선 → 전체 구역) 현재 단계를 알려 주고, P5에서는 **안전 색**이 화면에 표시된다.
- **시각 피드백**: 평상시 은은한 청록 화면 → 노출 시 편집 지점 결과가 밝게 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스

## 9. 보상 · 클리어 연동

처치 흐름: `Boss.OnDefeated` → `BossMission.OnBossDefeated` → 던전 클리어 처리(07 §3-10 공통). 장펑은 CRISPR 편집 연구소의 **마지막 보스**(샤르팡티에→다우드나→장펑 고정 순서의 종착) —
처치 시 던전 완전 클리어. 드랍·보상 세부는 02_던전-스테이지-템플릿.md 소관. 초안 제안:
- **전리품 후보**: 유전체 편집 태블릿 파편(장비 재료?), 장펑의 다중 편집 기록(연구자원).
- 바이오스 **여섯 번째(마지막) 던전 클리어**이므로 레벨 스케일링 하한 카운트([[dungeon_level_scaling_rule]])에 반영. 이 던전 클리어로 바이오스 대륙 던전 6개가 모두 끝난다.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 다중편집변이체 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 청록 단일 장판 예고→발동, 종료 직후 태블릿 1.8s 노출.
- [ ] **P2 전환**: HP 80% → 배너 + 청록·주황 동시 2곳, 노출 1.6s.
- [ ] **P3 전환**: HP 60% → 배너 + 3색 동시 3곳, 노출 1.4s.
- [ ] **P4 전환**: HP 40% → 배너 + 연쇄 편집(0.4s 간격 순차 발동), 노출 1.2s.
- [ ] **P5 전환**: HP 20% → 배너 + 4색 구역 편집, **태블릿에 표시된 안전 색 구역만 안전**, 노출 1.0s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
