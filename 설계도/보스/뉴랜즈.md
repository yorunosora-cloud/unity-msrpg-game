## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"원자량 순으로 늘어놓으면 8번째마다 성질이 닮는다 — 그러나 규칙에는 끝이 있다."**

19세기 영국의 화학자 존 뉴랜즈(John Newlands)를 형상화한 존재. 원소를 원자량 순으로 배열하면 8번째 원소가 첫 원소와 닮는다는 **옥타브설**(1865)을 주장했다. 음계에 빗댄 이름 때문에
학회에서 조롱을 받았지만, 훗날 주기성 발견의 선구로 인정받았다(1887년 데이비 메달). 그의 규칙은 **칼슘 이후의 원소에는 잘 맞지 않았고**, 발견되지 않은 원소의 빈칸도 남기지 않았다.
원소 주기율표 대성당 3보스 중 **옥타브 구역의 중간 난이도 보스**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "원소 주기율표 대성당 보스: 뉴랜즈 · 멘델레예프 · 라부아지에".
- [알케미아_원소주기율표대성당.md](../../디자인/던전/알케미아_원소주기율표대성당.md) §1, §2: 옥타브 구역 중간보스 "나트륨 성상" 처치 후 진입하는 파이프오르간실의 주인. 진행 순서 ②번.

### 포지션
원소 주기율표 대성당 **중간 난이도**(옥타브 구역, 4페이즈). 난이도 계단: 라부아지에 3P → **뉴랜즈 4P** → 멘델레예프 5P.

## 2. 비주얼 명세

**컨셉(확정)**: 19세기 영국 화학자 + 음악 지휘 장비. 19세기 중반 영국 신사 학자 복장(프록코트·구레나룻)에 지휘봉과 음계처럼 원소가 적힌 악보를 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — NewlandsSetup.cs로 구현 가능)

```
뉴랜즈 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 짙은 갈색 프록코트
├── Hair              Sphere(납작)  scale(0.55, 0.3, 0.55)  pos(0, 2.7, 0)
├── Whiskers          Cube×2(소)  pos(±0.32, 2.35, 0.3)  — 구레나룻
├── Baton             Cylinder(아주 가는)  scale(0.03, 0.4, 0.03)  pos(-0.55, 1.6, 0.35)  — 지휘봉
├── WeakPoint         (BossWeakPoint) pos(0.5, 1.5, 0.4)  — 손에 든 원소 악보
│   └── ElementScore  Quad(펼친 악보)  scale(0.5, 0.35, 1)  Emission OFF→ON 노출 시 (원소 기호가 음표처럼 배치)
├── OctaveEmitter     empty     pos(0, 0, 0)  — 원소 장판 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 각 장판 위에 **원소 기호와 원자량**이 크게 표시된다. 알칼리 금속=주황, 할로젠=초록, 그 외=은청, 칼슘 이후 예외 원소=회색 테두리.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 19세기 영국 화학자 — 갈색 프록코트·구레나룻, 한 손에 지휘봉, 다른 손에 원소 악보.
- **소품**: 원소 악보(약점, 오선 위에 원소 기호), 지휘봉.
- **발광**: 악보 — 평상시 낡은 종이색, 노출 시 원소 기호가 계열 색으로 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 갈색 코트(#5A4030) + 낡은 종이(#E8DCC0) + 알칼리 주황(#E8823C) + 할로젠 초록(#5FA05A) + 교황청 금(#C9A646) + 밝은 Emission(#FFF3C4, 약점).
- **실루엣**: 키 약 3.0 Unity units. 들어 올린 지휘봉과 펼친 악보가 지휘자 실루엣을 만든다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 원자량 순 → 주기성 → 족의 성질 → 옥타브설의 한계, 4페이즈 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **원자량 순서** | 원소 장판 8개가 흩어져 나타나고 **원자량이 작은 것부터** 차례로 발동 (Li 7 → Be 9 → B 11 → C 12 → N 14 → O 16 → F 19 → Na 23) |
| P2 | **주기성(옥타브)** | **8번째 장판은 1번째와 같은 모양·같은 공격**으로 발동(Na는 Li를 닮음) — 첫 장판을 기억해 대비 |
| P3 | **족의 성질** | **알칼리 금속**(Li·Na·K)은 바닥의 물웅덩이와 겹치면 **폭발 반경 확대**, **할로젠**(F·Cl)은 발동 후 **기체가 퍼지는 장판**을 남김 |
| P4 | **옥타브설의 한계** | 칼슘 이후 원소(Ti·Cr·Mn·Fe 등)가 섞여, **반복 자리에 와도 닮지 않은 다른 효과**를 냄 — 원소 기호를 읽어 예외를 가려냄 |

| 패턴 에셋 | 화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `OctaveLawPattern.asset` (신규) | **옥타브설**(원자량 순 배열·주기성·같은 족의 성질·규칙의 한계) | 원소 기호·원자량이 표시된 순차 장판 | 지휘봉으로 원소를 차례로 가리킴 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 뉴랜즈가 지휘봉을 들면 **원소 기호·원자량이 적힌 장판 8개**가 예고된다.
2. 플레이어는 원자량이 작은 순서를 읽고, 이미 발동한 자리로 이동하며 피한다.
   - P2~: 첫 장판의 모양을 기억해 **8번째**를 대비한다.
   - P3~: 알칼리 장판 근처의 **물웅덩이**를 피하고, 할로젠 장판 뒤 **퍼지는 기체**에서 벗어난다.
   - P4: **칼슘 이후 원소**는 반복 규칙을 믿지 말고 표시를 보고 피한다.
3. **8번째 장판이 발동한 직후**, 뉴랜즈가 규칙을 확인하려 **악보를 펼치는 동안 약점 노출**(§5).

### 원소 편성 (초안)
| 페이즈 | 시전에 쓰는 원소 8개 |
|--------|------------------|
| P1~P2 | Li → Be → B → C → N → O → F → Na |
| P3 | 위 편성과 Na → Mg → Al → Si → P → S → Cl → K 교대 |
| P4 | K → Ca → Ti → V → Cr → Mn → Fe → Co (옥타브가 어긋나는 구간) |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 오르간 앞 지휘대에서 지휘
- 파이프오르간 앞 지휘대에서 거의 이동하지 않고 지휘봉으로 원소를 가리킨다.
- 8번째 장판 발동 후 **악보를 앞으로 펼쳐 확인하는** 모션 — 이때 악보가 플레이어가 접근 가능한 높이로 내려온다.

### 페이즈 전환
- P2~P4 진입 시 짧은 무적(~1초) + 배너. P4 진입 시 악보의 음표 배열이 흐트러지는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 순차 장판 | P1~ | 원소 `Quad` + `TextMesh`(기호·원자량), 원자량 순 0.45s 간격 발동 |
| 8번째 반복 | P2~ | 1번째 장판의 모양·효과를 복제해 8번째에 적용 |
| 족의 성질 | P3~ | 물웅덩이 `Quad`와 겹침 판정 → 반경 확대 / 기체 장판 `Scale` 확장 |
| 예외 원소 | P4 | 회색 테두리 장판, 반복 대신 개별 효과 |
| 악보 펼치기 | 8번째 발동 직후 | 보스 모션 + `ElementScore` Emission On |

## 5. 약점 메커니즘

### 손에 든 원소 악보 (BossWeakPoint)
- **위치(확정)**: 왼손에 펼쳐 든 원소 악보(localPos 0.5, 1.5, 0.4).
- **노출 타이밍(확정)**: **8번째 원소 장판이 발동한 직후**, 뉴랜즈가 **악보를 펼쳐 규칙을 확인하는 동안** `SetExposed(duration)` 호출. duration은 §4 표(1.8s→1.2s).
  장판 순서를 세고 있으면 타이밍을 예측할 수 있다. 8번째가 마지막 장판이므로 노출 중 새 장판은 없다(P3의 퍼지는 기체는 남을 수 있음).
- **시각 피드백**: 평상시 낡은 악보 → 노출 시 원소 기호 점등.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 악보 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 나트륨 성상 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 원소 장판 8개가 원자량 순으로 발동, 8번째 직후 악보 1.8s 노출.
- [ ] **P2 전환**: HP 75% → 배너 + 8번째가 1번째와 같은 모양, 노출 1.6s.
- [ ] **P3 전환**: HP 50% → 배너 + 알칼리·물웅덩이 확대, 할로젠 기체, 노출 1.4s.
- [ ] **P4 전환**: HP 25% → 배너 + 칼슘 이후 편성과 예외 효과, 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 장판 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 주기율표 구역 게이트 개방 조건 충족.
