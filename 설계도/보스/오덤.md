## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"생태계는 에너지가 흐르는 하나의 회로다 — 생산자에서 소비자, 분해자로 흘러 다시 순환한다."**

20세기 중반 미국의 생태학자 하워드 오덤(Howard T. Odum)과 유진 오덤을 형상화한 존재. 생태계를 에너지 흐름과 물질 순환의
**시스템**으로 체계화하고, 실버 스프링스 등 생태계의 에너지 흐름을 측정해 회로도 기호(에너지 회로 언어)로 그렸다. 개념사 계보
(훔볼트 생물지리 → 헤켈 생태학 용어 → 오덤 생태계 시스템)의 **최종 단계**이자 생태계 순환 대원의 **최종 보스**.

### 세계관 근거
- [바이오스_조감도.md](../../디자인/대륙/바이오스_조감도.md) §3: "보스: 훔볼트 · 헤켈 · 오덤(…생태계를 하나의 시스템으로 체계화한 개념사 계보)".
- [바이오스_생태계순환대원.md](../../디자인/던전/바이오스_생태계순환대원.md) §1, §6: 분해자 링 중간보스 "균사분해체" 처치 열쇠로
  진입하는 에너지 회로 제어실의 주인. 진행 순서 ③번(헤켈 처치 후 개방).

### 포지션
생태계 순환 대원 **최고 난이도**(중심 분해자 링, 5페이즈). 난이도 계단: 훔볼트 3P → 헤켈 4P → **오덤 5P**.
> **⚠ 게임적 설정**: 오덤=분해자 링(중심)은 개념사 계보를 영양 단계 순서에 맞춘 게임용 대응이다. (실제 오덤이 분해자만 연구한 것은 아니다.)

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 중반 미국 생태학자 + 에너지 회로도 장비. 반소매 셔츠에 트위드 재킷 차림의 20세기 중반 미국 생태학자(현장 조사용 장화)에
에너지 회로도를 그린 두루마리와 측정 패널을 갖춘 모습. 린네(18세기)·월리스(빅토리아시대)·다윈(비글호 1830년대)·훔볼트(낭만주의)·헤켈(19세기 후반 독일)보다
가장 **현대적인 시대감**으로 계보의 마지막에 위치.

### 2-A 지금 (프리미티브 조립 — OdumSetup.cs로 구현 가능)

```
오덤 (BossRoot)
├── BossBody          Capsule   scale(1.0, 1.5, 1.0)  pos(0, 1.5, 0)   Color: 올리브색 트위드 재킷
├── Boots             Cylinder×2  pos(±0.25, 0.3, 0)  — 현장 조사용 장화(장식)
├── CircuitScroll     Cylinder(누운, 두루마리)  scale 0.25x0.6  pos(0.5, 1.4, 0.25)  — 에너지 회로도 두루마리(장식)
├── WeakPoint         (BossWeakPoint) pos(-0.55, 1.5, 0.3)  — 왼팔 팔뚝에 찬 에너지 흐름 계량기
│   └── FlowGauge     Cube(납작 패널)  scale(0.25, 0.18, 0.05)  Color: 짙은 회색  Emission OFF→ON 노출 시 (회로 기호 새김)
├── CircuitEmitter    empty     pos(0, 0, 0)  — 노드·회로선·흐름 구슬 생성 기준
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.5  height 3.0
```

**패턴 식별 시각**: 아레나에 **에너지 노드**(생산자=초록·소비자=황토·분해자=암갈색)가 놓이고 **회로선**(`LineRenderer`)이 노드를 잇는다.
에너지 구슬이 회로선을 따라 노드 사이를 이동한다. 노드는 에너지 회로 언어 기호(원·방패·육각·접지)로 모양을 구분한다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 중반 미국 생태학자 — 반소매 셔츠·트위드 재킷·장화, 현장 노트와 측정기를 든 모습.
- **소품**: 에너지 회로도 두루마리(장식), 팔뚝의 에너지 흐름 계량기(약점, 회로 기호가 새겨진 패널과 바늘).
- **발광**: 계량기 — 평상시 짙은 회색, 노출 시 바늘·회로 기호가 밝게 점등하며 과부하 불꽃.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 올리브 재킷(#5B5E3A) + 회로 초록(#5FA05A)/황토(#C79A4A)/암갈색(#5A4A3E) + 밝은 Emission(#F2E6A0, 약점).
- **실루엣**: 키 약 3.2 Unity units. 아레나 중앙에서 사방으로 뻗는 회로선과 노드가 함께 실루엣을 이룬다.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: 에너지 회로망 — 생태계 에너지 흐름(생산자→소비자→분해자→순환)을 노드·회로선·흐름 구슬로 직역한 **네트워크형 패턴**.
앞선 보스의 누적/교체/대칭/환경 패턴과 다르게 **플레이어가 회로를 끊는 개입**이 핵심이다.

| 패턴 에셋 | 생태학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|---------|---------|---------------------|
| `EnergyCircuitPattern.asset` (신규) | **에너지 흐름·순환**(에너지 회로 언어) | 노드가 회로선으로 연결, 에너지 구슬이 노드 사이를 흐르며 노드를 폭발시킴 | 회로도 두루마리를 펼쳐 에너지를 흘려보냄 |

### 동작 순서 (한 번의 시전) — 게임적 설정
1. 오덤이 회로도를 펼치면 **에너지 구슬(흐름)** 이 **생산자 노드에서 출발**해 회로선을 따라 **소비자 노드 → 분해자 노드** 순으로 이동한다.
2. 구슬이 노드에 **도착하면 그 노드가 폭발**(원형 장판)하고, 구슬이 지나는 **회로선 구간에는 짧은 지속 장판**(통전)이 생긴다.
3. 구슬이 **분해자 노드까지 도달한 뒤 오덤에게 되돌아오면 "순환 완주"** — 오덤이 에너지를 얻어 **과충전(강화)** 상태가 된다.
4. 플레이어가 구슬이 도착하기 전에 **노드를 파괴**하면 **회로가 끊기고** 에너지가 **역류**해 오덤의 팔뚝 계량기가 과부하되며 **약점이 노출**된다(§5).
   끊긴 노드는 일정 시간 뒤 재생성되고 흐름은 처음부터 다시 시작한다.

### 과충전 규칙 (초안)
- 순환 완주 시 **과충전 스택 +1**(최대 3): 이후 노드 폭발·회로선 장판 피해 +25%/스택.
- **노드를 파괴해 회로를 끊으면 과충전 스택이 모두 초기화**된다 — "노드를 깨야 약점도 나오고 강화도 막는다"는 이중 보상.
- 노드를 방치하면 순환 완주가 반복되어 오덤이 점점 강해지므로 플레이어에게 **파괴 압박**이 생긴다.

### 페이즈별 규칙 (초안)
| 페이즈 | 노드 수 | 흐름(구슬) 수 | 추가 요소 |
|--------|--------|--------------|----------|
| P1 | 3 (생산자·소비자·분해자) | 1 | 단일 직선 회로 — 가장 단순한 구조 |
| P2 | 3 | 1 (속도 증가) | 회로선 통전 장판 추가 |
| P3 | 4 (소비자 노드 2개로 분기) | 2 | 분기 회로 — 두 경로 중 하나로 흐름이 갈림 |
| P4 | 5 (소비자·분해자 각 2개) | 2 (동시) | 두 흐름이 같은 노드에 겹치면 **과부하 폭발**(피해 2배) |
| P5 | 6 (열 싱크 노드 포함) | 3 | **순환 회로 완성**(오덤에게 되돌아오는 선 포함) + 열 싱크 노드(에너지가 열로 방출되며 광역 장판) |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 중앙 고정, 회로도를 펼쳐 제어
- 오덤은 아레나 중앙(CircuitEmitter) 부근에 고정해 회로도 두루마리를 펼친 채 에너지를 지휘하는 자세를 유지한다.
- 노드가 파괴되어 역류가 발생하면 오덤이 팔뚝을 부여잡고 계량기를 확인하는 **과부하 모션**을 취하며 왼팔 계량기가 플레이어 쪽으로 노출된다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 아레나 바닥 회로선이 한 단계 더 복잡하게 점등되는 연출(새 노드/분기가 나타남).

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 회로선 | 시전 시작 | 노드 사이 `LineRenderer`, 흐름 경로 점등 |
| 에너지 구슬 | 흐름 중 | `Sphere`가 회로선 경로를 따라 `Lerp` 이동 |
| 노드 폭발 | 구슬 도착 | 노드 중심에 원형 장판 + 이펙트 |
| 노드 파괴 | 노드 HP 0 | 회로 끊김, 구슬 소멸, 역류 이펙트, 노드 재생성 타이머 시작 |
| 과충전 표시 | 스택 증가 | 오덤 주변 링 이펙트(스택 수만큼) |
| 계량기 Emission | 역류 노출 중 | `FlowGauge` 머티리얼 Emission On |

## 5. 약점 메커니즘

### 팔뚝에 찬 에너지 흐름 계량기 (BossWeakPoint)
- **위치(확정)**: 왼팔 팔뚝(localPos -0.55, 1.5, 0.3). 이미 쓴 부위(손·허리·어깨 위·등·가슴·머리 위)와 겹치지 않는 새 부위.
- **노출 타이밍(확정)**: 플레이어가 **노드를 파괴해 회로가 끊기면** 에너지가 **역류**해 오덤의 팔뚝 계량기가 과부하되며 `SetExposed(duration)` 호출.
  duration은 §4 표(2.0s→1.2s). 노드를 파괴하지 않으면 노출 기회가 없다.
- **능동 + 위치 판단**: 노드 위치(아레나 곳곳)까지 이동해 파괴해야 하며, 파괴 후 즉시 오덤에게 접근해 약점을 공격해야 한다. 노드가 멀리 있을수록
  노출 시간 내 접근이 어려워진다.
- **시각 피드백**: 평상시 짙은 회색 패널 → 역류 시 바늘이 흔들리고 회로 기호가 밝게 점등, 과부하 불꽃.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = Biology`. Biology 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 계량기 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 균사분해체 처치 → 열쇠 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 노드 3개·흐름 1, 구슬이 생산자→소비자→분해자 순 이동·노드 폭발, 순환 완주 시 과충전 +1.
- [ ] **노드 파괴**: 구슬 도착 전 노드 파괴 → 회로 끊김·역류, 팔뚝 계량기 2.0s 노출, 과충전 초기화, 노드 15s 후 재생성.
- [ ] **P2 전환**: HP 80% → 배너 + 고속 흐름·통전 장판, 노출 1.8s.
- [ ] **P3 전환**: HP 60% → 배너 + 노드 4·분기 회로·흐름 2, 노출 1.6s.
- [ ] **P4 전환**: HP 40% → 배너 + 노드 5·겹침 과부하 폭발(피해 2배), 노출 1.4s.
- [ ] **P5 전환**: HP 20% → 배너 + 노드 6·열 싱크·순환 회로 완성·흐름 3, 노출 1.2s.
- [ ] **처치**: HP 0 → defeatLine + 노드·회로 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.

## 11. 향후 확장

- **리깅 모션**: 회로도를 펼치는 손짓, 팔뚝 계량기 확인 모션, 장화 걸음.

- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
