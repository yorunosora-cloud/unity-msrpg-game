> 원소 자리를 밟았을 때** — 능동)·보스방(X선관 정점실)은 사용자 확정. **자리 밟기 세부 규칙**·장판·수치·대사는 **초안**.
> **수치 기준**: 모든 수치는 **Lv1 기준 값**이며 실제 값은 [21_던전-레벨-스케일링.md](../21_던전-레벨-스케일링.md)가 정한다(maxHp·def는 §4-4-bis 공통표).
> **⚠ 게임적 설정 표시**: 원소의 특성 X선 진동수가 원자번호에 따라 규칙적으로 커진다는 모즐리의 법칙과 빈 원자번호 예측은 실제 업적이나, "진동수가 발동 속도가 된다",
> "원자번호 순으로 자리를 밟으면 약점이 노출된다"는 것은 **게임용 해석**이다.

## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"원소의 진짜 순서는 원자번호다 — X선이 그것을 센다."**

20세기 초 영국의 물리학자 헨리 모즐리(Henry Moseley)를 형상화한 존재. 1913년 원소가 내는 **특성 X선의 진동수**가 원자번호에 따라 규칙적으로 커짐(**모즐리의 법칙**)을 밝혀
**원자번호**를 원소 배열의 기준으로 세웠고, 비어 있는 번호(43·61·72·75)를 예측했다. 1915년 제1차 세계대전에서 27세로 전사했다.
분광 분석의 등대 3보스 중 **최종 보스**.

### 세계관 근거
- [알케미아_조감도.md](../../디자인/대륙/알케미아_조감도.md) §3: "분광 분석의 등대 보스: 분젠 · 키르히호프 · 모즐리(X선 분광학으로 원자번호 개념 정립)".
- [알케미아_분광분석등대.md](../../디자인/던전/알케미아_분광분석등대.md) §1, §2, §4: 분젠·키르히호프를 모두 처치하고 던전 문제 게이트를 연 뒤, X선 구역 중간보스 "43번 빈자리 환영수"를 처치해 진입하는 X선관 정점실의 주인.

### 포지션
분광 분석의 등대 **최고 난이도**(X선 구역, 5페이즈). 난이도 계단: 분젠·키르히호프 4P → **모즐리 5P**.

## 2. 비주얼 명세

**컨셉(확정)**: 20세기 초 영국 젊은 물리학자 + X선관·결정 장비. 20세기 초 영국의 젊은 연구자 복장에 유리 X선관과 회절용 결정, 원자번호 그래프를 갖춘 모습.

### 2-A 지금 (프리미티브 조립 — MoseleySetup.cs로 구현 가능)

```

├── Hair              Sphere(납작)  scale(0.55, 0.3, 0.55)  pos(0, 2.7, 0)  — 가르마 머리
├── Tie               Cube(가는)  scale(0.1, 0.5, 0.05)  pos(0, 1.75, 0.5)
├── Crystal           Octahedron/Cube(회전)  scale 0.2  pos(-0.55, 1.55, 0.35)  — 회절 결정(장식)
├── WeakPoint         (BossWeakPoint) pos(0.55, 1.5, 0.45)  — 손에 든 유리 X선관
│   └── XrayTube      Cylinder(반투명)+Sphere×2(전극)  Emission OFF→ON 노출 시

```

**패턴 식별 시각**: X선=가는 연두빛 직선, 원소 장판·자리에는 **원소 기호**와 원자번호(또는 진동수 막대) 표시, 빈 번호 자리=점선 테두리.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 20세기 초 영국 젊은 연구자 — 셔츠·조끼·넥타이, 한 손에 유리 X선관, 다른 손에 결정.
- **소품**: 유리 X선관(약점), 회절 결정, 원자번호 그래프.
- **발광**: X선관 — 평상시 희미한 연두빛, 노출 시 밝게 점등.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory`. 적용은 아트 완성 단계).
- **팔레트**: 정장 회색(#50545C) + 유리(#CFE8F0) + X선 연두(#B8FF80) + 구리 표적(#B87333) + 밝은 Emission(#F0FFE0, 약점).
- **실루엣**: 키 약 3.0 Unity units. 손의 길쭉한 유리관 빛이 특징.

## 3. 패턴 ↔ 원리 매핑

**방향(확정)**: X선 발생 → 특성 X선 → 모즐리 법칙 → 원자번호 재배열 → 빈 번호, 5페이즈 누적.

| 페이즈 | 추가되는 개념 | 장판 규칙 (게임적 설정) |
|--------|-------------|----------------------|
| P1 | **X선 발생** | 전자 빔이 **금속 표적**에 부딪히면 표적에서 **직선 X선**이 여러 방향으로 뿜어짐 |
| P2 | **특성 X선** | 표적 원소마다 **고유한 이중 고리**(안쪽·바깥 고리 반경이 원소별로 다름) |
| P3 | **모즐리 법칙** | 원소 장판 여러 개 — **원자번호가 클수록(진동수가 클수록) 빨리** 발동 |
| P4 | **원자번호 재배열** | **원자량 순과 어긋나는 쌍**(코발트 27 / 니켈 28, 아르곤 18 / 칼륨 19)이 섞여, **원자번호 순**으로 발동 |
| P5 | **빈 번호** | 번호가 매겨진 칸들이 모두 발동하고 **수열에서 빠진 번호(43·61·72·75)의 자리만 안전** |

**원소 데이터(초안)**: 칼슘 20 · 타이타늄 22 · 바나듐 23 · 크로뮴 24 · 망가니즈 25 · 철 26 · 코발트 27 · 니켈 28 · 구리 29 · 아연 30 (+ 재배열용 아르곤 18 · 칼륨 19).

| 패턴 에셋 | 물리·화학 원리 | 필드 연출 | 시전 제스처 (미래 레이어) |
|----------|-------------|---------|---------------------|
| `MoseleyLawPattern.asset` (신규) | **특성 X선·모즐리 법칙·원자번호** | X선·원소·번호 장판 | X선관을 표적에 겨눔 |

### 플레이어의 원자번호 순 밟기 (약점 조건, 초안·게임적 설정)
1. 사이클마다 바닥에 **원소 자리**가 페이즈별 수만큼 놓인다.
2. 플레이어는 **원자번호가 작은 자리부터** 차례로 0.3초씩 머물러 밟는다.
3. **순서가 틀린 자리를 밟으면 진행이 처음으로 초기화**된다(피해 없음) — 순서가 의미를 갖게 하는 규칙.
4. 단서는 페이즈에 따라 달라진다.

| 페이즈 | 자리 수 | 자리에 표시되는 것 |
|---|---|---|
| P1 | 3 | 원소 기호 + 원자번호 |
| P2 | 3 | 원소 기호 + 원자번호 |
| P3 | 4 | 원소 기호 + **X선 진동수 막대**(길수록 번호가 큼) |
| P4 | 4 | 원소 기호 + **원자량**(함정: 원자량 순이 아니라 번호 순으로 밟아야 함) |
| P5 | 5 | 원소 기호만(벽의 원소표를 보고 판단) |

5. **모두 순서대로 밟으면 모즐리가 측정값을 확인하며 약점 노출**(§5). 노출이 끝나면 자리가 새로 정해진다.

### 시전 순환 (초안)
| 페이즈 | 활성 개념 | 시전 순환 |
|--------|----------|----------|
| P1 | X선 발생 | X선 |
| P2 | + 특성 X선 | X선 → 특성 … |
| P3 | + 모즐리 법칙 | X선 → 특성 → 법칙 … |
| P4 | + 재배열 | 특성 → 법칙 → 재배열 … |
| P5 | + 빈 번호 | 특성 → 법칙 → 재배열 → 빈 번호 |

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 표적대 앞에서 X선관 조작
- 정점실의 표적대 앞에서 거의 이동하지 않고 X선관의 방향을 조절한다.
- 자리를 모두 순서대로 밟으면 **X선관을 앞으로 들어 측정값을 확인하는** 모션 — 이때 관이 플레이어가 접근 가능한 높이에 온다.

### 페이즈 전환
- P2~P5 진입 시 짧은 무적(~1초) + 배너. 벽의 원자번호 그래프에 점이 하나씩 찍힌다.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| X선 | P1~ | 표적에서 직선 `Quad` 다발 |
| 특성 고리 | P2~ | 원소별 반경 두 고리 `Cylinder` |
| 법칙 | P3~ | 원자번호에 비례해 지연 단축 |
| 재배열 | P4~ | 원소 장판을 번호 순 순차 발동 |
| 빈 번호 | P5 | 번호 칸 전체 발동, 빠진 번호만 제외 |
| 측정 확인(노출) | 순서 밟기 완료 | 보스 모션 + `XrayTube` Emission On |

## 5. 약점 메커니즘

### 손에 든 유리 X선관 (BossWeakPoint)
- **위치(확정)**: 손에 든 X선관(localPos 0.55, 1.5, 0.45).
- **노출 조건(확정)**: **플레이어가 원자번호 순으로 원소 자리를 모두 밟았을 때** `SetExposed(duration)` 호출(능동). duration은 §4 표(2.6s→2.2s).
- **진행 단서**: 밟은 순서가 맞으면 머리 위에 점이 하나씩 켜지고, 틀리면 모두 꺼진다(초안).
- **시각 피드백**: 평상시 희미한 연두빛 → 노출 시 밝은 점등.
- **데미지 배율**: ×3, 속성 무관.
- **막힘 방지(초안)**: 원소 자리는 장판이 계속 덮지 않는 위치에 놓고, 같은 번호는 한 사이클에 두 번 나오지 않는다.

### weakness 속성 보너스
- `weakness = Chemistry`. Chemistry 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. X선관 약점(×3)과는 독립.

## 9. 보상 · 클리어 연동

처치 흐름: `Boss.OnDefeated` → `BossMission.OnBossDefeated` → 던전 클리어 처리(07 §3-10 공통). 모즐리는 분광 분석의 등대의 **마지막 보스** — 처치 시 던전 완전 클리어.
드랍·보상 세부는 02_던전-스테이지-템플릿.md 소관. 초안 제안:
- **전리품 후보**: X선관 유리 조각(장비 재료?), 모즐리의 측정 노트(연구자원).
- 신규 던전 클리어로 레벨 스케일링 하한 카운트([[dungeon_level_scaling_rule]])에 반영.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 43번 빈자리 환영수 처치 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1**: 표적에서 X선 다발, 원소 자리 3곳을 번호 순으로 밟으면 X선관 2.6s 노출, 순서가 틀리면 초기화.
- [ ] **P2 전환**: HP 80% → 배너 + 원소별 이중 고리, 노출 2.4s.
- [ ] **P3 전환**: HP 60% → 배너 + 번호가 클수록 빠른 발동, 자리 단서가 진동수 막대, 자리 4곳.
- [ ] **P4 전환**: HP 40% → 배너 + 코발트·니켈 등 번호 순 발동, 자리 단서가 원자량(함정).
- [ ] **P5 전환**: HP 20% → 배너 + 빠진 번호 칸만 안전, 자리 5곳(기호만).
- [ ] **처치**: HP 0 → defeatLine + 장판·자리 소멸 + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 완전 클리어.
