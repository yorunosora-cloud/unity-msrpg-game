## 1. 정체성 · 세계관 컨텍스트

### 핵심 테마
**"증거는 대칭이다 — 우연이라기엔 너무나 정확하게."**

미국의 지질학자이자 해군 장교 해리 헤스(Harry Hess)를 형상화한 존재. 2차대전 당시 함선을
지휘하며 소나로 해저 지형을 관측하다가 해저산맥·해구를 발견했고, 이후 해저확장설을 제시해
판구조론을 완성시켰다. 판게아 유적 3보스 중 "증거" 단계 — 판구조론 정립의 마지막 단계를
상징하는, 3보스 중 **가장 어려운 최종 관문**.

### 세계관 근거
- [테라노바_조감도.md](../../디자인/대륙/테라노바_조감도.md) §3: "보스: 알프레드 베게너
  (대륙이동설)·아서 홈스(맨틀대류설)·해리 헤스(해저확장설) — 한국 지구과학Ⅰ 교육과정의
  '판구조론 정립 과정' 표준 3단계"
- [테라노바_판게아유적.md](../../디자인/던전/테라노바_판게아유적.md) §2, §6: 동태평양
  해팽 구역의 중간보스 "쌍둥자철석"을 처치하면 얻는 증거 아이템으로 진입하는 해군 함선
  연구실 아레나의 주인.

### 포지션
판게아 유적 3보스방 중 **최고 난이도** — 베게너의 정직함, 홈스의 타이밍 압박을 모두 통과한
플레이어를 시험하는 최종 관문. 판게아 유적 자체가 토네이도 정령의 영혼 평원의 다음 단계
허브이므로, 헤스는 사실상 이 시점까지의 지구과학 콘텐츠 전체를 통틀어 가장 어려운 보스로
설계했다(로스비의 4페이즈보다도 한 단계 더 긴 **5페이즈**).

## 2. 비주얼 명세

### 2-A 지금 (프리미티브 조립 — HessSetup.cs로 구현 가능)

```
헤스 (BossRoot)
├── BossBody          Capsule   scale(1.1, 1.5, 1.1)  pos(0, 1.5, 0)   Color: 짙은 남색 해군 장교 제복
├── NavyCoat (Pivot)  empty     pos(0, 1.5, 0)          — 제복 재킷 자락
│   └── CoatPanel×3    납작 Cube  각 scale(0.45, 1.2, 0.05)
├── SonarHeadset      Cylinder(헤드폰 형) scale(0.5, 0.15, 0.5)  pos(0, 2.5, 0)  — 머리에 쓴 소나 헤드셋
├── WeakPoint         (BossWeakPoint) pos(0, 1.7, 0.5)  — 가슴에 달린 소나 헤드셋(제어 유닛)
│   └── SonarCore     Cylinder(납작)  scale 0.32  Color: 짙은 남색  Emission OFF→ON 노출 시
├── BeamAnchor×2(L/R) empty     pos(±0.6, 1.5, 0.3)     — 대칭광선이 발사되는 좌우 기준점
└── CapsuleCollider   center(0, 1.5, 0)  radius 0.55  height 3.2
```

**패턴 식별 시각**: 소나핑은 원형으로 퍼져나가는 동심원 텔레그래프, 대칭광선은 항상 좌우
쌍으로 동시에 나타나는 평행 직선 텔레그래프 — 페이즈가 진행될수록 평행선 쌍의 수가 늘어나
바닥이 격자처럼 채워진다.

### 2-B 미래 (최종 아트 가이드)

- **모델**: 2차대전 당시 미 해군 장교 제복 위에 소나 관측 장비(헤드셋+가슴 유닛)를 착용한
  혼합 스타일 — 홈스의 "실험복+학자품" 조합과 대칭되는 군인풍.
- **소품**: 가슴에 달린 소나 제어 유닛(약점) — 평상시 짙은 남색, 대칭광선 발사 직후 밝은
  남색으로 발광.
- **발광**: 소나 코어 — 평상시 약한 Emission, 노출 시 강한 Emission + 동심원 파동 이펙트.
- **셰이딩**: URP 툰 셰이더 + 외곽선 (`celshading_mandatory` 메모리 참조. 적용은 아트 완성 단계).
- **팔레트**: 짙은 남색 제복(#1A2E44) + 금색 견장 포인트(#C9A24B) + 밝은 남색 Emission(#4C8FE0, 약점) + 대칭광선 청록(#3ED0C4).
- **실루엣**: 키 약 3.1 Unity units. 3보스 중 가장 각지고 단단한(군인풍) 실루엣.

## 3-bis. 보스 모션 · 이동 명세

### 이동 방식: 절도 있는 도보 이동(군인풍)
- 패턴 캐스팅 사이(idle 구간) 플레이어를 향해 일정한 속도로 절도 있게 이동. 속도 ~1.8 m/s —
  베게너보다 빠르고 홈스보다는 동적임(군인다운 기민함).
- 이동 경로가 항상 직선적 — 판게아 3보스 중 가장 예측 가능한 이동 패턴(대신 공격 물량이 최고).

### 페이즈 전환
- P2~P5 진입 시 아레나 중앙으로 즉각 이동 + 짧은 무적(~1초), 배너와 동기화.
- 전환 VFX: ① 지금 = 없음. ② 미래 = 헤드셋에서 동심원 파동이 아레나 전체로 퍼지는 연출.

### 지금(프리미티브) 레이어 모션
| 효과 | 조건 | 구현 방법 |
|------|------|-----------|
| 제복 자락 흔들림 | 항상 | `Update()`: `CoatPanel[i].localRotation`을 `Mathf.Sin(Time.time*speed+i)`로 흔듦 |
| 소나 헤드셋 파동 | SonarPing 캐스팅 중 | 헤드셋 중심에서 동심원 파티클 확산 |
| 소나 코어 Emission | 대칭광선 발사 직후 | `SonarCore` 머티리얼 Emission 토글(노출 시간과 동기화) |

## 5. 약점 메커니즘

### 가슴의 소나 헤드셋(제어 유닛) (BossWeakPoint)
- **위치**: 가슴 전면(localPos 0, 1.7, 0.5).
- **노출 타이밍**: `SymmetricBeamPattern` 발사 직후 자동 `SetExposed(duration)` 호출 —
  duration은 광선 쌍 수와 함께 페이즈별로 1.0s→1.2s→1.4s→1.6s→1.8s로 **오히려 늘어남**(§4).
  광선 쌍이 많아질수록 위험하지만 반격 기회도 커지는 구조.
- **시각 피드백**: 평상시 짙은 남색 → 노출 시 밝은 남색 Emission + 동심원 파동 이펙트.
- **데미지 배율**: ×3, 속성 무관.

### weakness 속성 보너스
- `weakness = EarthSci`. EarthSci 속성 캐릭터의 일반 공격에 `CombatMath.ComputeDamage` 보너스 적용. 소나 헤드셋 약점(×3)과는 독립.

## 10. 검증 방법

Play 모드에서 스크린샷으로 확인 (`feedback_game_verification` 메모리 참조):

- [ ] **아레나 진입**: 쌍둥자철석 처치 → 증거 아이템 사용 → 포탈 텔레포트 → BossHealthBar 등장 + introLine.
- [ ] **P1 패턴**: SonarPing(원형 확산) / SymmetricBeam(1쌍) 정상 발동, 발사 직후 약점 1.0s 노출 확인.
- [ ] **P2~P5 전환**: HP 80/60/40/20% 도달마다 배너 + 대칭광선 쌍 수 순차 증가(2→3→4→5) 확인, 약점 노출 시간도 1.2→1.4→1.6→1.8s로 함께 증가 확인.
- [ ] **최종 페이즈 밸런스**: P5(5쌍 동시 발사)에서 회피 공간이 과도하게 좁아지지 않는지 확인 — 필요 시 아레나 크기 또는 광선 폭 조정.
- [ ] **처치**: HP 0 → defeatLine + BossHealthBar 숨김 + SealDoor 비활성화 + 던전 클리어.

## 11. 향후 확장

- **리깅 모션**: 제복 물리 시뮬레이션, 소나 탐지 제스처 애니메이션.
- **셀셰이딩**: URP 툰 셰이더 + 외곽선(`celshading_mandatory`).
- **광선 배치 다양화**: 현재는 항상 좌우 평행선 — 페이즈 후반에 방사형·회전형 대칭 배치 등으로 확장하는 안 검토.
- **미래 아트 레이어 전환**: 최종 아트 완성 후 프리미티브 → 아트 에셋 교체.
