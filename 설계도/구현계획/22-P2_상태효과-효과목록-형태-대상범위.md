# 22 P2 구현 계획 — 상태 효과 · 효과 목록 · 스킬 형태 · 대상 범위

> 근거: `설계도/22_전투-시스템-확장.md` §4-2~4-5-1, §4-9, §5 P2. 선행: P1 완료(커밋 33bb12a~e7018b3).
> 방식: TDD(빨강→구현→초록→커밋), 테스트는 `-testPlatform PlayMode`, 기준선 247개 중 245 통과(기존 `SkillProgressTests` 2건 실패는 P2와 무관).

**목표:** 스킬 효과를 조합 가능한 목록으로 일반화하고, 상태 효과(StatusHolder)·형태(Cone/Line/Circle)·아군 대상(TargetScope)을 도입한다. 기존 4종 `effectKind` 경로와 기존 테스트는 그대로 통과해야 한다.

## 결정 사항(설계도에 없던 구현 판단)

| 항목 | 결정 |
|---|---|
| 버프 중복 | 같은 `id`는 갱신(수치·시간 큰 쪽). 스택형(`maxStacks>1`)은 스택 +1(상한), 시간 갱신 |
| 스택 수치 | 곱연산 배율 = `1 + (value−1) × stacks` |
| 예약 버프 | 대기 캐릭터에게 걸린 이로운 효과는 `Pending`. 활성이 되면 타이머 시작(`OnSwitchIn`/Tick). 60초 실시간 후 소멸, 기절·`RestoreAll` 시 소멸 |
| 도트 | `value` = 초당 피해(시전 시점 `Atk × 비율`로 환산해 저장). 1초 미만 누적분은 소수 누적기로 보관 후 정수 단위로 `dealDot` |
| 피해 파이프라인 | `dmg = ComputeDamage(...) × 받는피해배율`(적/아군 공통), 보호막이 먼저 흡수 |
| 보스 면역 | **스턴·넉백·견인 면역이 기본**(`BossDef.ccImmune = true`). 둔화·도트·받는피해배율·표식은 받는다 (설계도 §7 미결 항목의 잠정안 — 튜닝 가능) |
| 적 공격 | 활성 캐릭터에게만. 피해는 `CombatCharacter.TakeHit`(보호막·받는피해배율 적용) |
| 대기 아군 선택 | 기절 제외, HP 비율 낮은 순. `Bench`+`targetCap=1`은 대기 아군이 없으면 자신(fallbackSelf), `SelfAndBench`는 자신 항상 포함 |

## 단계

### A — 순수 C# 코어 (Unity 의존 없음)
- A1 `StatusEffect`·`StatKind`·`StatusKind`·`StatusHolder` (Apply/Tick/OnSwitchIn/Mult/Stacks/IsStunned/Absorb/Cleanse/Clear) — 테스트 `StatusHolderTests`
- A2 `SkillShapes.Contains`(Cone/Line/Circle 판정, 순수 수학) — 테스트 `SkillShapeTests`
- A3 `TargetScope`·`TargetResolver`(아군 선택 규칙) — 테스트 `TargetResolverTests`
- A4 `SkillEffectType`·`SkillEffectEntry`·`SkillShape`·`SkillKind` 타입 정의

### B — CombatCharacter·Party 통합
- B1 `CombatCharacter.Status`, `Atk`에 상태 배율 반영, `ApplyAtkBuff`→StatusHolder 흡수(기존 SkillTests 통과), `TickStatus(dt,isActive)`, `TakeHit`, 기절/`RestoreFull` 시 Clear
- B2 `Party.Tick`에서 멤버별 `TickStatus`(활성 여부 전달), 전환 시 `OnSwitchIn`, `PlayerSkills`의 중복 `TickBuffs` 제거

### C — SkillDef·Executor·적 측
- C1 `SkillDef` 필드 추가(`skillType/shape/lineWidth/radius/effects/factNoteKo/gameNoteKo`), 호환 유지
- C2 `Enemy`·`Boss`에 `StatusHolder`(스턴·둔화·도트·받는피해배율, 넉백/견인), 보스 면역
- C3 `SkillExecutor` 효과 목록 경로(기존 4종 호환), 형태 판정 연동, 레벨 스케일링
- C4 `SkillRangeVisualizer` Line/Circle 표시

### D — HUD (씬 재생성 필요)
- D1 `PartyHud` 슬롯별 버프 표시(활성=남은 시간, 예약=흐림). 빌더(`AtlantisSetup`, `BootstrapSetup` 편집만) 반영. 씬은 사용자가 메뉴로 재생성.
