# 22번 P1 — 입력·슬롯·파티 5명·기본기 일반화 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설계도 22번의 P1을 구현한다 — 스킬 키를 `Q`(기본기)·`R/T/F/V/G/B`(슬롯 1~6)로 교체하고, 파티를 5명(`1~5` 키)으로 확장하며, 기본기(Q)를 캐릭터별 스킬(슬롯 0)로 일반화한다. 전환 쿨타임 1초와 대기 캐릭터의 쿨타임·MP 자연회복 진행도 함께 넣는다.

**Architecture:** `SkillDef`에 `slot`(기본 -1 = 레거시)·`formReq`를 추가하고, `CombatCharacter`가 슬롯→스킬 인덱스를 해석한다(기존 인덱스 기반 API와 테스트는 그대로 유지). 순수 로직(`SkillSlots`, `BasicAttack`, `Party` 확장)은 `MSRPG.Tests` 어셈블리 테스트로 검증하고, 입력 컴포넌트(`PlayerSkills`, `PlayerCombat`, `PartyController`)는 이 순수 로직을 호출만 한다. UI(HUD)는 배열 길이 기반이라 에디터 빌더의 슬롯 수만 바꾼다.

**Tech Stack:** Unity 6000.3.16f1, C#, NUnit 테스트(`MSRPG.Tests` 어셈블리, PlayMode 플랫폼으로 실행), Unity Input System(`Keyboard.current`).

**근거 문서:** `설계도/22_전투-시스템-확장.md` §2(규칙 15·16), §4-1, §5 P1.

## 확정 사항 (이 계획의 전제)

| 항목 | 결정 |
|---|---|
| 레거시 호환 | `SkillDef.slot = -1`(기본)이면 **슬롯 = 배열 인덱스 + 1**. 기존 시드 캐릭터 10종은 변경 없이 `R/T/F/V/G/B`로 동작한다(Q는 고정 평타). 기존 인덱스 기반 API·테스트(`CastSkill(0)`, `IsUnlocked(0)` 등)는 **수정하지 않는다** |
| 슬롯 | 0=`Q`(기본기), 1=`R`, 2=`T`, 3=`F`, 4=`V`, 5=`G`, 6=`B` |
| 폼 | P1에서는 `CurrentFormId`가 항상 빈 문자열(스텁). `formReq`가 비지 않은 스킬은 P3 전까지 해석되지 않는다 |
| 기본기 | 슬롯 0 스킬이 있으면 그 `range/halfAngle/damageMultiplier/cooldown` 사용, 없으면 `PlayerCombat`의 기존 고정값. MP 소모 없음(기본기 규칙). P1은 **부채꼴만**(직선·원형은 P2) |
| 파티 | 최대 5명. 수동 전환 후 **1초 쿨타임**, 기절로 인한 자동 교체(`AutoSwitchToNext`)는 쿨타임 검사·시작 없음 |
| 대기 캐릭터 | 스킬 쿨타임과 MP 자연회복이 **대기 중에도 진행**(기절자의 MP 회복 제외). 버프 타이머는 P1에서 건드리지 않는다(활성만 틱 — 현 동작이 규칙과 일치) |

/// <summary>
/// 스킬 슬롯 상수 (설계도 22 §4-1).
/// 슬롯 0=Q(기본기), 1=R, 2=T, 3=F, 4=V, 5=G, 6=B.
/// SkillDef.slot이 -1(레거시)이면 슬롯 = 배열 인덱스 + 1.
/// </summary>
public static class SkillSlots
{
    public const int Basic = 0;   // Q
    public const int Count = 7;   // 0..6

    static readonly string[] Labels = { "Q", "R", "T", "F", "V", "G", "B" };

    /// <summary>슬롯의 키 라벨. 범위 밖이면 "?".</summary>
    public static string KeyLabel(int slot)
        => (slot >= 0 && slot < Labels.Length) ? Labels[slot] : "?";

    /// <summary>slot이 -1(레거시)인 스킬의 슬롯: 배열 인덱스 + 1.</summary>
    public static int LegacySlot(int arrayIndex) => arrayIndex + 1;
}

        spec.halfAngle        = s.halfAngle;

    [Tooltip("false 면 R/T/F/V/G/B 스킬 키를 차단. 파일·컴포넌트는 보존 — true로 되돌리면 복구.")]
    [SerializeField] bool skillsEnabled = true;

    [Header("MP 자연 회복")]
    [Tooltip("MaxMp 대비 초당 자연 회복 비율 (기본 3%) — 파티 전원(대기 포함)에 적용")]
    [SerializeField] float mpRegenPercent = 0.03f;

    // 슬롯 1~6에 대응하는 키 (슬롯 0=Q는 PlayerCombat)
    static readonly Key[] SlotKeys = { Key.R, Key.T, Key.F, Key.V, Key.G, Key.B };

    const float RegenTickSeconds = 0.5f;

    BoxCharacterBuilder _builder;
    float               _regenAccum; // 자연 회복 누적 시간

    void Awake()
    {
        _builder = GetComponent<BoxCharacterBuilder>();
    }

    void Update()
    {
        var active = PlayerRuntime.Active;
        if (active == null) return;

        var   party = PlayerRuntime.Party;
        float dt    = Time.deltaTime;

        // 쿨다운 틱: 파티 전원(대기 포함) + 전환 쿨타임. UI가 열려 있어도 계속 감소.
        if (party != null) party.Tick(dt);
        else               active.TickCooldowns(dt);

        // 버프 틱: 활성 캐릭터만 (버프 타이머는 활성일 때만 흐른다)
        active.TickBuffs(dt);

        if (UIManager.IsAnyPanelOpen) return;

        // 자연 MP 회복: 파티 전원(대기 포함, 기절 제외)
        _regenAccum += dt;
        if (_regenAccum >= RegenTickSeconds)
        {
            if (party != null) party.RegenMpTick(mpRegenPercent, RegenTickSeconds);
            else               active.RegenMpTick(mpRegenPercent, RegenTickSeconds);
            _regenAccum -= RegenTickSeconds;
        }

        var kb = Keyboard.current;
        if (kb == null) return;

        if (!skillsEnabled) return;

        for (int i = 0; i < SlotKeys.Length; i++)
            if (kb[SlotKeys[i]].wasPressedThisFrame)
                TryCast(i + 1, active);   // 슬롯 = 키 순서 + 1
    }

    void TryCast(int slot, CombatCharacter active)
    {
        int index = active.IndexForSlot(slot);
        if (index < 0) return;                       // 그 슬롯에 스킬 없음

        var skill = active.CastSkill(index);
        if (skill == null) return;                   // MP 부족, 쿨다운 중, 잠금

        SkillExecutor.Execute(skill, index, active, transform);
        _builder?.PlaySkill(skill.effectKind);       // effectKind별 전용 모션
        SkillRangeVisualizer.Show(skill, transform); // 범위 시각화
    }
}
