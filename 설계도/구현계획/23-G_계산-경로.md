# 23-G 구현 계획 — 계산 경로(피해 기준·방어 무시·상황 비례·급소·확률 분기)

> 배경: 23-A·B·C 이후 남은 "계산 경로" 계열 근사를 원본 의도로 되돌린다. 피해 효과(`Damage`)에 **데이터 열**을 추가해 CSV만으로 표현한다.
> 방식: TDD, `-testPlatform PlayMode`.

## 목표(원본 규칙)
| 스킬 | 원본 규칙 | 필요한 계산 |
|---|---|---|
| 벨로시아 상대속도 | 추가 피해 = max(0, 본인 spd − 적 spd) × 1%, 최대 +100%(Lv.3 +130%) | 속도 차 비례 |
| 에네르기아 운동에너지(Q) | 이동 속도에 비례, 최대 속도에서 +50%(Lv.3 +70%) | 이동 속도 비율 비례 |
| 에네르기아 중력 퍼텐셜(Q) | 지면 대비 높이에 비례, 최대 높이에서 +100%(Lv.3 +130%) | 높이 비례 |
| 글루온 다운쿼크 | 피해 = **상대 공격력 × 1/3** | 피해 기준을 대상 공격력으로 |
| 글루온 참쿼크 | **방어력·속성 무시** 고정 피해 = 공격력×1.5, 급소 명중 시 ×2.5 | 방어 무시 + 급소 |
| 글루온 스트레인지 쿼크 | 1/2 확률로 ① 직접 피해 ② 도트+둔화 중 하나 | 확률 분기 |

## 설계 결정 — `SkillEffectEntry`(Damage)에 열 추가
1. **피해 기준** `damageBasis`: `CasterAtk`(기본) / `TargetAtk`. TargetAtk면 기준 공격력 = 대상의 공격력(`ISkillTarget.AttackPower`: 적은 접촉 피해량, 보스는 0 → 최소 1). 위력 배율·타격 공식은 그대로 곱한다.
2. **방어 무시** `ignoreDefense`: 방어력·약점 배율·피해 증감 이전의 정수 피해를 `ISkillTarget.ReceiveFixedHit(int)`로 직접 준다(받는 피해 배율 `DamageTaken`은 적용).
3. **상황 비례** `scaleBy`: `None` / `SpeedDiff` / `MoveSpeedRatio` / `Height`, `scaleCoeff`(SpeedDiff: 속도 1당 증분), `scaleCap`(최대 증분), `milestoneScaleCap`(Lv.3 교체). 위력 배율 = `1 + bonus`.
   - SpeedDiff: `min(cap, max(0, 시전자 기본 spd − 대상 spd) × coeff)` — 대상별.
   - MoveSpeedRatio: `speedRatio(0~1) × cap` — `PlayerRuntime.Motion.speedRatio`.
   - Height: `clamp(높이 / 최대 점프 높이, 0, 1) × cap` — 높이는 `CombatMotionState.height`(공중일 때 지면 기준), 최대 점프 높이는 `jumpSpeed²/2|g|`.
4. **급소** `critMult` + `critHalfAngle`: 대상이 조준 방향 ±critHalfAngle 안(정면 중앙)이면 피해 ×critMult. 참쿼크 `critMult 2.5, critHalfAngle 10`.
5. **확률 분기** `branchGroup` + `branchId`: 같은 그룹에서 행동마다 branchId 하나를 균등 확률로 고르고, 고르지 않은 분기의 효과는 건너뛴다. 난수는 `SkillExecutor.Random01`(테스트 주입).
6. 열 추가는 CSV 임포터 검증과 함께: 열거값 오류, `scaleBy`는 `Damage`에서만, `branchGroup`은 `branchId`와 짝, `ignoreDefense`+`damageBasis=TargetAtk` 조합 허용.

## 단계
- A `ISkillTarget.AttackPower/ReceiveFixedHit`, `CombatCharacter.BaseSpd`, `CombatMotionState.height`·`PlayerRuntime.MaxJumpHeight`(컨트롤러 계측).

- C CSV 열·임포터 검증 + 6개 스킬 원본 교체(`gameNoteKo` 정리), `ShippedCsvTests`.
