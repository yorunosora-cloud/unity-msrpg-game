# 12. 상점 시스템 + 소비 아이템 시스템

> 재료·결정 목록 → **[재료-목록.md](재료-목록.md)** / **CrystalCatalog.cs** 참조.
> 요리 재료 구매 창구는 이 상점이 담당 — 09 요리 설계의 "재료 상점 탭"을 이 시스템이 공식 흡수.

---

## 세계관 맥락

- **지식의 거래소(HubExchange)** — 메조리아 허브 동쪽 랜드마크. 6대륙에서 모여든 재료·마법석·지식 결정이 골드로 거래된다. "배움이 곧 재화"라는 세계관을 상징하는 공간.
- 소비 아이템은 **"지식의 정수"** 형태 — 집중력 보충제(Focus Potion), 연구 자원 교환팩(Resource Pack), 회복약(Recovery Potion), 경험 결정(EXP Crystal). 실험실에서 제조된 즉효성 물약이며, 지속 버프는 09 요리가 담당한다.

---

## 1. 목표 / 완료 정의

1. **상점 진입**: 메조리아 거래소 건물 `E` → `ShopPanel` 오픈. 대륙별 탭(물리·화학·생명·지구·수학·정보) + 공용 탭.
2. **구매**: 골드 보유 충분 + 일일 한도 잔여 → 골드 차감 → 해당 재화/인벤토리에 즉시 지급.
3. **일일 한도 리셋**: 로컬 날짜가 바뀌면 품목별 `purchasedToday`가 0으로 리셋.
4. **소비 아이템 보유**: `ConsumableInventory`에 int[] 잔량 보유. `InventoryPanel`(Tab)에서 확인·사용.
5. **즉시 효과 적용**: 소비 아이템 [사용] → 즉시 효과 반영(Focus 충전 / 파티 HP·MP 회복 / 연구 자원 지급 / 캐릭터 EXP 지급).
6. **저장·복원**: 일일 구매 한도 상태·소비 아이템 보유량이 PlayFab에 저장되어 재로그인 후 유지.

### 확정 설계 결정

| # | 결정 | 근거 |
|---|------|------|
| 1 | 진입: `HubExchange` → `OpenShop()` — 학술원(`OpenLab`) · 도서관(`OpenLibrary`)과 동일 WireBuilding 패턴 | 기존 인프라 100% 재사용 |
| 2 | 구매 통화 = **골드 단독** | 현재 골드 소비처 0 → 첫 소비처 확보 |
| 3 | 재고 모델 = **품목별 일일 구매 한도** (로컬 날짜 경계 리셋) | 인플레이션 방지 + 데일리 동기 부여 |
| 4 | 구획 = **대륙별 탭**(자기 대륙 재료만) + **공용 탭**(소비 아이템·범용 요리재료) | 세계관 정합, 탭 전환으로 직관 탐색 |
| 5 | 소비 아이템 = **즉시 효과 전용** (지속 버프는 09 요리 전담) | 역할 분리. 중복 회피 |

```csharp
[Serializable]
public class ConsumableInventory
{
    const int Count = 4; // ConsumableKind 값 수
    int[] _amounts = new int[Count];

    public int  Get(ConsumableKind k)                     => _amounts[(int)k];
    public void Add(ConsumableKind k, int n)              { _amounts[(int)k] += n; }
    public bool CanUse(ConsumableKind k)                  => Get(k) > 0;
    public bool TryConsume(ConsumableKind k)              { if (!CanUse(k)) return false; _amounts[(int)k]--; return true; }
    public ConsumableInventoryData Export()               => new() { amounts = (int[])_amounts.Clone() };
    public void LoadState(ConsumableInventoryData d)      { if (d?.amounts != null) Array.Copy(d.amounts, _amounts, Count); }
}
[Serializable] public class ConsumableInventoryData { public int[] amounts; }
```

**`Scripts/Meta/ConsumableEffect.cs`** (신규) — 즉시 효과 라우터:
```csharp
public static class ConsumableEffect
{
    // targetSlot: EXP책 전용 (0~2). 나머지 -1.
    public static bool Apply(ConsumableKind k, int targetSlot = -1)
    {
        switch (k)
        {
            case ConsumableKind.FocusPotion:
                MetaState.Wallet.Add(CurrencyKind.Focus, 30);
                return true;
            case ConsumableKind.ResourcePack:
                // targetSlot을 Continent로 재사용 (호출측 보장)
                MetaState.StudyMaterials.Add((Continent)targetSlot, 3);
                return true;
            case ConsumableKind.RecoveryPotion:
                MetaState.ActiveParty?.RestoreAll(0.5f); // 50% 회복 오버로드 추가
                return true;
            case ConsumableKind.ExpCrystal:
                // targetSlot = 로스터 인덱스, 호출측이 캐릭터 선택 후 전달
                var cc = MetaState.ActiveParty?.GetMember(targetSlot);
                cc?.GainExp(500);
                return cc != null;
        }
        return false;
    }
}
```

> **EXP책·연구자원 교환팩 대상 선택:** `InventoryPanel`에서 [사용] 클릭 시 로스터 슬롯 선택 팝업(캐릭터 초상화 3칸 또는 대륙 버튼) 표시 → 선택값을 `targetSlot`으로 전달. 팝업은 기존 `PartyHud` 아이콘 재사용.

**`Scripts/Meta/ShopDailyState.cs`** (신규):
```csharp
[Serializable]
public class ShopDailyState
{
    public string lastResetDate = "";          // "yyyy-MM-dd" 로컬
    public Dictionary<string, int> purchased = new(); // itemDef.id → purchasedToday

    public void TryResetIfNewDay()
    {
        string today = DateTime.Now.ToString("yyyy-MM-dd");
        if (lastResetDate == today) return;
        purchased.Clear();
        lastResetDate = today;
    }
    public int GetPurchased(string id) => purchased.TryGetValue(id, out int v) ? v : 0;
    public void Record(string id, int qty) => purchased[id] = GetPurchased(id) + qty;
    // Export/LoadState — JSON 직렬화 (Dictionary → List<KV> DTO)
}
```

> **직렬화 주의**: `JsonUtility`는 Dictionary를 직렬화하지 못함. `ShopDailyData` DTO에 `List<ShopEntry>{ string id; int count; }` 배열로 변환 후 저장. 로드 시 역변환.

**`Scripts/Meta/ShopService.cs`** (신규):
```csharp
public static class ShopService
{
    public static bool Purchase(ShopItemDef item, int qty = 1)
    {
        MetaState.ShopDaily.TryResetIfNewDay();

        int remaining = item.dailyLimit - MetaState.ShopDaily.GetPurchased(item.id);
        if (remaining < qty) return false;                        // 1. 한도 초과

        int total = item.priceGold * qty;
        if (!MetaState.Wallet.TrySpend(CurrencyKind.Gold, total)) return false; // 2. 골드 부족

        // 3. 지급
        for (int i = 0; i < qty; i++) DispatchGood(item);
        MetaState.ShopDaily.Record(item.id, qty);
        MetaSaveService.SaveShop();
        return true;
    }

    static void DispatchGood(ShopItemDef item)
    {
        switch (item.goodType)
        {
            case GoodType.Crystal:       MetaState.Crystals.Add((CrystalKind)item.kindIndex, item.qty); break;
            case GoodType.StudyMaterial: MetaState.StudyMaterials.Add((Continent)item.kindIndex, item.qty); break;
            case GoodType.Ingredient:    MetaState.Ingredients?.Add((IngredientKind)item.kindIndex, item.qty); break; // 09 미구현 시 null safe
            case GoodType.Consumable:    MetaState.Consumables.Add((ConsumableKind)item.kindIndex, item.qty); break;
        }
    }
}
```

**`Backend/ShopPanel.cs`** (신규) — UI:
- `Show()` / `Hide()` : `UIManager`에 등록 (`IsAnyPanelOpen` 연동)
- 상단: 골드 잔액 텍스트 (`MetaState.Wallet.OnChanged` 구독)
- 탭 바: 물리·화학·생명·지구·수학·정보·공용 (7개 버튼)
- 콘텐츠: 활성 탭의 `ShopCatalog` 항목 스크롤 목록. 각 행: 이름·설명·가격·"잔여 N/D"·[구매] 버튼.
- 패널 오픈 시 `ShopDailyState.TryResetIfNewDay()` 호출.
- [구매] 클릭 → `ShopService.Purchase(item)` → 성공 시 행 갱신 (잔여 한도·골드 HUD).
- `Ingredient` 타입 행은 `MetaState.Ingredients == null`이면 "(재료 시스템 준비 중)" 표시·버튼 비활성.

**데이터 흐름:**
```
HubExchange [E]
  → MetaPanelController.OpenShop()
    → ShopPanel.Show()
      → TryResetIfNewDay()
      → 탭 렌더 (ShopCatalog 항목)
        → [구매] 클릭
          → ShopService.Purchase(item)
            → 한도 체크 → Wallet.TrySpend → DispatchGood → ShopDailyState.Record
              → MetaSaveService.SaveShop()
              → ShopPanel 행 갱신

InventoryPanel [Tab]
  → 소비 아이템 섹션
    → [사용] 클릭
      → (EXP책·교환팩: 선택 팝업 표시)
      → ConsumableInventory.TryConsume()
        → ConsumableEffect.Apply(kind, targetSlot)
          → 즉시 효과 적용
          → MetaSaveService.SaveConsumable()
```

## 6. 엣지 케이스 / 주의점

- **일일 리셋 기준:** `DateTime.Now.ToString("yyyy-MM-dd")` 로컬 날짜 비교. 오프라인 복귀 시 패널 오픈 순간 1회 체크. 기기 시간 조작 가능성은 1차에서 허용(서버 검증은 PlayFab CloudScript 후속 확장).
- **Dictionary 직렬화:** `JsonUtility`가 Dictionary 미지원. `List<ShopEntry>{ id, count }` DTO 변환 필수. 로드 시 동일 id ShopEntry → Dictionary 역변환.
- **구매 원자성:** `remaining < qty` 체크가 `TrySpend` 보다 먼저 → 골드 먼저 빠지는 경우 없음. `TrySpend` 내부도 원자적(`if (Get < amount) return false`).
- **요리 재료 탭 graceful 처리:** `MetaState.Ingredients == null`이면 `DispatchGood`에서 null-safe skip + UI 행 비활성. 09 구현 후 `MetaState.Init()`에서 `Ingredients` 등록 시 자동 활성.
- **EXP책 대상:** `GainExp`는 `CombatCharacter`에 있고, 전투 밖(`RnEPanel`)에서도 `DirectLevelUp`으로 캐릭터가 `CombatCharacter`로 래핑돼야 함. `ConsumableEffect.Apply`에서 `MetaState.ActiveParty`가 null이면 사용 불가 안내.
- **회복약 전투 외 사용:** `MetaState.ActiveParty`가 null이면(메인 메뉴) 사용 실패 처리 또는 별도 `MetaState.StandbyRoster` 회복 경로 필요. 1차는 "파티 활성화 후 사용 가능" 안내로 처리.
- **대륙↔결정 매핑 불균등:** 지구 대륙에 결정 3~4종(MemoryOfStar·BoneOfTheEarth·OceanPrime 확인 후 TornadoCore 포함 여부 결정). `CrystalCatalog.ContinentLabel`로 "지구·천문" 등 세분 표기.
- **저장 하위호환:** 신규 키 없는 구세이브 → `JsonUtility`가 빈 DTO로 역직렬화 → `_amounts` 전부 0(빈 인벤) + `purchased` 비어있음(한도 미소진). 별도 마이그레이션 불필요.
- **구매 수량:** 1차는 1개씩. 일괄 구매(5개 등)는 후속 확장. 한도 클램프 로직 `ShopService.Purchase`에 `qty` 매개변수로 이미 준비.
