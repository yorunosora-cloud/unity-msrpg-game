# 03. 시너지·연계 시스템

---

## 세계관 맥락

- `게임 시스템 설계.md §6`은 시너지를 **전투의 정체성**으로 규정한다 — "연계하지 않으면 매우 약하다. 파티 빌딩이 핵심 퍼즐."
- 공식 관계(F=ma, p=mv, 2H₂+O₂→H₂O)·물질대사·자연 현상 등 실제 개념 관계가 연계의 토대. 캐릭터를 육성하면서 자연히 공식을 익히는 교육 RPG의 핵심.
- **이 설계도는 시너지 3유형(표식연계·파티패시브·합동필살기)의 데이터·아키텍처 전체와 1차 레퍼런스 구현을 다룬다.**

---

## 1. 목표 / 완료 정의

1. **표식 연계 레퍼런스(F=ma)**: 질량(Mark 스킬) → 가속도로 교체 → 지정 트리거 스킬 명중 → **"힘 · F=ma!" 배너 + comboSkill 데미지 + 표식 소멸**의 한 사이클이 동작한다.
2. **표식 만료**: 기본 8초, 만료 1.5초 전 깜빡임. 보스전 진입 시 `BossDef.markDurationMult`(예: 0.6)로 단축되어 고인물 압박이 생긴다.
3. **데이터 주도**: `SynergyComboDef` + `SkillDef(comboSkill)` 에셋 배치만으로 새 연계를 추가할 수 있다(새 코드 0줄).
4. **파티 패시브**: 시간 캐릭터 편성 시 전체 쿨다운 -15% 레퍼런스가 동작하고, 시간 기절 시 원복된다.
5. **합동 필살기**: 지정 페어 편성 → 타격/연계로 게이지 충전 → Y키 발동의 1사이클이 동작한다.

### 확정된 설계 결정
| # | 결정 | 근거 |
|---|------|------|
| 1 | 연계기 = 별도 `SkillDef` (기존 스킬 시스템 재사용) | 연계마다 고유 범위·연출, 추가 실행 코드 0 |
| 2 | 소모자 = 캐릭터 id 고정 (`consumerCharId`) | 명시적·통제 쉬움. 설계된 쌍만 에셋화로 n² 회피 |
| 3 | 표식 = 기본 8초 × 난이도 배율 (보스 진입 시 단축) | 초반 넉넉, 후반 고인물 압박 |
| 4 | 트리거 = 지정 스킬만 (`triggerSkillId`) | 공식 의도대로 정밀 발동 |
| 5 | 파티 패시브 = 정적 컨텍스트 (`PartyContext`) | 단일 파티라 전역 무해, 배선 최소·확장 쉬움 |
| 6 | 합동 게이지 = 타격/연계 충전 위주 | 적극 전투·연계 보상, 시너지 철학과 일관 |

### 3-1. 표식 모델 업그레이드 (`Enemy.cs`)

현 `Continent? _mark` 단일 표식 → **다중 markId 표식 + 만료 타이머**.

**필드 교체** (현 42~47줄 `_mark`/`Mark` 블록 대체):
```csharp
public struct ActiveMark { public string markId; public Continent tint; public float expiry; public GameObject indicator; }
readonly List<ActiveMark> _marks = new();
public IReadOnlyList<ActiveMark> Marks => _marks;
public bool HasMark(string id) { foreach (var m in _marks) if (m.markId == id) return true; return false; }
```

**`SetMark` 시그니처 변경** (현 127줄 대체):
```csharp
public void SetMark(string markId, Continent tint, float baseDuration) {
    float dur = baseDuration * SynergyTuning.MarkDurationMult;
    for (int i = 0; i < _marks.Count; i++)
        if (_marks[i].markId == markId) { var m = _marks[i]; m.expiry = Time.time + dur; _marks[i] = m; return; }
    var ind = CreateMarkIndicator(tint, _marks.Count);
    _marks.Add(new ActiveMark { markId = markId, tint = tint, expiry = Time.time + dur, indicator = ind });
}
public void ClearMark(string markId) {
    for (int i = 0; i < _marks.Count; i++) if (_marks[i].markId == markId) {
        if (_marks[i].indicator) Destroy(_marks[i].indicator); _marks.RemoveAt(i); return; }
}
```

**`CreateMarkIndicator(Continent tint, int slot)`** — 다중 표식 가로 배치:
```csharp
go.transform.localPosition = new Vector3((slot - 0.5f * (_marks.Count)) * 0.35f, 2.8f, 0f);
rend.material.color = ContinentColors.Of(tint);
```

**`Update()` 만료 정리 + 깜빡임** (UIManager 체크 뒤 삽입):
```csharp
for (int i = _marks.Count - 1; i >= 0; i--) {
    float left = _marks[i].expiry - Time.time;
    if (left <= 0f) { if (_marks[i].indicator) Destroy(_marks[i].indicator); _marks.RemoveAt(i); continue; }
    if (left < 1.5f && _marks[i].indicator)
        _marks[i].indicator.SetActive(Mathf.FloorToInt(left * 6f) % 2 == 0);  // 만료 1.5초 전 깜빡임
}
```
> `ReceiveHit(Continent, int)` 시그니처는 **불변** — 보스/IDamageable 무영향.

### 3-3. 연계 발동 — `SynergyResolver` + `SkillExecutor` 수정

**`Scripts/Combat/SynergyResolver.cs`** (신규):
```csharp
public static class SynergyResolver {
    /// <summary>SkillExecutor.Execute 말미에서 호출. 트리거 스킬 발동 시 표식 소모·연계기 실행.</summary>
    public static void TryTrigger(SkillDef skill, CombatCharacter caster, Transform origin) {
        var combo = MetaState.Combos != null
            ? MetaState.Combos.FindByTrigger(caster.Id, skill.id) : null;
        if (combo == null || combo.comboSkill == null) return;

        bool fired = false;
        foreach (var enemy in Enemy.All.ToArray()) {
            if (enemy == null || !enemy.HasMark(combo.requiredMarkId)) continue;
            enemy.ClearMark(combo.requiredMarkId);
            fired = true;
        }
        if (!fired) return;

        // 연계기(별도 SkillDef) 실행 — 사거리·effectKind·배율 모두 comboSkill 에셋이 결정
        SkillExecutor.Execute(combo.comboSkill, 0, caster, origin);
        ComboBanner.Show(combo.comboName);    // "힘 · F=ma!"
        SynergyLog.Record(combo.id);
        JointUltGauge.NotifyCombo();          // 합동 게이지 보너스 충전
    }
}
```
> AoE 트리거가 표식 적 다수에 명중하면 모두 ClearMark, comboSkill은 1회 시전(범위로 동시 타격).

**`Scripts/Combat/SkillExecutor.cs` 수정 — 2곳**:

(1) `ExecMark`(현 78줄) — `skill` 인자 추가 후 markId화:

```csharp
        enemy.SetMark(skill.markId, caster.Element, skill.markDuration);  // markId 기반으로 변경

```

(2) `Execute` switch 직후(현 26줄 뒤) 추가:

**`Scripts/Combat/SynergyLog.cs`** (신규) — 연계 횟수 기록(조건 해금 토대):
```csharp
public static class SynergyLog {
    static readonly Dictionary<string,int> _counts = new();
    public static void Record(string comboId) {
        _counts.TryGetValue(comboId, out int n); _counts[comboId] = n + 1; }
    public static int Count(string comboId) =>
        _counts.TryGetValue(comboId, out int n) ? n : 0;
    public static void Reset() => _counts.Clear();   // 씬 전환 시
}
```

**`Scripts/Combat/PartyBuffs.cs`** (신규) — 집계 후 `PartyContext`에 기록:
```csharp
public static class PartyBuffs {
    /// <summary>파티 편성·기절 변경 시 호출. 생존 멤버 패시브를 합산해 PartyContext에 반영.</summary>
    public static void Recompute(Party party) {
        PartyContext.Reset();
        float cdReduce = 0f;
        foreach (var m in party.Members) {
            var p = m.Passive;
            if (p == null || !p.hasPassive || m.IsDowned) continue;  // 기절 멤버 제외
            if (p.stat == PartyStat.CooldownReduce) cdReduce += p.value;
        }
        PartyContext.CooldownMult = Mathf.Clamp(1f - cdReduce, 0.4f, 1f);  // 최소 0.4배 상한
    }
}
```

**`Scripts/Combat/Party.cs` 수정** — Recompute 훅 추가:
- 생성자 말미: `PartyBuffs.Recompute(this);`
- `RestoreAll()` 말미: `PartyBuffs.Recompute(this);`
- `AutoSwitchToNext()` 호출 지점(기절 발생)에서 호출: 기절 상태 변화는 `PlayerDeath`/`Enemy.Update`에서 발생하므로, `PlayerRuntime.Active.Damage` → HP=0 → `PartyBuffs.Recompute(PlayerRuntime.Party)` 흐름 추가.

**`Scripts/Combat/JointUltGauge.cs`** (신규, Player GameObject 부착 MonoBehaviour):
```csharp
public class JointUltGauge : MonoBehaviour {
    static JointUltGauge _inst;
    JointUltDef _def;
    float _gauge;
    bool _active;  // 페어 전원 생존 시 true

    public static void SetDef(JointUltDef def) { if (_inst) _inst._def = def; }
    public static void AddHit()   { if (_inst && _inst._active) _inst._gauge = Mathf.Min(_inst._def.gaugeMax, _inst._gauge + _inst._def.fillPerHit); }
    public static void NotifyCombo() { if (_inst && _inst._active) _inst._gauge = Mathf.Min(_inst._def.gaugeMax, _inst._gauge + _inst._def.fillPerCombo); }

    void Awake() { _inst = this; }

    void Update() {
        if (_def == null) return;
        _active = IsPairActive();
        if (!_active) { JointUltGaugeHud.SetFraction(0f); return; }

        _gauge = Mathf.Min(_def.gaugeMax, _gauge + _def.fillPerSec * Time.deltaTime);
        JointUltGaugeHud.SetFraction(_gauge / _def.gaugeMax);

        if (_gauge >= _def.gaugeMax && Keyboard.current.yKey.wasPressedThisFrame) {
            SkillExecutor.Execute(_def.ultSkill, 0, PlayerRuntime.Active, transform);
            ComboBanner.Show(_def.ultName);
            _gauge = 0f;
        }
    }

    bool IsPairActive() {
        if (_def == null || PlayerRuntime.Party == null) return false;
        foreach (var id in _def.requiredCharIds) {
            bool found = false;
            foreach (var m in PlayerRuntime.Party.Members)
                if (m.Id == id && !m.IsDowned) { found = true; break; }
            if (!found) return false;
        }
        return true;
    }
}
```

### 3-7. 연출 UI — `ComboBanner`

**`Backend/ComboBanner.cs`** (신규, Assembly-CSharp):
```csharp
public class ComboBanner : MonoBehaviour {
    static ComboBanner _inst;
    [SerializeField] Text         _label;
    [SerializeField] CanvasGroup  _group;
    void Awake() { _inst = this; _group.alpha = 0f; }

    public static void Show(string text) { if (_inst) _inst.Play(text); }

    void Play(string text) {
        _label.text = text;
        StopAllCoroutines();
        StartCoroutine(Flash());
    }

    IEnumerator Flash() {
        _group.alpha = 1f;
        yield return new WaitForSeconds(0.8f);
        for (float t = 0; t < 0.5f; t += Time.deltaTime) {
            _group.alpha = 1f - t / 0.5f;
            yield return null;
        }
        _group.alpha = 0f;
    }
}
```

## 6. 엣지 케이스 / 주의점

| 상황 | 처리 방식 |
|------|----------|
| 표식 만료 전 미소모 | 조용히 소멸(window 압박 의도). 만료 1.5초 전 깜빡임 경고 |
| 트리거 스킬 명중했으나 사거리 내 표식 적 없음 | `fired==false`이면 연계기 미발동. MP·쿨다운은 트리거 스킬 기준 이미 소모됨(의도) |
| AoE 트리거 + 표식 적 다수 | 전부 `ClearMark`, comboSkill은 1회 시전(범위 AoE가 동시 타격) |
| 복수 markId 표식 동시 보유 | markId별 독립 관리. 1차 F=ma는 단일 markId |
| `Enemy.ReceiveHit` 시그니처 불변 | 보스/IDamageable 코드 무영향. 보스 표식 연계는 향후 |
| 패시브 중복(시간 2명) | 합산 후 `Clamp(0.4, 1)` 상한 |
| `PartyContext`/`SynergyTuning` 전역 → 씬 전환 | `PlayerDeath`·씬 전환 지점에서 `Reset()` 호출 필요 |
| EditMode 테스트 | `[SetUp]`에서 `PartyContext.Reset()` + `SynergyTuning.Reset()` 필수 |
| 합동 게이지: 페어 일원 기절 | `IsPairActive()` false → 충전 정지. 전원 복귀 시 재개 |
| 합동 게이지: 씬 전환/전투 종료 | 게이지 0으로 리셋(런타임 전용) |
| `SynergyComboCatalog` null | `MetaState.Combos` null 체크로 방어(카탈로그 미로드 시 연계 미발동) |
