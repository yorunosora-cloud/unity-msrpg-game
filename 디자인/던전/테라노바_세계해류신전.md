## 0-bis. 랜드마크 외형 — 신전 실루엣

### 실루엣 · 접근
- 산호초·다도해 위에 떠 있는 대형 수상 신전. 신전 하단을 실제 해류가 관통하며 흘러나가는
  모습이 **밖에서도 보인다** — 멀리서 카누를 타고 다가가면 신전 주변 바다에 뚜렷한 물살의
  흐름이 눈에 들어온다.
- 스케일: 적당히 거대함 — 거대 천문대 피라미드보다는 작지만, 토네이도 정령의 영혼 평원보다는
  훨씬 웅장한 단일 건축물.

### 재질 · 색상
- 신전 본체: 짙은 목재색 기둥(고상가옥 확장판) + 야자잎 지붕, 폴리네시아풍 건축 팔레트 유지.
- 해류: 투명한 청록·남색 빛이 신전 하단을 관통하며 흐른다 — "지형이 곧 현상"이라는 조감도
  기법을 외형에도 그대로 반영(아틀란티스 뉴턴-라이프니츠 폭포와 동일 기법).
- 팔레트: 목재 기둥(#4A3524) + 야자잎 지붕(#5C6B3E) + 해류 청록빛(#2FA8A0) + 해류 남색빛(#1B4E8C).

### 지금(프리미티브) 구현 메모
- `OceanCurrentTempleExteriorBuilder.cs`(가칭): 산호초 바다 Plane 위에 고상가옥형 기둥+지붕
  구조물을 다수 배치해 신전 실루엣 구성, 신전 하단을 관통하는 물살은 흐르는 텍스처(UV
  스크롤) + 파티클로 표현.
- 아레나 절차 생성 Editor 빌더 목록에 이 외형 빌더를 추가 — §8 체크리스트에 반영.

## 1. 전체 구조 — 해류를 타고 흐르는 선형 던전

1. 입구(해류 상류)에서 진입하면, 플레이어는 계속 **하류 방향으로 흘러가며** 진행한다
   (강물을 타고 내려가는 감각 — 오픈필드 미로형·수직 등반형과 달리 진행 방향이 명확한
   선형 구조).
2. 흐름을 따라가다 보면 **3갈래 해류**(난센·에크만·스토멜)로 갈라지는 지점에 도달
3. 각 갈래 입구는 **에크만 나선 게이트**(§4)로 막혀 있음 — 나선형으로 흘러가며 좁혀지는
   흐름의 타이밍을 맞춰야 갈래가 열린다
4. 갈래를 타고 계속 흐르며 하자드를 통과해 **중간보스**(§2)와 조우
5. 중간보스 처치 시 **열쇠**를 드롭
6. 열쇠로 대응하는 보스방(§6)에 진입 가능 — 07번 설계도 "보스룸 복수 배치→택1" 원칙

플레이어는 3갈래 중 원하는 순서로 도전하며, 최소 1개 갈래를 클리어하면 그에 대응하는
보스방으로 들어가 던전을 클리어할 수 있다(다른 세 던전과 동일한 "택1" 원칙).

## 2. 중간보스 3종 (갈래별) — 해류의 기운을 받아 변이한 해양 생물

토네이도(자연 정령)·판게아(살아있는 지질/광물)·천문대(살아있는 천체 현상)에 이은 네 번째
세계관 축: **해류의 기운을 받아 변이한 해양 생물**(거북·장어·고래 등). 실제 필드용 고유
생물(판구조 해초·해류 거북)과는 별개의, 던전 전용으로 새로 설계된 개체다
([[feedback_map_worldview_reference]] 규칙 — 고유 동식물은 필드용, 던전 잡몹/미니보스는
새로 설계).

### 🐢 표류얼음거북 (난센 갈래)
- **시각**: 북극 표류얼음을 등껍질처럼 뒤집어쓴 거대 거북.
- **전투 컨셉**: 난센이 북극 표류 중 에크만 수송 현상을 **관찰**했다는 업적을 반영 — 느리고
  정직하게 이동하며 얼음 파편을 흩뿌리는 단순한 패턴. 3종 중 가장 정직함(진입 관문 역할).

### 🐍 나선조류장어 (에크만 갈래)
- **시각**: 몸이 나선형으로 흐르는 장어형 생물 — 에크만 나선(Ekman spiral)을 몸으로 직역.
- **전투 컨셉**: 에크만 수송 **이론**(바람 방향과 다른 각도로 흐르는 나선형 이동)을 반영 —
  이동 경로 자체가 나선형으로 꺾이며 예측이 필요한 이동형 공격.

### 🐋 심해순환고래 (스토멜 갈래)
- **시각**: 거대한 몸에 전 지구 심해 순환(컨베이어벨트) 무늬가 발광 문양으로 새겨진 고래.
- **전투 컨셉**: 스토멜의 **종합 모델**(전 지구 심층순환)을 반영 — 여러 개의 순환 흐름을
  동시에 만들어내는 복합 패턴. 3종 중 가장 복잡하고 강력함(최고 난이도).

### 2-bis. 중간보스 3종 상세 스킬 — 07번 `BossPatternModule` 축소판

다른 세 던전과 동일하게, 중간보스는 페이즈 전환·약점 노출 윈도 없이 07_보스전.md
`BossPatternModule` 구조만 재사용하는 경량 버전이다(단일 패턴 루프만 순환).
`enemy_catalog.csv`에 MiniBoss 행으로 스탯·스킬이 확정되어 있다.

**표류얼음거북** (lv20, HP195/DEF11/EXP125) — 난센 갈래, 진입 관문
- `StraightChargePattern`: 원형 근접 텔레그래프 → 느린 직선 돌진, 큰 데미지
- `IceShardScatterPattern`: 주변으로 얼음 파편이 흩어지는 원거리 공격
- 패턴 인터벌 ~2.5s, 3종 중 가장 느리고 정직함("관찰" 단계를 반영)

**나선조류장어** (lv21, HP230/DEF13/EXP145) — 에크만 갈래, 중간
- `SpiralProjectilePattern`: 원거리 투사체가 직선이 아니라 나선형(공전) 궤적을 그리며 날아옴 —
  에크만 나선(바람과 다른 각도로 편향되는 현상)을 투사체 궤적으로 직역
- 패턴 인터벌 ~2.0s

**심해순환고래** (lv22-23, HP275/DEF16/EXP175) — 스토멜 갈래, 최고 난이도
- `MultiCirculationZonePattern`: 앞선 두 미니보스와 패턴을 공유하지 않는 완전히 새로운
  전용 패턴 — 여러 개의 순환 흐름(광역 장판)이 동시에 발생. 전 지구 심층순환의 "종합
  모델" 성격을 다중 동시 장판으로 형상화
- 패턴 인터벌 ~1.8s, 3종 중 가장 복잡하고 강력함

3종 모두 처치 시 대응하는 보스방 열쇠(`해류열쇠_난센` 등, §7)를 드롭.

### 에크만 나선 게이트 메커니즘 (공통, §4에서 상세)
세 갈래 모두 입구가 **나선형으로 좁혀지는 흐름**으로 막혀 있다. 순수 타이밍 액션으로 통과
가능하지만, 던전 문제를 풀면 나선이 더 느리게 돌거나 타이밍 창이 넓어져 통과가 쉬워진다
(사용자 확정: "순수 타이밍 액션 + 문제 풀면 쉬워지는 보조 방식" — 다른 세 던전의 "던전 문제가
곧 게이트"인 방식과 달리, 이 던전은 던전 문제가 **난이도 경감 보조 수단**이라는 점이 새로움).

## 3. 던전 형태 — 선형 흐름 + 3갈래

```
입구(해류 상류)
      │  (하류로 계속 흐름)
      ▼
   3갈래 분기점(에크만 나선 게이트 3개)
   ┌─────────┼─────────┐
[난센 갈래] [에크만 갈래] [스토멜 갈래]
   │           │            │
 미니보스     미니보스      미니보스
   │           │            │
 보스방       보스방        보스방
```

세 갈래는 서로 합류하지 않음 — 한 번 갈래를 타면 그 갈래의 보스방까지 직행한다(허브 경유
없이 완전히 독립된 세 흐름). 천문대의 "외벽 3계단"과 유사한 완전 분리 구조이나, 여긴 수직이
아니라 수평(흐름) 방향의 분기라는 점이 다르다.

## 4. 에크만 나선 게이트 — 상세

- 각 갈래 입구는 나선형으로 돌면서 점점 좁혀지는 소용돌이 흐름으로 막혀 있다.
- **기본 통과 방식**: 순수 타이밍 액션 — 나선이 좁아지는 리듬에 맞춰 이동/입력해야 통과.
- **던전 문제 보조**: 문제를 풀면(난이도 택1) 나선 회전 속도가 느려지거나 타이밍 판정 창이
  넓어져 통과가 쉬워진다. 풀지 않아도 통과 자체는 가능(순수 실력으로도 클리어 가능) —
  던전 문제는 선택적 난이도 경감 수단.
- **정정(2026-09)**: 레벨업/스킬용 `ProblemDef`(R&E) 재사용 방침을 철회하고
  [20_던전-문제-풀.md](../../설계도/20_던전-문제-풀.md)의 `DungeonProblemDef` 전용 풀로
  교체 — `dungeonId="ocean_current_temple"`, 갈래별 `gateId="ekman_gate_nansen"` /
  `"ekman_gate_ekman"` / `"ekman_gate_stommel"`(3개 독립 게이트), 과목=EarthSci로 분류.

## 5. 갈래 3종 — 계단식 난이도

## 6. 보스방 3종 — 실제 업적을 형상화한 공간

천문대의 "업적 공간화" 접근을 계승 — 실제 역사적 사실에 근거한 개인 공간을 아레나로 삼는다.

### 🚢 난센 보스방 — 프람호 얼음 갇힌 선내
프리티오프 난센이 실제로 탔던 북극 탐험선 프람(Fram)호가 얼음에 갇힌 채 표류하던 상태를
재현한 선내 공간.

### 📐 에크만 보스방 — 수학적 나선이론 연구실
반프리드 에크만이 나선 수송 이론을 수학적으로 유도했던 연구실 — 칠판·공식판이 늘어선 공간.

### 🌍 스토멜 보스방 — 지구 순환 모형실
헨리 스토멜의 전 지구 심층순환("대컨베이어벨트")을 거대한 모형으로 재현한 방. 케플러의
타원궤도 모형실과 유사한 맥락이나, 여긴 해류 순환이 테마.

세부 패턴·수치·페이즈 설계는 콘텐츠 채우기 단계(§8)에서 [해들리.md](../../설계도/보스/해들리.md)·
[코페르니쿠스.md](../../설계도/보스/코페르니쿠스.md) 등과 동일한 형식으로 개별 문서화한다.
