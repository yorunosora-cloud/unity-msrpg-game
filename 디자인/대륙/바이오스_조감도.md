# 생명과학의 대륙 — 바이오스 (Bios) 조감도

> **이 문서**: 대륙 전체 구조 + 3국 + 6랜드마크 상세 조감도. 실제 Unity 좌표·씬 배치는
> [메조리아_대륙배치.md](메조리아_대륙배치.md) §4의 그리드 셀 스트리밍 구현 시점에 확정.
> 몬스터/보스 전투 스탯·패턴은 이 문서 소관 아님 — [17_적리스트-몬스터도감.md](../../설계도/17_적리스트-몬스터도감.md)·
> [07_보스전.md](../../설계도/07_보스전.md) 참고. 이 문서는 **인선·컨셉·형태**만 정한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 컨셉 | 중국 삼국시대 + 무림 세계관 모티브. 생명의 숲·유전의 강·진화의 산맥·실험 계곡이 어우러진 극도로 다양한 생태계 대륙. |
| 학문 모티브 | 분자생물학·유전공학(헬릭스), 고전유전학·해부학·생리학(제네시스), 진화생물학·생태학(에코스) |
| 정치 구조 | **3국 삼파전** — 헬릭스 제국 / 제네시스 왕국 / 에코스 연맹. 반란 세력 없이 3국 자체가 지속적으로 다툼 |
| 건축 양식 | **대륙 전체 통일**: 중국풍(궁궐·서원·원림) 기본 + 서양식 요소를 국가마다 다른 비율로 융합 ([[메조리아_대륙배치]] §5 원칙 — 3국 모두 삼국지라는 공유 문화 뿌리가 있어 지구과학과 달리 대륙 통일 적용) |
| 다른 대륙 동맹 | 헬릭스 제국 — 화학(유기화학)과 강한 동맹 / 에코스 연맹 — 지구과학(테라노바)과 강한 동맹 / 제네시스 왕국 — 정보 대륙(유전정보학)과 협력 |
| 갈등 | 영토·자원·연구방향·이념을 둘러싼 3국 삼파전. 생명과학 대륙 내부 갈등이 7대륙 중 가장 복잡 |
| 메조리아 연결 | 직접 접경 없음(내륙 대륙) — 지구과학 해양 부족을 거쳐 진입 |

## 2. 공간 구조 — 삼각 접경 (중립 허브 없음)

지구과학의 "판게아 유적 중앙 허브" 패턴과 달리, 이 대륙은 3국이 실제로 국경을 다투는 전쟁
상태라 인위적인 중립 허브를 두지 않는다. 대신 3국이 서로 국경을 맞대는 **삼각 배치**로,
국경 지대 자체가 분쟁지대(오픈필드)로 기능한다.

```
                [에코스 연맹]
               지구과학 접경(★ 진입)
                    /    \
                   /      \
     [제네시스 왕국] ────── [헬릭스 제국]
       내륙(외부 미접촉)      화학 접경
```

- ★ = 지구과학 해양 부족을 거쳐 육로 진입 시 최초 도착 지점(에코스 연맹 — 생태 연속성이 가장
  자연스러운 접점)
- 3국 사이 국경 지대는 전부 오픈필드(적 스폰) — 아틀란티스·테라노바의 "허브 경유" 구조 대신
  "3국이 서로 직접 맞닿는" 구조라 어느 국가에서 다른 국가로도 직행 가능
- 제네시스 왕국은 외부 대륙과 접하지 않는 유일한 내륙국 — 가장 폐쇄적·전통적인 국가 성격과 지리적 위치가 일치

### 2-1. 대륙 경계 접점

| 국가 | 접경 대상 | 연출 |
|---|---|---|
| 에코스 연맹 | 지구과학(테라노바) 해양 부족 | 산호초 → 생태 연속성으로 자연 전환(강한 동맹과 지형 일치) |
| 헬릭스 제국 | 화학(알케미아) | 유기화학 강한 동맹 — 바이오 공장지대와 화학 산업지대가 자연스럽게 이어짐 |
| 제네시스 왕국 | (외부 접경 없음) | 대륙 내륙 깊숙이 위치, 3국 중 가장 폐쇄적 |

## 3. 3국 상세

### 🧬 헬릭스 제국 (Helix Empire) — 화학 접경
- **학문**: 분자생물학, 유전공학, 바이오테크놀로지, 합성생물학
- **성격**: 실용적·공격적·중앙집권. 7대륙 중 가장 강력한 군사력·산업력
- **건축**: 중국 궁궐 양식(자금성풍 금빛 지붕·용 문양)을 기본으로, 서양 첨단 유리·금속 실험시설을
  **가장 강하게 융합** — 전통 궁궐 구조 위로 이중나선 첨탑이 솟아오르는 이질적 조합
- **환경/분위기**: 대규모 바이오 공장도시와 실험지대가 밀집. 공장 굴뚝과 궁궐 처마가 나란히 선
  스카이라인
- **생명체**: CRISPR 장미(유전자를 자유롭게 편집할 수 있는 가시 장미), 형질전환 쥐(원하는
  형질을 빠르게 획득하는 실험동물), 이중나선 독수리(DNA 나선 구조 깃털을 가진 새)

**랜드마크**
- **이중나선 황궁** — DNA 이중나선으로 꼬인 거대한 황금 궁전. 두 개의 나선 탑이 서로 감으며
  솟아오르는 구조. 보스: **왓슨 · 크릭 · 프랭클린**(DNA 이중나선 구조 발견)
- **CRISPR 편집 연구소** — 유전자를 실시간 홀로그램으로 편집하는 초대형 첨단 시설. 염기서열
  빛줄기가 편집대 위에 투영되는 연출. 보스: **다우드나 · 샤르팡티에 · 장펑**(CRISPR-Cas9
  유전자가위 개발의 핵심 3인, 다우드나·샤르팡티에는 2020 노벨화학상)

---

### 📚 제네시스 왕국 (Genesis Kingdom) — 내륙
- **학문**: 고전유전학, 해부학, 생리학, 세포생물학
- **성격**: 전통과 깊이를 중시하는 보수적 왕국. 학문적 정통성을 가장 중요하게 여김
- **건축**: 3국 중 **가장 순수한 전통 중국 양식**(서원·도관풍, 목재+수묵 톤). 서양 요소는 거의
  배제하고, 장서각 내부 서가 구조에만 서양 대도서관풍 배치를 은은히 차용
- **환경/분위기**: 깊은 산맥, 고전 도서관, 유전자 보관소가 많음. 고요하고 학구적인 분위기
- **생명체**: 멘델 완두콩나무(꽃 색이 3:1 비율로 피어나는 식물)

**랜드마크**
- **멘델의 유전 도서관** — 완두콩 유전 비율(3:1)이 실제 정원 배치로 구현된 거대 도서관. 서가
  사이 정원에 노랑:초록 완두꽃이 정확히 3:1로 심어져 있다. 보스: **멘델 · 모건 · 매클린톡**
  (유전법칙 → 염색체설 → 전이인자로 이어지는 고전유전학 계보)
- **해부학의 지하 성역** — 고전 생체 모형이 살아 움직이는 지하 성역. 세포 단위로 확대된 모형이
  실제로 분열·기능하는 연출. 보스: **슐라이덴 · 슈반 · 피르호**(세포설 3단계: 식물세포설 →
  동물세포설 → "세포는 세포로부터")

---

### 🌿 에코스 연맹 (Ecos Alliance) — 지구과학 접경 (★ 진입)
- **학문**: 진화생물학, 생태학, 환경생물학, 분류학, 계통학
- **성격**: 자연과의 조화, 생태계 전체를 중시. 가장 유연하고 적응력이 강함
- **건축**: 중국 원림 양식(정자·다리·연못)을 기본으로, 서양 온실/유기건축 요소를 결합 — 유리
  온실이 전통 정자를 그대로 감싸며 자라난 듯한 형태. 인공 구조물이 자연에 가장 깊이 잠식된 국가
- **환경/분위기**: 광활한 원시림·습지·산호초·다층 생태계. 개방적이고 조화로운 분위기
- **생명체**: 진화의 나무(실시간 적응형 거목), 공생 슬라임(여러 생물이 한 몸으로 공생하는 생물)

**랜드마크**
- **진화의 세계수** — 환경에 따라 실시간으로 형태가 변하는 초거대 나무. 계절·기후 변화에 가지·
  잎 형태가 적응하는 연출. 보스: **다윈 · 월리스 · 린네**(1858년 공동 발표한 자연선택설 +
  근대 분류학의 아버지)
- **생태계 순환 대원** — 먹이사슬과 물질순환이 시각적으로 보이는 거대한 원형 경기장. 관중석처럼
  층층이 생산자→소비자 단계가 배치. 보스: **훔볼트 · 헤켈 · 오덤**(생물지리학 개척 → "생태학"
  용어 창시 → 생태계를 하나의 시스템으로 체계화한 개념사 계보)

## 4. 이동 · 진행

### 3국 접경 그래프

```
에코스 연맹 ──── 제네시스 왕국 ──── 헬릭스 제국
     │                                    │
     └──────────── (직접 접경) ───────────┘
```

- 허브 경유 없이 3국이 서로 직접 국경을 맞댐 — 어느 국가에서든 다른 두 국가로 직행 가능
- 국경 지대(오픈필드)는 3국의 영토 다툼이 실제로 벌어지는 분쟁 지역으로 연출(임무 콘텐츠 훅)

### 진행 흐름

```
[지구과학 해양 부족] → 에코스 연맹 도착
      ↓ (원시림 오픈필드 탐험)
  국경 지대를 통해 제네시스 왕국 / 헬릭스 제국 자유 이동
      ↓
  각 국가 랜드마크 던전 → 역사적 과학자 보스전(랜드마크당 3인)
      ↓
  헬릭스 제국 국경 넘으면 화학 대륙으로 연결
```

## 5. 사회 — 3국 삼파전

| | 헬릭스 제국 | 제네시스 왕국 | 에코스 연맹 |
|---|---|---|---|
| 거점 | 화학 접경, 공장도시 | 내륙, 고전 도서관 | 지구과학 접경, 원시림 |
| 성향 | 실용·공격적·팽창주의 | 보수·정통·폐쇄적 | 유연·조화·적응 |
| 군사·산업력 | 7대륙 중 최강 | 중간(방어 위주) | 약함(생태 적응으로 대체) |
| 대외 관계 | 화학과 강한 동맹 | 정보 대륙과 협력(유전정보학) | 지구과학과 강한 동맹 |

**삼파전 컨셉**: 영토·자원·연구 방향·이념 갈등이 끊이지 않으며, 플레이어는 이 갈등을 중재하거나
한 세력을 지원하는 루트를 선택할 수 있다(향후 퀘스트 콘텐츠 훅) — 세계관 원문 그대로.

## 6. 기후 · 연출

| 현상 | 설명 |
|---|---|
| **생태 반응성 기후** | 생물의 활동과 진화가 기후 자체에 실시간으로 영향(세계관 원문 "생물 활동과 진화가 기후에 영향") |
| **극단적 생태 다양성** | 지역마다 생물 다양성과 지형이 급격히 전환 — 헬릭스의 공장 연기, 제네시스의 고요한 안개, 에코스의 습한 정글 공기가 각각 뚜렷이 구분 |
| **DNA 나선광** | 헬릭스 제국 전역, 이중나선 첨탑에서 뿜어나오는 은은한 청록 발광 |
| **완두꽃 개화** | 제네시스 왕국 유전 도서관 정원, 3:1 비율로 노랑·초록 꽃이 항상 개화 상태 유지 |
| **적응형 수관 변화** | 에코스 연맹 진화의 세계수, 낮/밤·계절에 따라 실루엣이 서서히 변화([[season_time_system_design]] 연동 후보) |
