# 화학의 대륙 — 알케미아 신성연합 (Alchemia Holy Union) 조감도

> **이 문서**: 대륙 전체 구조 + 5세력 + 5랜드마크 상세 조감도. 실제 Unity 좌표·씬 배치는
> [메조리아_대륙배치.md](메조리아_대륙배치.md) §4의 그리드 셀 스트리밍 구현 시점에 확정.
> 몬스터/보스 전투 스탯·패턴은 이 문서 소관 아님 — [17_적리스트-몬스터도감.md](../../설계도/17_적리스트-몬스터도감.md)·
> [07_보스전.md](../../설계도/07_보스전.md) 참고. 이 문서는 **인선·컨셉·형태**만 정한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 컨셉 | 바티칸 + 신성로마제국 모티브. 연금술 → 현대화학으로 이어지는 종교·제국 국가 연합. |
| 학문 모티브 | 무기화학·금속화학(교황청), 유기화학·고분자화학(황제령), 물리화학·반응속도론(피지컬리아), 분석화학·분광학(아날리티카), 양자화학·오비탈이론(오비탈 혁명파) |
| 정치 구조 | **교황청+황제령 공동통치** 중심부 + 피지컬리아·아날리티카 중립 2국 + **오비탈 혁명파** 대륙 외곽 반란 세력(5세력) |
| 건축 양식 | **대륙 전체 통일**: 고딕 대성당 + 신성로마제국 궁정 양식을 기본으로, 세력마다 세부화 ([[메조리아_대륙배치]] §5 원칙 — 바티칸+신성로마제국이라는 공유 문화 뿌리이므로 생명과학과 같은 "대륙 통일" 사례) |
| 지형/기후 | 원소의 본질이 강한 중앙 고원 + 화학반응이 활발한 주변 분지. 땅 자체가 살아있는 듯 지속 반응. 지역마다 색·냄새·물질상태 극단적으로 다름. 촉매 바람이 불면 폭발적 반응 |
| 다른 대륙 동맹 | 생명과학 헬릭스 제국과 밀접한 협력(화학→생물 응용) |
| 갈등 | 오비탈 혁명파 vs 기존 교황청·황제령 체제(슈뢰딩거 방정식 이후 "오비탈 혁명"으로 촉발된 종교개혁 성격 갈등) |
| 메조리아 연결 | 직접 접경 없음(내륙 대륙) — 생명과학 헬릭스 제국을 거쳐 진입 |

## 2. 공간 구조 — 중앙 쌍둥이 수도 + 4방향 확장

지구과학의 "중립 허브", 생명과학의 "삼각 접경"과 또 다른 세 번째 패턴: **정치적으로 실제
공동통치 중인 두 수도(교황청+황제령)가 지리적 중심**을 이루고, 나머지 세력이 사방으로 뻗어
나간다. 오비탈 혁명파만 "대륙 외곽 촉매 빈민가"라는 세계관 원문 그대로 가장 먼 변경에 위치.

```
                  [피지컬리아 공국]
                    물리 대륙 접경
                         │
   [오비탈 혁명파]                       [아날리티카 연맹]
   외곽 촉매 빈민가                       중립·대륙 내부
   (대륙에서 가장 먼 변경)  ＼           ／
                          [교황청 인오르가니아]
                          ＋
                          [황제령 오르가니아]
                          (중앙 공동통치 쌍둥이 수도,
                           황제령은 생명과학 쪽으로 치우침)
                                 │
                          생명과학 대륙 접경
```

- 교황청과 황제령은 완전히 겹치지 않는 "쌍둥이 수도" — 서로 인접해 실질적으로 하나의 거대
  도시권을 이루되, 황제령 쪽이 생명과학 접경으로 살짝 치우쳐 있다(유기화학=탄소기반 생명이라는
  주제가 생명과학과 자연스럽게 이어지도록)
- 피지컬리아는 물리 대륙과 맞닿는 북쪽, 오비탈 혁명파는 그 반대편 가장 외진 변경(세계관 원문
  "대륙 외곽 촉매 빈민가" 그대로), 아날리티카는 특정 대륙과 접경하지 않는 중립적 내륙 위치

### 2-1. 대륙 경계 접점

| 세력 | 접경 대상 | 연출 |
|---|---|---|
| 황제령 오르가니아 | 생명과학(바이오스) 헬릭스 제국 | 탄소기반 화합물 지대가 바이오 공장지대로 자연스럽게 이어짐(강한 동맹과 지형 일치) |
| 피지컬리아 공국 | 물리(뉴토니아 퀀티카) | "물리와 화학의 경계 브릿지 국가"라는 세계관 설정과 지리적 위치가 정확히 일치 |
| 교황청 인오르가니아 | (외부 접경 없음) | 대륙 중심 깊숙이 위치, 황제령과 나란히 공동통치 |
| 아날리티카 연맹 | (외부 접경 없음) | 중립적 관찰자 위치, 대륙 내부 |
| 오비탈 혁명파 | (외부 접경 없음, 대륙 내 가장 먼 변경) | 반란 세력답게 모든 정식 세력·인접 대륙에서 가장 멀리 고립 |

## 3. 5세력 상세

### ⛪ 교황청 인오르가니아 (Inorganic Papal State) — 중앙 공동통치
- **학문**: 무기화학, 금속화학, 이온화학
- **성격**: 가장 보수적이고 권위적인 세력. 원소의 '본질'을 중시
- **건축**: 고딕 대성당 양식(첨탑·스테인드글라스)을 기본으로, 금속 소재를 종교적 장식으로
  승화 — 금속 프레스코, 이온결정으로 만든 스테인드글라스
- **환경/분위기**: 중앙 고원, 금속 원소 결정이 대지에 그대로 박혀있는 지형. 장엄하고 엄숙함
- **생명체**: 주기율표 결정수(잎에 원소 기호가 새겨진 광물성 식물)

**랜드마크**: **원소 주기율표 대성당** — 118개 원소가 조각된 거대 성당. 보스: **뉴랜즈 · 멘델레예프
· 라부아지에**(원소 개념 확립 → 규칙성 발견 시도(옥타브설) → 현대 주기율표 완성)

---

### 👑 황제령 오르가니아 (Organic Imperial Realm) — 중앙 공동통치 (생명과학 쪽 치우침)
- **학문**: 유기화학, 탄소화합물, 고분자화학
- **성격**: 가장 다채롭고 생동감 넘치는 세력. 탄소 기반 생명의 중심지
- **건축**: 신성로마제국 궁정 바로크 양식 + 탄소 사슬처럼 뻗어나가는 유기적 곡선 회랑
- **환경/분위기**: 다채로운 색상, 탄소 골렘이 거리를 활보하는 활기찬 도시
- **생명체**: 탄소 골렘(다이아몬드·그래핀·풀러렌으로 변신 가능), 촉매 나비꽃(주변 화학반응
  속도를 가속시키는 식물)

**랜드마크**: **벤젠의 육각 신전** — 육각형 구조가 반복되는 신전 숲. 보스: **케쿨레 · 뵐러 ·
폴링**(벤젠 고리 구조 발견 → 무기물로부터 유기물 최초 합성 → 화학결합론 확립. 현재 한국 고교
화학Ⅰ에는 유기화학 단원이 없어 대학 수준 화학사 표준으로 보충)

---

### ⚔ 피지컬리아 공국 (Physical Chemistry Duchy) — 물리 접경
- **학문**: 물리화학, 반응속도론, 양자화학, 열역학적 화학
- **성격**: 물리학과 화학의 경계에 위치한 학문적 브릿지 국가
- **건축**: 공국다운 소규모 성채 양식 + 실험시설이 융합된 형태. 물리 대륙에 가까울수록 더
  기계적·정밀한 색채가 짙어짐
- **환경/분위기**: 화로·반응로가 늘어선 산업지대. 늘 타오르는 불꽃이 도시 전체를 밝힘
- **생명체**: 파동함수 늑대

**랜드마크**: **촉매의 영원한 화로** — 한 번 점화되면 영원히 타는 화로. 보스: **아레니우스 ·
반트호프 · 랭뮤어**(반응속도론·활성화에너지의 아레니우스 방정식은 반트호프의 연구에 근거해
제안됨 — 반트호프는 최초의 노벨화학상 수상자. 랭뮤어는 촉매 표면화학·흡착이론)

---

### 🔬 아날리티카 연맹 (Analytical Chemistry League) — 중립, 대륙 내부
- **학문**: 분석화학, 분광학, 질량분석, 크로마토그래피
- **성격**: 모든 것을 분해하고 측정·분석하는 관찰자들의 연합
- **건축**: 유리와 프리즘을 활용한 관측탑·등대 중심 건축. 빛을 분해하는 구조 자체가 건물의
  형태가 됨
- **환경/분위기**: 안개와 스펙트럼 빛이 가득한 관측지대. 조용하고 분석적인 분위기
- **생명체**: (별도 지정 없음 — 세계관 원문에 아날리티카 전용 동식물 언급 없음, 필요 시 후속
  세션에서 추가)

**랜드마크**: **분광 분석의 등대** — 모든 빛을 분해해 분석하는 초고층 등대. 보스: **분젠 ·
키르히호프 · 모즐리**(불꽃반응+선 스펙트럼으로 원소 분석법을 공동 확립 → X선 분광학으로
원자번호 개념 정립)

---

### 🌩 오비탈 혁명파 (Orbital Reformation) — 대륙 외곽 촉매 빈민가
- **학문**: 양자화학, 오비탈 이론, 현대 결합론
- **성격**: 슈뢰딩거 방정식 이후 일어난 "오비탈 혁명"으로 기존 교황청·황제령 체제에 반발하는
  종교개혁 세력
- **건축**: 낡은 성당 잔해 위에 불법 개조된 양자실험 기구가 뒤섞인 극적 대비 풍경
- **환경/분위기**: 촉매 빈민가. 불안정한 화학반응이 잦고 위태로운 분위기
- **생명체**: 오비탈 구름덩굴

**랜드마크**: **전자구름의 혼돈 지대**. 보스: **슈뢰딩거 · 하이젠베르크 · 디랙**(세계관 원문에
이 세력의 중심 학문으로 이미 명시된 인물 — 슈뢰딩거 방정식·불확정성 원리·상대론적 양자역학)

## 4. 이동 · 진행

### 세력 접경 그래프

```
              피지컬리아 공국
                    │
오비탈 혁명파 ──── 교황청+황제령 ──── 아날리티카 연맹
  (변경)              (중앙)
                    │
                생명과학(황제령 접경)
```

### 진행 흐름

```
[생명과학 헬릭스 제국] → 황제령 오르가니아 도착
      ↓
  중앙 쌍둥이 수도(교황청+황제령) 전역 탐험
      ↓ (사방으로 확장)
  피지컬리아 / 아날리티카 방문 → 물리 대륙 접경까지 이어짐
      ↓ (가장 먼 변경으로)
  오비탈 혁명파 잠입 → 종교개혁 세력의 진실 대면
      ↓
  각 세력 랜드마크 던전 → 역사적 화학자 보스전(랜드마크당 3인)
```

## 5. 사회 — 공동통치와 반란

| | 교황청 인오르가니아 | 황제령 오르가니아 | 피지컬리아 공국 | 아날리티카 연맹 | 오비탈 혁명파 |
|---|---|---|---|---|---|
| 위상 | 공동 통치자 | 공동 통치자 | 중립, 학문적 영향력 | 중립, 학문적 영향력 | 피지배·반란 |
| 성향 | 보수·권위 | 다채·생동감 | 브릿지·실용 | 관찰·분석 | 개혁·저항 |
| 체제에 대한 입장 | 체제 수호 | 체제 수호 | 불간섭 | 불간섭 | 체제 타파 |

**내부 상황**: 교황청과 황제령이 공동 통치하나, 오비탈 혁명파의 종교개혁 영향으로 대륙 전체가
내부 긴장 상태(세계관 원문 그대로). 피지컬리아와 아날리티카는 중립을 지키면서도 학문적으로는
양쪽 모두에 영향력을 행사 — 향후 퀘스트에서 "중재자" 역할로 활용 가능.

## 6. 기후 · 연출

| 현상 | 설명 |
|---|---|
| **반응성 다색 기후** | 지역마다 색과 성질이 완전히 다름 — 교황청은 금속광택 톤, 황제령은 원색 계열, 오비탈 혁명파는 불안정한 색 파동 |
| **촉매 바람** | 바람이 불면 화학반응이 폭발적으로 일어나는 「촉매 바람」현상(세계관 원문) — 메조리아의 "교역 폭풍"과 연동되는 특이기후 후보 |
| **영원한 화로 불빛** | 피지컬리아 전역, 화로에서 뿜어나오는 붉은 빛이 상시 배경을 밝힘 |
| **스펙트럼 안개** | 아날리티카 연맹 지역, 빛이 분해되며 무지개색 안개가 낀 듯한 시각 효과 |
| **전자구름 파동** | 오비탈 혁명파 지역, 확률구름처럼 흐릿하게 일렁이는 지형 경계(오비탈의 시각적 은유) |

## 7. 랜드마크별 보스 인선 총정리
