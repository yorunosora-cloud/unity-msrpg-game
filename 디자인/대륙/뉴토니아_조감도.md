# 물리의 대륙 — 뉴토니아 퀀티카 (Newtonia Quantica) 조감도

> **이 문서**: 대륙 전체 구조 + 5국가(세력) + 5랜드마크 상세 조감도. 실제 Unity 좌표·씬 배치는
> [메조리아_대륙배치.md](메조리아_대륙배치.md) §4의 그리드 셀 스트리밍 구현 시점에 확정.
> 몬스터/보스 전투 스탯·패턴은 이 문서 소관 아님 — [17_적리스트-몬스터도감.md](../../설계도/17_적리스트-몬스터도감.md)·
> [07_보스전.md](../../설계도/07_보스전.md) 참고. 이 문서는 **인선·컨셉·형태**만 정한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 컨셉 | 서유럽(영국·프랑스) 모티브. 고전역학 → 현대물리 혁명으로 이어지는 이중 구조 대륙. |
| 학문 모티브 | 역학·만유인력(뉴턴), 전자기학·빛(맥스웰), 상대성이론(아인슈타인), 열역학·통계역학(볼츠만), 양자역학(양자혁명군) |
| 정치 구조 | 고전역학 황실파(뉴턴 제국 중심의 4국 연합) vs **양자혁명군**의 내전 상태. 7대륙 중 가장 불안정 |
| 건축 양식 | **대륙 전체 통일**: 계몽주의 시대 서유럽 왕립학회·천문대 양식을 기본으로 국가마다 세부화 ([[메조리아_대륙배치]] §5 원칙 — 서유럽이라는 공유 문화 뿌리이므로 화학·생명과학과 같은 "대륙 통일" 사례). 단, 양자혁명군은 이 양식이 붕괴·왜곡된 형태 |
| 지형/기후 | 서쪽은 질서정연·안정적, 동쪽으로 갈수록 확률적·혼돈스러운 이중 구조. 지형 자체가 불안정하며 관찰에 따라 변하기도 함. 고전 지역=예측 가능한 사계절, 양자 지역=극단적으로 불안정·중첩된 날씨 |
| 다른 대륙 동맹 | 응용파(양자혁명군)는 수학(아틀란티스 응용파)·정보 대륙과 강한 동맹. 순수 고전파는 다른 대륙과 거리를 둠 |
| 갈등 | 고전역학 황실파 vs 양자혁명군의 내전 |
| 메조리아 연결 | 직접 접경 없음(내륙 대륙) — 화학 피지컬리아 공국을 거쳐 진입 |

## 2. 공간 구조 — 서→동 그라데이션 (선형이 아닌 자연스러운 2D 배치)

세계관 원문에 이미 "서쪽=질서, 동쪽=혼돈"이라는 구조가 명시돼 있고, 이는 기존 메조리아 고리
배치(화학이 서쪽 접경, 정보가 동쪽 접경)와 완벽히 일치한다. 국가를 일렬로 세우지 않고, 수도
(뉴턴 제국)를 기준으로 서→동 그라데이션이 유지되는 자연스러운 2D 형태로 배치한다.

```
                [화학 접경 · 서]
                      │
                [뉴턴 제국]
               (수도·정치중심)
                /          \
      [맥스웰 공국]      [아인슈타인 연방]
       중부 북쪽              중부 남쪽
                \          /
              [볼츠만 열공화국]
              동쪽 다리(확률론 근접)
                      │
             [양자혁명군 확률 빈민촌]
                최동단
                      │
                [정보 접경 · 동]
```

- 뉴턴 제국이 서쪽 관문이자 "황실파" 정치 중심 — 화학 대륙에서 진입 시 최초 도착 국가
- 맥스웰 공국·아인슈타인 연방은 중부에서 남북으로 갈라짐(직행 경로 없음, 뉴턴 제국을 통해 연결)
- 볼츠만 열공화국은 통계역학이 역사적으로 양자역학(플랑크의 흑체복사 문제)으로 이어진 학문적
  다리 역할 — 지리적으로도 양자혁명군과 가장 가까운 고전 국가로 배치
- 양자혁명군은 최동단 "확률 빈민촌", 정보 대륙과 접경

### 2-1. 대륙 경계 접점

| 국가 | 접경 대상 | 연출 |
|---|---|---|
| 뉴턴 제국 | 화학(알케미아) 피지컬리아 공국 | "물리와 화학의 경계 브릿지"라는 피지컬리아 설정과 지리적으로 자연스럽게 연결 |
| 양자혁명군 | 정보(사이버네시아) | 응용파·양자파가 정보 대륙과 강한 동맹이라는 설정과 지형이 일치 |

## 3. 5국가(세력) 상세

### 🍎 뉴턴 제국 (Classical Mechanics) — 서쪽 관문, 수도
- **학문**: 역학, 운동법칙, 만유인력
- **성격**: 고전역학 황실파의 중심. 가장 질서정연하고 웅장한 권위
- **건축**: 계몽주의 왕립 궁정 + 천문대 양식(조지 왕조풍 궁전, 대형 반사망원경 돔) — 대륙 전체
  건축 언어의 "정본" 격
- **환경/분위기**: 안정적이고 예측 가능한 사계절. 완만한 구릉과 질서정연한 정원식 도시 배치
- **생명체**: 만유인력 사과나무, 관성 황소

**랜드마크**: **만유인력의 왕궁**. 보스: **뉴턴 · 훅 · 갈릴레이**(운동법칙·만유인력 / 훅의 법칙·
탄성력(물리학Ⅰ 2021 수능부터 강조) / 관성 개념 — 갈릴레이는 지구과학 대륙 천문학 랜드마크에도
등장하나 이곳에서는 역학 스킬셋으로 재구성, [[메조리아_대륙배치]] §5 원칙)

---

### ⚡ 맥스웰 공국 (Electromagnetism) — 중부 북쪽
- **학문**: 전자기학, 빛
- **성격**: 스코틀랜드풍 소규모 학술 공국. 정밀하고 예리한 지적 분위기
- **건축**: 등대·철탑 모티브가 두드러지는 계몽주의 양식 변형 — 전자기장 선을 형상화한 첨탑 장식
- **환경/분위기**: 전자기장이 눈에 보이는 형태로 시각화된 지형(자기력선을 따라 흐르는 빛의 줄기)
- **생명체**: 광자 새, 전자기 장미

**랜드마크**: **빛의 속도 철로**. 보스: **패러데이 · 맥스웰 · 헤르츠**(전자기 유도 실험 → 전자기
방정식 이론화 → 전자기파 실증 검출의 표준 계보)

---

### 🌌 아인슈타인 연방 (Relativity) — 중부 남쪽
- **학문**: 특수상대성, 일반상대성, 중력
- **성격**: 근대 학술 연방. 계몽주의 양식이 시공간의 곡률을 반영해 부드럽게 휘어짐
- **건축**: 직선이 거의 없는 곡선형 계몽주의 건축 — 궁정 구조가 중력에 의해 휜 것처럼 보임
- **환경/분위기**: 중력에 의해 지형이 실제로 휘어져 보이는 착시 지대. 거대한 질량 근처에서
  빛이 굴절되는 시각효과
- **생명체**: 시공간 왜곡 버드나무, 블랙홀 거북

**랜드마크**: **시공간 왜곡 관측소**. 보스: **로런츠 · 아인슈타인 · 에딩턴**(로런츠 변환의
수학적 기초 → 상대성이론 발표 → 1919년 개기일식 관측으로 실증. 에딩턴 검증은 물리학Ⅱ
교육과정에 중요한 역사적 사례로 명시됨)

---

### 🔥 볼츠만 열공화국 (Thermodynamics & Statistical Mechanics) — 동쪽 다리
- **학문**: 열역학, 엔트로피, 통계역학
- **성격**: 오스트리아풍 공화국. 증기·열기관 산업 시대의 활기와 무질서가 공존
- **건축**: 증기기관·보일러 구조물이 결합된 계몽주의 양식. 굴뚝과 배관이 궁정 건축을 관통
- **환경/분위기**: 무작위적이고 확률적인 날씨 패턴 — 양자 지역으로 넘어가기 직전의 전조
- **생명체**: 엔트로피 선인장, 브라운 운동 벌

**랜드마크**: **엔트로피의 대로**. 보스: **카르노 · 클라우지우스 · 볼츠만**(열기관 효율의
카르노 정리 → 엔트로피 개념 최초 도입 → 엔트로피의 통계역학적 해석. 셋 다 물리학Ⅰ/Ⅱ
"열과 에너지" 단원 표준 계보)

---

### 🌀 양자혁명군 (Quantum Rebellion) — 최동단 확률 빈민촌
- **학문**: 양자역학
- **성격**: 슈뢰딩거 방정식 이후 고전역학 황실파에 반발하는 혁명 세력. 대륙에서 가장 불안정
- **건축**: 계몽주의 양식이 붕괴·왜곡된 형태 — 궁정 구조의 잔해가 불확정성 원리처럼 불안정하게
  흔들리며 겹쳐 보임
- **환경/분위기**: 관찰 행위 자체가 지형을 바꾸는 확률 지대. 비 대신 확률구름이 낀다
- **생명체**: 슈뢰딩거 고양이풀, 중첩 토끼

**랜드마크**: **슈뢰딩거의 상자 연구소**. 보스: **플랑크 · 드브로이 · 슈뢰딩거 · 하이젠베르크**
(4인 — 양자가설 시작 → 물질파·입자-파동 이중성 → 파동함수로 수학화 → 불확정성 원리. 물리학Ⅱ
현대물리 단원 표준 계보. 슈뢰딩거·하이젠베르크는 화학 대륙 오비탈 혁명파 랜드마크에도 등장하나
스킬셋은 다르게 튜닝, [[메조리아_대륙배치]] §5 원칙)

## 4. 이동 · 진행

### 국가 연결 그래프

```
                뉴턴 제국
               /         \
        맥스웰 공국    아인슈타인 연방
               \         /
              볼츠만 열공화국
                    │
               양자혁명군
```

### 진행 흐름

```
[화학 피지컬리아 공국] → 뉴턴 제국 도착
      ↓ (계몽주의 궁정 지대 탐험)
  맥스웰 공국 / 아인슈타인 연방 자유 방문 (뉴턴 제국 경유)
      ↓ (동쪽으로)
  볼츠만 열공화국 — 질서에서 혼돈으로 전환되는 경계
      ↓
  양자혁명군 확률 빈민촌 잠입 — 내전의 실체 대면
      ↓
  각 국가 랜드마크 던전 → 역사적 물리학자 보스전
      ↓
  양자혁명군 국경 넘으면 정보 대륙으로 연결
```

## 5. 사회 — 황실파 vs 혁명군

| | 뉴턴 제국 | 맥스웰 공국 | 아인슈타인 연방 | 볼츠만 열공화국 | 양자혁명군 |
|---|---|---|---|---|---|
| 진영 | 황실파(핵심) | 황실파 | 황실파 | 황실파(경계) | 반란 |
| 성향 | 질서·권위 | 정밀·예리 | 근대적·사색적 | 활기·무질서 공존 | 불안정·혁명적 |
| 체제 입장 | 체제 수호 | 체제 수호 | 체제 수호(단, 학문적으로는 혁명군과 가까움) | 체제 경계선(양쪽에 양다리) | 체제 타파 |

**내전 상태**: 고전역학 황실파(뉴턴 제국 중심)와 양자혁명군의 내전이 지속 중 — 세계관 원문상
7대륙 중 가장 불안정한 대륙. 아인슈타인 연방은 학문적으로는 현대물리(상대성+양자)에 가까워
정치적으로는 황실파에 속하지만 사상적으로는 양쪽 다리를 걸친 뉘앙스로 연출 가능(향후 퀘스트
훅).

## 6. 기후 · 연출

| 현상 | 설명 |
|---|---|
| **서-동 안정성 그라데이션** | 서쪽(뉴턴 제국)일수록 사계절이 뚜렷하고 예측 가능, 동쪽(양자혁명군)일수록 날씨가 중첩·불안정 |
| **관찰자 효과 지형** | 양자혁명군 지역, 플레이어가 보고 있을 때와 안 볼 때 지형이 달라지는 연출(세계관 원문 "관찰에 따라 변하기도 한다") |
| **전자기장 시각화** | 맥스웰 공국 전역, 자기력선을 따라 흐르는 빛의 궤적 |
| **시공간 왜곡** | 아인슈타인 연방 전역, 거대 질량 근처에서 배경이 휘어 보이는 렌즈 효과 |
| **확률구름** | 양자혁명군, 비 대신 확률구름이 낀다(세계관 원문 준용, 아틀란티스 "증명 조각 비"와 같은 급의 특이기후) |

## 7. 랜드마크별 보스 인선 총정리

| 랜드마크 | 국가 | 보스 | 근거 |
|---|---|---|---|
| 만유인력의 왕궁 | 뉴턴 제국 | 뉴턴 · 훅 · 갈릴레이 | 물리학Ⅰ 역학 단원(훅의 법칙은 2021 수능부터 강조) |
| 빛의 속도 철로 | 맥스웰 공국 | 패러데이 · 맥스웰 · 헤르츠 | 전자기유도→전자기파 이론→실증 표준 계보 |
