# 메조리아 기준 5대륙 배치 — 마스터 조감도

> **이 문서**: 메조리아(허브)에 육로로 붙는 5개 대륙(물리·화학·생명과학·지구과학·정보)의 전체
> 배치·연결 순서·씬 구조만 잡는 마스터 문서. 대륙별 상세(국가·랜드마크·보스)는 대륙마다 별도
> `디자인/대륙/<대륙명>_조감도.md`로 분리. 수학(아틀란티스)은 하늘섬이라 이 배치에서 제외 —
> 별도 씬(`Atlantis.unity`)이며, 이 문서에서는 "원경 배경"으로만 등장(§3).

---

## 1. 왜 이런 배치인가

5대륙 중 아틀란티스(수학)만 하늘섬이라 별도 씬으로 격리돼 있고([[scene_architecture]]), 나머지
5대륙은 세계관상 전부 "육로로 메조리아와 연결"되어야 한다. 어느 대륙을 어디에 붙일지는 임의로
정하지 않고, `세계관 아이디어-2.txt`에 명시된 대륙 간 동맹 관계를 그대로 지도에 반영한다:

| 인접 쌍 | 근거 (세계관 원문) |
|---|---|
| 물리 ↔ 화학 | 화학 피지컬리아 공국 = "물리학과 화학의 경계에 위치한 학문적 브릿지 국가" |
| 화학 ↔ 생명과학 | "강한 동맹: 생명과학 헬릭스 제국과 밀접한 협력" (화학) / "헬릭스 제국 — 화학과 강한 동맹" (생명과학) |
| 생명과학 ↔ 지구과학 | "에코스 연맹 — 지구과학(테라노바)과 강한 동맹" / "강한 동맹: 에코스 연맹과 매우 친밀" (지구과학) |
| 물리 ↔ 정보 | "강한 동맹: 물리(양자파), 수학(응용파)와 협력" (정보) / "응용파는 수학과 정보와 강한 동맹" (물리) |
| 정보 ↔ 지구과학 (고리를 닫는 연결) | 명시된 갈등 없음. 둘 다 세계관상 비교적 평화·중립 성향 |

이 관계를 고리로 펼치면 인접한 모든 쌍이 세계관에 명시된 우호 관계와 일치한다:

```
        지구과학 ── 생명과학
          │                  │
        정보                화학
          └──────물리────────┘
```

**확정 순서**: 지구과학 — 생명과학 — 화학 — 물리 — 정보 — (다시 지구과학)

## 2. 메조리아 기준 진입 방향

메조리아 남쪽 성문이 기존에 스폰 지점과 가장 가까운 주 출입구이므로, **지구과학을 남쪽 진입
대륙**으로 삼는다(테라 노바는 세계관상 "가장 평화로운 대륙"이라 튜토리얼성 첫 대륙으로도 적합).
나머지는 고리 순서대로 시계 방향 배치:

| 방향(개념적) | 대륙 | 비고 |
|---|---|---|
| 남 (메조리아 정문) | 지구과학 (테라 노바) | 육로 진입 첫 대륙 |
| 남서 | 생명과학 (바이오스) | 지구과학과 접경 |
| 서 | 화학 (알케미아 신성연합) | 생명과학과 접경 |
| 북서 | 물리 (뉴토니아 퀀티카) | 화학과 접경 |
| 북동 | 정보 (사이버네시아) | 물리와 접경, 지구과학과도 접경(고리 폐합) |
| 북 (중앙) | — (연합 의회궁 + 바다, 기존 유지) | 육로 대륙 없음 |

> 실제 Unity 월드 좌표·그리드 셀 배정은 §4(씬 구조) 구현 시점에 확정한다. 이 표는 방향 관계만
> 규정하는 토폴로지 문서다.

### 2-1. 기존 메조리아 성벽과의 충돌

`Assets/Editor/MesoriaHubBuilder.cs`의 `BuildCityGates()`(L2248)는 남/동/서 3개 성문만 생성하고
북쪽은 연합 의회궁+바다로 막혀 있다(L2206-2221). 5대륙을 붙이려면 성문이 2곳 더 필요하다:

- 기존 남쪽 성문 → 지구과학 방향 그대로 사용
- 기존 서쪽 성문 → 화학 방향 그대로 사용 (고리상 화학이 서쪽에 위치하므로 위치 일치)
- 기존 동쪽 성문 → 이번 고리에는 해당 방향에 대륙이 없음. **정보 대륙(북동)으로 용도 변경**하거나
  신규 성문 추가 필요 — 구현 세션에서 확정
- 신규: 북서(물리), 남서(생명과학) 2곳 — 성벽 라인(`Wall_N/S/E/W`, L2226-2230)에 개구부 추가

이 조정은 코드 구현 시점 작업이며, 이 문서는 "몇 곳에 어떤 대륙이 붙는가"만 확정한다.

## 3. 아틀란티스 원경 배경

아틀란티스(수학)는 하늘섬이라 이 육로 고리에 포함되지 않지만, 세계관상 "천공대륙"이라는 정체성을
시각적으로 암시하기 위해 **실체 없는 원경 배경 오브젝트**로 하늘에 띄운다.

- **위치**: 물리 ↔ 정보 대륙 방향 사이, 하늘 높은 곳 (두 대륙이 응용수학파와 강한 동맹 관계라는
  세계관 설정과 방향이 일치)
- **구현 방식**: `AtlantisHubBuilder.cs`의 "원경 실루엣 4섬"(구현 완료 기록, [[implementation_status]])과
  동일한 패턴 재사용 — 저디테일 실루엣 메시, 콜라이더 없음, 안개 처리, 그리드 스트리밍 대상 아님
  (배경 스카이박스에 가까운 취급이라 항상 렌더링해도 부담 적음)

## 4. 씬 구조 — 그리드 셀 애디티브 스트리밍

5대륙 + 메조리아를 하나의 이음매 없는 세계로 묶는 기술 구조는 이미 완전히 설계돼 있다:
**[01_대륙-씬-전환-인프라.md](../../설계도/01_대륙-씬-전환-인프라.md)를 그대로 채택**한다(신규
설계 불필요). 핵심 요약:

- 영구 `Bootstrap.unity` 씬(플레이어·카메라·HUD) + 그리드 셀마다 별도 `Cell_X_Y.unity` 씬
- `WorldStreamer`가 플레이어 위치 기준 `loadRadius`는 `LoadSceneAsync(Additive)`,
  `unloadRadius` 밖은 `UnloadSceneAsync` — 셀 경계를 넘어도 로딩 화면 없이 이어짐(선행 로딩)
- 모든 셀이 **같은 월드 좌표계**를 공유하므로 동시에 로드된 셀끼리 지형이 자연히 맞물림
- 국가 내부 = `ZoneTrigger.Safe`(안전지대, 전투 없음), 대륙·국가 사이 = `ZoneTrigger.OpenField`
  (적 스폰) — 이번 대륙별 설계의 "국가 단위" 구획과 정확히 대응

> **주의**: 이 방식은 기존 아틀란티스 포탈(`ScenePortal.Go()` → `SceneManager.LoadScene()`,
> 완전 전환·컷 있음)과는 다른 메커니즘이다. 5대륙 고리는 전부 이음매 없는 애디티브 스트리밍,
> 아틀란티스만 별도 씬 완전 전환 유지.

## 5. 대륙 콘텐츠 설계 원칙

대륙별 상세 문서(`<대륙명>_조감도.md`)를 쓸 때 따르는 공통 규칙:

1. **3단계 구체화**: 대륙 단위(건축 양식 — 단, 아래 예외 참고) → 국가 단위(환경·분위기·생명체
   조성) → 랜드마크 단위(형태 + 몬스터/보스 정보)
2. **건축 양식 적용 단위 — 기준은 정치구조가 아니라 문화적 뿌리 공유 여부** (2026-07-30 정정):
   - **국가들이 하나의 문화적 뿌리를 공유하면 대륙 전체를 하나의 건축 언어로 통일**하고,
     국가마다 그 언어 안에서 세부화(융합 비율·강조점만 다르게). 예: 생명과학 — 3국(헬릭스
     제국·제네시스 왕국·에코스 연맹) 전부 삼국지/무림이라는 공유 문화 뿌리가 있어 "중국풍
     기본 + 서양식 요소" 하나로 통일, 국가별로 서양 융합 비율만 다름([[bios_design]])
   - **서로 무관한 실제 문화가 병존하면 국가(부족) 단위로 건축 양식을 개별 설정**. 예: 지구과학
     — 4부족이 마야·잉카·폴리네시아·그레이트플레인즈로 서로 무관한 문화라 부족별 완전 개별
     ([[terra_nova_design]])
   - **정치 구조(중앙집권 vs 부족연합)는 판단 기준이 아니다** — 생명과학은 3국 다 중앙집권
     국가지만 대륙 통일이고, 지구과학은 부족 연합이라서가 아니라 문화가 무관해서 개별이다.
     (초판에는 "중앙집권=통일/부족=개별"로 잘못 정리했었음 — 오해 방지용으로 남겨둠)
3. **몬스터/보스는 신규 시스템을 만들지 않는다**: 랜드마크의 "몬스터 정보"는
   [17_적리스트-몬스터도감.md](../../설계도/17_적리스트-몬스터도감.md)의 CSV 스키마에 맞춰 나중에
   행으로 채우고, "보스 정보"는 [07_보스전.md](../../설계도/07_보스전.md)의 `BossDef` 자산으로
   구현한다. 이 조감도 문서들은 **인선·컨셉만** 정한다.
4. **보스 인선 기준**: 학문적 유명세보다 **한국 교육과정(특히 최신 개정) 실제 등장 인물**을
   우선한다 — 게임의 교육 목적에 맞춤. 커리큘럼에 부족하면 대학 수준 표준 인물로 보충.
   같은 과학자가 여러 대륙·랜드마크에 중복 등장해도 무방(랜드마크·국가 컨셉에 맞게 스킬·능력치를
   다르게 튜닝 — 07번 설계도의 "같은 과학자, 다른 BossDef" 패턴 그대로).
5. **랜드마크 1곳에 보스 여러 명 가능**: 07번 설계도의 "보스룸 복수 배치 → 택1 클리어" 확장
   경로를 사용. 한 랜드마크 안에서 여러 역사적 과학자를 순서대로 또는 분기로 만날 수 있다.
