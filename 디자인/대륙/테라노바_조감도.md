# 지구과학의 대륙 — 테라 노바 (Terra Nova) 조감도

> **이 문서**: 대륙 전체 구조 + 4국가(부족) + 5랜드마크 상세 조감도. 실제 Unity 좌표·씬 배치는
> [메조리아_대륙배치.md](메조리아_대륙배치.md) §4의 그리드 셀 스트리밍 구현 시점에 확정.
> 몬스터/보스 전투 스탯·패턴은 이 문서 소관 아님 — [17_적리스트-몬스터도감.md](../../설계도/17_적리스트-몬스터도감.md)·
> [07_보스전.md](../../설계도/07_보스전.md) 참고. 이 문서는 **인선·컨셉·형태**만 정한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 컨셉 | 아메리카 원주민 문화(마야·아즈텍·잉카·폴리네시아·그레이트플레인즈) 모티브. 고산·평원·해양·화산·사막·정글이 한 대륙에 공존, 판구조 활동이 활발한 다양성의 대륙. |
| 학문 모티브 | 천문학·해양학·기상학·지질학. 4개 학문 = 4개 부족. |
| 정치 구조 | **부족 연합** (중앙집권 국가 없음) — 건축 양식은 대륙 공통이 아니라 **부족마다 개별 설정** ([[메조리아_대륙배치]] §5 원칙 예외 사례) |
| 사회 구조 | 천문 부족 / 해양 부족 / 대기 부족 / 지질 부족. 외부 침략(유사과학 유목민)에는 공동 방어 |
| 다른 대륙 동맹 | 에코스 연맹(생명과학)과 매우 친밀 |
| 갈등/취약점 | 대규모 전쟁 없음(가장 평화로운 대륙 중 하나). 유사과학 약탈자들의 주기적 침략이 유일한 위협 |
| 메조리아 연결 | 남쪽 성문 — 육로 진입 첫 대륙 ([[메조리아_대륙배치]] §2) |

## 2. 공간 구조 — 방사형 (판게아 유적 중심)

아틀란티스의 "세계수 아크시움 + 5섬 방사형" 패턴을 그대로 재사용한다. 판게아 유적이 "초대륙이
갈라지는 유적"이라는 세계관 컨셉 자체가 4부족이 갈라져 나가는 방사형 지도와 정확히 맞아떨어진다.

```
                [천문 부족]
              고원·산악(안쪽)
                    │
   [지질 부족] ──────┼────── [해양 부족]
   산맥·화산         │        산호초·다도해
   (정보 대륙 접경) │        (생명과학 대륙 접경)
                    ●
              판게아 유적
              (중앙 허브)
                    │
               [대기 부족]
              평원 (★ 입구)
                    │
               메조리아(남)
```

- ★ = 메조리아에서 육로 진입 시 최초 도착 지점 (대기 부족 — 평원이라 이동·전투 난이도가 가장
  완만해 진입 지역으로 적합)
- 판게아 유적이 4부족 사이 중앙 허브 — 아틀란티스 아크시움과 동일한 역할(모든 부족은 유적을
  경유해 서로 연결, 부족→부족 직통 경로 없음)
- 지질 부족 방향이 정보 대륙과, 해양 부족 방향이 생명과학 대륙과 접경(§2-1)

### 2-1. 대륙 경계 접점

| 부족 | 접경 대상 | 연출 |
|---|---|---|
| 해양 부족 | 생명과학(바이오스) | 산호초 → 에코스 연맹의 습지·산호초 생태계로 자연스럽게 이어지는 연속 생태 전환(강한 동맹 관계와 지형이 일치) |
| 지질 부족 | 정보(사이버네시아) | 험준한 산맥·화산 지대가 갑자기 네온빛 디지털 도시로 바뀌는 극적 대비 프론티어 존 |
| 천문 부족 | (대륙 내부, 외부 접경 없음) | 고원·산악 안쪽에 위치, 가장 늦게 탐험하는 심층 지역 |
| 대기 부족 | 메조리아 | 진입 지역 |

## 3. 4부족 + 중앙 허브

### 🌋 판게아 유적 (Pangaea Ruins) — 중앙 허브
- **역할**: 4부족이 모이는 지구과학 대륙의 중심. 초대륙이 갈라지는 순간을 형상화한 유적.
- **형태**: 거대한 원형 대지가 사방으로 균열을 이루며 갈라진 구조. 균열 하나하나가 다리가 되어
  각 부족 방향으로 뻗어나간다(아틀란티스 세계수 가지의 지질학적 등가물).
- **분위기**: 대지가 실제로 미세하게 흔들리는 연출(판구조 활동), 균열 사이로 마그마 빛이 새어나옴
- **보스**: **알프레드 베게너**(대륙이동설) · **아서 홈스**(맨틀대류설) · **해리 헤스**(해저확장설)
  — 한국 지구과학Ⅰ 교육과정의 "판구조론 정립 과정" 표준 3단계 그대로

---

### 🌾 대기 부족 (Atmosphere Clans, 그레이트플레인즈) — ★ 진입 지역
- **학문**: 기상학, 대기과학, 기후학
- **건축**: 티피형 천막 + 목조 토템, 벽 없는 개방형 야영지
- **환경**: 광활한 초원, 시야가 트인 평지. 원경에 회오리구름이 상시 배경으로 회전
- **분위기**: 역동적, 바람 소리와 먼지 파티클
- **생명체**: 토네이도 덩굴(회전하며 바람을 일으키는 식물)
- **랜드마크**: 토네이도 정령의 영혼 평원 — 회전하는 다수의 토네이도 사이를 지나는 회피형 평원
  던전
- **보스**: **해들리**(해들리 순환) · **페렐**(페렐 순환) · **로스비**(로스비파) — 지구과학Ⅰ
  "대기 대순환" 단원의 이름 붙은 순환·파동 3종

---

### 🔭 천문 부족 (Astro Nomads, 마야+아즈텍)
- **학문**: 천문학, 별자리학, 우주기상
- **건축**: 계단식 석조 피라미드, 정교한 부조·달력석
- **환경**: 고원·산악 지대. 밤하늘이 유독 강조됨(밤에 별자리가 실제로 투영되는 연출)
- **분위기**: 신성하고 고요함. [[season_time_system_design]]의 밤 시간대 훅과 연결 가능(밤에 더
  화려해지는 지역)
- **생명체**: 별자리 선인장(밤에 별자리 모양으로 빛나는 식물), 혜성 새(긴 꼬리를 끌며 주기 이동)
- **랜드마크**: 거대 천문대 피라미드 — 계단식 피라미드 + 정상 관측 플랫폼, 밤 별자리 투영
- **보스**: **니콜라우스 코페르니쿠스**(지동설) · **갈릴레오 갈릴레이**(관측천문학) ·
  **요하네스 케플러**(행성운동법칙) — 지구과학Ⅰ "행성의 운동" 단원 표준 서사(뉴턴은 물리
  대륙에 배정돼 있어 이 순서에서 제외, [[메조리아_대륙배치]] §5-4에 따라 중복 배치는 허용되므로
  추후 다른 랜드마크에 다시 등장 가능)

---

### 🌊 해양 부족 (Oceanic Tribes, 폴리네시아/하와이)
- **학문**: 해양학, 해류, 기후 순환, 해양생태
- **건축**: 고상가옥(수상 가옥), 목재+야자잎 지붕, 항해 카누 부두
- **환경**: 산호초·다도해, 열대
- **분위기**: 개방적이고 따뜻함, 파도 소리
- **생명체**: 판구조 해초(서서히 이동하는 거대 해초), 해류 거북(특정 해류를 따라 세계를 도는 거북)
- **랜드마크**: 세계 해류 신전 — 신전 내부로 실제 해류가 흐르는 구조(아틀란티스 뉴턴-라이프니츠
  폭포와 같은 "지형이 곧 현상"인 연출 기법 재사용)
- **보스**: **프리티오프 난센**(북극 탐험 중 에크만 수송 현상 최초 관측) · **반프리드 에크만**
  (에크만 수송 이론 정립) · **헨리 스토멜**(전 지구 심층순환 모델, 대학 표준 보충)

---

### ⛰ 지질 부족 (Geo Clans, 잉카)
- **학문**: 지질학, 판구조론, 광물학, 화산학, 지진학
- **건축**: 이음새 없는 거석 계단식 요새(마추픽추풍)
- **환경**: 험준한 산맥·화산 지대, 화산재 파티클
- **분위기**: 웅장하고 단단함
- **생명체**: 화석 고사리(살아있으면서 화석처럼 단단한 식물), 판구조 코끼리(등에 산맥이 솟아있는
  거대 생물)
- **랜드마크**: 판구조 산맥 신전 — 산맥을 깎아 만든 요새 신전, 용암 균열
- **보스**: **제임스 허턴**(동일과정설, "지질학의 아버지") · **찰스 리히터**(지진 규모) ·
  **주세페 메르칼리**(지진 진도, 한국이 채택한 수정 메르칼리 진도)

## 4. 이동 · 진행

### 유적-부족 연결 그래프

```
대기 부족 ──── 판게아 유적 ──── 해양 부족
                    │
        천문 부족 ───┴─── 지질 부족
```

- 모든 부족은 판게아 유적을 경유해 연결 — 부족 간 직통 경로 없음(아틀란티스 아크시움 패턴과 동일)
- 메조리아 → 대기 부족(평원, 진입) → 판게아 유적(허브) → 나머지 3부족으로 방사

### 진행 흐름

```
[메조리아 남쪽 성문] → 대기 부족 도착
      ↓ (평원 오픈필드 탐험)
  판게아 유적 도달
      ↓ (허브에서 3방향 분기)
  천문 부족 / 해양 부족 / 지질 부족 방문
      ↓
  각 부족 랜드마크 던전 → 역사적 과학자 보스전
```

- 지질 부족 안쪽 경계를 넘으면 정보 대륙, 해양 부족 안쪽 경계를 넘으면 생명과학 대륙으로 이어짐
  (§2-1) — 대륙 간 이동도 로딩 컷 없이 동일한 그리드 스트리밍으로 처리

## 5. 사회 — 4부족 관계

| | 대기 부족 | 천문 부족 | 해양 부족 | 지질 부족 |
|---|---|---|---|---|
| 거점 | 평원(진입) | 고원·산악(안쪽) | 산호초·다도해(생명과학 접경) | 산맥·화산(정보 접경) |
| 성향 | 개방적·역동적 | 신성·관조적 | 온화·개방적 | 웅장·단단함 |
| 대외 관계 | 메조리아와 첫 접촉 | 대륙 내부, 외부 교류 적음 | 생명과학과 생태 연속성 | 정보와 극적 대비(자연 vs 기술) |

**공동 방어**: 4부족은 평시 독립적이나, 유사과학 유목민(몽골식 대규모 침략 이벤트)의 침공 시
판게아 유적에 공동 결집 — 향후 대륙 단위 이벤트 콘텐츠 훅으로 활용 가능.

## 6. 기후 · 연출

| 현상 | 설명 |
|---|---|
| **판구조 진동** | 판게아 유적 및 지질 부족 지역에서 대지가 미세하게 흔들리는 연출 |
| **밤하늘 별자리 투영** | 천문 부족 지역, 밤 시간대에 실제 별자리 모양이 하늘에 투영 ([[season_time_system_design]] 밤 훅 연동 후보) |
| **회전 토네이도** | 대기 부족 지역, 원경에 상시 회전하는 토네이도 실루엣 |
| **해류 가시화** | 해양 부족 신전 내부, 실제 물살이 흐르는 것처럼 보이는 연출 |
| **화산재 낙하** | 지질 부족 지역, 약한 화산재 파티클이 지속적으로 낙하 |
| **전체 극단적 다기후** | 세계관 원문대로 "한 대륙 안에서 지역별 기상이 극단적으로 다름" — [[season_time_system_design]]의 `ClimateProfile`을 부족별로 4종 작성 필요(향후) |

## 7. 랜드마크별 보스 인선 총정리

| 랜드마크 | 부족 | 보스 3인 | 커리큘럼 근거 |
|---|---|---|---|
| 판게아 유적 (허브) | — | 베게너 · 홈스 · 헤스 | 지구과학Ⅰ "판구조론의 정립 과정" |
| 토네이도 정령의 영혼 평원 | 대기 부족 | 해들리 · 페렐 · 로스비 | 지구과학Ⅰ "대기 대순환" |
| 거대 천문대 피라미드 | 천문 부족 | 코페르니쿠스 · 갈릴레이 · 케플러 | 지구과학Ⅰ "행성의 운동"(뉴턴은 물리 대륙) |
| 세계 해류 신전 | 해양 부족 | 난센 · 에크만 · 스토멜 | 지구과학Ⅰ "해류"(스토멜은 대학 표준 보충) |
| 판구조 산맥 신전 | 지질 부족 | 허턴 · 리히터 · 메르칼리 | 지구과학 "지질학 기초" + "지진 규모·진도" |

**총 15명**. 07번 설계도의 "보스룸 복수 배치 → 택1 클리어" 구조로 랜드마크당 3명을 배치한다.
스킬·능력치는 랜드마크·부족 컨셉에 맞춰 개별 튜닝(예: 같은 인물이 다른 대륙에 재등장해도 무방,
[[메조리아_대륙배치]] §5-4).
