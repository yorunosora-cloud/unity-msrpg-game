# 정보의 대륙 — 사이버네시아 (Cybernesia) 조감도

> **이 문서**: 대륙 전체 구조 + 5세력 + 5랜드마크 상세 조감도. 실제 Unity 좌표·씬 배치는
> [메조리아_대륙배치.md](메조리아_대륙배치.md) §4의 그리드 셀 스트리밍 구현 시점에 확정.
> 몬스터/보스 전투 스탯·패턴은 이 문서 소관 아님 — [17_적리스트-몬스터도감.md](../../설계도/17_적리스트-몬스터도감.md)·
> [07_보스전.md](../../설계도/07_보스전.md) 참고. 이 문서는 **인선·컨셉·형태**만 정한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 컨셉 | 사이버펑크 + 디지털 세계 + 현대 컴퓨터 과학. 실제 역사문화 대응물이 없는 유일한 대륙 — 대신 "사이버펑크"라는 하나의 일관된 미학 장르를 공유 문화 뿌리로 삼음 |
| 학문 모티브 | 인공지능·알고리즘·계산이론(튜링), 빅데이터·머신러닝(데이터마이닝), 오픈소스·분산네트워크(오픈소스), 암호학·보안(암호화), 해킹·탈중앙화(해커길드) |
| 정치 구조 | 튜링 중앙집권국의 강력한 중앙 통제 + 오픈소스 연합·해커 길드의 저항. "독립 vs 식민지 잔재" 문제가 핵심 갈등 |
| 건축 양식 | **대륙 전체 통일**: 사이버펑크를 기본 미학 언어로 삼고, 세력마다 다른 하위 장르로 세부화 ([[메조리아_대륙배치]] §5 원칙 — 실제 역사문화는 없지만 사이버펑크 자체가 일관된 문화적 뿌리이므로 화학·생명과학·물리와 같은 "대륙 통일" 사례) |
| 지형/기후 | 데이터가 물질화된 입체적·다층 세계. **표면(네트워크)·중간(코드)·심층(언더넷)** 3층 + 상공(클라우드)으로 구성된 **수직 구조** — 다른 4대륙과 달리 평면이 아니라 아틀란티스처럼 높이(Y축)가 의미를 가짐. 표면=네온빛 도시형 전자기후, 심층=고온·고밀도·어두움, 상공=가볍고 유동적인 클라우드 기후 |
| 다른 대륙 동맹 | 물리(양자파)·수학(응용파)와 협력. 생명과학 제네시스 왕국과 "유전정보학" 공동 프로젝트 |
| 갈등 | 튜링 중앙집권국의 통제 vs 오픈소스 연합·해커 길드의 저항. 물리·수학의 "식민지"였던 과거에 대한 독립 투쟁 |
| 메조리아 연결 | 직접 접경 없음(내륙 대륙) — 물리 양자혁명군을 거쳐 진입, 고리를 닫아 지구과학과도 인접 |

## 2. 공간 구조 — 수직 층위 (5대륙 중 유일한 예외)

지구과학(방사형)·생명과학(삼각접경)·화학(중앙+4방향)·물리(서-동 그라데이션)까지 전부 **평면**
구조였던 것과 달리, 사이버네시아는 세계관 자체가 이미 "표면·중간·심층" 3층 구조를 명시하고
있어 **수직 층위**로 설계한다. 아틀란티스가 유일하게 하늘섬(수직)이었던 것과 대칭적으로,
사이버네시아는 지상 5대륙 고리 중 유일하게 수직 구조를 갖는 대륙이 된다.

```
                 상공 (클라우드층)
              ─ 가볍고 유동적인 데이터 구름 ─
                        │
   ┌────────────────────┴────────────────────┐
   │              표면 (네트워크층)              │
   │   튜링 중앙집권국(메가시티) ── 오픈소스 연합    │
   │              (자유도시 연합)                │
   └────────────────────┬────────────────────┘
                        │
              ┌─────────┴─────────┐
              │   중간 (코드층)     │
              │   암호화 제국(요새) │
              └─────────┬─────────┘
                        │
              ┌─────────┴─────────┐
              │  심층 (언더넷층)    │
              │  해커 길드(다크웹)  │
              └───────────────────┘

   데이터 마이닝 공화국 = 전 층을 관통하는 수직 채굴축
   (표면-중간-심층을 잇는 파이프라인/엘리베이터 구조로 존재)
```

- 표면층에 튜링 중앙집권국(가장 공개적·중앙집권적 메가시티)과 오픈소스 연합(자유도시 연합)이
  나란히 위치 — 둘 다 "공개된 네트워크"라는 층위 성격에 부합
- 중간층(코드)에 암호화 제국 — 완전히 공개되지도, 완전히 숨겨지지도 않은 "보호된 중간" 성격이
  요새형 국가 컨셉과 일치
- 심층(언더넷)에 해커 길드 — 세계관 원문 "대륙 최하층 다크웹 빈민구역" 그대로
- 데이터 마이닝 공화국은 특정 층에 속하지 않고 전 층을 수직으로 관통하는 구조 — "빅데이터가
  모든 층을 가로지른다"는 컨셉을 공간 자체로 표현

### 2-1. 대륙 경계 접점

| 세력 | 접경 대상 | 연출 |
|---|---|---|
| 표면층(튜링/오픈소스) | 물리(뉴토니아 퀀티카) 양자혁명군 | 응용파·양자파와 정보 대륙의 강한 동맹이 지리적으로 표면층 진입로에 반영 |
| (고리 폐합) | 지구과학(테라 노바) | 명시된 갈등 없음, 중립적 연결 — [[메조리아_대륙배치]] §1 고리 폐합 근거 |

## 3. 5세력 상세

### 🏙 튜링 중앙집권국 (Turing Central Authority) — 표면층
- **학문**: 인공지능, 알고리즘, 계산이론, 중앙집권 시스템
- **성격**: 가장 강력한 중앙 통제 세력. 거대한 메가시티를 운영
- **건축**: 매끈한 초고층 기업형 사이버펑크 — 획일적이고 압도적인 스카이라인, 감시 카메라가
  건축 요소처럼 곳곳에 통합됨
- **환경/분위기**: 네온빛 가득한 전자 도시. 질서정연하지만 억압적인 느낌
- **생명체**: 알고리즘 나무(가지가 최적 경로로만 뻗는 나무)

**랜드마크**: **튜링 테스트 탑** — 인공지능과 인간을 구분하는 거대한 테스트 시설. 보스:
**튜링 · 폰노이만 · 섀넌**(튜링 기계·컴퓨터 과학의 아버지 / 현대 컴퓨터 구조의 기초 / 정보이론
의 아버지 — 컴퓨터과학사 표준 계보, "정보"라는 대륙명 자체가 섀넌의 정보이론에서 유래)

---

### ⛏ 데이터 마이닝 공화국 (Data Mining Republic) — 전 층 관통
- **학문**: 빅데이터, 머신러닝, 통계학, 데이터 과학
- **성격**: 방대한 데이터를 채굴하고 분석하는 산업 중심 국가
- **건축**: 산업형 파이프라인·데이터센터 타워가 표면부터 심층까지 수직으로 관통하는 구조
- **환경/분위기**: 끊임없이 데이터가 위아래로 흐르는 채굴 갱도 같은 공간
- **생명체**: (별도 지정 없음 — 세계관 원문에 데이터 마이닝 공화국 전용 동식물 언급 없음,
  필요 시 후속 세션에서 추가)

**랜드마크**: **알고리즘 코어** — 모든 계산과 결정이 이루어지는 중앙 신전. 보스:
**피셔 · 사무엘 · 힌튼**(통계학의 아버지, 실험설계 / "머신러닝"이라는 용어를 만든 인물 /
딥러닝의 대부, 2024 노벨물리학상 — 2022 개정 교육과정에 AI·데이터 단원이 신설된 것과 궤를
같이 함)

---

### 🛠 오픈소스 연합 (Open Source Federation) — 표면층
- **학문**: 오픈소스, 분산 네트워크, 협업 컴퓨팅
- **성격**: 자유와 공유를 중시하는 다수의 자유 도시 연합
- **건축**: DIY·메이커 해커스페이스가 모여 이룬 자유분방한 증축 건축 — 정형화된 계획 없이
  유기적으로 계속 확장되는 구조
- **환경/분위기**: 다채롭고 산만하지만 활기찬 분위기. 누구나 자유롭게 드나들 수 있는 개방감
- **생명체**: 포크 풀(잘라 심으면 복제되는 식물)

**랜드마크**: **포크의 자유 광장** — 누구나 코드를 복제·수정할 수 있는 열린 광장. 보스:
**스톨먼 · 토르발스 · 버너스리**(자유 소프트웨어 운동·GNU 프로젝트 / 리눅스 창시자 / WWW를
무료로 공개한 상징적 결정 — "포크"와 "자유"라는 랜드마크 컨셉과 정확히 일치)

---

### 🔒 암호화 제국 (Empire of Cryptography) — 중간층
- **학문**: 암호학, 보안, 프라이버시, 블록체인
- **성격**: 철저한 보안과 방어를 중시하는 요새형 국가
- **건축**: 폐쇄적인 성벽형 방어 건축. 표면에서도 심층에서도 완전히 보이지 않는 "보호된 중간"
  이라는 층위 성격이 그대로 건축에 반영
- **환경/분위기**: 삼엄하고 정적인 분위기. 곳곳에 암호화된 관문
- **생명체**: 암호화 장미(꽃잎에 암호가 새겨져 해독해야 피는 장미), 블록체인 거북(등껍질에
  거래 기록이 새겨짐)

**랜드마크**: **불가능한 퍼즐 요새** — RSA, ECC 등 최신 암호가 실제 성벽으로 구현된 요새. 보스:
**리베스트 · 샤미르 · 애들먼**(RSA 공개키 암호 — 이름 이니셜 자체가 R-S-A, 정보 교과에서
공개키 암호화의 대표 사례로 명시. 2002년 튜링상 공동 수상)

---

### 💀 해커 길드 & 언더넷 (Hacker Guild / UnderNet) — 심층
- **학문**: 해킹, 크래킹, 탈중앙화, 디지털 자유
- **성격**: 중앙집권국에 반발하는 자유주의·무정부주의 세력. 대륙 최하층 다크웹 빈민구역
- **건축**: 언더그라운드 글리치·판자촌 — 신호가 끊기고 깨진 것처럼 왜곡된 디지털 텍스처
- **환경/분위기**: 깊을수록 위험한 다층 지하 네트워크. 어둡고 불안정함
- **생명체**: 바이러스 버섯, 해커 여우

**랜드마크**: **언더넷 심연** — 깊을수록 위험한 다층 지하 네트워크. 보스:
**사토시 나카모토 · 짐머만 · 슈나이어**(익명의 블록체인·탈중앙화 창시자 / PGP 암호화로 개인
프라이버시를 지킨 인물 / 보안 전문가·저술가 — 케빈 미트닉 등 범죄 이력이 있는 인물은 교육적
이유로 배제)

## 4. 이동 · 진행

### 층위 연결 그래프

```
              [상공 클라우드]
                    │
   [튜링 중앙집권국]─[오픈소스 연합]   (표면)
                    │
              [암호화 제국]            (중간)
                    │
              [해커 길드]              (심층)

   [데이터 마이닝 공화국] = 모든 층을 수직으로 관통
```

### 진행 흐름

```
[물리 양자혁명군] → 표면층(튜링 중앙집권국) 도착
      ↓ (표면 자유 탐험)
  오픈소스 연합 방문
      ↓ (아래로 진입)
  암호화 제국(중간층) — 보안을 뚫고 통과
      ↓ (더 아래로)
  해커 길드(심층·언더넷) — 저항 세력의 실체 대면
      ↓
  데이터 마이닝 공화국은 전 층에서 수직 엘리베이터/파이프라인으로 접근 가능
      ↓
  각 세력 랜드마크 던전 → 역사적 정보학자·과학자 보스전
```

## 5. 사회 — 중앙 통제와 저항

| | 튜링 중앙집권국 | 데이터 마이닝 공화국 | 오픈소스 연합 | 암호화 제국 | 해커 길드 |
|---|---|---|---|---|---|
| 위상 | 지배 세력 | 산업 협력자 | 저항(온건) | 중립·방어 | 저항(급진) |
| 성향 | 통제·질서 | 실용·분석 | 자유·공유 | 보안·폐쇄 | 무정부·자유 |
| 체제에 대한 입장 | 체제 수호 | 체제와 협력 | 체제 저항 | 불간섭 | 체제 타파 |

**핵심 갈등**: "독립 vs 식민지 잔재" — 물리·수학의 "식민지"로 여겨졌던 과거에 대한 독립 투쟁이
대륙 내부 갈등과 겹침(세계관 원문). 플레이어는 중앙집권국과 저항 세력 사이에서 선택 루트를 가질
수 있음(향후 퀘스트 훅).

## 6. 기후 · 연출

| 현상 | 설명 |
|---|---|
| **층별 디지털-물리 기후** | 표면=네온빛 도시형 전자기후, 심층=고온·고밀도·어두운 환경, 상공=가볍고 유동적인 클라우드 기후(세계관 원문) |

| **암호화 관문 이펙트** | 암호화 제국 경계, 통과 시 암호 해독 애니메이션이 실제 게이트 기믹으로 작동 |
