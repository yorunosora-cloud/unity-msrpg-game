# 미니게임 목록 (사용자가 채우는 표)

> 이 문서는 **아이디어를 적는 곳**입니다. "어떻게 시스템이 동작하는지"는
> [`미니게임-시스템.md`](../../../../설계도/미니게임-시스템.md)(오락관 설계도)에 이미 정리돼 있고,
> 여기서는 그 틀에 끼워 넣을 **게임 하나하나의 내용**만 채우면 됩니다.
> 개발(코드 구현)은 나중에 이 표를 보고 진행합니다.

---

## 채우는 방법

한 줄 = 미니게임 하나. 아래 칸을 채워주세요. **★는 꼭 필요**, 나머지는 비워둬도 됩니다
(비워두면 개발할 때 적당히 정하거나 다시 물어볼게요).

| 칸 | 뜻 | 예시 |
|---|---|---|
| 이름★ | 목록·화면에 보이는 게임 이름 | 빛의 속도 계산 |
| 한 줄 설명★ | 목록에서 보이는 소개 문구 | 제한시간 안에 계산 문제를 최대한 많이! |
| 조작 방법 | 시작 전 "어떻게 하는지" 안내 | 화면의 답을 눌러 맞히세요 |
| 분류 | 교육형 / 아케이드 + 과목(수학·과학 등) | 교육형·수학 |
| 제한시간 | 몇 초짜리인지. 스스로 끝나는 게임이면 "없음" | 60초 |
| 점수 기준★ | 점수가 무엇을 세는지. **항상 "높을수록 좋음"**이어야 함 | 맞힌 개수 |
| 보상 아이디어 | 점수 구간별로 뭘 주면 좋을지(대략적인 감으로 OK, 나중에 밸런스 조정) | 20개 이상: 골드 500 / 10개 이상: 골드 200 |
| 비고 | 참고 이미지, 관련 미니게임, 떠오른 메모 등 자유롭게 | |
