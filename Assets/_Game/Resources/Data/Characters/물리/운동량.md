## 시너지 연계 (임펄사→모멘타, 2026-11-17 확정)

설계도 03(`03_시너지-연계-시스템.md`)의 `SynergyComboDef` 스키마를 그대로 사용(변위→속도→가속도
선례와 동일 패턴 — 마크를 거는 쪽과 소모하는 쪽을 분리).

### 연계 — `combo_J_dp` (충격량 · 운동량 변화 도출)
```
SynergyComboDef {
  id: "combo_J_dp"
  comboName: "충격량-운동량 정리 (J=Δp)"
  formula: "J = Δp"
  requiredMarkId: "impulsa_j"        // 임펄사 [2/T] 충격량 정리가 부여(6초, 마일스톤 8초)
  consumerCharId: "momenta_sr"
  triggerSkillId: "momenta_s2"       // 비탄성충돌
  comboSkill: 신규 SkillDef "충격량-운동량 정리" — effectKind Aoe, range 4.0, halfAngle 60,
              damageMultiplier 3.0, mpCost 0, cooldown 0(마크 유무로만 게이팅)
}
```
발동 흐름: 임펄사가 [2/T]로 적에게 `impulsa_j` 마크(6초)를 건다 → 모멘타가 그 적에게 [2/T]
비탄성충돌을 명중시키면 마크가 소모되며 "충격량-운동량 정리"(dmg3.0, 범위형)가 추가로 터진다.
- **사실 기반**: 충격량은 운동량의 변화량과 같다(J=Δp). 비탄성충돌 순간에 충격량이 전달된다.
- **게임적 설정**: 마크를 걸고 소모해 연계기가 터지는 메커니즘, 연계기의 피해량·범위는 게임용
  해석. UI·도감에서 "게임적 설정"임을 표기해야 한다.
- 구현 메모: `SynergyComboDef` 에셋 1개(`combo_J_dp`) + comboSkill SkillDef 1개("충격량-운동량
  정리") 신규 생성 필요 — 설계도 03의 구현 순서(§5)를 따라 구현 세션에서 작성
