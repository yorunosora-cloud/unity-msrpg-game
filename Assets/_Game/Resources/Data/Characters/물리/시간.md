## 확정된 스키마 확장 (이전 결정)
`SkillDef`에 범용 패시브 트리거 필드 2개를 추가하기로 확정:
```csharp
public enum PassiveTriggerType { None, TargetMoving, PartyPresence, OnHit, HpBelowPercent, SelfDebuffed }
public PassiveTriggerType passiveTrigger;
public float passiveValue;   // 트리거 시 적용되는 수치(문맥에 따라 배율 또는 비율)
```
`TargetMoving`/`PartyPresence`는 위 두 스킬에 확정 사용. 나머지 값(`OnHit`/`HpBelowPercent`/`SelfDebuffed`)은 다른 캐릭터 패시브(예: 스페이시아의 "고유 공간", 질량/관성의 "정지 관성" 등)를 채울 때 재사용할 것을 대비해 미리 열어둔 것 — 실제 적용 로직(이동 판정, 파티 조회 등)은 구현 세션에서 작성.
