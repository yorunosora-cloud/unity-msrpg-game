## 폼 전환 — 역학적 에너지 (속도 교차 + 점프 덮어쓰기)

두 폼은 **자동 전환**된다. 이동 속도(운동에너지)와 점프 높이(위치에너지)를 같은 역학적 에너지
관점에서 판정한다.

- **속도 교차 (기본 규칙, 히스테리시스)**
  - 현재 이동 속도가 최대 이동속도(spd)의 **70% 이상**이면 → 운동에너지 폼
  - 현재 이동 속도가 최대 이동속도(spd)의 **40% 미만**이면 → 위치에너지 폼
  - 40~70% 구간에서는 현재 폼 유지(임계값 근처 깜빡임 방지)
- **점프 덮어쓰기** (`PlayerController`의 `JumpPhase`, `_velocityY` 사용)
  - 점프 상승 정점 근처(수직 속도 |vY| < 1.5)는 **위치에너지 폼**으로 강제
  - 하강 시작(vY < -1.5)은 **운동에너지 폼**으로 강제
- **전환 직후 2초 차지 버프**: [1/R] 역학적 에너지 보존 참고
- 기준치(70%/40%/1.5)는 조정 가능한 잠정값
- 구현 메모: 이동 속도 비율 감지·점프 단계 감지·히스테리시스·폼 전환 쿨은 `SkillDef` 밖 —
  구현 세션에서 신규 상태머신 필요(마시오&이네르셔의 정지/이동 2초 감지와 같은 계열)
