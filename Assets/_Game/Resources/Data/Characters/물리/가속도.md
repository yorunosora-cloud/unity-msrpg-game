## 시너지 연계 (변위→속도→가속도, 2026-09-16 확정)

설계도 03(`03_시너지-연계-시스템.md`)의 `SynergyComboDef` 스키마를 그대로 사용 — 이미 그 문서
예시에 `requiredMarkId="mass"`/`consumerCharId="accel"`인 F=ma 연계가 있었고, 우리 액셀의 id가
정확히 `axel_sr`이라 향후 질량 마크 캐릭터가 생기면 [1/R] 뉴턴 제2법칙을 그 연계의 트리거로
비워둠(아래 두 연계는 [2/T] 등가속운동을 씀 — 트리거 스킬이 겹치지 않게 분리).

x→v→a 미분 체인을 2단계 릴레이로 구현: 벡토르가 마크를 걸면 벨로시아가 소모하며 자기 마크를
새로 걸고, 액셀이 그 마크를 다시 소모하는 구조.

### 연계 1 — `combo_vx_v` (변위 · 속도 도출)
```
SynergyComboDef {
  id: "combo_vx_v"
  comboName: "속도 도출 (v=Δx/Δt)"
  formula: "v = Δx/Δt"
  requiredMarkId: "vektor_disp"     // 벡토르 [2/T] 변위벡터합성이 부여
  consumerCharId: "velocia_sr"
  triggerSkillId: "velocia_s1"      // 순간속도
  comboSkill: 신규 SkillDef "속도 도출" — effectKind Aoe, range 4.0, halfAngle 60,
              damageMultiplier 2.5, mpCost 0, cooldown 0(마크 유무로만 게이팅)
}
```
발동 흐름: 벡토르가 [2]로 적에게 `vektor_disp` 마크(8초 유지)를 건다 → 벨로시아가 그 적에게
[1]순간속도를 명중시키면 마크가 소모되며 "속도 도출"(dmg2.5, 범위형)이 추가로 터진다.

### 연계 2 — `combo_v_a` (속도 · 가속도 도출)
```
SynergyComboDef {
  id: "combo_v_a"
  comboName: "가속도 도출 (a=Δv/Δt)"
  formula: "a = Δv/Δt"
  requiredMarkId: "velocia_v"        // 벨로시아 [1/R] 순간속도가 부여
  consumerCharId: "axel_sr"
  triggerSkillId: "axel_s2"          // 등가속운동
  comboSkill: 신규 SkillDef "가속도 도출" — effectKind Aoe, range 4.0, halfAngle 60,
              damageMultiplier 3.0, mpCost 0, cooldown 0(마크 유무로만 게이팅)
}
```
발동 흐름: 벨로시아가 [1]로 적을 때리면(변위 마크 소모 여부와 무관하게 항상) `velocia_v`
마크(8초 유지)를 새로 건다 → 액셀이 그 적에게 [2]등가속운동을 명중시키면 마크가 소모되며
"가속도 도출"(dmg3.0, 범위형)이 추가로 터진다.

**전체 흐름 요약**: 벡토르(변위 마크) → 벨로시아(마크 소비+새 마크 부여, 동시에 가능) →
액셀(마크 소비) — 세 캐릭터를 순서대로 기용하면 미분 체인 x→v→a를 그대로 콤보로 체감하는 구조.
