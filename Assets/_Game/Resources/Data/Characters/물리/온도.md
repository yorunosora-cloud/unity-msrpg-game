## 폼 전환 — 열평형

`AttributeProfile.temp`(설계도 18, 적 속성)를 활용한 신규 메커니즘. 마시오&이네르셔의
"정지/이동 지속시간" 자동전환과 달리, **상대방의 온도**를 기준으로 열이 흐르는 방향대로
전환된다(열평형 원리를 그대로 게임화).

- **temp ≥ 50인 적을 3회 연속 타격 → 고온 폼으로 전환** (뜨거운 대상에게서 열을 흡수)
- **temp < 50인 적을 3회 연속 타격 → 저온 폼으로 전환** (차가운 대상에게 열을 빼앗김)
- 기준치는 조정 가능(50은 현재 temp 속성 스케일을 0~100대로 가정한 잠정값)
- 구현 메모: "연속 타격 카운트 + 상대 temp 판정" 로직은 `SkillDef` 밖 — 구현 세션에서 신규
  상태머신 필요. 기존 스탯 기반 strengthTags 시스템(`TagRule.Evaluate`)과는 별개의 판정 경로
