## 폼 전환

루미에르(수동 전용 FormChange 액티브 스킬)와 달리, 이 캐릭터는 **자동 전환**을 채택. 뉴턴
제1법칙(관성의 법칙 — "정지한 물체는 계속 정지하려 하고, 운동하는 물체는 계속 운동하려 한다")을
그대로 게임 메커닉으로 옮긴 것:

- **정지 상태를 2초 이상 유지 → 마시오(질량) 폼으로 자동 전환**
- **이동 상태를 2초 이상 유지 → 이네르셔(관성) 폼으로 자동 전환**
- 기본 액티브(슬롯 0, Q키)는 폼과 무관하게 항상 같은 키로 발동 — 현재 폼에 따라 대검 베기/대도
  강타 중 하나가 자동으로 나감(formReq 분기)
- 구현 메모: 별도의 FormChange 스킬 슬롯 없이, 캐릭터의 이동 상태 지속시간을 감지하는 신규
  상태머신 로직 필요(스킬 시스템 밖의 캐릭터 컨트롤러 레벨 구현) — 구현 세션에서 확정

### HP 캐리오버 메커니즘 (신규 — "몸은 하나" 구현)

마시오와 이네르셔는 role이 달라(Tanker/Dealer) maxHP도 독립적으로 다름(2975 / 1700). 억지로
hp를 통일하는 대신, **폼 전환 시 현재 체력의 "비율(%)"이 유지**되도록 해서 "몸은 하나"라는 설정을
살림.

- 계산식: `새 폼 현재HP = 새 폼 maxHP × (전환 직전 현재HP / 전환 직전 maxHP)`
- 예시: 마시오 상태에서 체력이 40/2975(약 1.3%)라면, 이네르셔로 전환 시 1700×0.013 ≈ 23으로 재설정
- 구현 메모: 기존 스탯/버프 시스템에 없는 신규 로직 — 폼 전환 이벤트 훅에서 hp 퍼센트를 읽어
  재계산하는 코드 필요(구현 세션에서 확정)

## 수치·이름 확정 완료 (2026-09-03)
스탯(폼별 5종×2) + 스킬 6개(폼별 3×2)의 모든 수치를 확정. 캐릭터명 "질량"→**마시오 & 이네르셔

스킬 이름은 전부 유지(대검 베기·대도 강타=무기명, 정지 관성·운동 관성·질량 보존·관성력=실제

**hp를 폼 공통으로 맞추지 않고 각 폼 고유 공식값을 쓰는 대신 폼 전환 시 현재체력 %를 유지하는
런타임 캐리오버**로 "몸은 하나" 컨셉을 구현. 폼 전환은 루미에르의 수동 액티브 대신 **정지/이동
2초 지속 감지 기반 자동 전환**(뉴턴 제1법칙 컨셉)으로 확정. 양 폼 모두 원문 그대로 3스킬씩 대칭
구성이라 루미에르 같은 빈 슬롯 신규 창작은 불필요. "관성력"의 운동량 비례 효과는 새 공식 대신
