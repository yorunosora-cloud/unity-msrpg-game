# 화학 원소 캐릭터 — 족(계열) 체계

> 원소 92종(수소~우라늄)을 개별이 아니라 **족(계열) 단위로 묶어 설계**하는 틀이다. 2026-11-21 대화로
> 확정. 원문(`캐릭터 정리.txt`)에서 화학 소제목은 "화학(연금술사)"이고, 원소는 "수소, 탄소, 산소, 금,
> 수은 일단 만들기"로 지시되어 있어 이 5원소를 가장 먼저 정밀 설계한다.

## 1. 확정 규칙

| 항목 | 결정 |
|---|---|
| 체계 | **족 중심 계열 설계**. 주기(원자번호)는 등급과 공통 스킬 수치에만 반영 |
| 연금술사 컨셉 | 공통 테마. 모두 연금술사이되 **직업·외형·성격은 원소마다 고유**(계열 공통 모티브 아래 개성) |
| 국가(소속) | 학문 분야로 배정 — 계열마다 아래 표의 국가(원소 개별로 예외는 계열 작업 시 결정 가능) |
| 등급(rarity) | **교육과정 등장 학년 기준**(학습 학년 원칙). 아래 §3 |

| 게임적 설정 표기 | 과학 사실이 아닌 게임용 해석은 스킬마다 **"게임적 설정"** 으로 구분 표기(사용자 요청) |
| 스킬 슬롯 배치(초안) | `[0/Q]` 계열 공통① (기본기, mp0) / `[1/R]` 원소 고유① / `[2/T]` 계열 공통② / `[3/F]` 원소 고유②. **확정은 첫 계열 작업 시** |

## 3. 등급(rarity) 기준표 (초안)

등급 = 그 원소를 한국 교육과정에서 **몇 학년에 배우는가**(학습 학년 원칙). 원소별 최종 등급은
계열 작업 시 확정한다.

| 등급 | 기준 | 예시 경향 |
|---|---|---|
| N | 초등~중1에서 일상 물질로 접하는 원소 | 수소·산소·탄소·철·구리·금 등 |
| R | 중2~3 주기율표·원소 기호 단원의 주요 원소(1~20번 중심) | 나트륨·칼슘·염소 등 |
| SR | 고1~2 화학(주기율 경향·이온·전이금속 일부) | 알칼리·할로젠 계열 전반 등 |
| SSR | 고3 화학Ⅱ 심화(전이금속·착이온 등) | 전이금속 상당수 |
| UR | 대학 수준(희토류·악티늄족·방사성 원소) | 희토류·악티늄족 |

## 4. 작업 순서

1. **5원소 정밀 설계**: 수소 → 탄소(14족) → 산소(16족) → 금(11족) → 수은(12족)
2. **계열별 진행**: 계열마다 ① 모티브·공통 스킬 2개 확정 ② 원소별 직업·외형·성격·등급·고유 스킬 2개 확정
   ③ 파일 반영(캐릭터 1명 = 파일 1개, 계열 단위로 커밋)
3. 비원소 개념 캐릭터 19종(원자·분자·오비탈 등)은 원소 체계가 끝난 뒤 별도 진행

## 5. 처리 규칙

- 캐릭터 1명이 끝나기 전에는 파일을 건드리지 않고, **다 정한 뒤 한 번에 문서화**한다.
- 공통 스킬은 계열 문서(이 폴더의 계열 정의)에 한 번 정의하고, 각 원소 파일에는 수치(주기별 값)만 둔다.
