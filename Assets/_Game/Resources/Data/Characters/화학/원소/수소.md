## 폼 전환 — 중성자 포획 (수동 순차)

**[0/Z] 중성자 포획** 스킬로 경수소 → 중수소 → 삼중수소 순서로 한 단계씩 전환한다(역방향 수동 전환 없음).
- 경수소에서 쓰면 **중수소**, 중수소에서 쓰면 **삼중수소**가 된다. 삼중수소에서는 사용 불가.
- 중수소는 시간 제한 없이 유지된다.
- **삼중수소는 진입 후 12.3초가 지나면 자동으로 경수소로 복귀**한다(방사성 붕괴 컨셉).
- 현재 HP%는 폼 전환 시 그대로 유지된다(hp 공통이라 수치 동일).
- **사실 기반**: 수소의 동위원소는 중성자 수가 0·1·2개로 다르며(경수소·중수소·삼중수소), 삼중수소는 방사성이고
  반감기가 약 12.3년이다.
- **게임적 설정**: 중성자를 포획해 순차 전환하는 방식, 삼중수소의 반감기를 12.3초로 환산한 것, 복귀 대상이
  경수소인 것은 게임용 해석이다.
