## 폼 전환 — 해리·결합 (O₂ 허브)

**산소 분자(O₂)가 기본 폼이자 허브**이다.
- **[0/Z] 해리**: O₂에서 사용하면 **원자 산소(O)** 가 된다. 원자 산소는 **8초 후 자동으로 O₂로 복귀**한다.
- **[0/X] 결합**: O₂에서 사용하면 **오존(O₃)** 이 된다. 오존은 **10초 후 자동으로 O₂로 복귀**한다.
- 원자 산소·오존 상태에서 Z 또는 X를 다시 누르면 **즉시 O₂로 복귀**한다(복귀 시 mp 소모 없음, 쿨타임만 적용).
- 원자 산소에서 오존으로(또는 반대로) 곧바로 갈 수는 없고, 반드시 O₂를 거친다.
- 현재 HP%는 폼 전환 시 그대로 유지된다(hp 공통이라 수치 동일).
- **사실 기반**: 자외선이 산소 분자(O₂)를 두 개의 원자 산소(O)로 해리하고, 원자 산소가 O₂와 결합하면 오존(O₃)이 된다
  (방전으로도 오존이 생성된다). 원자 산소와 오존은 불안정해 스스로 O₂로 돌아간다.
- **게임적 설정**: 해리·결합을 수동 스킬로 환산한 방식, 두 전환 키(Z·X) 사용, 8초·10초 자동 복귀 시간, mp·쿨타임.
